  <Expandable title="params 객체 속성">
    <ParamField body="image_url" type="string" required>
      분해할 원본 이미지 URL

      * 필수이며, **1장**의 이미지만 전달할 수 있습니다
      * 다음 두 가지 형식을 지원합니다:
        1. 공개적으로 접근 가능한 URL
        2. Base64 인코딩 형식
           * 반드시 완전한 Data URI 형식을 사용해야 합니다: `data:image/{형식};base64,{base64데이터}`
           * 지원되는 이미지 형식: jpeg, png, webp
           * 예: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 주의: 반드시 `data:image/jpeg;base64,` 접두사 부분을 포함해야 하며, base64 이미지 크기는 10MB를 초과할 수 없습니다
      * 이미지의 최소 크기는 ≥ 300px이어야 합니다

### 조회 응답 - 레이어 출력 구조

작업이 완료되면, `output`은 레이어 객체 배열이며, 각 레이어에는 `url`과 `metadata`가 포함됩니다:

<ResponseField name="output" type="array">
  레이어 목록, 각 요소는 하나의 레이어 객체

  <Expandable title="레이어 객체 속성">
    <ResponseField name="url" type="string">
      해당 레이어의 투명 PNG 이미지 URL
    </ResponseField>

    <ResponseField name="metadata" type="object">
      레이어 메타데이터

      <Expandable title="metadata 속성">
        <ResponseField name="kind" type="string">
          고정값 `"layer"`, 이것이 레이어 출력임을 식별합니다
        </ResponseField>

        <ResponseField name="z_index" type="number">
          레이어 계층 인덱스

          * `z_index = 0`: 하위 레이어(재구성된 전체 배경 이미지), `bounding_box`는 `null`
          * `z_index ≥ 1`: 전경 레이어, 뒤에서 앞으로의 순서로 정렬됨
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          원본 이미지에서의 레이어 위치 영역

          하위 레이어(z_index=0)는 `null`이며, 나머지 레이어는 좌표 객체를 반환합니다:

          <Expandable title="bounding_box 속성">
            <ResponseField name="absolute" type="array">
              원본 이미지 해상도를 기준으로 한 절대 픽셀 좌표 `[x1, y1, x2, y2]`
            </ResponseField>

            <ResponseField name="normalized" type="array">
              정규화된 좌표 `[x1, y1, x2, y2]`, 범위는 0–1000
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          레이어 이름(예: `"Sky background"`, `"Moss platform"`)
        </ResponseField>

        <ResponseField name="description" type="string | null">
          레이어 설명(예: `"Soft light blue sky with scattered fluffy white clouds"`)
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>
