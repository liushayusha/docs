## Authorizations

<ParamField header="Authorization" type="string" required>
  모든 인터페이스는 인증에 Bearer Token을 사용해야 합니다.

  API Key 가져오기:

  <a href={apiKeyUrl} target="_blank">API Key 관리 페이지</a>에 접속하여 API Key를 받으세요.

  사용할 때는 요청 헤더에 다음을 추가합니다:

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  모델 이름.

  고정값: `"mj_v8_1_retexture"`
</ParamField>

<ParamField body="params" type="object" required>
  모델 매개변수 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="image_url" type="string[]" required>
      원본 이미지 배열. 재생성을 위한 기준으로 1장의 이미지를 반드시 전달해야 합니다.

      * 최대 1장 이미지
      * 단일 이미지 최대 10MB
      * jpeg, png, webp 지원
      * 다음 두 가지 형식 지원:
        1. 공개적으로 접근 가능한 URL
        2. 완전한 Base64 Data URI, 예: `data:image/jpeg;base64,/9j/4AAQ...`

      <Warning>
        URL은 공용 네트워크에서 직접 접근 가능해야 하며, 로그인, Cookie 또는 임시 페이지 권한 부여가 필요해서는 안 됩니다.
      </Warning>
    </ParamField>

    <ParamField body="prompt" type="string" required>
      재생성 지시문. 대상 스타일 또는 텍스처 변환을 설명합니다. 원본 Midjourney 문법(--ar, --s, --no 등)을 지원합니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출 측에서 정의한 작업 ID로, 멱등성 제출과 결과 조회에 사용됩니다.

  * 길이 1-64자
  * 문자, 숫자, 밑줄, 하이픈만 허용
  * 동일한 API Key에서 중복 사용 불가
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  호출자 작업 ID로, 결과를 조회하는 데 사용할 수 있습니다.
</ResponseField>

<ResponseField name="status" type="string">
  초기 상태로, `"pending"`으로 고정됩니다.
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  예상 소모 크레딧.
</ResponseField>

<ResponseField name="created_at" type="string">
  생성 시간, ISO 8601 형식.
</ResponseField>

## 조회 결과

제출이 성공한 후, 동일한 `out_task_id`를 사용하여 호출합니다:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "mj_v8_1_retexture_task_001"
  }'
```

작업 상태에는 `pending`, `processing`, `completed`, `failed`가 포함됩니다. 작업이 완료되면 결과 이미지는 `data.output`에 있으며, 실제 사용된 크레딧은 `data.credits_used`에 있습니다.

  ```java Java
  import java.net.URI;
  import java.net.http.HttpClient;
  import java.net.http.HttpRequest;
  import java.net.http.HttpResponse;

  public class Main {
      public static void main(String[] args) throws Exception {
          String payload = """
          {
            "model": "mj_v8_1_retexture",
            "params": {
              "prompt": "transform into an oil painting with bold brush strokes",
              "image_url": ["https://example.com/original.png"]
            },
            "out_task_id": "mj_v8_1_retexture_java_001"
          }
          """;

          HttpRequest request = HttpRequest.newBuilder()
              .uri(URI.create("https://aireiter.com/api/openapi/submit"))
              .header("Authorization", "Bearer <token>")
              .header("Content-Type", "application/json")
              .POST(HttpRequest.BodyPublishers.ofString(payload))
              .build();

          HttpResponse<String> response = HttpClient.newHttpClient().send(
              request,
              HttpResponse.BodyHandlers.ofString()
          );
          System.out.println(response.body());
      }
  }
  ```
