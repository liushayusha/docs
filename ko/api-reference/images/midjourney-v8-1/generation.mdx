## Body

<ParamField body="model" type="string" required>
  모델 이름.

  고정 값: `"mj_v8_1"`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      이미지 생성 지시문. 원본 Midjourney 문법을 지원하며, 프롬프트에서 다음 파라미터를 직접 사용할 수 있습니다:

      * `--ar` - 가로세로 비율(예: `--ar 16:9`)
      * `--s` - 스타일화 정도 0-1000
      * `--chaos` - 변동 정도 0-100
      * `--seed` - 재현을 위한 난수 시드
      * `--sref` - 스타일 참조 이미지 URL
      * `--oref` - 이미지 참조 URL
      * `--iw` - 이미지 가중치
      * `--no` - 부정 프롬프트
    </ParamField>

    <ParamField body="speed" type="string" default="fast">
      속도 단계.

      다음 값을 지원합니다:

      * `draft` - 저비용 빠른 반복
      * `fast` - 표준 생성(기본값)

      <Warning>
        Draft 속도는 Standard 화질만 지원하며, HD 화질은 지원하지 않습니다.
      </Warning>
    </ParamField>

    <ParamField body="quality" type="string" default="standard">
      화질 단계.

      다음 값을 지원합니다:

      * `standard` - 표준 화질(기본값)
      * `hd` - 고화질, Fast 속도에서만 지원

      <Warning>
        HD 화질은 Fast 속도에서만 사용할 수 있으며, Draft 속도는 HD를 지원하지 않습니다.
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string[]">
      참조 이미지 배열. 전달하면 자동으로 이미지-투-이미지 모드를 사용하며, 전달하지 않으면 텍스트-투-이미지 모드를 사용합니다.

      * 최대 1장의 참조 이미지
      * 단일 이미지 최대 10MB
      * jpeg, png, webp 지원
      * 다음 두 가지 형식을 지원합니다:
        1. 공개적으로 접근 가능한 URL
        2. 완전한 Base64 Data URI, 예: `data:image/jpeg;base64,/9j/4AAQ...`

      <Warning>
        URL은 공용 네트워크에서 직접 접근할 수 있어야 하며, 로그인, Cookie 또는 임시 페이지 권한 부여가 필요하면 안 됩니다.
      </Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출 측에서 정의한 작업 ID로, 멱등성 제출과 결과 조회에 사용됩니다.

  * 길이는 1-64자
  * 문자, 숫자, 밑줄, 하이픈만 허용됩니다
  * 동일한 API Key에서는 중복 사용할 수 없습니다
</ParamField>

<ResponseField name="out_task_id" type="string">

## Query Results

After successful submission, call using the same `out_task_id`:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "mj_v8_1_task_001"
  }'
```

Task statuses include `pending`, `processing`, `completed`, and `failed`. After the task is completed, the result images are located in `data.output`, and the actual credits used are located in `data.credits_used`.
