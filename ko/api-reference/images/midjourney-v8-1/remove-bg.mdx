## Authorizations

<ParamField header="Authorization" type="string" required>
  모든 엔드포인트는 인증에 Bearer Token을 사용해야 합니다.

  API Key 가져오기:

  <a href={apiKeyUrl} target="_blank">API Key 관리 페이지</a>에 접속하여 API Key를 가져오세요.

  사용할 때 요청 Header에 다음을 추가합니다:

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  모델 이름입니다.

  고정값: `"mj_v8_1_remove_bg"`
</ParamField>

<ParamField body="params" type="object" required>
  모델 매개변수 객체입니다.

  <Expandable title="params 객체 속성">
    <ParamField body="image_url" type="string[]" required>
      처리할 이미지 배열입니다. 반드시 1장의 이미지를 전달해야 합니다.

      * 최대 1장
      * 단일 이미지 최대 10MB
      * jpeg, png, webp 지원
      * 다음 두 가지 형식을 지원합니다:
        1. 공개적으로 접근 가능한 URL
        2. 완전한 Base64 Data URI, 예: `data:image/jpeg;base64,/9j/4AAQ...`

      <Warning>
        URL은 공용 네트워크에서 직접 접근할 수 있어야 하며, 로그인, Cookie 또는 임시 페이지 권한이 필요해서는 안 됩니다.
      </Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출자가 정의한 Task ID로, 멱등 제출과 결과 조회에 사용됩니다.

  * 길이: 1-64자
  * 문자, 숫자, 밑줄 및 하이픈만 허용됩니다.
  * 동일한 API Key 내에서는 중복 사용할 수 없습니다.
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  호출자의 작업 ID로, 결과를 조회하는 데 사용할 수 있습니다.
</ResponseField>

<ResponseField name="status" type="string">
  초기 상태이며, 고정값은 `"pending"`입니다.
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  예상 소모 포인트.
</ResponseField>

<ResponseField name="created_at" type="string">
  생성 시간, ISO 8601 형식.
</ResponseField>

## 조회 결과

제출이 성공한 후, 동일한 `out_task_id`를 사용하여 호출합니다:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "mj_v8_1_removebg_task_001"
  }'
```

작업 상태에는 `pending`, `processing`, `completed`, `failed`가 포함됩니다. 작업이 완료되면 결과 이미지는 `data.output`에 있고, 실제 사용된 크레딧은 `data.credits_used`에 있습니다.

  int main(void) {
      CURL *curl;

      curl_global_init(CURL_GLOBAL_DEFAULT);
      curl = curl_easy_init();

      if(curl) {
          const char *url = "https://aireiter.com/api/openapi/submit";
          const char *payload = "{\"model\":\"mj_v8_1_remove_bg\",\"params\":{\"image_url\":[\"https://example.com/product-photo.png\"]},\"out_task_id\":\"mj_v8_1_removebg_task_001\"}";

          headers = curl_slist_append(headers, "Content-Type: application/json");

          curl_easy_setopt(curl, CURLOPT_URL, url);
          curl_easy_setopt(curl, CURLOPT_POSTFIELDS, payload);
          curl_easy_setopt(curl, CURLOPT_HTTPHEADER, headers);

          res = curl_easy_perform(curl);

              fprintf(stderr, "curl_easy_perform() failed: %s\n",
                      curl_easy_strerror(res));
          }

          curl_slist_free_all(headers);
          curl_easy_cleanup(curl);
      }

      curl_global_cleanup();
      return 0;
  }

                      return;
                  }
                  NSString *result = [[NSString alloc] initWithData:data
                                                          encoding:NSUTF8StringEncoding];
                  NSLog(@"%@", result);
              }];

          [task resume];
          [[NSRunLoop mainRunLoop] run];
      }
      return 0;
  }
