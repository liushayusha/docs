## Body

<ParamField body="model" type="string" required>
  모델 이름

<ParamField body="params" type="object" required>
  모델 파라미터 객체

  <Expandable title="params 객체 속성">
    <ParamField body="image_url" type="string" required>
      업스케일할 원본 이미지 URL

      * 필수 항목이며, 이미지는 **1장만** 전달할 수 있습니다
      * 다음 두 가지 형식을 지원합니다:
        1. 공개적으로 액세스 가능한 URL
        2. Base64 인코딩 형식
           * 완전한 Data URI 형식을 사용해야 합니다: `data:image/{형식};base64,{base64데이터}`
           * 지원하는 이미지 형식: jpeg, png, webp
           * 예시: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 주의: 반드시 `data:image/jpeg;base64,` 접두사 부분을 포함해야 하며, Base64 이미지 크기는 10MB를 초과할 수 없습니다
    </ParamField>

    <ParamField body="upscale_mode" type="string" default="target">
      확대 모드

      * `target` - 목표 픽셀에 따라 고정된 메가픽셀(MP) 크기로 확대(기본값), `target` 파라미터와 함께 사용
      * `factor` - 배율에 따라 확대, 각 변에 `factor`를 곱함, `factor` 파라미터와 함께 사용
    </ParamField>

    <ParamField body="target" type="integer" default="4">
      목표 해상도(단위: MP, 메가픽셀)

      * 유효 범위: `1` ~ `128`
      * `upscale_mode`가 `target`일 때만 유효
    </ParamField>

    <ParamField body="factor" type="number" default="2">
      확대 배율

      * 유효 범위: `1` ~ `8`
      * `upscale_mode`가 `factor`일 때만 유효
      * 출력 이미지는 최대 128MP를 초과할 수 없으며, 초과 시 자동으로 상한이 적용됩니다
    </ParamField>

    <ParamField body="enhance_details" type="boolean" default="false">
      디테일 강화

      미세한 질감과 작은 디테일을 강화하며, 대비가 증가하여 원본 이미지와 약간의 차이가 발생할 수 있습니다.
    </ParamField>

    <ParamField body="enhance_realism" type="boolean" default="false">
      사실감 강화

      화면의 사실감을 높이지만, 원본 이미지와의 차이가 더 커질 수 있습니다. AI 생성 이미지에 사용하는 것을 권장합니다.
    </ParamField>

    <ParamField body="output_format" type="string" default="jpg">
      출력 이미지 형식

      * `jpg` - JPEG 형식(기본값)
      * `png` - PNG 형식
      * `webp` - WebP 형식
    </ParamField>

    <ParamField body="output_quality" type="integer" default="80">
      출력 이미지 품질

      * 유효 범위: `0` ~ `100`, 100이 최고 품질, 0이 최저 품질
      * `output_format`이 `png`일 경우 이 파라미터는 적용되지 않습니다
    </ParamField>
  </Expandable>
</ParamField>
