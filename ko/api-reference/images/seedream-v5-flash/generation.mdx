## Body

<ParamField body="model" type="string" required>

<ParamField body="params" type="object" required>
  모델 파라미터 객체

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      이미지 생성을 위한 텍스트 설명입니다. 참조 이미지를 전달할 경우, 참조 이미지에 적용할 수정 사항이나 병합 방식을 설명합니다.

      * 참조 이미지에 박스 선택, 화살표, 좌표 등의 마킹으로 수정 위치를 지정하고 프롬프트에 설명하는 방식을 지원합니다.
      * 다국어 텍스트 렌더링을 지원합니다.
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      참조 이미지로, 이미지 투 이미지(편집, 병합, 스타일 변환)에 사용됩니다.

      * 미전달 시: 텍스트 투 이미지
      * 1~10장 전달 시: 이미지 투 이미지, 여러 장일 경우 배열 형태로 전달
      * 지원하는 이미지 형식: jpeg, png, webp, 장당 30MB 이하
      * 다음 두 가지 형식을 지원합니다:
        1. 공개적으로 접근 가능한 URL
        2. Base64 인코딩 형식
           * 반드시 완전한 Data URI 형식을 사용해야 합니다: `data:image/{형식};base64,{base64 데이터}`
           * 예시: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 주의: 반드시 `data:image/jpeg;base64,` 접두사 부분을 포함해야 하며, Base64 이미지 크기는 10MB를 초과할 수 없습니다.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      출력 이미지의 가로세로 비율

      * `1:1` - 정사각형(기본값)
      * `4:3` - 가로 4:3
      * `3:4` - 세로 3:4
      * `16:9` - 가로 와이드스크린
      * `9:16` - 세로 화면
      * `3:2` - 가로 3:2
      * `2:3` - 세로 2:3
      * `21:9` - 울트라 와이드스크린
    </ParamField>

    <ParamField body="resolution" type="string" default="2K">
      출력 해상도 옵션

      * `1K` - 1K 해상도
      * `1.5K` - 1.5K 해상도
      * `2K` - 2K 해상도(기본값)
    </ParamField>

    <ParamField body="output_format" type="string" default="jpeg">
      출력 이미지 형식

      * `jpeg` - JPEG(기본값)
      * `png` - PNG
    </ParamField>
  </Expandable>
