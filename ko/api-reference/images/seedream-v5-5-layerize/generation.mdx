  <Expandable title="params 객체 속성">
    <ParamField body="image_url" type="string" required>
      분할할 원본 이미지 URL

      * 필수이며, **1장**의 이미지만 전달할 수 있습니다
      * 지원하는 이미지 형식: jpeg, png
      * 다음 두 가지 형식을 지원합니다:
        1. 공개적으로 접근 가능한 URL
        2. Base64 인코딩 형식
           * 완전한 Data URI 형식을 사용해야 합니다: `data:image/{格式};base64,{base64数据}`
           * 예시: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 주의: `data:image/jpeg;base64,` 접두사 부분을 반드시 포함해야 하며, base64 이미지 크기는 10MB를 초과할 수 없습니다
    </ParamField>

    <ParamField body="prompt" type="string">
      텍스트 프롬프트(선택 사항)

      분할할 요소를 지정하는 데 사용됩니다(예: `把标题文字和鹦鹉拆成单独的图层`). 전달하지 않으면 화면의 요소를 자동으로 인식합니다.
    </ParamField>

    <ParamField body="resolution" type="string" default="auto">
      출력 해상도 옵션

      * `auto` - 원본 이미지 크기로 출력(기본값): 1K 미만의 원본 이미지는 1K로 상향하고, 2K 초과의 원본 이미지는 2K로 축소합니다
      * `1K` - 1K 해상도
      * `1.5K` - 1.5K 해상도
      * `2K` - 2K 해상도

      옵션을 지정하면 배경 이미지와 각 레이어가 모두 선택한 옵션에 따라 출력되며, 각각 원본 비율을 유지합니다. 종횡비 또는 사용자 정의 픽셀 크기는 지원하지 않습니다.
    </ParamField>

    <ParamField body="max_images" type="integer" default="30">
      반환할 최대 이미지 수(배경 이미지 포함)

      * 값 범위: 2–100
      * 실제 반환되는 이미지 수는 화면 내용에 따라 결정되며 이 값을 초과하지 않습니다
      * 30장을 초과하면 소요 시간이 길어지며, 100장은 약 5분이 소요됩니다
    </ParamField>

    <ParamField body="text_recognition" type="boolean" default="false">
      텍스트 인식

      활성화하면 화면에서 명확하게 식별 가능한 텍스트 레이어에 대해 텍스트 내용과 스타일을 인식합니다
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      배경 이미지 출력 형식

      * `png` - PNG(기본값)
      * `jpeg` - JPEG

      배경 이미지(z_index = 0)에만 적용되며, 나머지 레이어는 투명 배경 PNG로 고정됩니다
    </ParamField>

### 조회 응답 - 레이어 출력 구조

작업이 완료되면 `output`은 이미지 객체 배열로 반환되며, 첫 번째 항목은 배경 이미지이고 나머지는 레이어입니다. 각 항목에는 `url`과 `metadata`가 포함됩니다:

<ResponseField name="output" type="array">
  배경 이미지 및 레이어 목록

  <Expandable title="이미지 객체 속성">
    <ResponseField name="url" type="string">
      이미지 URL(배경 이미지는 불투명 이미지, 레이어는 투명 PNG)
    </ResponseField>

    <ResponseField name="metadata" type="object">
      레이어 메타데이터

      <Expandable title="metadata 속성">
        <ResponseField name="kind" type="string">
          고정값 `"layer"`, 레이어 출력임을 나타냄
        </ResponseField>

        <ResponseField name="z_index" type="number">
          레이어 계층 인덱스

          * `z_index = 0`: 최하단 레이어(재구성된 전체 배경 이미지), `bounding_box`, `name`, `description`은 `null`
          * `z_index ≥ 1`: 전경 레이어, 숫자가 클수록 위에 위치함
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          원본 이미지에서 레이어의 위치 영역

          최하단 레이어(z_index=0)는 `null`이며, 나머지 레이어는 좌표 객체를 반환합니다:

          <Expandable title="bounding_box 속성">
            <ResponseField name="absolute" type="array">
              절대 픽셀 좌표 `[x1, y1, x2, y2]`, 배경 이미지 해상도 기준
            </ResponseField>

            <ResponseField name="normalized" type="array">
              정규화된 좌표 `[x1, y1, x2, y2]`, 범위 0–1000
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          레이어 이름
        </ResponseField>

        <ResponseField name="description" type="string | null">
          레이어 설명
        </ResponseField>

        <ResponseField name="background" type="string">
          배경 유형: 배경 이미지는 `"opaque"`, 레이어는 `"transparent"`
        </ResponseField>

        <ResponseField name="output_format" type="string">
          이미지 포맷, 예: `"png"`
        </ResponseField>

        <ResponseField name="size" type="string">
          해당 이미지의 픽셀 크기, 형식은 `너비x높이`
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>

<ResponseField name="credits_used" type="number">
