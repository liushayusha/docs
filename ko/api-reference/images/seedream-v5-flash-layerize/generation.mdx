## Body

<ParamField body="model" type="string" required>
  모델 이름

  고정값: `"seedream_v5_flash_layerize"`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체

  <Expandable title="params 객체 속성">
    <ParamField body="image_url" type="string | string[]" required>
      분할할 원본 이미지

      * 필수 항목이며, **1장**의 이미지만 전달할 수 있습니다
      * 지원되는 이미지 형식: png, jpeg, 단일 파일 최대 30MB
      * 총 픽셀 범위 262,144 – 36,000,000, 가로세로 비율 범위 1:16 – 16:1
      * 다음 두 가지 형식을 지원합니다:
        1. 공개적으로 액세스 가능한 URL
        2. Base64 인코딩 형식
           * 완전한 Data URI 형식을 사용해야 합니다: `data:image/{형식};base64,{base64데이터}`
           * 예시: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 주의: 반드시 `data:image/jpeg;base64,` 접두사 부분을 포함해야 하며, base64 이미지 크기는 10MB를 초과할 수 없습니다
    </ParamField>

    <ParamField body="prompt" type="string">
      분할 프롬프트 (선택 사항)

      * 전달 시, 프롬프트에 따라 지정된 요소를 분할합니다. 예: `Separate the title text and the parrot into independent layers`
      * `<bbox>x1 y1 x2 y2</bbox>`를 사용하여 요소 위치를 정밀하게 지정할 수 있으며, 좌표는 0–1000으로 정규화된 값입니다. 예: `Separate the parrot <bbox>330 274 641 991</bbox> into a layer`
      * 전달하지 않거나 4자 미만인 경우, 모델이 이미지의 주요 요소를 자동으로 인식합니다
      * 최대 5000자
    </ParamField>

    <ParamField body="resolution" type="string" default="auto">
      출력 해상도 옵션

      * `auto` - 원본 이미지 크기에 따라 자동 선택 (기본값)
      * `1K` - 1K 해상도
      * `1.5K` - 1.5K 해상도
      * `2K` - 2K 해상도

      베이스 이미지는 원본 이미지의 가로세로 비율을 유지하며, 각 레이어는 원본 이미지 내 해당 요소의 가로세로 비율을 유지합니다.
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      베이스 이미지의 출력 형식

      * `png` - PNG (기본값)
      * `jpeg` - JPEG

      베이스 이미지 형식만 제어하며, 분할된 레이어는 투명 PNG로 고정됩니다.
    </ParamField>
  </Expandable>

### 조회 응답 - 레이어 출력 구조

작업이 완료되면 `output`은 레이어 객체 배열이며, 각 레이어는 `url` 및 `metadata`를 포함합니다:

<ResponseField name="output" type="array">
  레이어 목록으로 각 요소는 레이어 객체이며, 최대 17개(베이스 이미지 1장 + 레이어 16개)입니다.

  <Expandable title="레이어 객체 속성">
    <ResponseField name="url" type="string">
      해당 레이어의 이미지 URL입니다. 베이스 이미지 형식은 `output_format`에 의해 결정되며, 나머지 레이어는 투명 PNG입니다.
    </ResponseField>

    <ResponseField name="metadata" type="object">
      레이어 메타데이터

      <Expandable title="metadata 속성">
        <ResponseField name="kind" type="string">
          고정값 `"layer"`로, 레이어 출력임을 나타냅니다.
        </ResponseField>

        <ResponseField name="z_index" type="number">
          레이어 계층 인덱스

          * `z_index = 0`: 베이스 이미지(전체 배경), `bounding_box`는 `null`
          * `z_index ≥ 1`: 전경 레이어, 뒤에서 앞으로 순서대로 정렬
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          원본 이미지 내 레이어의 위치 영역

          베이스 이미지(z_index=0)는 `null`이며, 나머지 레이어는 좌표 객체를 반환합니다:

          <Expandable title="bounding_box 속성">
            <ResponseField name="absolute" type="array">
              절대 픽셀 좌표 `[x1, y1, x2, y2]`로, 출력 베이스 이미지 해상도 기준
            </ResponseField>

            <ResponseField name="normalized" type="array">
              정규화 좌표 `[x1, y1, x2, y2]`로, 범위는 0–1000
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          레이어 이름, 베이스 이미지는 `null`
        </ResponseField>

        <ResponseField name="description" type="string | null">
          레이어 설명, 베이스 이미지는 `null`
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>
