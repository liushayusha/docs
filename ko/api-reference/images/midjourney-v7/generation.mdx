## Body

<ParamField body="model" type="string" required>
  모델 이름.

  고정값: `"mj_v7"`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      이미지 생성 지시문. 기본 Midjourney 문법을 지원하며, 프롬프트에서 다음 매개변수를 직접 사용할 수 있습니다:

      * `--ar` - 가로세로 비율(예: `--ar 16:9`)
      * `--s` - 스타일화 정도 0-1000
      * `--chaos` - 변동 정도 0-100
      * `--seed` - 재현을 위한 랜덤 시드
      * `--sref` - 스타일 참고 이미지 URL
      * `--oref` - 이미지 참고 URL
      * `--iw` - 이미지 가중치
      * `--no` - 부정 프롬프트
    </ParamField>

    <ParamField body="speed" type="string" default="fast">
      속도 단계.

      다음 값들을 지원합니다:

      * `draft` - 저비용 빠른 반복
      * `fast` - 표준 생성(기본값)
      * `turbo` - 가장 빠른 속도

      속도 단계는 생성 시간에 영향을 줍니다.
    </ParamField>

    <ParamField body="image_url" type="string[]">
      참고 이미지 배열. 전달하면 자동으로 이미지 기반 생성 모드를 사용하며, 전달하지 않으면 텍스트 기반 생성 모드를 사용합니다.

      * 최대 1장의 참고 이미지
      * 단일 이미지 최대 10MB
      * jpeg, png, webp 지원
      * 다음 두 가지 형식을 지원합니다:
        1. 공개적으로 접근 가능한 URL
        2. 전체 Base64 Data URI, 예: `data:image/jpeg;base64,/9j/4AAQ...`

      <Warning>
        URL은 공용 네트워크에서 직접 접근 가능해야 하며, 로그인, Cookie 또는 임시 페이지 권한 부여가 필요하면 안 됩니다.
      </Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출 측에서 사용자 정의한 작업 ID로, 멱등성 제출 및 결과 조회에 사용됩니다.

  * 길이는 1-64자입니다
  * 문자, 숫자, 밑줄 및 하이픈만 허용됩니다
  * 동일한 API Key 아래에서는 중복 사용할 수 없습니다
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">

<ResponseField name="status" type="string">

</ResponseField>

<ResponseField name="created_at" type="string">

</ResponseField>

## 조회 결과

제출이 성공한 후, 동일한 `out_task_id`를 사용하여 호출합니다:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "mj_v7_task_001"
  }'
```

작업 상태에는 `pending`, `processing`, `completed`, `failed`가 포함됩니다. 작업이 완료되면 결과 이미지는 `data.output`에, 실제 사용된 크레딧은 `data.credits_used`에 있습니다.
