## Authorizations

<ParamField header="Authorization" type="string" required>
  모든 인터페이스는 Bearer Token을 사용하여 인증해야 합니다.

  API Key 가져오기:

  <a href={apiKeyUrl} target="_blank">API Key 관리 페이지</a>에 접속하여 API Key를 가져오세요.

  사용할 때는 요청 헤더에 다음을 추가하세요:

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  모델 이름.

  고정 값: `"mj_v7_remove_bg"`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="image_url" type="string[]" required>
      처리할 이미지 배열. 반드시 1장의 이미지를 전달해야 합니다.

      * 최대 1장
      * 단일 이미지 최대 10MB
      * jpeg, png, webp 지원
      * 다음 두 가지 형식을 지원합니다:
        1. 공개적으로 접근 가능한 URL
        2. 완전한 Base64 Data URI, 예: `data:image/jpeg;base64,/9j/4AAQ...`

      <Warning>
        URL은 공용 네트워크에서 직접 접근 가능해야 하며, 로그인, Cookie 또는 임시 페이지 권한 부여가 필요해서는 안 됩니다.
      </Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출자가 사용자 정의한 작업 ID로, 멱등 제출과 결과 조회에 사용됩니다.

  * 길이는 1-64자
  * 문자, 숫자, 밑줄 및 하이픈만 허용됩니다
  * 동일한 API Key 아래에서는 중복 사용할 수 없습니다
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  호출 측 작업 ID로, 결과 조회에 사용할 수 있습니다.
</ResponseField>

<ResponseField name="status" type="string">
  초기 상태이며, 고정값은 `"pending"`입니다.
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  예상 소모 포인트.
</ResponseField>

<ResponseField name="created_at" type="string">
  생성 시간, ISO 8601 형식.
</ResponseField>

## Query Results

After submission succeeds, call using the same `out_task_id`:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "mj_v7_removebg_task_001"
  }'
```

Task status includes `pending`, `processing`, `completed`, and `failed`. After the task is completed, the result image is located in `data.output`, and the actual credits used are located in `data.credits_used`.

  import java.net.http.HttpClient;
  import java.net.http.HttpRequest;

  public class Main {
      public static void main(String[] args) throws Exception {
          String payload = """
          {
            "model": "mj_v7_remove_bg",
            "params": {
              "image_url": ["https://example.com/product-photo.png"]
