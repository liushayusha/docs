## Authorizations

<ParamField header="Authorization" type="string" required>
  모든 API는 Bearer Token 인증이 필요합니다.

  <a href={apiKeyUrl} target="_blank">API Key 관리 페이지</a>에 접속하여 API Key를 발급받고, 요청 헤더에 추가하세요:

  ```text
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정값: `"grok_imagine_2_0_ext"`.
</ParamField>

<ParamField body="params" type="object" required>
  모델 매개변수 객체입니다.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      이미지 생성 지시문입니다. 중국어와 영어를 지원하며, 앞뒤 공백을 제거한 후 비어 있을 수 없습니다.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      출력 이미지 가로세로 비율입니다. 지원:

      * `1:1`(기본값)
      * `2:3` / `3:2`
      * `3:4` / `4:3`
      * `9:16` / `16:9`

      <Warning>
        `auto`, 사용자 정의 픽셀 크기 또는 기타 비율은 지원하지 않습니다.
      </Warning>
    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      출력 이미지 수량으로, 값의 범위는 `1`부터 `12`까지입니다.

      범위 내의 모든 정수를 사용할 수 있으며, 예를 들어 `3`, `5`, `7`과 같이 `1`, `4`, `8`, `12`에 국한되지 않습니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출자 정의 작업 ID로, 멱등한 제출 및 결과 조회에 사용됩니다.

  * 길이는 1~64자
  * 영문자, 숫자, 밑줄 및 하이픈만 지원
  * 동일한 API Key에서 중복하여 사용할 수 없음
</ParamField>

<Warning>
  이 모델은 텍스트-이미지 생성(Text-to-Image)만 지원합니다. `image_url`, `resolution`, `quality`, `size` 또는 출력 형식 매개변수를 전달하지 마세요.
</Warning>

## Response

<ResponseField name="out_task_id" type="string">
  호출자 작업 ID로, 작업 상태 및 결과를 조회하는 데 사용할 수 있습니다.
</ResponseField>

<ResponseField name="status" type="string">
  초기 상태로, 일반적으로 `"pending"`입니다.
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  이번 작업의 예상 소모 크레딧입니다.
</ResponseField>

<ResponseField name="created_at" type="string">
  작업 생성 시간, ISO 8601 형식입니다.
</ResponseField>
