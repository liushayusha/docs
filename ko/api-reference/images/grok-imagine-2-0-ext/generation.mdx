## Authorizations

<ParamField header="Authorization" type="string" required>
  모든 인터페이스는 Bearer Token 인증이 필요합니다.

  <a href={apiKeyUrl} target="_blank">API Key 관리 페이지</a>에 접속하여 API Key를 가져온 다음, 요청 헤더에 다음을 추가하세요:

  ```text
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정값: `"grok_imagine_2_0_ext"`.
</ParamField>

<ParamField body="params" type="object" required>
  모델 Parameters object.

  <Expandable title="params object Properties">
    <ParamField body="prompt" type="string" required>
      이미지 생성 지시문. 중국어와 영어를 지원하며, 앞뒤 공백을 제거한 후 비어 있으면 안 됩니다.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      출력 이미지의 가로세로 비율입니다. 지원 항목:

      * `1:1`(기본값)
      * `2:3` / `3:2`
      * `3:4` / `4:3`
      * `9:16` / `16:9`

      <Warning>
        `auto`, 사용자 지정 픽셀 크기 또는 다른 비율은 지원하지 않습니다.
      </Warning>
    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      출력 이미지 개수이며, 값 범위는 `1`에서 `12`입니다.

      범위 내의 임의의 정수를 사용할 수 있습니다. 예를 들어 `3`, `5`, `7`은 사용할 수 있으며, `1`, `4`, `8`, `12`에만 제한되지 않습니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출 측에서 정의한 task ID로, idempotent 제출과 결과 조회에 사용됩니다.

  * 길이는 1-64자입니다.
  * 문자, 숫자, 밑줄 및 하이픈만 지원합니다.
  * 같은 API Key에서는 중복 사용이 불가능합니다.
</ParamField>

<Warning>
  이 모델은 text-to-image만 지원합니다. `image_url`, `resolution`, `quality`, `size` 또는 output format parameters를 전달하지 마세요.
</Warning>

## Response

<ResponseField name="out_task_id" type="string">
  호출자의 task ID로, 작업 상태와 결과를 조회하는 데 사용할 수 있습니다.
</ResponseField>

<ResponseField name="status" type="string">
  초기 상태이며, 일반적으로 `"pending"`입니다.
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  이번 작업의 예상 소모 포인트입니다.
</ResponseField>

<ResponseField name="created_at" type="string">
  작업 생성 시간, ISO 8601 형식입니다.
</ResponseField>

## Query Results

After submission succeeds, call [Get Task Status](/en/api-reference/tasks/status) using the same `out_task_id` to query. Once the task is completed, the image results are located in `data.output`.

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/submit \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "model": "grok_imagine_2_0_ext",
      "params": {
        "prompt": "Red apples on a white ceramic plate, clean studio product photography",
        "aspect_ratio": "1:1",
        "output_n": 3
      },
      "out_task_id": "grok_image_2_ext_001"
    }'
  ```

  ```python Python
  import requests

  response = requests.post(
      "https://aireiter.com/api/openapi/submit",
      headers={
          "Authorization": "Bearer <token>",
          "Content-Type": "application/json"
      },
      json={
          "model": "grok_imagine_2_0_ext",
          "params": {
              "prompt": "A glass greenhouse in a wildflower meadow at sunrise, editorial photography style",
              "aspect_ratio": "2:3",
              "output_n": 3
          },
          "out_task_id": "grok_image_2_ext_python_001"
      }
  )

  print(response.json())
  ```

  ```javascript JavaScript
  const response = await fetch("https://aireiter.com/api/openapi/submit", {
    method: "POST",
    headers: {
      Authorization: "Bearer <token>",
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      model: "grok_imagine_2_0_ext",
      params: {
        prompt: "A futuristic city street in the rain at night, with neon light reflections",
        aspect_ratio: "16:9",
        output_n: 1
      },
      out_task_id: "grok_image_2_ext_js_001"
    })
  });

  console.log(await response.json());
  ```
</RequestExample>
