    - 제출된 prompt는 플랫폼의 민감한 단어 / 안전성 검사를 거치며, 규정을 위반하는 내용은 직접 거부됩니다

## Authorizations

<ParamField header="Authorization" type="string" required>
  모든 인터페이스는 Bearer Token 인증이 필요합니다.

  <a href={apiKeyUrl} target="_blank">API Key 관리 페이지</a>에 접속하여 API Key를 가져온 다음, 요청 헤더에 다음을 추가하세요:

  ```text
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정값: `"grok_imagine_2_0_ext"`.
</ParamField>

<ParamField body="params" type="object" required>
  모델 Parameters object.

  <Expandable title="params object Properties">
    <ParamField body="prompt" type="string" required>
      이미지 생성 지시문. 중국어와 영어를 지원하며, 앞뒤 공백을 제거한 후 비어 있으면 안 됩니다.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      출력 이미지의 가로세로 비율입니다. 지원 항목:

      * `1:1`(기본값)
      * `2:3` / `3:2`
      * `3:4` / `4:3`
      * `9:16` / `16:9`

      <Warning>
        `auto`, 사용자 지정 픽셀 크기 또는 다른 비율은 지원하지 않습니다.
      </Warning>
    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      출력 이미지 개수이며, 값 범위는 `1`에서 `12`입니다.

      범위 내의 임의의 정수를 사용할 수 있습니다. 예를 들어 `3`, `5`, `7`은 사용할 수 있으며, `1`, `4`, `8`, `12`에만 제한되지 않습니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출 측에서 정의한 task ID로, idempotent 제출과 결과 조회에 사용됩니다.

  * 길이는 1-64자입니다.
  * 문자, 숫자, 밑줄 및 하이픈만 지원합니다.
  * 같은 API Key에서는 중복 사용이 불가능합니다.
</ParamField>

<Warning>
  이 모델은 text-to-image만 지원합니다. `image_url`, `resolution`, `quality`, `size` 또는 output format parameters를 전달하지 마세요.
</Warning>

                      curl_easy_strerror(res));
