## Body

<ParamField body="model" type="string" required>
  모델 이름

  고정 값: `"krea_2_turbo"`
</ParamField>

<ParamField body="params" type="object" required>
  모델 매개변수 객체

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      이미지 생성 텍스트 설명. 영어 프롬프트가 가장 좋으며, 최대 640 토큰.
    </ParamField>

    <ParamField body="aspect_ratio" type="string">
      이미지 생성 화면비. 지원 값 (총 11종):

      * `1:1` - 정사각형
      * `4:3` - 가로 4:3
      * `3:4` - 세로 3:4
      * `5:4` - 가로 5:4
      * `4:5` - 세로 4:5
      * `3:2` - 가로 3:2
      * `2:3` - 세로 2:3
      * `16:9` - 가로 와이드스크린
      * `9:16` - 세로 스크린
      * `2:1` - 파노라마
      * `1:2` - 세로 긴 형
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      이미지 해상도. 지원: `1K`（기본값）、`2K`
    </ParamField>

    <ParamField body="seed" type="integer">
      선택사항. 재현 가능한 생성을 위한 랜덤 시드. 범위 0-1048576. 생략 또는 0이면 랜덤 생성.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  작업 완료 후 콜백 주소
</ParamField>

<ParamField body="metadata" type="object">
  사용자 정의 메타데이터, 그대로 반환됨
</ParamField>

<ParamField body="out_task_id" type="string" required>
  발신자 작업 ID

  사용자가 정의한 작업 식별자, 필수
</ParamField>
