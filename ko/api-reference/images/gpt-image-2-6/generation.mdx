<Note>
GPT-Image 2.6은 AIReiter에서 `gpt_image_2_6_flare`와 `gpt_image_2_6_sunburst`라는 두 가지 모델 이름을 가지며, 별도의 `gpt_image_2_6`은 없습니다. 두 모델의 파라미터는 완전히 동일합니다.

`output_format`은 `png`(기본값) 또는 `gif`를 선택할 수 있습니다. 본 인터페이스에서는 `quality`, `output_n`, `background`를 제공하지 않으며, SVG 벡터 이미지 및 마스크 / 영역 선택 부분 편집도 지원하지 않습니다.
</Note>

  * `"gpt_image_2_6_sunburst"` — Sunburst, 디테일에 더 집중하며 인물, 상품 또는 레이아웃을 보존해야 하는 편집에 적합

      * 최대 10장의 참조 이미지
      * 전달하지 않을 경우 순수 텍스트 기반 생성으로 진행
      * 다음 두 가지 형식 지원:
        1. 공개적으로 접근 가능한 URL
        2. Base64 인코딩 형식

           * 지원하는 이미지 형식: jpeg, png, webp
           * 예시: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 주의: 반드시 `data:image/jpeg;base64,` 접두사 부분을 포함해야 함
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      이미지 생성 비율, 기본값 `auto`

      지원하는 값은 다음과 같습니다:

      * `auto` - 가장 적합한 비율 자동 선택
      * `1:1` - 정사각형
      * `16:9` / `9:16` - 와이드스크린 가로 / 세로
      * `4:3` / `3:4` - 표준 화면 가로 / 세로
      * `3:2` / `2:3` - 클래식 가로 / 세로
      * `5:4` / `4:5` - 준정사각형 가로 / 세로
      * `2:1` / `1:2` - 넓은 가로 / 긴 세로
      * `21:9` / `9:21` - 울트라 와이드 가로 / 울트라 롱 세로

      <Warning>
        비율 문자열 또는 `auto`만 지원합니다. 픽셀 크기(예: `1024x1024`)를 전달하면 즉시 오류가 발생합니다. 정확한 픽셀이 필요한 경우 `size`를 사용하세요.
      </Warning>
    </ParamField>

      해상도 등급, 기본값 `1K`

      * `1K` - 약 1024 기준
      * `2K` - 약 2048 기준
      * `4K` - 약 3840 기준

      <Warning>
        `size`를 전달할 때는 `resolution` / `aspect_ratio`를 함께 전달하지 마세요. 그렇지 않으면 400이 반환됩니다.
      </Warning>
    </ParamField>

    <ParamField body="frame_count" type="integer" default="9">
      GIF 프레임 수, `output_format`이 `gif`일 때만 적용, 기본값 `9`

      * 설정 범위 `2` ~ `9`, 범위 초과 시 400 반환
    </ParamField>

    <ParamField body="frame_duration_ms" type="integer" default="200">
      GIF 프레임당 지속 시간(밀리초), `output_format`이 `gif`일 때만 적용, 기본값 `200`

      * 설정 범위 `100` ~ `500`, 10밀리초 단위로 반올림, 범위 초과 시 400 반환
      * 예: 9프레임 × 200밀리초, 1회 루프에 1.8초
    </ParamField>

    <ParamField body="size" type="string">

      형식은 `가로x세로`, 예: `2048x1536`, `3840x2160`.

      **사용 제한:**

      * 형식은 반드시 `^\d+x\d+$`이어야 함
      * 가로, 세로 모두 16의 배수
      * 각 변은 3840을 초과할 수 없음
      * 긴 변 / 짧은 변 비율은 3:1을 초과할 수 없음
      * 총 픽셀(가로 × 세로)은 **655,360 ~ 8,294,400**
      * `aspect_ratio`, `resolution`과 상호 배타적이며, 동시에 전달 시 400 반환
      * `gif`인 경우 비율에 따라 가장 가까운 GIF 프레임 크기로 변환됨(아래 GIF 프레임 크기 표 참조)

## 尺寸 × 分辨率映射表

`aspect_ratio × resolution` → 실제 픽셀(`auto`는 모델이 자동으로 선택하며, 표에 포함되지 않음):

| aspect\_ratio | `1K`      | `2K`      | `4K`      |
| ------------- | --------- | --------- | --------- |
| `1:1`         | 1024×1024 | 2048×2048 | 2880×2880 |
| `3:2`         | 1536×1024 | 2048×1360 | 3520×2336 |
| `2:3`         | 1024×1536 | 1360×2048 | 2336×3520 |
| `4:3`         | 1024×768  | 2048×1536 | 3312×2480 |
| `3:4`         | 768×1024  | 1536×2048 | 2480×3312 |
| `5:4`         | 1280×1024 | 2560×2048 | 3216×2576 |
| `4:5`         | 1024×1280 | 2048×2560 | 2576×3216 |
| `16:9`        | 1536×864  | 2048×1152 | 3840×2160 |
| `9:16`        | 864×1536  | 1152×2048 | 2160×3840 |
| `2:1`         | 1760×880  | 2688×1344 | 3840×1920 |
| `1:2`         | 880×1760  | 1344×2688 | 1920×3840 |
| `21:9`        | 1904×816  | 2688×1152 | 3840×1648 |
| `9:21`        | 816×1904  | 1152×2688 | 1648×3840 |

> `3:2` / `2:3` @ 2K는 실제로 2048×1360(근사 비율)입니다. 표 외의 비율이 필요한 경우 `size`를 사용하세요.

## GIF 帧尺寸

`output_format`이 `gif`일 때, 각 프레임의 크기는 `aspect_ratio`에 의해 결정됩니다(`auto`는 `1:1` 기준):

| aspect\_ratio | 프레임당 크기 |
| ------------- | -------- |
| `1:1`         | 896×896  |
| `16:9`        | 1088×608 |
| `9:16`        | 608×1088 |
| `4:3`         | 960×720  |
| `3:4`         | 720×960  |
| `3:2`         | 1008×672 |
| `2:3`         | 672×1008 |

## Query Task

GPT-Image 2.6은 비동기 이미지 생성 모델입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하세요. [작업 상태 조회](/ko/api-reference/tasks/status)를 참고할 수도 있습니다.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달한 요청자 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "my_task_123456"
  }'
```

조회가 성공하고 완료되면 응답의 `output` 배열에 생성된 이미지(PNG 또는 GIF)가 포함됩니다.

실측 기준 단일 1K 이미지는 약 25~45초, GIF는 약 25~70초 만에 완료되며, Sunburst는 일반적으로 Flare보다 약간 느립니다. 해상도가 높을수록, 참조 이미지가 많을수록 시간이 더 오래 걸리므로 중복 제출하지 말고 지속적으로 폴링해 주세요.

## 使用说明

* `prompt`만 전달하면 텍스트 투 이미지로 동작하며, `image_url`을 전달하면 참조 이미지 편집으로 처리되어 프롬프트에 언급되지 않은 부분은 최대한 그대로 유지됩니다.
* 요청당 1장의 이미지만 반환되며, 여러 장이 필요한 경우 각각 제출해 주세요.
* 기본 출력은 PNG이며, `output_format: "gif"`를 전달하면 반복 재생되는 GIF 애니메이션이 출력됩니다.
* GIF는 `prompt`만을 기반으로 생성되므로 프롬프트에 피사체, 동작 및 반복 방식을 명확히 작성해 주세요(예: "손을 흔든 후 초기 자세로 돌아가기"). 동작이 단순할수록 프레임 간 연결이 자연스럽습니다.
* 4K 옵션은 대형 결과물이 필요한 시나리오에 적합합니다. 디테일 요구도가 높은 사실적인 이미지의 경우, 먼저 1K / 2K로 구도를 확인한 후 4K로 생성하는 것을 권장합니다.
