## Body

<ParamField body="model" type="string" required>
  Model name, fixed value: `"qwen_image_3_pro"`.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="Properties of the params object">
    <ParamField body="prompt" type="string" required>
      Image generation or editing instruction. Supports Chinese and English.

      The Pro model is suitable for tasks that require readable text, complex hierarchy, dense layouts, and high-detail rendering. It is recommended to clearly describe the text content, font style, hierarchy, position, whitespace, and the reference image features that need to be preserved.
    </ParamField>

    <ParamField body="image_url" type="string[]">
      Array of reference images. When provided, image-to-image mode is used; when omitted, text-to-image mode is used.

      * Up to 3 reference images
      * Maximum size of a single image is 10MB
      * Supports jpeg, png, webp
      * Supports publicly accessible URLs or complete Base64 Data URIs

      <Warning>
        Image URLs must be directly accessible from the public internet and cannot rely on login status, cookies, or temporary page authorization.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      Output resolution tier.

      * `1K` - Base resolution (default)
      * `2K` - High-definition resolution, suitable for text, posters, and dense layouts
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      Output image aspect ratio.

      Supported values:

      * `1:1` - Square (default)
      * `3:2` / `2:3` - Classic landscape / portrait
      * `4:3` / `3:4` - Standard landscape / portrait
      * `16:9` / `9:16` - Widescreen landscape / portrait

    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      Number of images generated for this task, ranging from `1` to `6`.
    </ParamField>

    <ParamField body="prompt_extend" type="boolean" default="false">
      Smart prompt rewriting. Disabled by default to keep results predictable. Set to `true` when smart rewriting is needed.
    </ParamField>

    <ParamField body="prompt_extend_mode" type="string" default="direct">
      Prompt rewriting mode. Effective only when `prompt_extend` is `true`.

      * `direct` - Balanced rewriting, supports both text-to-image and image-to-image
      * `agent` - Aggressive rewriting, text-to-image only
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      Negative prompt, used to describe content you do not want to appear in the result, such as blur, garbled text, crowded layout, or structural distortion.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Caller-defined task ID, used for idempotent submission and result queries.

  * Length: 1-64 characters
  * It is recommended to use only letters, numbers, underscores, and hyphens
  * Do not reuse the same ID under the same API Key
</ParamField>
