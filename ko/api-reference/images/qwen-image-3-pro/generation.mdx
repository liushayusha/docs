## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정 값: `"qwen_image_3_pro"`.
</ParamField>

<ParamField body="params" type="object" required>
  모델 Parameters 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      이미지 생성 또는 편집 지침. 중국어와 영어를 지원합니다.

      Pro 모델은 읽을 수 있는 텍스트, 복잡한 계층 구조, 밀집된 레이아웃, 높은 디테일 표현이 필요한 작업에 적합합니다. 텍스트 내용, 글꼴 스타일, 계층 구조, 위치, 여백, 유지해야 할 참고 이미지의 특징을 구체적으로 설명하는 것이 좋습니다.
    </ParamField>

    <ParamField body="image_url" type="string[]">
      참고 이미지 배열. 전달하면 이미지-투-이미지 모드를 사용하고, 전달하지 않으면 텍스트-투-이미지 모드를 사용합니다.

      * 최대 3장까지 참고 이미지 허용
      * 단일 이미지 최대 10MB
      * jpeg, png, webp 지원
      * 공개적으로 접근 가능한 URL 또는 완전한 Base64 Data URI 지원

      <Warning>
        이미지 URL은 공용 네트워크에서 직접 접근할 수 있어야 하며, 로그인 상태, Cookie 또는 페이지의 임시 권한에 의존할 수 없습니다.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      출력 해상도 등급.

      * `1K` - 기본 해상도(기본값)
      * `2K` - 고해상도, 텍스트, 포스터 및 밀집된 레이아웃에 적합
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      출력 이미지의 가로세로 비율.

      다음 값을 지원합니다:

      * `1:1` - 정사각형(기본값)
      * `3:2` / `2:3` - 클래식 가로형 / 세로형
      * `4:3` / `3:4` - 표준 가로형 / 세로형
      * `16:9` / `9:16` - 와이드스크린 가로형 / 세로형

      <Warning>
        현재 인터페이스는 `21:9`를 지원하지 않으며, `1024x1024` 같은 사용자 지정 픽셀 크기도 지원하지 않습니다.
      </Warning>
    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      이번 작업에서 생성되는 이미지 수이며, 범위는 `1`에서 `6`까지입니다.
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      출력 형식이며, 현재는 `png`로 고정되어 있습니다.

      <Warning>
        현재 AIReiter 연동 채널은 JPEG 출력 옵션을 제공하지 않습니다.
      </Warning>
    </ParamField>

    <ParamField body="prompt_extend" type="boolean" default="true">

    </ParamField>

    <ParamField body="negative_prompt" type="string">
      네거티브 프롬프트로, 흐림, 깨진 문자, 혼잡한 레이아웃, 구조 변형처럼 결과에 나타나지 않기를 원하는 내용을 설명하는 데 사용합니다.
    </ParamField>
  </Expandable>

## 청구

| 청구 항목 | 가격 |
| --- | ---: |
| 이미지당 1K 출력 | 3.20 크레딧($0.032) |
| 이미지당 2K 출력 | 6.00 크레딧($0.060) |
| 입력 참고 이미지당 | 0.25 크레딧($0.0025) |

청구 공식:

* 1K: `3.20 × output_n + 0.25 × 참고 이미지 수`
* 2K: `6.00 × output_n + 0.25 × 참고 이미지 수`

예를 들어, 1장의 1K 이미지를 생성하고 1장의 참고 이미지를 전달하면 예상 소모량은 `3.45` 크레딧입니다. 1장의 2K 이미지를 생성하고 1장의 참고 이미지를 전달하면 예상 소모량은 `6.25` 크레딧입니다. 제출 성공 시, 응답의 `estimated_credits`는 예상 소모량이며, 작업 완료 후 조회 응답의 `credits_used`는 실제 소모량입니다. 작업 실패 시에는 최종 청구가 발생하지 않습니다.

## Query Results

After a successful submission, call the query endpoint using the same `out_task_id`:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "qwen_image_3_pro_task_001"
  }'
```

The task status includes `pending`, `processing`, `completed`, and `failed`. After the task is completed, the image array is located in `data.output`, and the actual credits consumed are located in `data.credits_used`.
