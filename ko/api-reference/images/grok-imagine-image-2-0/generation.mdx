## Body

<ParamField body="model" type="string" required>
  Model name, fixed value: `"grok_imagine_image_2_0"`.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Image generation or editing instructions. Supports Chinese and English.

      When using multiple reference images, you can use `<IMAGE_0>`, `<IMAGE_1>`, and `<IMAGE_2>` in the prompt to refer to the corresponding images.
    </ParamField>

    <ParamField body="image_url" type="string[]">
      Reference image array. Omitted for text-to-image; after being passed in, it automatically uses image-to-image or image editing mode.

      * Up to 3 images
      * Maximum 10MB per image
      * Supports JPG, PNG, and WebP
      * Supports public URLs, complete Base64 Data URIs, or plain Base64

      <Warning>
        When using a URL, the image must be directly accessible from the public internet and cannot depend on login status, cookies, or temporary page authorization.
      </Warning>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      Output image aspect ratio. Supports:

      * `auto` (default)
      * `1:1`
      * `4:3` / `3:4`
      * `3:2` / `2:3`
      * `16:9` / `9:16`
      * `2:1` / `1:2`
      * `19.5:9` / `9:19.5`
      * `20:9` / `9:20`

      Custom `WIDTHxHEIGHT` pixel dimensions are not supported.
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      Output resolution level: `1K` (default) or `2K`. `4K` is not supported.
    </ParamField>

    <ParamField body="quality" type="string" default="medium">
      Generation quality level:

      * `low` - faster and lower cost
      * `medium` - better details (default)
    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      Number of output images, ranging from `1` to `10`. Each image is billed separately.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Caller-defined task ID, used for idempotent submission and result querying.

  * Length: 1-64 characters
  * Only letters, numbers, underscores, and hyphens are supported
  * Cannot be reused under the same API Key
</ParamField>
