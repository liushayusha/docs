## Body

<ParamField body="model" type="string" required>
  모델 이름, `"mj_v8_2"`로 고정
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      이미지의 텍스트 설명, 원하는 장면을 자연어로 작성

      * 버전, 화면비, 화질, 속도 등의 Midjourney 파라미터는 아래 필드에 의해 자동으로 추가되므로 직접 작성할 필요가 없습니다
      * 프롬프트에 직접 작성한 `--` 파라미터(예: `--ar`, `--v`, `--fast`)는 무시되며, 첫 번째 `--`부터의 내용은 적용되지 않습니다
      * 이미지 편집(`use_edit`) 사용 시, 수정 명령어를 직접 작성할 수 있습니다. 예: "Render this logo as a hand drawn pencil sketch"
    </ParamField>

    <ParamField body="image_url" type="string[]">
      참조 이미지(Image Prompt)의 URL 목록으로, 결과물의 콘텐츠, 구도 및 색감에 영향을 줍니다

      * 최대 4장까지 가능하며, 전달된 순서대로 사용됩니다
      * 전달하지 않을 경우 텍스트 투 이미지(Text-to-Image)로 동작합니다
      * 다음 두 가지 형식을 지원합니다:
        1. 공개적으로 접근 가능한 URL(로그인, 쿠키 또는 임시 권한 요구 불가)
        2. Base64 인코딩 형식
           * 완전한 Data URI 형식을 사용해야 합니다: `data:image/{형식};base64,{base64데이터}`
           * 지원되는 이미지 형식: jpeg, png, webp
           * 예시: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 주의: 반드시 `data:image/jpeg;base64,` 접두사 부분을 포함해야 하며, base64 이미지 크기는 10MB를 초과할 수 없습니다
    </ParamField>

    <ParamField body="image_weight" type="number" default="1">
      참조 이미지 가중치(`--iw`에 해당), 결과물이 참조 이미지에 얼마나 가까운지를 결정

      * 값 범위 0-3, 기본값 1, 값이 클수록 참조 이미지와 유사해집니다
      * `image_url`을 전달한 경우에만 적용됩니다
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      이미지 가로세로 비율(`--ar`에 해당)

      지원되는 가로세로 비율:

      * `1:1` - 정사각형(기본값)
      * `16:9` - 가로 와이드스크린
      * `9:16` - 세로 화면
      * `4:3` - 가로 4:3
      * `3:4` - 세로 3:4
      * `3:2` - 가로 3:2
      * `2:3` - 세로 2:3
    </ParamField>

    <ParamField body="quality" type="string" default="sd">
      화질 단계

      지원되는 값:

      * `sd` - 표준 화질(기본값), 1:1 기준 장당 1024×1024
      * `hd` - 네이티브 고화질, 1:1 기준 장당 2048×2048

      기타 화면비는 비율에 따라 환산되며, 실제 크기는 반환된 이미지를 기준으로 합니다.
    </ParamField>

    <ParamField body="speed" type="string" default="fast">
      생성 속도(`--fast` / `--relax`에 해당)

      지원되는 값:

      * `fast` - 고속 모드(기본값)
      * `relax` - 저속 모드, 대기 시간이 더 길어집니다

      저속 모드는 별도의 채널에서 처리되며, 실제 테스트 결과 고속 모드보다 2배 이상 느립니다.
    </ParamField>

    <ParamField body="use_style_ref" type="boolean" default="false">
      스타일 참조 활성화 여부(`--sref`에 해당)

      다른 이미지의 화풍, 색감 및 질감을 차용하며, 인물이나 사물을 그대로 복사하지 않습니다. `true`로 설정할 경우 반드시 `style_image_url`을 전달해야 합니다.
    </ParamField>

    <ParamField body="style_image_url" type="string">
      스타일 참조 이미지, 1장

      * `use_style_ref`가 `true`일 때만 적용되며, 이때는 필수 항목입니다
      * 형식 요구 사항은 `image_url`과 동일합니다
    </ParamField>

    <ParamField body="style_weight" type="number" default="100">
      스타일 강도(`--sw`에 해당)

      * 값 범위 0-1000, 기본값 100
      * `use_style_ref`가 `true`일 때만 적용됩니다
    </ParamField>

    <ParamField body="use_edit" type="boolean" default="false">
      이미지 편집 활성화 여부(`--edit`에 해당)

      `prompt`를 수정 명령어로 사용하여 기존 이미지를 편집합니다. `true`로 설정할 경우 반드시 `edit_image_url`을 전달해야 합니다. `image_url`, 스타일 참조와 동시에 사용할 수 있습니다.
    </ParamField>

    <ParamField body="edit_image_url" type="string">
      편집할 대상 이미지, 1장

      * `use_edit`가 `true`일 때만 적용되며, 이때는 필수 항목입니다
      * 형식 요구 사항은 `image_url`과 동일합니다
    </ParamField>
  </Expandable>
</ParamField>
