## Body

<ParamField body="model" type="string" required>
  모델 이름.

  고정값: `"z_image_turbo"`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      이미지 생성 지시문, 최대 2000자.

      * 중영문 모두 지원하며, 주제, 장면, 구도, 조명, 재질을 명확하게 묘사하는 것을 권장합니다
      * 모델은 사실적인 스타일에 치우쳐 있어, 실제 같은 빛과 재질을 설명하는 프롬프트일수록 더 좋은 효과를 냅니다
      * 화면에 텍스트가 나타나야 할 때는 텍스트 내용을 따옴표로 감싸세요. 한중영 모두 가능합니다
      * 제출 전에 플랫폼의 민감어 / 안전 심사를 거치며, 위반 내용이 감지되면 바로 오류를 반환합니다
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      이미지 가로세로 비율.

      다음 값을 지원합니다:

      * `1:1` - 정사각형(기본)
      * `16:9` / `9:16` - 와이드 스크린 가로형 / 세로형
      * `4:3` / `3:4` - 표준 가로형 / 세로형
      * `3:2` / `2:3` - 클래식 가로형 / 세로형
      * `2:1` / `1:2` - 파노라마 가로형 / 긴 세로형

      <Warning>
        `aspect_ratio`는 모델의 목표 비율 구간을 의미하며, 고정된 픽셀 크기를 보장하지 않습니다. 반환되는 값은 해당 비율에 가까운 모델의 기본 크기입니다. 예를 들어 실제로 16:9를 측정하면 1536×864가 반환됩니다.
      </Warning>
    </ParamField>

    <ParamField body="seed" type="integer">
      랜덤 시드로, 결과 재현에 사용되며 범위는 1-2147483647입니다.

      * 동일한 `prompt` + `seed` 조합은 구도가 비슷한 이미지를 생성합니다
      * 전달하지 않으면 매번 랜덤 결과가 생성됩니다
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출 측에서 지정하는 사용자 정의 작업 ID로, 멱등 제출 및 결과 조회에 사용됩니다.

  * 길이는 1-64자
  * 영문자, 숫자, 밑줄, 하이픈만 허용됩니다
  * 동일한 API Key 아래에서는 중복 사용할 수 없습니다
</ParamField>

<Note>
  Z-Image Turbo는 텍스트로 이미지 생성만 지원합니다. 참고 이미지(`image_url`), 이미지 편집, 해상도 단계(`resolution`), 일괄 이미지 생성(`output_n`)은 모두 지원되지 않으며, 사용자 지정 픽셀 크기 `size`를 전달하면 즉시 `Model "z_image_turbo" does not support size parameter`를 반환합니다. 요청마다 항상 1장의 이미지만 반환되므로, 여러 장이 필요하면 서로 다른 `seed`로 여러 번 제출하세요.

  참고 이미지, 이미지 기반 이미지 생성 또는 더 큰 캔버스가 필요할 때는 GPT-Image 2, Seedream 5.0 Pro 또는 Nano Banana Pro를 사용하세요.
</Note>

## 조회 결과

제출이 성공한 후, 동일한 `out_task_id`를 사용하여 호출합니다:

```bash
curl --request POST \\
  --url https://aireiter.com/api/openapi/query \\
  --header 'Authorization: Bearer <token>' \\
  --header 'Content-Type: application/json' \\
  --data '{
    "out_task_id": "z_image_turbo_task_001"
  }'
```

작업 상태에는 `pending`, `processing`, `completed`, `failed`가 포함됩니다. 작업이 완료되면 결과 이미지는 `data.output`에 있으며, 실제 소모량은 `data.credits_used`에 있습니다. 작업 생성에 실패하면 시스템이 이번 작업의 사전 차감 크레딧을 자동으로 환불합니다.
