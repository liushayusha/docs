## Body

<ParamField body="model" type="string" required>
  모델 이름, `"nano_banana_v2_1"`로 고정
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      이미지 생성을 위한 텍스트 설명

      * 화면에 표시되어야 하는 텍스트는 따옴표를 사용하여 명시하는 것을 권장합니다. 예: 간판에 "FRESH BREAD"라고 적혀 있음
      * 참조 이미지를 전달한 경우 유지할 항목과 변경할 항목을 설명하세요
    </ParamField>

    <ParamField body="image_url" type="string[]">
      참조 이미지의 URL 목록, 이미지 투 이미지(Image-to-Image) / 다중 이미지 합성 편집에 사용

      * 최대 10장의 이미지, 전달된 순서대로 사용
      * 전달하지 않으면 텍스트 투 이미지(Text-to-Image)로 동작
      * 마스크(mask) 부분 재그리기(인페인팅)는 지원하지 않음
      * 다음 두 가지 형식을 지원합니다:
        1. 공개적으로 접근 가능한 URL
        2. Base64 인코딩 형식
           * 완전한 Data URI 형식을 사용해야 합니다: `data:image/{형식};base64,{base64데이터}`
           * 지원되는 이미지 형식: jpeg, png, webp
           * 예시: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 주의: 반드시 `data:image/jpeg;base64,` 접두사 부분을 포함해야 하며, base64 이미지 크기는 10MB를 초과할 수 없습니다
    </ParamField>

    <ParamField body="aspect_ratio" type="string">
      이미지 생성 가로세로 비율

      지원되는 가로세로 비율:

      * `auto` - 자동(프롬프트 또는 참조 이미지에 따라 적절한 비율 선택)
      * `1:1` - 정사각형
      * `3:2` - 가로 3:2
      * `2:3` - 세로 2:3
      * `4:3` - 가로 4:3
      * `3:4` - 세로 3:4
      * `5:4` - 가로 5:4
      * `4:5` - 세로 4:5
      * `16:9` - 가로 와이드스크린
      * `9:16` - 세로 화면
      * `21:9` - 울트라 와이드스크린
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      이미지 해상도

      지원되는 해상도:

      * `1K` - 기본 해상도(기본값)
      * `2K` - 표준 해상도
      * `4K` - 고해상도
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  요청자 작업 ID

  사용자 정의 작업 식별자, 필수 항목입니다. 영문자, 숫자, `_`, `-`만 지원하며 길이는 1-64자입니다
</ParamField>
