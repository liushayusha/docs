## 청구

| 청구 항목 | 가격 |
| --- | ---: |
| 이미지당 1K 출력 | 2.40 크레딧($0.024) |
| 이미지당 2K 출력 | 2.40 크레딧($0.024) |
| 입력 참고 이미지당 | 0.25 크레딧($0.0025) |

청구 공식: `2.40 × output_n + 0.25 × 참고 이미지 수`.

예를 들어, 이미지 1장을 생성하고 참고 이미지 1장을 전달하면 예상 소모량은 `2.65` 크레딧입니다. 제출이 성공하면 Response의 `estimated_credits`는 예상 소모량을 나타내며, 작업이 완료된 후 Query Response의 `credits_used`는 실제 소모량을 나타냅니다. 작업이 실패하면 최종 청구는 발생하지 않습니다.

## Query Results

After submission succeeds, call the query endpoint using the same `out_task_id`:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "qwen_image_3_task_001"
  }'
```

Task statuses include `pending`, `processing`, `completed`, and `failed`. After the task is completed, the image array is located in `data.output`, and the actual credits used are located in `data.credits_used`.
