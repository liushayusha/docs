<Note>
AIReiter에서 Seedance 2.5 Flash의 모델 이름은 `seedance2_5_flash`이며, Seedance 2.5의 빠른 버전입니다. 생성 속도가 더 빠르고 참고 소재의 최대 한도가 더 적으며, 파라미터 구조는 `seedance2_5`와 동일합니다.
</Note>

## Seedance 2.5와의 차이점

| 항목 | `seedance2_5` | `seedance2_5_flash` |
| --- | --- | --- |
| 참조 이미지 상한 | 30장 | 10장 |
| 참조 동영상 상한 | 9개 | 5개 |
| 참조 오디오 상한 | 10개 | 5개 |
| 생성 속도 | 표준 | 더 빠름 |

위 표의 항목을 제외하고 두 모델의 파라미터, 값 범위 및 소재 규격은 동일합니다.

## Body

<ParamField body="model" type="string" required>
  모델 이름, 다음 값으로 고정하여 사용합니다:

  * `seedance2_5_flash`
</ParamField>

<ParamField body="params" type="object" required>
  모델 매개변수 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      동영상 생성을 위한 텍스트 설명.

      피사체, 장면, 동작, 카메라 움직임, 시각적 스타일, 대사 및 환경음을 묘사하는 것이 좋습니다.
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      참조 모드, 참조 소재의 사용 방식을 결정합니다:

      * `all_reference` - 전체 참조 모드, 참조 이미지, 참조 동영상 및 참조 오디오를 사용할 수 있습니다
      * `first_last_frame` - 시작/끝 프레임 모드, 시작 프레임과 선택적 끝 프레임 이미지를 사용합니다

      두 모드는 상호 배타적이며, 한 번의 요청에 둘 중 하나만 사용할 수 있습니다.
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      참조 이미지 URL.

      * `all_reference` 모드: 최대 10장의 이미지; 장당 최대 30MB; 이미지 최소 변 길이 300px
      * `first_last_frame` 모드: 1-2장의 이미지, 순서대로 시작 프레임과 끝 프레임으로 사용됨; 장당 최대 10MB

      URL은 공용 네트워크에서 직접 접근할 수 있어야 합니다.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      참조 동영상 URL, `all_reference` 모드에서만 유효하며 최대 5개의 참조 동영상을 지원합니다.

      동영상 요구 사항:

      * 개별 동영상 길이 2-30초, 참조 동영상의 총 길이는 30초를 초과할 수 없음
      * 개별 동영상 최대 200MB
      * 프레임 속도 24-60 FPS
      * 화면비 범위 0.4-2.5
      * 가로/세로 범위 300-6000px
      * 총 픽셀 수 범위 409600-927408

      <Warning>`first_last_frame` 모드에서는 이 매개변수를 전달하지 마세요.</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      참조 오디오 URL, `all_reference` 모드에서만 유효하며 최대 5개의 오디오를 지원합니다.

      오디오 요구 사항:

      * 개별 오디오 길이 2-30초, 참조 오디오의 총 길이는 30초를 초과할 수 없음
      * WAV, MP3 지원
      * 개별 오디오 최대 15MB

      <Warning>`first_last_frame` 모드에서는 이 매개변수를 전달하지 마세요.</Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      동영상 해상도:

      * `480p`
      * `720p` - 기본값

      1080p, 4K는 지원하지 않습니다.
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      출력 동영상 길이, 단위는 초입니다.

      `4`에서 `30` 사이의 정수를 지원하며, 기본값은 `5`입니다.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      동영상 화면비:

      * `21:9` - 울트라 와이드
      * `16:9` - 가로 화면, 기본값
      * `9:16` - 세로 화면
      * `4:3` - 표준 가로 화면
      * `3:4` - 표준 세로 화면
      * `1:1` - 정사각형

      `first_last_frame` 모드에서는 화면비가 시작 프레임 이미지를 따르므로 이 매개변수는 적용되지 않습니다.
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      동영상과 동기화된 AI 오디오 생성 여부.

      * `true` - 오디오 생성, 기본값
      * `false` - 오디오 생성 안 함
    </ParamField>

    <ParamField body="output_format" type="string" default="mp4">
      출력 동영상 형식:

      * `mp4` - 범용 형식, 파일 크기가 비교적 작음, 기본값
      * `mov` - 고정밀 색상 형식(yuv444p), 후반 확장 및 이어붙이기 작업에 적합
    </ParamField>
  </Expandable>
</ParamField>

## Query Task

Seedance 2.5 Flash는 비동기 처리를 채택합니다. 제출이 성공한 후, 동일한 `out_task_id`를 사용하여 작업을 조회하세요:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "seedance2_5_flash_task_123456"
  }'
```

작업이 완료되면 응답의 `output` 배열에 생성된 비디오 URL이 포함됩니다. 전체 필드는 [작업 상태 가져오기](/ko/api-reference/tasks/status)를 참조하세요.

  request.setValue("application/json", forHTTPHeaderField: "Content-Type")

## Mode Rules

| type | 사용 가능한 소재 | 소재 제한 |
| --- | --- | --- |
| `all_reference` | `image_url`, `video_url`, `audio_url` | 이미지 최대 10장, 비디오 최대 5개, 오디오 최대 5개 |
| `first_last_frame` | `image_url` | 이미지 1-2장, 순서대로 첫 프레임 및 마지막 프레임; `video_url`, `audio_url`은 전달하지 마십시오; 화면 비율은 첫 프레임 이미지를 따름 |

<Warning>
모든 소재 URL이 공용 네트워크에서 직접 액세스 가능한지 확인해 주십시오. 작업은 비동기로 처리되므로 요청을 제출한 HTTP 연결을 유지하며 최종 비디오를 기다리지 마십시오.
</Warning>
