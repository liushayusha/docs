<ParamField body="model" type="string" required>

<ParamField body="params" type="object" required>

  <Expandable title="params 객체 Properties">
    <ParamField body="prompt" type="string" required>
      비디오 생성용 텍스트 설명, 최대 7000자.

      주체, 장면, 카메라 움직임, 동작, 스타일, 조명, 리듬 등의 내용을 설명할 수 있습니다.
    </ParamField>

    <ParamField body="type" type="string" default="text_to_video">
      생성 유형으로, MiniMax H3가 어떤 상위 모드를 사용할지 결정합니다.

      * `text_to_video` - 텍스트-투-비디오, 프롬프트만 사용해 비디오를 생성합니다.
      * `first_last_frame` - 첫 프레임/마지막 프레임 이미지 기반 비디오 생성, 첫 프레임, 마지막 프레임 또는 첫-끝 프레임 전환으로 비디오를 생성합니다.
      * `all_reference` - 여러 참고 자료 기반 비디오 생성, 참고 이미지, 참고 비디오, 참고 오디오를 사용할 수 있습니다.
    </ParamField>

    <ParamField body="video_length" type="number" default="4">
      생성 비디오 길이, 단위는 초입니다.

      정수 `4`부터 `15`까지 지원합니다.

      <Warning>비디오 길이는 과금에 직접 영향을 미칩니다.</Warning>
    </ParamField>

    <ParamField body="quality" type="string" default="2k">
      출력 품질, 현재 고정값:

      * `2k`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      비디오 가로세로 비율입니다.

      지원되는 가로세로 비율:

      * `21:9` - 초광각
      * `16:9` - 가로형, 기본값
      * `4:3` - 표준 가로형
      * `1:1` - 정사각형
      * `3:4` - 세로형 표준
      * `9:16` - 세로형

      <Warning>`first_last_frame` 모드는 가로세로 비율을 별도로 선택할 수 없으며, 출력은 입력 이미지 비율을 따릅니다.</Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      이미지 URL.

      `type`에 따라 의미가 다릅니다:

      * `text_to_video` - 이미지를 전달할 필요가 없습니다.
      * `first_last_frame` - 첫 프레임 이미지로 사용합니다. 배열도 전달할 수 있으며, 첫 번째 이미지는 첫 프레임, 두 번째 이미지는 마지막 프레임으로 사용됩니다.
      * `all_reference` - 참고 이미지로 사용하며, 최대 9장까지 가능합니다.

      이미지 요구 사항:

      * JPG, JPEG, PNG, WEBP, HEIC, HEIF 지원
      * 단일 이미지 최대 30MB
      * 가로세로 범위 256-5760px
      * 이미지 가로세로 비율 범위 0.4-2.5

    <ParamField body="end_image_url" type="string">

    </ParamField>

      `all_reference` 모드에서만 유효합니다.

      비디오 요구 사항:

      * 단일 비디오 길이 2-15초
      * MP4, MOV 지원
      * 비디오 인코딩 H.264 또는 H.265
      * 오디오 인코딩 AAC 또는 MP3
      * 단일 비디오 최대 50MB

      * 단일 오디오 길이 2-15초

      * 단일 오디오 최대 15MB

## Pricing

MiniMax H3는 생성된 비디오의 초 수, 참조 비디오의 초 수, 추가 참조 이미지 수를 기준으로 요금이 청구됩니다.

| Billing item | Price |
| --- | --- |
| 2K 생성 비디오 | 40.15 credits / 초 |
| 참조 비디오 입력 | 40.15 credits / 초 |
| 참조 이미지 | 처음 5장은 무료, 이후에는 12.1 credits / 장 |
| 참조 오디오 | 무료 |

요금 계산식:

```
(생성된 비디오 초 수 + 참조 비디오 초 수) × 40.15 + max(참조 이미지 수 - 5, 0) × 12.1
```

예시:

* 4초 텍스트-투-비디오: `4 × 40.15 = 160.6 credits`
* 4초 출력 + 9초 참조 비디오: `(4 + 9) × 40.15 = 521.95 credits`
* 15초 출력 + 15초 참조 비디오 + 9장 참조 이미지: `30 × 40.15 + 4 × 12.1 = 1252.9 credits`

## Mode Notes

<Note>
The `text_to_video` mode will call MiniMax H3 text-to-video capabilities; the `first_last_frame` mode will call image-to-video capabilities; and the `all_reference` mode will call multi-reference asset generation capabilities.
</Note>

<Warning>
When `type` is `first_last_frame`, do not rely on the `aspect_ratio` parameter. The output aspect ratio for this mode is determined by the input image.
</Warning>
