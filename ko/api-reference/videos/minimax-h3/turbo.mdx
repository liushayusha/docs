<ParamField body="params" type="object" required>

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      비디오 생성을 위한 텍스트 설명입니다.

      피사체, 장면, 카메라 무빙, 동작, 스타일, 조명, 템포 등의 내용을 설명할 수 있습니다.

      참조 소스를 사용할 경우, 프롬프트에서 '이미지 1 / 오디오 1'과 같이 순서대로 업로드한 콘텐츠를 지정할 수 있습니다.
    </ParamField>

    <ParamField body="video_length" type="number" default="5">
      생성할 비디오 길이(초 단위)입니다.

      지원 정수: `5` ~ `15`.
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      출력 해상도:

      * `480p`
      * `720p` - 기본값
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      비디오 화면 비율입니다.

      지원되는 화면 비율:

      * `21:9` - 울트라 와이드
      * `16:9` - 가로 화면, 기본값
      * `4:3` - 표준 가로 화면
      * `3:2` - 사진 가로 화면
      * `1:1` - 정사각형
      * `3:4` - 표준 세로 화면
      * `2:3` - 사진 세로 화면
      * `9:16` - 세로 화면
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      참조 이미지 URL, 선택 사항. 최대 9장.

      이미지를 전달하지 않으면 텍스트 투 비디오로 동작하며, 이미지를 전달하면 피사체, 스타일 또는 구도를 유도하는 참조 이미지로 사용됩니다.

      이미지 요구사항:

      * JPEG, PNG, WEBP 지원
      * 이미지당 최대 20MB
      * URL은 공개적으로 접근 가능해야 함
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      참조 오디오 URL, 선택 사항. 최대 3개.

      오디오 요구사항:

      * MP3, WAV 지원
      * 개별 오디오 최대 20MB
      * 개별 오디오 길이는 15초를 초과할 수 없음
      * URL은 공개적으로 접근 가능해야 함
    </ParamField>
  </Expandable>
</ParamField>

## Query Task

MiniMax H3 Turbo는 비동기 비디오 생성 모델입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하세요.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달된 요청자 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "minimax_h3_turbo_task_123456"
  }'
```

조회가 성공하고 완료되면 응답의 `output` 필드에 생성 결과가 포함됩니다. 비디오 URL은 `output.list[].video`에 있습니다.
