## Body

<ParamField body="model" type="string" required>
  모델 이름. 다음 중 하나:

  * `gemini_omni_flash_ext`
  * `gemini_omni_1_1_flash_ext`

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      동영상 생성을 위한 텍스트 설명. 필수.
    </ParamField>

    <ParamField body="video_length" type="string" default="6">
      생성 동영상 길이(초). 다음 문자열만 허용됩니다:

      * `"4"`
      * `"6"` - 기본값
      * `"8"`
      * `"10"`

      참조 동영상이 있으면 이 필드를 보내지 마세요. 출력 길이는 업로드된 동영상을 따릅니다.

      <Warning>
        `3`, `5`, `7`, `9` 또는 다른 초 수를 보내지 마세요. 열거 검증은 문자열을 요구하므로 숫자 `6`이 아니라 `"6"`을 보내세요.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      출력 해상도:

      * `720p` - 기본값
      * `1080p`
      * `4K`

      720p와 1080p는 가격이 같고, 4K는 더 비쌉니다.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      동영상 화면비:

      * `16:9` - 가로, 기본값
      * `9:16` - 세로
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      참조 이미지 URL. 공용 인터넷에서 직접 접근 가능해야 합니다. 단일 문자열도 가능합니다. 생략하면 텍스트 생성입니다.

      * 최대 7장, **2장 허용**
      * 짧은 변 300px 이상, 장당 10MB 이하

      참조 동영상과 함께 보낼 때 이미지 수 + 2는 ≤ 7이어야 합니다.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      참조 동영상 URL. 선택, 최대 1개. 단일 문자열도 가능합니다. 참조 이미지와 함께 보낼 수 있습니다.

      동영상 요구사항:

      * 형식 MP4, MOV
      * 길이 10초 이하
      * 100MB 이하
      * 짧은 변 300px 이상

      참조 동영상이 있으면 `video_length`를 보내지 마세요. 출력 길이는 업로드된 동영상을 따르며 최대 10초입니다. 참조 동영상은 7슬롯 할당량에서 2를 차지합니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출자 작업 ID.

  사용자 정의 작업 식별자. 필수. 영문, 숫자, 밑줄, 하이픈만 허용되며 길이는 1-64자입니다. 이후 이 ID로 작업 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Query Task

두 모델 모두 비동기 동영상 생성입니다. 제출 후 `out_task_id`로 상태를 조회하세요. [작업 상태 조회](/ko/api-reference/tasks/status)도 참고하세요.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달한 호출자 작업 ID.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_ext_t2v_123456"
  }'
```

조회가 성공하고 완료되면 응답의 `output` 배열에 생성된 동영상이 포함되며, 각 요소에 `video` 필드가 있습니다.

## 파라미터 대조

| 입력 | `image_url` | `video_url` | 길이 |
|---|---|---|---|
| 텍스트 생성 | 보내지 않거나 빈 배열 | 보내지 않음 | `video_length` `"4"` / `"6"` / `"8"` / `"10"` |
| 참조 이미지 | 1–7장 (2장 포함) | 보내지 않음 | 위와 같음 |
| 참조 동영상 | 보내지 않거나 빈 배열 | 1개, 최대 10초 | `video_length`를 보내지 않고 원본 동영상을 따름 |
| 이미지 + 동영상 | 최대 5장 (이미지 수 + 2 ≤ 7) | 1개, 최대 10초 | `video_length`를 보내지 않고 원본 동영상을 따름 |
