<Note>
Gemini Omni Flash Ext의 AIReiter 내 모델명은 `gemini_omni_flash_ext`입니다.

이것은 이 사이트의 공식 Omni Flash SKU(`gemini_omni_flash_preview`, 720p 출력)가 아닙니다. 이 페이지의 SKU는 720p / 1080p / 4K를 출력하며, 길이는 4, 6, 8, 10초만 지원합니다.
</Note>

## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정 값:

  * `gemini_omni_flash_ext`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      비디오 생성용 텍스트 설명. 필수.
    </ParamField>

    <ParamField body="type" type="string" default="frame">
      생성 유형입니다. 아래 두 값만 허용됩니다:

      * `frame` - First Frame. 프롬프트에 이미지 0장 또는 1장을 추가합니다. 참고 비디오는 전달할 수 없습니다.
      * `reference` - Reference. 프롬프트에 이미지 0장, 1장 또는 3장을 추가할 수 있으며, 선택적으로 참고 비디오 1개를 전달할 수 있습니다.

      이미지를 전달하지 않으면 텍스트-투-비디오이며, 두 유형 모두 사용할 수 있습니다.

      <Warning>
        `type=text`를 전달하지 마세요. `frame`은 `video_url`과 함께 전달할 수 없습니다.
      </Warning>
    </ParamField>

    <ParamField body="video_length" type="string" default="6">
      생성되는 비디오 길이이며, 단위는 초입니다. 문자열만 허용됩니다:

      * `"4"`
      * `"6"` - 기본값
      * `"8"`
      * `"10"`

      참고 비디오가 있을 때는 이 필드를 전달하지 마세요. 출력 길이는 업로드한 비디오를 따릅니다.

      <Warning>
        `3`, `5`, `7`, `9` 또는 그 밖의 초 단위를 전달하지 마세요. 열거형 검증은 문자열을 요구하므로, 숫자 `6`이 아니라 `"6"`을 전달하세요.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      출력 해상도:

      * `720p` - 기본값
      * `1080p`
      * `4K`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      비디오 화면 비율:

      * `16:9` - 가로형, 기본값
      * `9:16` - 세로형
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      이미지 URL이며, 공용 네트워크에서 직접 접근 가능해야 합니다. 단일 문자열로도 전달할 수 있습니다.

      * `frame` - 0장 또는 1장을 선택적으로 전달하며, 첫 프레임으로 사용됩니다. 전달하지 않으면 텍스트 생성입니다.
      * `reference` - 0장, 1장 또는 3장을 선택적으로 전달합니다. 전달하지 않으면 텍스트 생성입니다.

      이미지 요구 사항: 짧은 변의 길이는 300px 이상이어야 하며, 단일 이미지는 10MB를 초과할 수 없습니다.

      <Warning>
        2장 이미지는 지원하지 않습니다. `reference`에 2장을 전달하면 `Invalid image_url count. Allowed: [1, 3]`가 반환됩니다. 4장 이상도 전달하지 마세요.
      </Warning>
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      참고 비디오 URL입니다. `type=reference`일 때만 유효하며, 최대 1개까지 가능합니다. 단일 문자열로도 전달할 수 있습니다.

      비디오 요구 사항:

      * 형식: MP4, MOV
      * 길이: 10초 이하
      * 크기: 100MB 이하
      * 짧은 변의 길이: 300px 이상

      참고 비디오를 전달할 때는 `video_length`를 전달하지 마세요. 출력 길이는 업로드한 비디오를 따르며, 최대 10초입니다.

      <Warning>`type=frame`에서는 이 매개변수를 전달하지 마세요. 인터페이스가 즉시 거부합니다.</Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  요청 측 작업 ID.

  사용자가 정의한 작업 식별자이며, 필수입니다. 문자, 숫자, 밑줄, 하이픈만 지원하며 길이는 1-64자입니다. 이후 이 ID를 사용해 작업 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Query Task

Gemini Omni Flash Ext는 비동기 비디오 생성 모델입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하세요. 또한 [작업 상태 가져오기](/en/api-reference/tasks/status)도 참조하세요.

<ParamField body="out_task_id" type="string" required>
  작업을 제출할 때 전달한 발신 측 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_ext_t2v_123456"
  }'
```

작업이 성공적으로 조회되고 완료되면, 응답의 `output` 배열에 생성된 비디오가 포함되며, 각 요소에는 `video` 필드가 있습니다.

## 모드 파라미터 대응표

| `type` | `image_url` | `video_url` | 기간 |
|---|---|---|---|
| `frame`, 이미지 미전송 | 보내지 않음, 또는 빈 배열 | 보내지 않음 | `video_length` `"4"` / `"6"` / `"8"` / `"10"` |
| `frame` | 이미지 1장 | 보내지 않음 | 위와 같음 |
| `reference`, 이미지 미전송 | 보내지 않음, 또는 빈 배열 | 보내지 않음 | 위와 같음 |
| `reference` | 이미지 1장 또는 3장 | 보내지 않음 | 위와 같음 |
| `reference` | 0장, 1장 또는 3장 | 1개 클립, 최대 10초 | `video_length`를 보내지 않음, 소스 영상을 따름 |
