## Body

<ParamField body="model" type="string" required>
  모델 이름, 둘 중 하나를 선택합니다:

  * `gemini_omni_flash_ext`
  * `gemini_omni_1_1_flash_ext`

<ParamField body="params" type="object" required>
  모델 파라미터 객체입니다.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      비디오 생성을 위한 텍스트 프롬프트입니다. 필수 항목입니다.
    </ParamField>

    <ParamField body="video_length" type="string" default="6">
      생성할 비디오 길이(단위: 초)입니다. 문자열만 지원합니다:

      * `"4"`
      * `"6"` - 기본값
      * `"8"`
      * `"10"`

      참조 비디오가 있는 경우 이 필드를 전달하지 마십시오. 출력 길이는 업로드된 비디오를 따릅니다.

      <Warning>
        `3`, `5`, `7`, `9` 또는 기타 초 단위를 전달하지 마십시오. 열거형(Enum) 유효성 검사에서 문자열을 요구하므로 숫자 `6`이 아닌 `"6"`을 전달하십시오.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      출력 해상도:

      * `720p` - 기본값
      * `1080p`
      * `4K`

      720p와 1080p는 가격이 동일하며, 4K는 더 비쌉니다.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      비디오 화면비:

      * `16:9` - 가로 모드, 기본값
      * `9:16` - 세로 모드
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      참조 이미지 URL로, 공용 네트워크에서 직접 액세스할 수 있어야 합니다. 단일 문자열로 전달할 수도 있습니다. 전달하지 않으면 텍스트 투 비디오로 동작합니다.

      * 최대 7장, **2장 허용**
      * 짧은 변 기준 300px 이상, 단일 이미지당 10MB 이하

      참조 비디오와 함께 전달하는 경우, 이미지 수 + 2는 반드시 ≤ 7이어야 합니다.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      참조 비디오 URL, 선택 사항이며 최대 1개까지 가능합니다. 단일 문자열로 전달할 수도 있습니다. 참조 이미지와 함께 전달할 수 있습니다.

      비디오 요구 사양:

      * MP4, MOV 형식
      * 재생 시간 10초 이하
      * 100MB 이하
      * 짧은 변 기준 300px 이상

      참조 비디오를 전달할 때는 `video_length`를 전달하지 마십시오. 출력 길이는 업로드된 비디오를 따르며 최대 10초입니다. 참조 비디오는 7개 슬롯 할당량 중 2개 슬롯을 차지합니다.
    </ParamField>
  </Expandable>
</ParamField>

  사용자 정의 작업 식별자이며 필수 항목입니다. 영문자, 숫자, 밑줄(_), 하이픈(-)만 지원하며 길이는 1-64자입니다. 이후 이 ID를 사용하여 작업 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Query Task

두 모델 모두 비동기 비디오 생성 방식입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하세요. [작업 상태 조회](/ko/api-reference/tasks/status)도 참조할 수 있습니다.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달된 요청자 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_ext_t2v_123456"
  }'
```

조회가 성공하여 완료되면 응답의 `output` 배열에 생성된 비디오가 포함되며, 요소에는 `video` 필드가 포함됩니다.

## 参数对照

| 입력 | `image_url` | `video_url` | 재생 시간 |
|---|---|---|---|
| 텍스트 생성 | 전달하지 않거나 빈 배열 | 전달하지 않음 | `video_length` `"4"` / `"6"` / `"8"` / `"10"` |
| 참조 이미지 | 1~7장(2장 포함) | 전달하지 않음 | 동일 |
| 참조 비디오 | 전달하지 않거나 빈 배열 | 1개, 최대 10초 | `video_length`를 전달하지 않음, 원본 영상을 따름 |
| 이미지 + 비디오 | 최대 5장(이미지 수 + 2 ≤ 7) | 1개, 최대 10초 | `video_length`를 전달하지 않음, 원본 영상을 따름 |
