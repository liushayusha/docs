</Note>

## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정 사용:

  * `flux_3_video`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="mode" type="string" default="t2v">
      생성 모드:

      * `t2v` - 텍스트에서 비디오 생성, 프롬프트만 사용해 비디오를 생성
      * `i2v` - 순서가 있는 키 프레임, 1~10장의 이미지로 비디오 콘텐츠와 전환을 제어
      * `v2v` - 비디오 연장, 원본 비디오에서 이어서 동적 콘텐츠를 생성
    </ParamField>

    <ParamField body="prompt" type="string" required>
      비디오 생성용 텍스트 설명.

      주제, 장면, 동작, 카메라 움직임, 시각 스타일, 대사 및 환경음을 설명하는 것을 권장합니다.
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      순서가 있는 키 프레임 이미지 URL, `i2v` 모드에서만 사용합니다.

      * 공개적으로 접근 가능한 이미지 1~10장을 지원합니다
      * 이미지 순서가 곧 재생 순서입니다
      * 첫 번째와 마지막 이미지는 비디오의 시작 및 종료 장면을 정의하는 데 사용할 수 있습니다

      <Warning>`i2v` 모드에서는 최소 한 장의 이미지를 제공해야 합니다. 다른 모드에서는 이 매개변수를 전달하지 마세요.</Warning>
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      원본 비디오 URL, `v2v` 모드에서만 사용합니다.

      현재는 공개적으로 접근 가능한 MP4 비디오 하나만 지원합니다. 배열 형식으로 전달하면 첫 번째 URL만 사용합니다.

      <Warning>`v2v` 모드에서는 원본 비디오를 제공해야 합니다. 다른 모드에서는 이 매개변수를 전달하지 마세요.</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      출력 비디오 길이, 단위는 초입니다.

      `5`부터 `20`까지의 정수를 지원합니다.
    </ParamField>

    <ParamField body="resolution" type="string" default="hd">
      출력 품질:

      * `hd` - HD
      * `fhd` - FHD

      <Note>FHD는 HD보다 픽셀 수가 더 많으며, 구체적인 출력 크기는 화면 비율에 따라 달라집니다.</Note>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      비디오 화면 비율:

      * `auto` - 자동
      * `21:9` - 초광각
      * `2:1` - 와이드스크린
      * `16:9` - 가로형
      * `4:3` - 표준 가로형
      * `1:1` - 정사각형
      * `3:4` - 세로형 표준
      * `9:16` - 세로형
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      비디오와 동기화된 기본 오디오를 생성할지 여부입니다.

      대사, 환경음, 효과음을 포함할 수 있습니다.
    </ParamField>

    <ParamField body="safety_tolerance" type="integer" default="2">
      콘텐츠 안전 허용 수준, 정수 `0`부터 `4`까지 지원합니다.

      * `0` - 가장 엄격한 필터링
      * `4` - 가장 완화된 설정
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  요청 측 작업 ID.

  호출 측에서 생성하며 고유함을 보장해야 하고, 이후 이 ID로 작업 상태와 결과를 조회합니다.
</ParamField>

## Query Task

FLUX 3 Video는 비동기 처리를 사용합니다. 제출이 성공하면 동일한 `out_task_id`로 작업을 조회하세요:

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "flux_3_video_task_123456"
    }'
  ```
</RequestExample>

작업이 완료되면 응답의 `output` 배열에 생성된 비디오 URL이 포함됩니다. 전체 필드는 [작업 상태 가져오기](/ko/api-reference/tasks/status)를 참조하세요.

## Mode Rules

| mode | 필수 소재 | 소재 제한 |
| --- | --- | --- |
| `t2v` | 없음 | `image_url` 또는 `video_url`을 전송하지 마세요 |
| `i2v` | `image_url` | 순서가 지정된 이미지 1-10장 |
| `v2v` | `video_url` | 최대 원본 비디오 1개 |

<Warning>
이미지와 비디오 URL은 공용 네트워크에서 직접 접근 가능해야 합니다. 작업은 비동기 처리이므로, 최종 비디오를 기다리기 위해 제출 요청의 HTTP 연결을 사용하지 마세요.
</Warning>
