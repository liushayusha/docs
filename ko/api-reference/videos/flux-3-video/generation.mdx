<Note>
AIReiter에서 FLUX 3 Video의 모델 이름은 `flux_3_video`입니다. 현재 텍스트-투-비디오, 순서 있는 키프레임, 비디오 이어쓰기 세 가지 모드를 지원합니다.
</Note>


## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정값:

  * `flux_3_video`
</ParamField>

<ParamField body="params" type="object" required>
  모델 Parameters 객체.

  <Expandable title="params 객체 Properties">
    <ParamField body="mode" type="string" default="t2v">
      생성 모드:

      * `t2v` - 텍스트로 비디오 생성, 프롬프트만 사용해 비디오를 생성
      * `i2v` - 정렬된 키프레임, 1-10장의 이미지를 사용해 비디오 콘텐츠와 전환을 제어
      * `v2v` - 비디오 이어서 생성, 하나의 원본 비디오에서 동적 콘텐츠를 계속 생성
    </ParamField>

    <ParamField body="prompt" type="string" required>
      비디오 생성을 위한 텍스트 설명.

      주체, 장면, 동작, 카메라 움직임, 시각 스타일, 대사 및 환경음을 설명하는 것을 권장합니다.
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      정렬된 키프레임 이미지 URL, `i2v` 모드에서만 사용됩니다.

      * 공개적으로 접근 가능한 이미지 1-10장을 지원합니다
      * 이미지 순서는 재생 순서와 동일합니다
      * 첫 번째와 마지막 이미지는 비디오의 시작 및 종료 장면을 정의하는 데 사용할 수 있습니다

      <Warning>`i2v` 모드에서는 최소 한 장의 이미지를 제공해야 합니다. 다른 모드에서는 이 Parameters를 전달하지 마세요.</Warning>
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      원본 비디오 URL, `v2v` 모드에서만 사용됩니다.

      현재는 공개적으로 접근 가능한 MP4 비디오 하나만 지원합니다. 배열 형식으로 전달하면 첫 번째 URL만 사용됩니다.

      <Warning>`v2v` 모드에서는 원본 비디오를 제공해야 합니다. 다른 모드에서는 이 Parameters를 전달하지 마세요.</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      출력 비디오 길이, 단위는 초입니다.

      `5`부터 `20`까지의 정수를 지원합니다.
    </ParamField>

    <ParamField body="resolution" type="string" default="hd">
      출력 품질:

      * `hd` - HD
      * `fhd` - FHD

      <Note>FHD는 HD보다 픽셀 수가 더 높으며, 구체적인 출력 크기는 종횡비에 따라 달라집니다.</Note>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      비디오 종횡비:

      * `auto` - 자동
      * `21:9` - 울트라와이드
      * `2:1` - 와이드스크린
      * `16:9` - 가로형
      * `4:3` - 표준 가로형
      * `1:1` - 정사각형
      * `3:4` - 세로형 표준
      * `9:16` - 세로형
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      비디오와 동기화된 기본 오디오를 생성할지 여부입니다.

      대사, 환경음 및 음향 효과를 포함할 수 있습니다.
    </ParamField>

    <ParamField body="safety_tolerance" type="integer" default="2">
      콘텐츠 안전 허용도, 정수 `0`부터 `4`까지 지원합니다.

      * `0` - 가장 엄격한 필터링
      * `4` - 가장 완화된 설정
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  발신자 작업 ID.

  호출 측에서 생성하고 고유성을 보장해야 하며, 이후 이 ID를 사용해 작업 상태와 결과를 조회합니다.
</ParamField>

<ResponseField name="out_task_id" type="string">

<ResponseField name="status" type="string">

## 작업 조회

FLUX 3 Video는 비동기 처리를 사용합니다. 제출이 성공하면 동일한 `out_task_id`를 사용하여 작업을 조회하세요:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flux_3_video_task_123456"
  }'
```

작업이 완료되면 응답의 `output` 배열에 생성된 비디오 URL이 포함됩니다. 전체 필드는 [작업 상태 가져오기](/en/api-reference/tasks/status)를 참조하세요.

## Mode Rules

| mode | Required Materials | Material Limitations |
| --- | --- | --- |
| `t2v` | None | Do not pass `image_url` or `video_url` |
| `i2v` | `image_url` | 1-10 ordered images |
| `v2v` | `video_url` | Up to one source video |

<Warning>
Please ensure that the image and video URLs are directly accessible from the public internet. The task is processed asynchronously, so do not use the HTTP connection from the submission request to wait for the final video.
</Warning>
