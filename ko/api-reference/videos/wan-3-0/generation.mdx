## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정값:

</ParamField>

<ParamField body="params" type="object" required>
  모델 Parameters object.

  <Expandable title="params object properties">
    <ParamField body="prompt" type="string">
      비디오 생성용 텍스트 설명.

      `all_reference`는 프롬프트를 입력하는 것이 좋으며, 최소한 이미지, 비디오 또는 오디오 reference 중 하나를 제공해야 합니다. `first_last_frame` 및 `file_web`에서는 프롬프트가 optional이며, 입력하면 제어가 더 정확해집니다.

      reference 소재를 사용할 때는 프롬프트에서 「이미지1 / 비디오1 / 오디오1」처럼 유형과 순서에 따라 업로드된 내용을 지칭할 수 있습니다.
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      생성 모드로, 어떤 비디오 생성 방식을 사용할지 결정합니다. 하나의 Request에서는 세 가지 모드를 혼용할 수 없습니다:

      * `all_reference` - 텍스트/참조, 프롬프트만 사용할 수도 있고 이미지, 비디오, 오디오를 추가할 수도 있습니다
      * `first_last_frame` - 첫/끝 프레임, 필수 첫 프레임과 optional 끝 프레임을 사용합니다
      * `file_web` - 파일/웹페이지, 문서 URL 또는 공개 웹페이지 URL을 전달합니다

      <Warning>
        첫/끝 프레임은 reference 이미지, reference 비디오, reference 오디오, 문서 또는 웹페이지와 같은 Request에 함께 포함될 수 없습니다. `file_url`과 `link_url`도 동시에 전달할 수 없습니다.
      </Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      생성되는 비디오 길이로, 단위는 초입니다.

      정수 `2`부터 `30`까지 지원합니다. reference 비디오가 있는 경우, 입력된 초 수와 출력 초 수의 합이 30을 초과할 수 없습니다.
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      출력 해상도:

      * `480p`
      * `720p` - default
      * `1080p`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      비디오 화면 비율.

      지원되는 화면 비율:

      * `auto` - reference 소재 또는 프롬프트를 따름, default
      * `16:9` - 가로형
      * `9:16` - 세로형
      * `4:3` - 표준 가로형
      * `3:4` - 세로형 표준
      * `1:1` - 정사각형
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      원본 오디오 트랙을 생성할지 여부입니다.

      * `true` - 오디오 트랙 생성, default
      * `false` - 오디오 트랙 없는 비디오 출력
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      이미지 URL로, 반드시 public network에서 직접 접근할 수 있어야 합니다.

      `type`에 따라 의미가 다릅니다:

      * `all_reference` - optional reference image, 최대 10장
      * `first_last_frame` - 첫 번째는 첫 프레임(필수), 두 번째는 끝 프레임(optional)
      * `file_web` - 전달하지 마세요

      이미지 요구사항:

      * 짧은 변의 길이는 240px 이상, 긴 변은 8000px 이하
      * 단일 파일은 20MB 이하
    </ParamField>

    <ParamField body="end_image_url" type="string">
      끝 프레임 이미지 URL.

      `first_last_frame` 모드에서만 유효합니다. 끝 프레임을 `image_url` 배열의 두 번째 이미지로 전달할 수도 있습니다.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      reference 비디오 URL.

      `all_reference` 모드에서만 유효하며, 최대 5개 구간까지 지원합니다.

      비디오 요구사항:

      * 형식: MP4, MOV
      * 각 구간 1-15초, 합계는 15초 이하
      * 각 구간 100MB 이하
      * 짧은 변의 길이는 240px 이상, 긴 변은 4096px 이하

      reference 비디오 길이는 과금 시간에 포함됩니다: 과금 초 = 완성본 초 + reference 비디오 초(올림).

      <Warning>`first_last_frame` 및 `file_web`에서는 이 Parameters를 전달하지 마세요. URL이 public하게 접근 가능하고, 비디오 길이 metadata를 읽을 수 있는지 확인하세요.</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      reference 오디오 URL.

      `all_reference` 모드에서만 유효하며, 최대 5개 구간까지 지원합니다.

      오디오 요구사항:

      * 형식: WAV, MP3
      * 각 구간 1-15초, 합계는 15초 이하
      * 각 구간 15MB 이하

      reference 오디오는 과금 시간에 포함되지 않습니다.

      <Warning>`first_last_frame` 및 `file_web`에서는 이 Parameters를 전달하지 마세요.</Warning>
    </ParamField>

    <ParamField body="file_url" type="string">
      문서 URL.

      `file_web` 모드에서만 유효하며, 반드시 public network에서 직접 접근할 수 있어야 합니다.

      DOC(X), XLS(X), PPT(X), PDF, TXT, KEY, Pages, Numbers, MD를 지원합니다. 100MB 이하, 50페이지 이하이어야 합니다. 문서는 과금 시간에 포함되지 않습니다.

      <Warning>`link_url`과 상호 배타적이므로, 동시에 전달하지 마세요.</Warning>

      <Warning>`file_url`과 상호 배타적이므로, 동시에 전달하지 마세요.</Warning>
    </ParamField>

    <ParamField body="watermark" type="boolean" default="false">
      완성본에 워터마크를 추가할지 여부입니다. 기본값은 `false`입니다.

## Query Task

Wan 3.0은 비동기 비디오 생성 모델입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하세요.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달한 발신자 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "wan3_0_t2v_123456"
  }'
```

조회가 성공하고 완료되면, 응답의 `output` 배열에는 생성된 비디오가 포함되며, 각 요소에는 `video` 필드가 있습니다.

## Mode Notes

<Note>
`all_reference`는 순수 프롬프트만으로 생성할 수 있으며, 이미지, 비디오, 오디오 참조를 추가할 수도 있습니다. `first_last_frame`는 첫 프레임과 선택적 마지막 프레임을 사용합니다. `file_web`는 `file_url` 또는 `link_url`을 사용하여 문서나 웹페이지를 비디오로 변환합니다.
</Note>

<Warning>
`type`이 `first_last_frame`일 때는 `video_url`, `audio_url`, `file_url` 또는 `link_url`을 동시에 전달하지 마세요. `type`이 `file_web`일 때는 `file_url`과 `link_url` 중 하나만 전달할 수 있습니다.
</Warning>
