<Note>
재생 시간은 10초로 고정되며, 해상도는 720p로 고정되고, 완성된 영상에는 생성된 오디오 트랙이 기본으로 포함됩니다. `video_length` 및 `resolution`은 전달하지 않아도 됩니다.

참조 비디오, 참조 오디오, 첫 프레임 및 마지막 프레임, `seed`, `negative_prompt`는 지원하지 않으며, 오디오 트랙을 끌 수도 없습니다.
</Note>

## Body

<ParamField body="model" type="string" required>
  모델 이름이며, `muse_video_ext`로 고정됩니다.
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체입니다.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      비디오 생성을 위한 텍스트 설명으로, 중국어와 영어를 지원합니다. 필수 입력값이며, 앞뒤 공백을 제거한 후 비어 있을 수 없습니다.

      참조 이미지가 있는 경우, 프롬프트에서 `Picture 1`, `Picture 2`를 사용하여 1번째, 2번째 이미지를 지정할 수 있습니다.

      여러 샷이 있는 경우 각 샷을 개별 단락으로 작성하고 전환 위치를 타임스탬프로 표시합니다. 예:

      ```
      [Shot 1] 거실 전경, 여성이 옷걸이에 걸린 티셔츠를 들고 있다...
      [Shot 2] At 00:04.000, 카메라가 흰 벽 앞으로 전환되고, 남성이 이 티셔츠를 입는다...
      ```

      <Warning>
        프롬프트에 실제 브랜드, 스포츠팀 또는 로고 이름이 포함된 경우 콘텐츠 검토를 통과하지 못해 작업이 실패할 수 있습니다. 이름이 없는 설명으로 변경한 후 다시 시도해 주세요.
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      참조 이미지 URL로, 공용 네트워크에서 직접 접근할 수 있어야 합니다. 단일 문자열로 전달할 수도 있습니다. 전달하지 않으면 텍스트 기반 비디오 생성이 진행됩니다.

      * 최대 9장
      * 모든 이미지의 원본 크기 합계 11 MiB 이하
      * PNG, JPEG, WebP 권장

      로컬 경로 및 `blob:` 주소는 지원되지 않습니다.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      비디오 화면비:

      * `auto` - 기본값. 참조 이미지가 있는 경우 참조 이미지의 구도를 따르며, 순수 텍스트인 경우 `16:9`
      * `1:1`
      * `16:9`
      * `9:16`
      * `4:3`
      * `3:4`
      * `3:2`
      * `2:3`
    </ParamField>

    <ParamField body="video_length" type="string" default="10">
      비디오 길이이며, `"10"`으로 고정됩니다. 전달하지 않아도 됩니다.
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      출력 해상도이며, `720p`로 고정됩니다. 전달하지 않아도 됩니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  요청자 작업 ID입니다.

  사용자 정의 작업 식별자이며 필수 항목입니다. 영문자, 숫자, 밑줄(_), 하이픈(-)만 지원하며 길이는 1~64자입니다. 이후 이 ID를 사용하여 작업 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Query Task

본 모델은 비동기 비디오 생성 모델입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하세요. [작업 상태 조회](/en/api-reference/tasks/status)도 참조할 수 있습니다.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달한 요청자 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "muse_ext_t2v_123456"
  }'
```

조회가 성공하고 완료되면 응답의 `output` 배열에 생성된 비디오가 포함되며, 요소에는 `video` 필드가 포함됩니다.

생성 소요 시간은 입력에 따라 다릅니다. 텍스트만 있는 경우 일반적으로 약 1~2분 정도 소요되며, 참조 이미지가 많을 경우 몇 분 정도 걸릴 수 있으므로 중복 제출하지 마시고 계속 폴링해 주세요.

## 使用说明

| 입력 | `image_url` | `aspect_ratio` |
|---|---|---|
| 텍스트 투 비디오 | 전달하지 않거나 빈 배열 | 전달하지 않으면 기본값 `16:9`, 지정도 가능 |
| 이미지 투 비디오 | 1~9장, 합계 11 MiB 이하 | `auto`로 참조 이미지를 따르도록 권장하거나 지정 |

멀티샷 프롬프트의 효과:

* 전환 시점의 정확성: 프롬프트에 작성한 시점과 실제 전환 오차가 1초 이내입니다.
* 상품의 텍스트, 프린트 및 로고가 각 샷 간에 일관되게 유지됩니다.
* 샷 전환 후 인물이 참조 이미지와 달라질 수 있습니다. 동일 인물의 식별성을 유지해야 하는 경우, 전환 시점을 최대 2개로 제한하고 각 샷마다 외모 묘사를 반복하여 작성하는 것을 권장합니다.
