<Note>
HappyHorse 1.1의 AIReiter 내 모델 이름은 `happyhorse_1_1`이며, 현재 다중 참조 이미지 비디오 생성 워크플로우를 제공합니다.
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>


## Body

<ParamField body="model" type="string" required>
  모델 이름으로, `happyhorse_1_1`을 고정으로 사용합니다.
</ParamField>

<ParamField body="params" type="object" required>
  모델 매개변수 객체입니다.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      비디오 내용, 동작 및 시각 스타일 설명입니다.

      프롬프트에서 `[Image 1]`, `[Image 2]` 등의 표식을 사용하여 `image_url` 배열의 동일한 위치에 있는 이미지를 가리키고, 이미지의 구체적인 객체를 설명하세요. 예: `[Image 1]`에서 빨간색 치파오를 입은 여자가 `[Image 2]`의 접이식 부채를 엽니다.

      최대 2500개의 중국어 문자 또는 5000개의 비중국어 문자를 지원하며, 초과분은 잘립니다.
    </ParamField>

    <ParamField body="image_url" type="string | string[]" required>
      참고 이미지 URL로, 1-9장을 지원하며 이미지 순서는 프롬프트의 `[Image N]` 표식과 일치해야 합니다.

      이미지 요구 사항:

      * JPEG, JPG, PNG, WEBP 지원
      * 짧은 변의 길이는 400px 이상이어야 하며, 720p 이상 해상도 사용을 권장합니다
      * 단일 이미지는 10MB를 초과할 수 없습니다
      * URL은 공용 네트워크에서 직접 접근 가능해야 합니다
    </ParamField>

    <ParamField body="resolution" type="string" default="1080p">
      출력 해상도: `720p` 또는 `1080p`.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      출력 비디오의 화면 비율입니다.

      지원: `16:9`, `9:16`, `3:4`, `4:3`, `4:5`, `5:4`, `1:1`, `9:21`, `21:9`.
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      출력 비디오 길이로, 단위는 초입니다. 3-15 사이의 정수를 지원합니다.
    </ParamField>

    <ParamField body="seed" type="integer" default="0">
      랜덤 시드로, 범위는 0-2147483647입니다. `0`을 전달하거나 생략하면 랜덤 시드를 사용합니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출 측에서 생성한 고유 작업 ID로, 이후 이 ID를 사용해 작업 상태와 결과를 조회합니다.

  영문자, 숫자, 밑줄 및 하이픈만 지원하며, 길이는 1-64자입니다.
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">

</ResponseField>

<ResponseField name="status" type="string">
  초기 상태이며, 일반적으로 `pending`입니다.
</ResponseField>

<ResponseField name="created_at" type="string">

## Query Task

작업 제출이 성공한 후, 동일한 `out_task_id`를 통해 상태를 조회합니다. 작업 상태에는 `pending`, `processing`, `completed`, `failed`가 포함됩니다. 완료되면 `output` 배열에 비디오 결과가 포함됩니다.

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "happyhorse_1_1_task_123456"
  }'
```
