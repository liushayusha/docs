## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정 사용:

  * `flux_3_max`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체입니다.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      동영상 콘텐츠 설명이며, 모든 모드에서 필수입니다.

      화면, 동작, 카메라 워크, 사운드를 함께 설명하는 것을 권장합니다. 모델은 생성 전에 프롬프트를 자동으로 이해하고 확장합니다(확장 강도는 `reasoning_level` 참조).
    </ParamField>

    <ParamField body="type" type="string" default="text">
      생성 모드:

      * `text` - 텍스트 투 비디오, 기본값. 프롬프트만 사용하며 전달된 이미지는 무시됩니다
      * `frame` - 시작/마지막 프레임. `image_url[0]`을 시작 프레임(필수), `image_url[1]`을 마지막 프레임(선택 사항)으로 사용합니다
      * `keyframes` - 키프레임. 최대 10장의 이미지를 순서대로 전달하여 동영상 타임라인에 균등하게 배치하며, 동영상이 각 이미지를 순서대로 거쳐갑니다

      <Warning>
        `frame` 및 `keyframes` 모드는 최소 1장의 이미지가 필요합니다. 이미지를 전달하지 않으면 `text` 모드로 생성됩니다.
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      이미지 URL이며, 공용 네트워크에서 직접 접근할 수 있어야 합니다. `text` 모드에서는 전달할 필요가 없습니다.

      * `frame` - 1~2장: 첫 번째 이미지는 시작 프레임, 두 번째 이미지(선택 사항)는 마지막 프레임
      * `keyframes` - 1~10장, 업로드 순서에 따라 첫 번째 프레임부터 마지막 프레임까지 균등하게 배치

      이미지 요구 사항:

      * 형식: PNG, JPEG, WEBP
      * 장당 20MB 이하
    </ParamField>

    <ParamField body="end_image_url" type="string">
      마지막 프레임 이미지 URL이며, `frame` 모드에서만 유효합니다. `image_url`의 두 번째 이미지로 직접 전달할 수도 있으며, 둘 다 전달할 경우 `end_image_url`이 우선 적용됩니다.
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      생성할 동영상 길이(초 단위).

      지원 정수: `5`~`20`.
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      출력 해상도(24 fps):

      * `720p` - 기본값
      * `1080p`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      동영상 가로세로 비율:

      * `auto` - 기본값. `text` 모드에서는 16:9, 이미지가 있는 경우 첫 번째 이미지를 따름
      * `16:9` - 가로 화면
      * `9:16` - 세로 화면
      * `1:1` - 정사각형
      * `4:3` - 표준 가로 화면
      * `3:4` - 표준 세로 화면
      * `21:9` - 울트라와이드 화면
    </ParamField>

    <ParamField body="reasoning_level" type="string" default="high">
      프롬프트 추론 강도로, 모델이 생성 전에 프롬프트를 이해하고 확장하는 수준입니다:

      * `high` - 기본값. 확장이 더 풍부하고 효과가 좋으나 생성이 더 느림
      * `low` - 더 빠름

      두 단계 모두 가격은 동일합니다.
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      동영상과 함께 네이티브 오디오를 생성할지 여부입니다.

      * `true` - 오디오 트랙이 포함된 동영상 생성, 기본값
      * `false` - 무음 동영상 출력

      오디오 활성화 여부와 관계없이 가격은 동일합니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  요청자 작업 ID.

  사용자 정의 작업 식별자로 필수 항목입니다. 영문자, 숫자, 밑줄(_), 하이픈(-)만 지원하며 길이는 1~64자입니다. 추후 이 ID를 사용하여 작업 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Query Task

FLUX 3 Max는 비동기 비디오 생성 모델입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하십시오. 10-15초마다 한 번씩 조회하는 것을 권장합니다.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달한 요청자 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \

    "out_task_id": "flux_3_max_frame_123456"
```

## Mode Notes

<Note>
`text`는 프롬프트만 사용하여 생성하며, `frame`은 영상의 시작 부분을 고정합니다(끝 부분도 추가 고정 가능). `keyframes`는 여러 장의 이미지를 사용하여 전체 영상의 흐름을 제어하며, 이미지는 타임라인에 순서대로 균등하게 배치됩니다(예: 10초 영상에 3장을 전달하면 각각 0초, 5초, 10초에 배치). 세 가지 모드의 가격은 동일하며, 출력 시간(초)과 해상도에 따라 요금이 부과됩니다.
</Note>

<Warning>
`frame` 모드는 최대 2장의 이미지(첫 프레임 + 마지막 프레임)를 사용하며 초과된 이미지는 무시됩니다. `keyframes` 모드는 최대 10장까지 지원합니다. `text` 모드는 전달된 이미지를 무시합니다.
</Warning>
