## Body

<ParamField body="model" type="string" required>
  모델 이름으로, 다음과 같이 고정 사용합니다:

  * `vidu_q4`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체입니다.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string">
      비디오 내용 설명이며, 최대 20000자까지 가능합니다.

      * `frame` 모드에서는 선택 사항으로, 화면 동작 및 카메라 워크를 설명하는 데 사용됩니다
      * `reference` 모드에서는 필수입니다

      참조 모드에서는 업로드 순서에 따라 소재를 지칭할 수 있습니다(예: '참조 이미지 2의 남성', '참조 오디오 1의 음성 사용').
    </ParamField>

    <ParamField body="type" type="string" default="frame">
      생성 모드:

      * `frame` - 첫 프레임(기본값). 이미지 1장을 전달하여 비디오의 첫 프레임으로 사용하며, 비디오는 이미지의 가로세로비를 따릅니다
      * `reference` - 참조. 참조 이미지 1-15장을 전달하며, 0-3개의 참조 오디오를 추가할 수 있습니다

      <Warning>
        첫 프레임 모드에서는 이미지를 1장만 전달할 수 있으며, `audio_url`은 전달할 수 없습니다.
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]" required>
      이미지 URL로, 반드시 공용 네트워크에서 직접 접근할 수 있어야 합니다.

      * `frame` - 첫 프레임으로 정확히 1장이어야 함
      * `reference` - 참조 이미지 1-15장

      이미지 요구 사항:

      * 형식: JPG, JPEG, PNG, WEBP
      * 장당 최대 50MB
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      참조 오디오 URL로, 생성되는 비디오의 음색과 어조를 유도하는 데 사용됩니다.

      `reference` 모드에서만 유효하며, 최대 3개까지 가능합니다.

      오디오 요구 사항:

      * 형식: MP3
      * 개당 3-12초
      * 개당 최대 50MB

      <Warning>`frame` 모드에서는 이 파라미터를 전달하지 마세요.</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      생성할 비디오 길이(단위: 초).

      지원되는 정수: `3`부터 `16`까지.
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      출력 해상도:

      * `540p`
      * `720p` - 기본값
      * `1080p`
      * `2K`
      * `4K`

      해상도 단계는 화면의 총 픽셀 수로 계산됩니다. 16:9가 아닌 화면(예: 정사각형, 세로 화면)의 너비와 높이는 단계 이름과 다를 수 있으며, 예를 들어 540p의 1:1 비디오는 720×720입니다.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      비디오 가로세로비로, `reference` 모드에서만 유효합니다. `frame` 모드는 첫 프레임 이미지의 비율을 따르므로 전달해도 무시됩니다.

      지원되는 가로세로비:

      * `16:9` - 가로 화면, 기본값
      * `9:16` - 세로 화면
      * `1:1` - 정사각형
      * `4:3` - 표준 가로 화면
      * `3:4` - 표준 세로 화면
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      동기화된 오디오(대사 및 효과음) 생성 여부.

      * `true` - 오디오 트랙이 포함된 비디오 생성, 기본값
      * `false` - 무음 비디오 출력
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  요청자 작업 ID.

  사용자 정의 작업 식별자로, 필수 항목입니다. 영문자, 숫자, 밑줄(_), 하이픈(-)만 지원하며 길이는 1-64자입니다. 추후 이 ID를 사용하여 작업 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Query Task

Vidu Q4는 비동기 비디오 생성 모델입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하세요. 10-15초마다 한 번씩 조회하는 것을 권장합니다.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달된 요청자 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "vidu_q4_frame_123456"
  }'
```

조회가 성공하고 완료되면 응답의 `output` 배열에 생성된 비디오가 포함되며, 요소에는 `video` 필드가 포함됩니다.

## Mode Notes

<Note>
`frame`은 1장의 이미지를 첫 프레임으로 사용하여 비디오를 생성하며, 프롬프트는 선택 사항이고 가로세로 비율은 이미지를 따릅니다. `reference`는 1~15장의 참조 이미지와 최대 3개의 참조 오디오를 조합하여 새로운 장면을 생성하며, 프롬프트는 필수이고 가로세로 비율을 지정할 수 있습니다.
</Note>

<Warning>
`type`이 `frame`일 때 `image_url`은 반드시 정확히 1장이어야 하며, `audio_url`은 전달하지 마십시오. `type`이 `reference`일 때 `prompt`는 비워 둘 수 없으며, 참조 이미지는 최대 15장, 참조 오디오는 최대 3개까지 가능합니다.
</Warning>
