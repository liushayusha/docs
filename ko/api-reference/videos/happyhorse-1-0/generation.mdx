## Body

<ParamField body="model" type="string" required>
  모델 이름으로, 고정값 `happyhorse_1_0`을 사용합니다.
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체입니다.

  <Expandable title="params 객체 속성">
    <ParamField body="type" type="string" default="text_to_video" required>
      비디오 워크플로우:

      * `text_to_video` - 텍스트에 따라 비디오 생성
      * `image_to_video` - 한 장의 첫 프레임 이미지로 비디오 생성
      * `reference_to_video` - 1-9장의 참고 이미지로 비디오 생성
      * `video_edit` - 지시에 따라 원본 비디오 편집
    </ParamField>

    <ParamField body="prompt" type="string">
      비디오 콘텐츠 설명 또는 편집 지시사항입니다. `text_to_video`, `reference_to_video` 및 `video_edit`는 필수이며, `image_to_video`는 선택 사항입니다.

      최대 2500개의 중국어 문자 또는 5000개의 비중국어 문자를 지원하며, 초과분은 잘립니다.

      `reference_to_video` 모드에서는 이미지 순서에 따라 `character1`, `character2` 등의 이름으로 참고 이미지를 지칭합니다.
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      이미지 URL로, 공개 네트워크에서 직접 접근 가능해야 합니다.

      * `image_to_video` - 필수, 첫 번째 이미지를 첫 프레임으로 사용
      * `reference_to_video` - 필수, 1-9장의 순서가 있는 참고 이미지를 지원
      * `video_edit` - 선택 사항, 최대 5장의 스타일 또는 피사체 참고 이미지

      JPEG, JPG, PNG, WEBP를 지원합니다. 이미지로 비디오 생성 및 비디오 편집용 이미지는 가로·세로 길이가 모두 300px 이상이어야 하며, 다중 참고 이미지 모드는 짧은 변이 400px 이상이어야 합니다. 단일 이미지는 10MB를 초과할 수 없습니다.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      `video_edit` 모드에서 필수이며, 단 하나의 원본 비디오만 사용합니다.

      MP4, MOV를 지원하며, H.264 인코딩 사용을 권장합니다. 원본 비디오 요구사항:

      * 길이 3-60초, 15초를 초과하면 앞부분 15초만 처리
      * 파일은 100MB를 초과할 수 없음
      * 긴 변은 2160px을 초과할 수 없고, 짧은 변은 320px 이상이어야 함
      * 가로세로 비율 범위는 1:2.5에서 2.5:1까지
      * 프레임률은 8 FPS보다 커야 함
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      출력 해상도: `720p` 또는 `1080p`.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      `text_to_video` 및 `reference_to_video` 모드의 출력 가로세로 비율입니다.

      지원: `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `4:5`, `5:4`, `9:21`, `21:9`.

      <Warning>`video_edit`는 이 파라미터를 지원하지 않으므로 전달하지 마세요. `image_to_video`의 출력 가로세로 비율은 입력 이미지에 따릅니다.</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      출력 비디오 길이로, 단위는 초입니다. 3-15 사이의 정수를 지원합니다.

      <Warning>`video_edit`는 이 파라미터를 지원하지 않으므로 전달하지 마세요. 출력 길이는 원본 비디오에 의해 자동으로 결정되며, `min(입력 비디오 길이, 15초)`와 같습니다.</Warning>
    </ParamField>

    <ParamField body="seed" type="integer" default="0">
      랜덤 시드로, 범위는 0-2147483647입니다. `0`을 전달하거나 생략하면 랜덤 시드를 사용합니다.
    </ParamField>

    <ParamField body="keep_original_sound" type="boolean" default="false">
      `video_edit` 모드에서만 유효합니다. `true`로 설정하면 원본 비디오 오디오 트랙을 강제로 유지하며, `false`로 설정하거나 생략하면 모델이 자동으로 결정합니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출 측에서 생성한 고유한 작업 ID이며, 이후 이 ID로 작업 상태와 결과를 조회합니다.

  영문자, 숫자, 밑줄, 하이픈만 지원하며, 길이는 1-64자입니다.
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  호출자 작업 ID로, 결과를 조회하는 데 사용할 수 있습니다.
</ResponseField>

<ResponseField name="status" type="string">
  초기 상태이며, 일반적으로 `pending`입니다.
</ResponseField>

<ResponseField name="created_at" type="string">
  생성 시간, ISO 8601 형식입니다.
</ResponseField>

## Query Task

작업 제출이 성공한 후, 동일한 `out_task_id`를 통해 상태를 조회합니다. 작업 상태에는 `pending`, `processing`, `completed`, `failed`가 포함됩니다. 완료 후 `output` 배열에는 비디오 결과가 포함됩니다.

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "happyhorse_1_0_task_123456"
  }'
```

          curl_easy_setopt(curl, CURLOPT_HTTPHEADER, headers);

          res = curl_easy_perform(curl);

          if(res != CURLE_OK) {
              fprintf(stderr, "curl_easy_perform() failed: %s\n",
                      curl_easy_strerror(res));
          }

          curl_slist_free_all(headers);
          curl_easy_cleanup(curl);
      }

      curl_global_cleanup();
      return 0;
  }

## 워크플로우 매개변수 비교

| `type` | 필수 소재 | 길이 및 가로세로 비율 |
|---|---|---|
| `text_to_video` | `prompt` | `video_length` 3-15초, 선택 사항 `aspect_ratio` |
| `image_to_video` | `image_url` | `video_length` 3-15초, 가로세로 비율은 이미지를 따름 |
| `reference_to_video` | `prompt`、`image_url` | `video_length` 3-15초, 선택 사항 `aspect_ratio` |
| `video_edit` | `prompt`、`video_url` | 길이와 가로세로 비율은 원본 비디오를 따르며, 출력은 최대 15초 |
