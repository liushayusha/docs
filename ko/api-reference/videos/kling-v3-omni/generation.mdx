## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정 값:

  * `kling_v3_omni`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      비디오 생성 텍스트 설명. 필수.

      참조 이미지는 프롬프트에서 `<<<image_1>>>`, `<<<image_2>>>`로 `image_url` 순서에 맞춰 인용할 수 있습니다. 이미지는 보냈지만 인용이 없으면 앞에 `<<<image_1>>>`이 자동으로 붙습니다.
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      네거티브 프롬프트. 최대 2500자.
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      생성 모드. 한 요청에서 섞지 마세요:

      * `all_reference` - 텍스트/참조. 프롬프트 필수. 참조 이미지 최대 7장, 참조 비디오 1개
      * `first_last_frame` - 첫/마지막 프레임. 첫 프레임 필수, 마지막 프레임 선택

      <Warning>
        첫/마지막 프레임은 참조 이미지나 참조 비디오와 같은 요청에 넣을 수 없습니다.
      </Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      출력 길이(초). 정수 `3`–`15`.

      * 참조 비디오가 없거나 `refer_type=feature`: 출력은 이 필드를 따름
      * `refer_type=base`: 출력은 업로드 클립을 따르며 이 필드에 의존하지 마세요
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      출력 해상도:

      * `720p` - 기본값
      * `1080p`
      * `4K`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      화면비. 첫 프레임 또는 참조 비디오가 있으면 무시됩니다.

      * `16:9` - 가로, 기본값
      * `9:16` - 세로
      * `1:1` - 정사각
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="false">
      네이티브 오디오 트랙 생성 여부.

      * `false` - 생성하지 않음, 기본값
      * `true` - 생성

      <Warning>
        `video_url`이 있으면 무시됩니다. 참조 비디오와 함께 쓸 수 없습니다.
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      이미지 URL. 공개 접근 가능해야 합니다.

      * `all_reference` - 선택, 최대 7장
      * `first_last_frame` - 첫 항목이 첫 프레임(필수), 둘째가 마지막 프레임(선택)

      짧은 변 300px 이상, 장당 최대 20MB.
    </ParamField>

    <ParamField body="end_image_url" type="string">
      마지막 프레임 이미지 URL.

      `first_last_frame`에서만 유효합니다. `image_url` 두 번째 항목으로도 전달할 수 있습니다. 마지막 프레임만 있고 첫 프레임이 없으면 오류입니다.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      참조 비디오 URL. `all_reference`에서만, 최대 1개.

      요구 사항:

      * MP4 또는 MOV
      * 3-10초
      * 최대 200MB
      * 짧은 변 720px 이상

      <Warning>`first_last_frame`에서는 보내지 마세요. URL은 공개되어야 하고 길이 메타데이터를 읽을 수 있어야 합니다.</Warning>
    </ParamField>

    <ParamField body="refer_type" type="string" default="feature">
      참조 비디오 사용 방식. `video_url`이 있을 때만:

      * `feature` - 스타일/모션 참조. 출력 길이는 `video_length`
      * `base` - 업로드 클립을 편집. 출력 길이는 원본을 따르고 `video_length`는 무시
    </ParamField>

    <ParamField body="keep_original_sound" type="boolean" default="false">
      참조 비디오 원음 유지. `video_url`이 있을 때만.

      * `false` - 유지하지 않음, 기본값
      * `true` - 원음 유지
    </ParamField>

    <ParamField body="watermark" type="boolean" default="false">
      워터마크. 기본값 `false`.
    </ParamField>

    <ParamField body="multi_shot" type="boolean" default="false">
      멀티샷. `true`이면 모델이 프롬프트를 자동으로 샷으로 나눕니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  호출자 작업 ID.

  필수. 영문, 숫자, 밑줄, 하이픈만, 1-64자. 같은 ID로 상태와 결과를 조회합니다.
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  호출자 작업 ID. 결과 조회에 사용합니다.
</ResponseField>

<ResponseField name="status" type="string">
  초기 상태. 보통 `"pending"`.
</ResponseField>

<ResponseField name="created_at" type="string">
  생성 시각, ISO 형식.

## Query Task

Kling v3 Omni는 비동기입니다. 제출 후 `out_task_id`로 상태를 조회하세요.

<ParamField body="out_task_id" type="string" required>
  제출 시 보낸 호출자 작업 ID.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "kling_v3_omni_t2v_123456"
  }'
```

완료되면 `output` 배열에 `video` 필드가 있는 생성 결과가 들어갑니다.

## 모드 파라미터 대조

| `type` / 참조 비디오 | 필수 | 길이 |
|---|---|---|
| `all_reference`, `video_url` 없음 | `prompt` | `video_length` 3-15초 |
| `all_reference`, `refer_type=feature` | `prompt`, `video_url` | 출력은 `video_length` |
| `all_reference`, `refer_type=base` | `prompt`, `video_url` | 출력은 업로드 클립 3-10초 |
| `first_last_frame` | `prompt`, 첫 프레임 `image_url` | `video_length` 3-15초 |
