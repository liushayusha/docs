      * 짧은 변 300px 이상, 장당 10MB 이하

      참조 이미지는 피사체와 스타일을 정하는 데 사용되며 첫/마지막 프레임이 아닙니다. 영상이 특정 이미지로 시작하거나 끝나도록 강제되지 않습니다.

## Query Task

이 모델은 비동기 비디오 생성 방식입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하세요. [작업 상태 조회](/ko/api-reference/tasks/status)도 참조할 수 있습니다.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달된 요청자 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_12_t2v_123456"
  }'
```

조회가 성공하여 완료되면 응답의 `output` 배열에 생성된 비디오가 포함되며, 요소에는 `video` 필드가 포함됩니다.

## 파라미터 대조표

| 입력 | `image_url` | `video_length` | `aspect_ratio` |
|---|---|---|---|
| 텍스트 기반 생성 | 전달하지 않거나 빈 배열 | `"3"`–`"10"` | `16:9` 또는 `9:16` |
| 텍스트 기반 생성(장시간) | 전달하지 않거나 빈 배열 | `"11"`–`"15"` | `9:16`만 |
| 참조 이미지 | 1–3장 | `"3"`–`"10"` | `16:9` 또는 `9:16` |
| 참조 이미지(장시간) | 1–3장 | `"11"`–`"15"` | `9:16`만 |

지원하지 않는 필드: `resolution`(720p 고정), `video_url`(참조 비디오 미지원).
