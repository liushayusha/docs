## Body

<ParamField body="model" type="string" required>
  모델 이름입니다. `jev`로 고정하여 입력합니다.

  응답의 `result.result.model`은 업스트림에서 실제로 사용된 버전 번호(예: `jev-1.14.0`)입니다. 이 필드는 업스트림에서 반환되므로 요청에 버전 번호를 입력하지 마세요.
</ParamField>

<ParamField body="input" type="object" required>
  판단 내용입니다. `state`, `questions`를 포함하며 이미지가 있는 경우 `assets`를 추가합니다.

  <Expandable title="필드 설명">
    <ParamField body="state" type="string | object | array" required>
      판단할 자료입니다. 한 문장일 수도 있고 객체나 배열일 수도 있습니다. 판단을 완료하는 데 필요한 데이터만 넣고, API Key, 비밀번호 등 민감한 정보는 넣지 마세요.

      이미지가 포함된 경우 `state`에 이미지 참조명을 작성합니다(예: `{ "photo": "img-7f3a91" }`). 참조명은 `assets`의 키에 해당합니다.

    <ParamField body="assets" type="object">
      이미지 테이블(Beta)입니다. 키는 참조명이고 값은 이미지 객체입니다. 이미지가 없으면 전달하지 않습니다.

      참조명은 순수 텍스트로 일치되며, `state`, 문제의 `instructions` 또는 `criteria` 내 임의의 문자열에 작성할 수 있습니다. 모델은 해당 위치에서 이 이미지를 확인합니다. 참조명은 본문 텍스트와 겹치지 않는 문자열을 선택해야 하며, 이미지마다 UUID를 사용하는 것을 권장합니다. 각 참조명은 요청에 최소 한 번 이상 나타나야 합니다.

      <Expandable title="이미지 객체">
        <ParamField body="type" type="string">
          `image`로 고정되며 생략할 수 있습니다.
        </ParamField>

        <ParamField body="format" type="string" required>
          이미지 형식: `png`, `jpg` 또는 `jpeg`(소문자).
        </ParamField>

        <ParamField body="data_base64" type="string" required>
          이미지 파일의 base64 인코딩입니다. 표준 base64 알파벳을 사용하고 `=` 패딩을 포함하며, 줄바꿈이 없어야 하고 `data:` 접두사를 포함할 수 없습니다.
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="questions" type="object" required>
      문제 테이블이며 비어 있을 수 없습니다. 키 이름은 직접 지정하며, 각 문제는 하나의 객체입니다.

      각 문제에는 `type`과 `instructions`가 있어야 합니다.

      * `noul` — 진위형(OX) 문제. 0에서 1 사이의 '예' 확률을 나타내는 `noul`을 반환합니다. `criteria`는 선택 사항이며 형태는 `{ "true": "어떠한 경우에 참인지", "false": "어떠한 경우에 거짓인지" }`입니다.
      * `choice` — 단일 선택형. `criteria`는 필수이며 '옵션명 → 설명' 형태의 객체입니다. 반환되는 `choice`는 선택된 옵션명입니다.
      * `score` — 점수 매기기. `criteria`는 필수이며 낮은 순에서 높은 순으로 정렬된 최소 2개 이상의 항목으로 구성된 배열입니다. 반환되는 `score`는 어느 단계에 해당하는지 나타내는 숫자이며, 첫 번째 항목은 0이고 소수일 수 있습니다. 예를 들어 3단계인 경우 `1.99`는 거의 세 번째 항목에 해당함을 나타냅니다.
      * `box` — 이미지 내 위치 지정(Beta). 이미지가 반드시 포함되어야 하며 `criteria`는 허용되지 않습니다. `instructions`에는 무엇을 찾는지, 어느 이미지에 있는지를 작성합니다(예: ``"the car in `photo`"``). 대상을 둘러싼 사각형을 반환합니다.
    </ParamField>
  </Expandable>
</ParamField>

단일 요청에 여러 개의 `noul`, `choice`, `score`, `box`를 동시에 포함할 수 있습니다. `stream`은 전달하지 마세요. 본 인터페이스는 완전한 JSON을 한 번만 반환합니다.

## 图片与 Box 示例（Beta）

이미지는 `assets`에 배치하고, `state`는 참조 이름으로 이를 가리킵니다. 질문에서는 `` `photo` ``로 이 이미지를 지칭합니다. 아래 예시는 '이미지에 차가 있는지'와 '차가 어디에 있는지'를 동시에 질문합니다.

```json theme={null}
{
  "model": "jev",
  "input": {
    "state": { "photo": "img-7f3a91" },
    "assets": {
      "img-7f3a91": {
        "type": "image",
        "format": "jpg",
        "data_base64": "/9j/4AAQSkZJRg..."
      }
    },
    "questions": {
      "has_car": {
        "type": "noul",
        "instructions": "Is there a car in `photo`?"
      },
      "car": {
        "type": "box",
        "instructions": "the car in `photo`"
      }
    }
  }
}
```

응답의 `answers`:

```json theme={null}
{
  "has_car": { "type": "noul", "noul": 0.97 },
  "car": {
    "type": "box",
    "box": { "top": 0.24, "bottom": 0.81, "left": 0.15, "right": 0.74 },
    "confidence": 0.74
  }
}
```

Box 문제는 항상 박스를 반환하며, '찾을 수 없음'과 같은 결과는 없습니다. 이미지에 대상이 없을 때도 박스를 반환하지만 신뢰도가 낮을 뿐입니다. 대상이 존재하는지 불확실한 경우, 위 예시처럼 동일한 요청에 `noul`을 하나 추가하고 `noul`이 매우 낮으면 이 박스를 무시하세요.

### 이미지 요구사항

| 항목 | 제한사항 |
| - | - |
| 형식 | PNG 또는 JPEG 정적 이미지, 애니메이션 이미지는 지원하지 않음. WebP, GIF, HEIC 등은 먼저 PNG 또는 JPEG로 변환해야 함 |
| 단일 이미지 크기 | 디코딩 후 16 MiB 이하 |
| 너비, 높이 | 각 변 280~1568 픽셀, 범위를 벗어나면 즉시 오류가 발생하며 자동으로 크기가 조절되지 않음 |
| 요청 본문 | JSON 및 base64 포함 32 MiB 이하 |

* 전송 전에 긴 변을 1568 픽셀 이하로 줄이세요. 업스트림에서 EXIF를 제거하며 EXIF 방향에 따라 회전하지 않으므로, 휴대폰 사진은 먼저 픽셀 자체의 방향을 바로잡아 주세요.
* 이미지는 입력 토큰으로 환산되어 `usage.input_tokens`에 합산되며, 컨텍스트 창도 차지합니다. 약 800 픽셀의 이미지는 약 1500 tokens입니다.
* 요청 중 유효하지 않은 이미지가 하나라도 있으면 전체 요청이 실패하며, 부분적인 결과는 반환되지 않습니다.

## 注意事项

* 본 인터페이스는 채팅 인터페이스가 아니므로 `messages`를 전달할 수 없으며, `stream`도 전달할 수 없습니다.
* 이미지 입력과 Box 문제는 현재 Beta이며, 요청 형식, 결과 및 제한 사항은 버전에 따라 변경될 수 있어 프로덕션 의사결정에 직접 사용하는 것은 권장하지 않습니다.
* 컨텍스트 창은 32000 tokens입니다.
* 비즈니스 실패 시 HTTP 상태 코드가 여전히 200일 수 있으므로 `success`와 `errors`를 함께 확인해 주세요. 인증 실패 시 `401`을 반환하고, `model` 누락 또는 유효하지 않은 JSON의 경우 `400`을 반환하며, 모델이 존재하지 않을 경우 `404`를 반환합니다.
