## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정값:

  * `seed_audio_1_0`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      합성할 텍스트 또는 오디오 장면에 대한 설명으로, 최대 1500자입니다.

      참조 오디오를 사용할 때는 프롬프트에서 `@audio1` / `@audio2` / `@audio3`를 순서대로 사용해 참조 음색을 지정할 수 있습니다.
    </ParamField>

    <ParamField body="reference_mode" type="string" default="text">
      참조 모드는 이번 요청에서 어떤 종류의 참조 소재를 사용할지 결정합니다:

      * `text` - 프롬프트만 사용하여 생성하며, 참조 오디오나 참조 이미지는 전달하지 않음
      * `audio` - 참조 오디오로 음색을 복제
      * `image` - 한 장의 참조 이미지로 감정과 표현을 유도

      <Warning>참조 오디오와 참조 이미지는 동시에 사용할 수 없습니다. 참조 소재를 사용하려면 해당 `reference_mode`를 명시적으로 전달해야 하며, 그렇지 않으면 참조 필드는 무시됩니다.</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      참조 오디오 URL.

      `reference_mode`가 `audio`일 때만 유효하며, 최대 3개까지 지원합니다. 순서는 `@audio1` / `@audio2` / `@audio3`에 대응합니다.

      참조 오디오 요구 사항:

      * 형식 WAV, MP3, PCM, OGG Opus
      * 단일 구간은 30초를 초과할 수 없음
      * 단일 구간은 10MB를 초과할 수 없음
      * URL은 공개적으로 접근 가능해야 함
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      참조 이미지 URL.

      `reference_mode`가 `image`일 때만 유효하며, 최대 1장까지 지원합니다.

      이미지 요구 사항:

      * 형식 JPEG, PNG, WEBP
      * 10MB를 초과할 수 없음
      * URL은 공개적으로 접근 가능해야 함
    </ParamField>

    <ParamField body="speech_rate" type="number" default="1">
      말하기 속도 배율이며, 범위는 `0.5`~`2`이고 소수점 둘째 자리까지 지원합니다. `1`은 정상 속도입니다.
    </ParamField>

    <ParamField body="loudness_rate" type="number" default="1">
      음량 배율이며, 범위는 `0.5`~`2`이고 소수점 둘째 자리까지 지원합니다. `1`은 정상 음량입니다.
    </ParamField>

    <ParamField body="pitch_rate" type="integer" default="0">
      음정, 단위는 반음입니다. 범위는 `-12`~`12`입니다. `0`은 원래 음정, `12`는 한 옥타브 높임, `-12`는 한 옥타브 낮춤입니다.
    </ParamField>

    <ParamField body="sample_rate" type="string" default="24000">
      출력 샘플링 레이트(Hz):

      * `8000`
      * `16000`
      * `24000` - 기본값
      * `32000`
      * `44100`
      * `48000`
    </ParamField>

    <ParamField body="format" type="string" default="wav">
      출력 오디오 형식:

      * `wav` - 기본값
      * `mp3`
      * `ogg_opus`
      * `pcm`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  요청자 작업 ID.

  사용자가 정의한 작업 식별자이며, 필수입니다. 영문자, 숫자, 밑줄, 하이픈만 지원하며 길이는 1-64자입니다. 이후 이 ID로 작업 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Query Task

Seed Audio 1.0은 비동기 오디오 생성 모델입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하세요.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달되는 호출 측 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "seed_audio_text_123456"
  }'
```

조회가 성공하고 완료되면, `output` 예시는 다음과 같습니다:

```json
{

    "status": "completed",
    "created_at": "2026-08-26T10:12:11.000Z",

      {
```

## Mode Notes

<Note>
`text` 모드는 프롬프트에 따라 음성, 대사 또는 효과음을 생성합니다. `audio` 모드는 참고 오디오로 음색을 클론합니다. `image` 모드는 한 장의 참고 이미지를 사용해 표현을 안내합니다.
</Note>

<Warning>
`reference_mode`가 `audio`일 때는 `image_url`을 전달하지 마세요. `reference_mode`가 `image`일 때는 `audio_url`을 전달하지 마세요. 단일 요청의 최대 길이는 120초입니다.
</Warning>
