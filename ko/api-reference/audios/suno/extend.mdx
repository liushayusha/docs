## 본문

<ParamField body="model" type="string" required>
  모델 이름, 고정값으로 사용:

  * `suno_extend`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체입니다.

  <Expandable title="params 객체 속성">
    <ParamField body="audio_url" type="string | string[]" required>
      이어서 작성할 오디오 URL로, 반드시 공개적으로 접근 가능해야 합니다. 배열을 전달할 경우 첫 번째 항목을 사용합니다.

      오디오 요구사항:

      * 형식: MP3, WAV
      * 길이는 8분을 초과하지 않아야 합니다.
      * 20MB를 초과하지 않아야 합니다.
    </ParamField>

    <ParamField body="prompt" type="string">
      선택 사항입니다. 이어쓰기 부분이 어떻게 전개되기를 원하는지 설명합니다. 예: 후렴을 더 크게, 아웃트로를 더 조용하게, 새로운 악기를 추가하기 등.
    </ParamField>

    <ParamField body="continue_at" type="number" default="60">
      원곡의 몇 초 지점부터 이어서 작성할지 지정합니다. 범위는 `0`부터 `240`까지이며, 원본 오디오 길이보다 짧아야 합니다. 기본값은 `60`이며, 보통 벌스나 후렴 뒤에 이어집니다.
    </ParamField>

    <ParamField body="suno_model" type="string" default="V5">
      Suno 버전:

      * `V4`
      * `V4_5`
      * `V4_5PLUS`
      * `V4_5ALL`
      * `V5` - 기본값
      * `V5_5`
    </ParamField>

    <ParamField body="instrumental" type="boolean" default="false">
      이어쓰기 부분이 순수 음악인지 여부입니다.

      * `false` - 보컬이 포함된 상태로 계속 생성
      * `true` - 반주만 생성
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  발신 측 작업 ID입니다.

  사용자가 정의한 작업 식별자로, 필수입니다. 문자, 숫자, 밑줄, 하이픈만 지원하며 길이는 1-64자입니다. 이후 이 ID로 작업 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Query Task

Suno Extend는 비동기 음악 연장 모델입니다. 작업을 제출한 후에는 `out_task_id`를 사용하여 작업 상태를 조회하세요. 완료 후 `output`에는 일반적으로 2개의 연장 결과가 포함되며, 각 항목에는 `audio`, `url`, `title`, `text`가 포함됩니다.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달한 발신자 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "suno_extend_123456"
  }'
```

조회가 성공하고 완료되면 `output` 예시는 다음과 같습니다:
