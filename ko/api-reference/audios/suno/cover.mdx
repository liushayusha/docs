## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정 사용:

  * `suno_cover`
</ParamField>

<ParamField body="params" type="object" required>
  모델 매개변수 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      리메이크 후 어떤 분위기를 원하나요. 멜로디는 원곡에 가깝게 유지되며, 여기서는 장르, 보컬, 프로덕션을 바꿉니다.

      사용자 정의 모드를 켜고 순수 음악이 아닐 경우, 프롬프트는 가사로 처리됩니다. V5 / V5.5 / V4.5 시리즈는 최대 5000자입니다.
    </ParamField>

    <ParamField body="audio_url" type="string | string[]" required>
      리메이크할 오디오 URL, 공개적으로 접근 가능해야 합니다. 배열을 전달하면 첫 번째 항목을 사용합니다.

      오디오 요구 사항:

      * 형식 MP3, WAV
      * 길이는 8분을 초과할 수 없습니다.
      * 20MB를 초과할 수 없습니다.
    </ParamField>

    <ParamField body="suno_model" type="string" default="V5">
      Suno 버전:

      * `V4`
      * `V4_5`
      * `V4_5PLUS`
      * `V4_5ALL`
      * `V5` - 기본값
      * `V5_5`
    </ParamField>

    <ParamField body="custom_mode" type="boolean" default="false">
      사용자 정의 모드를 켤지 여부.

      * `false` - 간단 모드, `prompt`와 `audio_url`만 필요
      * `true` - 사용자 정의 모드, `title`과 `style`을 지정해야 함
    </ParamField>

    <ParamField body="instrumental" type="boolean" default="false">
      순수 음악으로 변환할지 여부.

      * `false` - 보컬 유지
      * `true` - 반주만 생성
    </ParamField>

    <ParamField body="vocal_gender" type="string" default="m">
      보컬 성별 선호. 순수 음악일 때는 무시됩니다.

      * `m` - 남성 보컬, 기본값
      * `f` - 여성 보컬
    </ParamField>

    <ParamField body="title" type="string">
      곡 제목. 사용자 정의 모드에서만 유효하며, 최대 100자입니다. `custom_mode`를 켰을 때 필수입니다.
    </ParamField>

    <ParamField body="style" type="string">
      새로운 장르와 프로덕션 방향. 사용자 정의 모드에서만 유효하며, 최대 1000자입니다. `custom_mode`를 켰을 때 필수입니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  요청 측 작업 ID.

  사용자가 정의한 작업 식별자이며, 필수입니다. 영문자, 숫자, 밑줄, 하이픈만 지원하며 길이는 1-64자입니다. 이후 이 ID로 작업 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Query Task

Suno Cover는 비동기 커버 생성 모델입니다. 작업을 제출한 후에는 `out_task_id`를 사용하여 작업 상태를 조회하세요. 완료되면 `output`에는 일반적으로 2개의 커버 결과가 포함되며, 각 항목에는 `audio`, `url`, `title`, `text`가 포함됩니다.

<ParamField body="out_task_id" type="string" required>
  작업을 제출할 때 전달한 호출 측 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "suno_cover_123456"
  }'
```

조회가 성공하고 완료되면, `output` 예시는 다음과 같습니다:
