## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정값으로 사용:

  * `suno`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="prompt" type="string" required>
      곡 설명. 주제, 감정, 악기와 리듬을 작성할 수 있습니다.

      커스텀 모드를 끄면 모델이 이를 바탕으로 제목, 스타일, 가사를 자동으로 작성합니다. 커스텀 모드를 켜고 순수 음악이 아닌 경우, 프롬프트는 가사로 처리됩니다.

      V5 / V5.5 / V4.5 시리즈는 최대 5000자까지 지원합니다.
    </ParamField>

    <ParamField body="suno_model" type="string" default="V5">
      Suno 버전:

      * `V4`
      * `V4_5`
      * `V4_5PLUS`
      * `V4_5ALL`
      * `V5` - 기본값
      * `V5_5`
    </ParamField>

    <ParamField body="custom_mode" type="boolean" default="false">
      커스텀 모드를 켤지 여부입니다.

      * `false` - 간단한 모드로, 프롬프트만 입력하면 제목, 스타일, 가사는 모델이 생성합니다
      * `true` - 커스텀 모드로, `title`과 `style`을 지정해야 합니다. 보컬이 있는 경우 `prompt`는 가사로 사용됩니다
    </ParamField>

    <ParamField body="instrumental" type="boolean" default="false">
      순수 음악을 생성할지 여부입니다.

      * `false` - 보컬이 있는 곡을 생성합니다
      * `true` - 반주만 생성하며, 보컬과 가사는 없습니다
    </ParamField>

    <ParamField body="vocal_gender" type="string" default="m">
      보컬 성별 선호입니다. 순수 음악일 때는 무시됩니다.

      * `m` - 남성 보컬, 기본값
      * `f` - 여성 보컬
    </ParamField>

    <ParamField body="title" type="string">
      곡 제목입니다. 커스텀 모드에서만 유효하며, 최대 100자까지 가능합니다. `custom_mode`를 켜면 필수입니다.
    </ParamField>

    <ParamField body="style" type="string">
      곡 스타일과 제작 방향입니다. 예: indie folk, lo-fi hip hop, 80s synthwave. 커스텀 모드에서만 유효하며, 최대 1000자까지 가능합니다. `custom_mode`를 켜면 필수입니다.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  요청 측 작업 ID.

  사용자가 직접 정의한 작업 식별자이며, 필수입니다. 문자, 숫자, 밑줄, 하이픈만 지원하며 길이는 1-64자입니다. 이후 이 ID로 작업 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Query Task

Suno는 비동기 음악 생성 모델입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하세요. 완료되면 `output`에는 일반적으로 2곡이 포함되며, 각 항목에는 `audio`(오디오 URL), `url`(커버 이미지), `title`, `text`(가사)가 포함됩니다.

<ParamField body="out_task_id" type="string" required>
  작업을 제출할 때 전달한 발신 측 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "suno_gen_123456"
  }'
```
