<Note>
Flow Music Replace의 AIReiter 내 모델 이름은 `flow_music_replace`입니다. `clip_id`는 성공한 작업의 `output[].clip_id`에서 가져옵니다.
</Note>

## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정 값:

  * `flow_music_replace`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="clip_id" type="string" required>
      성공한 작업의 `clip_id`로, `output[].clip_id`에서 가져옵니다.

      generate / extend / replace / cover / upload 성공 후 모두 반환됩니다. stems / download / video는 동일한 `clip_id`를 재사용하며, 새로 생성하지 않습니다. `clip_id`가 없고 오디오 파일만 있는 경우에는 먼저 `flow_music_upload`를 호출하세요.
    </ParamField>

    <ParamField body="prompt" type="string" required>
      교체 지시문으로, 이 구간을 어떤 형태로 바꾸길 원하는지 설명합니다.
    </ParamField>

    <ParamField body="start_s" type="number" default="0">
      시작 초입니다. 범위는 `0`부터 `240`까지입니다.
    </ParamField>

    <ParamField body="end_s" type="number" default="10">
      종료 초입니다. 범위는 `1`부터 `240`까지이며, `start_s`보다 커야 합니다.
    </ParamField>

    <ParamField body="version" type="string" default="lyria-3-pro">
      Lyria 버전, 가격은 동일합니다:

      * `lyria-3-pro` - 기본값
      * `lyria-3.5` - 더 최신의 보컬 모델
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  요청 측 작업 ID.

  사용자가 직접 정의한 작업 식별자이며, 필수입니다. 문자, 숫자, 밑줄, 하이픈만 지원하며 길이는 1-64자입니다. 이후 이 ID로 작업 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  요청 측 작업 ID로, 결과를 조회하는 데 사용할 수 있습니다.
</ResponseField>

<ResponseField name="status" type="string">
  초기 상태로, 일반적으로 `"pending"`입니다.
</ResponseField>

<ResponseField name="created_at" type="string">
  생성 시간, ISO 형식.
</ResponseField>

## Query Task

Flow Music Replace는 비동기 음악 교체 모델입니다. 작업을 제출한 후 `out_task_id`를 사용하여 작업 상태를 조회하세요. 완료되면 `output`에는 `audio`, `url`, `title` 및 새로운 `clip_id`가 포함됩니다.

<ParamField body="out_task_id" type="string" required>
  작업을 제출할 때 전달하는 요청자 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flow_music_replace_123456"
  }'
```

조회가 성공하고 완료되면, `output` 예시는 다음과 같습니다:

```json
{
  "statusCode": 200,

      }
    ]
  }
}
```
