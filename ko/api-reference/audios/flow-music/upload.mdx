<Note>
Flow Music Upload의 AIReiter 내 모델 이름은 `flow_music_upload`입니다. 외부 오디오를 편집 가능한 `clip_id`로 변환하는 데 사용됩니다.
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  모든 엔드포인트는 Bearer Token을 사용하여 인증해야 합니다.


## Body

<ParamField body="model" type="string" required>
  모델 이름, 고정 사용 값:

  * `flow_music_upload`
</ParamField>

<ParamField body="params" type="object" required>
  모델 파라미터 객체.

  <Expandable title="params 객체 속성">
    <ParamField body="audio_url" type="string | string[]" required>
      가져올 오디오 URL로, 반드시 공개적으로 접근 가능해야 합니다. 배열을 전달할 경우 첫 번째 항목을 사용합니다.

      오디오 요구사항:

      * 형식: MP3, WAV, M4A
      * 길이는 8분을 초과할 수 없음
      * 20MB를 초과할 수 없음
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  요청 주체의 태스크 ID.

  사용자가 직접 정의한 태스크 식별자로, 필수입니다. 문자, 숫자, 밑줄, 하이픈만 지원하며 길이는 1-64자입니다. 이후 이 ID로 태스크 상태와 결과를 조회할 수 있습니다.
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  요청 측 작업 ID로, 결과를 조회하는 데 사용할 수 있습니다.
</ResponseField>

<ResponseField name="status" type="string">
  초기 상태이며, 일반적으로 `"pending"`입니다.
</ResponseField>

<ResponseField name="created_at" type="string">
  생성 시간, ISO 형식.
</ResponseField>

## Query Task

Flow Music Upload는 비동기 오디오 가져오기 모델입니다. 작업을 제출한 후 `out_task_id`를 사용해 작업 상태를 조회하세요. 완료되면 `output`에 `audio`와 새로운 `clip_id`가 포함됩니다.

<ParamField body="out_task_id" type="string" required>
  작업 제출 시 전달한 호출 측 작업 ID입니다.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flow_music_upload_123456"
  }'
```

조회가 성공하고 완료되면, `output` 예시는 다음과 같습니다:

```json
{
  "statusCode": 200,
  "message": "",
  "data": {
    "out_task_id": "flow_music_upload_123456",
    "status": "completed",
    "created_at": "2026-08-28T07:44:48.000Z",
    "completed_at": "2026-08-28T07:45:40.000Z",
      "output": [
      {
        "audio": "https://static.aireiter.com/tmp/audio-generator/20260828/8TAJJH-mCxIrvHGvBJHiU-audio-0.m4a",
        "clip_id": "744c9e0b-ca79-4866-93ad-ead4832e67d1"
      }
    ]
  }
}
```
