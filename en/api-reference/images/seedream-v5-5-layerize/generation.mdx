---
title: 'Seedream 5.5 Layerize Image Decomposition'
description: |
    - Asynchronous processing mode, returns a task ID for subsequent queries
    - Decomposes an image into a base image and multiple independently editable transparent PNG layers (up to 100 images including the base image)
    - Each layer includes a name, description, z_index, and bounding_box
    - Optional text recognition, returns the content and style of text layers
api: 'POST https://aireiter.com/api/openapi/submit'
---

## Body

<ParamField body="model" type="string" required>
  Model name

  Fixed value: `"seedream_v5_5_layerize"`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object

  <Expandable title="params Object Properties">
    <ParamField body="image_url" type="string" required>
      URL of the original image to be split into layers

      * Required, and only **1** image can be passed
      * Supported image formats: jpeg, png
      * Supports the following two formats:
        1. Publicly accessible URL
        2. Base64-encoded format
           * Must use the complete Data URI format: `data:image/{格式};base64,{base64数据}`
           * Example: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ Note: Must include the `data:image/jpeg;base64,` prefix, and the base64 image size must not exceed 10MB
    </ParamField>

    <ParamField body="prompt" type="string">
      Text prompt (Optional)

      Used to specify the elements to split, for example `把标题文字和鹦鹉拆成单独的图层`. If not passed, elements in the image will be recognized automatically.
    </ParamField>

    <ParamField body="resolution" type="string" default="auto">
      Output resolution tier

      * `auto` - Output according to original image dimensions (Default): original images below 1K are upscaled to 1K, and original images above 2K are downscaled to 2K
      * `1K` - 1K resolution
      * `1.5K` - 1.5K resolution
      * `2K` - 2K resolution

      When a tier is specified, both the base image and each layer are output at the selected tier while preserving their respective original aspect ratios. Custom aspect ratios or pixel dimensions are not supported.
    </ParamField>

    <ParamField body="max_images" type="integer" default="30">
      Maximum number of returned images (including the base image)

      * Value range: 2–100
      * The actual number of returned images is determined by the image content and will not exceed this value
      * Returning more than 30 images takes longer; 100 images take approximately 5 minutes
    </ParamField>

    <ParamField body="text_recognition" type="boolean" default="false">
      Text recognition

      When enabled, recognizes the text content and styles of clearly legible text layers in the image
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      Base image output format

      * `png` - PNG (Default)
      * `jpeg` - JPEG

      Applies only to the base image (z_index = 0); all other layers are fixed as transparent-background PNGs
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  Callback URL after the task is completed
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata, returned as-is
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID

  User-defined task identifier, required
</ParamField>

## Query Task Result

After submitting a task, use the `POST /api/openapi/query` endpoint to poll the task status. Layer decomposition usually takes tens of seconds to several minutes. Please save the `out_task_id` and keep querying until it reaches a terminal state; do not resubmit. Once the task is completed, the `output` field returns the base image and the list of layers.

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "my_task_123456"
    }'
  ```
</RequestExample>

### Query Response - Layer Output Structure

Once the task is completed, `output` is an array of image objects. The first item is the base image, and the rest are layers. Each item contains `url` and `metadata`:

<ResponseField name="output" type="array">
  Base image and layer list

  <Expandable title="Image Object Properties">
    <ResponseField name="url" type="string">
      Image URL (the base image is an opaque image, and layers are transparent PNGs)
    </ResponseField>

    <ResponseField name="metadata" type="object">
      Layer metadata

      <Expandable title="metadata Properties">
        <ResponseField name="kind" type="string">
          Fixed value `"layer"`, identifying this as a layer output
        </ResponseField>

        <ResponseField name="z_index" type="number">
          Layer hierarchy index

          * `z_index = 0`: Base layer (reconstructed complete background image), where `bounding_box`, `name`, and `description` are `null`
          * `z_index ≥ 1`: Foreground layer; higher values are positioned closer to the top
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          Position region of the layer in the original image

          `null` for the base layer (z_index=0); returns a coordinate object for other layers:

          <Expandable title="bounding_box Properties">
            <ResponseField name="absolute" type="array">
              Absolute pixel coordinates `[x1, y1, x2, y2]`, based on the base image resolution
            </ResponseField>

            <ResponseField name="normalized" type="array">
              Normalized coordinates `[x1, y1, x2, y2]`, ranging from 0–1000
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          Layer name
        </ResponseField>

        <ResponseField name="description" type="string | null">
          Layer description
        </ResponseField>

        <ResponseField name="background" type="string">
          Background type: `"opaque"` for the base image, `"transparent"` for layers
        </ResponseField>

        <ResponseField name="output_format" type="string">
          Image format, such as `"png"`
        </ResponseField>

        <ResponseField name="size" type="string">
          Pixel dimensions of the image, in `widthxheight` format
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="credits_used" type="number">
  Actual credits consumed
</ResponseField>
