description: |
    - Asynchronous processing mode, returning a task ID for subsequent queries
    - A lightweight open-source weights version of FLUX 3 Image (5.6B parameters) released by Black Forest Labs in October 2026, focused on fast image editing while also supporting text-to-image
    - Supports text-to-image and image-to-image, automatically switching to image-to-image when image_url is passed
    - Supports up to 3 reference images, with the first being the image to edit and the rest providing subject, product, and style references
    - Prompts are automatically expanded before generation
    - Supports 7 common image aspect ratios
    - Supports 1K / 2K resolution tiers, generating up to 4 images at a time
    - Submitted prompts undergo platform sensitive word / safety review, and non-compliant content will be directly rejected

## Body

<ParamField body="model" type="string" required>
  Model name.

  Fixed value: `"flux_3_klein"`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Image generation or editing prompt, up to 4000 characters.

      * Supports Chinese and English. It is recommended to clearly describe the subject, scene, composition, lighting, material, and reference image features to be retained
      * In image-to-image mode, clearly specify in the prompt what needs to be retained and what needs to be modified
      * The model will automatically expand the prompt before generation. Simply state your intent clearly without stacking modifiers
      * Submissions will undergo platform sensitive word / security review. If violating content is hit, an error will be returned directly
    </ParamField>

    <ParamField body="image_url" type="string[]">
      Reference image array. When passed, image-to-image mode is automatically used; when omitted, text-to-image mode is used.

      * Up to 3 reference images. The first image is the one being edited, while the rest are used to provide subject, product, or style references
      * Maximum 10 MB per image
      * Supports jpeg, png, and webp
      * Supports the following two formats:
        1. Publicly accessible URL
        2. Complete Base64 Data URI, for example `data:image/jpeg;base64,/9j/4AAQ...`

      <Warning>
        The URL must be directly accessible over the public internet and cannot require login, cookies, or temporary page authorization.
      </Warning>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      Image aspect ratio.

      Supports the following values:

      * `1:1` - Square (default)
      * `5:4` / `4:5` - Slight landscape / portrait
      * `4:3` / `3:4` - Standard landscape / portrait
      * `16:9` / `9:16` - Widescreen landscape / portrait

      <Warning>
        `aspect_ratio` indicates the target ratio setting of the model and does not guarantee fixed pixel dimensions. The returned dimensions will be the model native size close to this ratio.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      Image resolution tier.

      * `1K` - Standard resolution (default)
      * `2K` - High-definition resolution
    </ParamField>

    <ParamField body="output_n" type="string" default="1">
      Number of images to generate.

      Supports the following values:

      * `"1"` - Generate 1 image (default)
      * `"2"` - Generate 2 images
      * `"4"` - Generate 4 images
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Custom task ID provided by the caller, used for idempotent submission and querying results.

  * Length is 1-64 characters
  * Only letters, numbers, underscores, and hyphens are allowed
  * Cannot be reused under the same API Key
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  Caller task ID, can be used to query results.
</ResponseField>

<ResponseField name="status" type="string">
  Initial status, fixed as `"pending"`.
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time, in ISO 8601 format.
</ResponseField>

## 查询结果

After successful submission, use the same `out_task_id` to call:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flux_3_klein_task_001"
  }'
```

Task statuses include `pending`, `processing`, `completed`, and `failed`. After the task is completed, the result images are located in `data.output`, which is an array of multiple image URLs when multiple images are generated.
