---
title: 'Midjourney V8.2 Image Generation'
description: |
    - Asynchronous processing mode, returns a task ID for subsequent queries
    - Generates 4 independent images per request, billed per request, not per image
    - Supports text-to-image, reference images (up to 4 images), style reference, and image editing
    - Aspect ratio, quality, and speed are selected via parameters, without needing to manually write Midjourney parameters in the prompt
api: 'POST https://aireiter.com/api/openapi/submit'
---

## Body

<ParamField body="model" type="string" required>
  Model name, fixed to `"mj_v8_2"`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Text description of the image, written in natural language to describe the desired scene

      * Midjourney parameters such as version, aspect ratio, quality, and speed are automatically added by the fields below and do not need to be written manually
      * Manually written `--` parameters (such as `--ar`, `--v`, `--fast`) in the prompt will be ignored; content starting from the first `--` will not take effect
      * When using image editing (`use_edit`), you can directly write modification instructions, for example: "Render this logo as a hand drawn pencil sketch"
    </ParamField>

    <ParamField body="image_url" type="string[]">
      URL list of reference images (Image Prompt), affecting the content, composition, and color scheme of the final result

      * Up to 4 images, used in the order passed
      * If omitted, text-to-image generation is performed
      * Supports the following two formats:
        1. Publicly accessible URL (cannot require login, cookies, or temporary authorization)
        2. Base64 encoded format
           * Must use the complete Data URI format: `data:image/{format};base64,{base64_data}`
           * Supported image formats: jpeg, png, webp
           * Example: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ Note: Must include the `data:image/jpeg;base64,` prefix; Base64 image size cannot exceed 10 MB
    </ParamField>

    <ParamField body="image_weight" type="number" default="1">
      Reference image weight (corresponding to `--iw`), indicating how closely the output adheres to the reference image

      * Value range: 0-3, default is 1; higher values make it resemble the reference image more
      * Takes effect only when `image_url` is provided
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      Image aspect ratio (corresponding to `--ar`)

      Supported aspect ratios:

      * `1:1` - Square (default)
      * `16:9` - Landscape widescreen
      * `9:16` - Portrait vertical
      * `4:3` - Landscape 4:3
      * `3:4` - Portrait 3:4
      * `3:2` - Landscape 3:2
      * `2:3` - Portrait 2:3
    </ParamField>

    <ParamField body="quality" type="string" default="sd">
      Image quality level

      Supported values:

      * `sd` - Standard definition (default), 1024×1024 per image at 1:1
      * `hd` - Native high definition, 2048×2048 per image at 1:1

      Other aspect ratios are converted proportionally; the actual size depends on the returned image.
    </ParamField>

    <ParamField body="speed" type="string" default="fast">
      Generation speed (corresponding to `--fast` / `--relax`)

      Supported values:

      * `fast` - Fast mode (default)
      * `relax` - Relaxed mode, longer queuing time

      Relaxed mode is processed by a dedicated queue, which in practice is more than twice as slow as fast mode.
    </ParamField>

    <ParamField body="use_style_ref" type="boolean" default="false">
      Whether to enable style reference (corresponding to `--sref`)

      Borrows the art style, color scheme, and texture from another image without copying its people or objects. When set to `true`, `style_image_url` must be provided.
    </ParamField>

    <ParamField body="style_image_url" type="string">
      Style reference image, 1 image

      * Takes effect only when `use_style_ref` is `true`, and is required in this case
      * Format requirements are the same as `image_url`
    </ParamField>

    <ParamField body="style_weight" type="number" default="100">
      Style strength (corresponding to `--sw`)

      * Value range: 0-1000, default is 100
      * Takes effect only when `use_style_ref` is `true`
    </ParamField>

    <ParamField body="use_edit" type="boolean" default="false">
      Whether to enable image editing (corresponding to `--edit`)

      Edits an existing image using `prompt` as the modification instruction. When set to `true`, `edit_image_url` must be provided. Can be used simultaneously with `image_url` and style reference.
    </ParamField>

    <ParamField body="edit_image_url" type="string">
      Image to be edited, 1 image

      * Takes effect only when `use_edit` is `true`, and is required in this case
      * Format requirements are the same as `image_url`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Caller Task ID

  User-defined task identifier, required. Supports only letters, numbers, `_`, and `-`, with a length of 1-64 characters
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  Caller task ID, can be used to query results
</ResponseField>

<ResponseField name="status" type="string">
  Initial status, fixed as `"pending"`
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time (ISO format)
</ResponseField>

After the task is completed, retrieve the result via the query endpoint: `data.output` contains 4 images, arranged in the order of the original 2x2 grid: top-left, top-right, bottom-left, and bottom-right. Generation usually takes a few minutes; please do not submit repeatedly while waiting.

              dataTaskWithRequest:request

                      return;
                  }

                                                          encoding:NSUTF8StringEncoding];
                  NSLog(@"%@", result);
              }];

          [task resume];
          [[NSRunLoop mainRunLoop] run];
      }
      return 0;
  }
