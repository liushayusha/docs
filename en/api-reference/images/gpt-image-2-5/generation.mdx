## Body

<ParamField body="model" type="string" required>
  Model name, choose one of the two:

  * `"gpt_image_2_5_flare"` — Flare, faster for everyday text-to-image / image editing
  * `"gpt_image_2_5_sunburst"` — Sunburst, greater emphasis on editing fidelity (characters, layout, product appearance)

  There is no bare `gpt-image-2.5` ID. Keep the prompt, reference images, aspect ratio, and resolution identical when comparing the two tiers.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Text description for image generation

      * Supports Chinese and English; detailed descriptions are recommended
      * When editing images, clearly specify what to change and what must remain unchanged
      * Before submission, it will undergo platform sensitive word / safety review; hitting violating content will directly return an error
    </ParamField>

    <ParamField body="image_url" type="string[]">
      Array of reference images; when passed, it enters image-to-image / editing mode

      * Up to 10 reference images
      * If not passed, it uses pure text-to-image mode
      * Supports the following two formats:
        1. Publicly accessible URL
        2. Base64 encoded format
           * Must use the complete Data URI format: `data:image/{格式};base64,{base64数据}`
           * Supported image formats: jpeg, png, webp
           * Example: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ Note: Must include the `data:image/jpeg;base64,` prefix
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      Aspect ratio for image generation, default is `auto`

      Supports the following values:

      * `auto` - Automatically select the most suitable aspect ratio
      * `1:1` - Square
      * `16:9` / `9:16` - Widescreen landscape / portrait
      * `4:3` / `3:4` - Standard landscape / portrait
      * `3:2` / `2:3` - Classic landscape / portrait
      * `5:4` / `4:5` - Near-square landscape / portrait
      * `21:9` - Ultra-wide landscape

      <Warning>
        Only aspect ratio strings or `auto` are supported; passing pixel dimensions (such as `1024x1024`) will directly return an error. Use `size` if exact pixels are required.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      Resolution tier, default is `1K`

      * `1K` - Approx. 1024 base
      * `2K` - Approx. 2048 base
      * `4K` - Approx. 3840 base

      <Warning>
        Do not pass `resolution` / `aspect_ratio` when `size` is passed, otherwise a 400 error will be returned.
      </Warning>
    </ParamField>

    <ParamField body="size" type="string">
      Custom pixel dimensions (API only, **mutually exclusive** with `aspect_ratio` / `resolution`)

      Formatted as `宽x高` (width x height), e.g., `2048x1536`, `3840x2160`.

      **Usage Limitations:**

      * Format must match `^\d+x\d+$`
      * Both width and height must be multiples of 16
      * Each side must not exceed 3840
      * Long side / short side ratio must not exceed 3:1
      * Total pixels (width × height) must be between **655,360 ~ 8,294,400**
      * Mutually exclusive with `aspect_ratio` and `resolution`; passing them together returns 400
    </ParamField>

    <ParamField body="background" type="string" default="auto">
      Output image background, default is `auto`

      * `auto` - The model decides whether to make it transparent
      * `opaque` - Opaque background
      * `transparent` - Transparent background, returns PNG with alpha channel

      <Warning>
        When `transparent` is selected, the platform automatically outputs in PNG format without needing to pass `output_format`. `output_format` is not available on this page.
      </Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID

  User-defined task identifier, required. Use the same value to call `POST /api/openapi/query` when querying results.
</ParamField>

## Size × Resolution Mapping Table

`aspect_ratio × resolution` → Actual pixels (`auto` is automatically selected by the model and is not in the table):

| aspect\_ratio | `1K`      | `2K`      | `4K`      |
| ------------- | --------- | --------- | --------- |
| `1:1`         | 1024×1024 | 2048×2048 | 2880×2880 |
| `3:2`         | 1248×832  | 2496×1664 | 3504×2336 |
| `2:3`         | 832×1248  | 1664×2496 | 2336×3504 |
| `4:3`         | 1152×864  | 2304×1728 | 3264×2448 |
| `3:4`         | 864×1152  | 1728×2304 | 2448×3264 |
| `5:4`         | 1120×896  | 2240×1792 | 3200×2560 |
| `4:5`         | 896×1120  | 1792×2240 | 2560×3200 |
| `16:9`        | 1280×720  | 2560×1440 | 3840×2160 |
| `9:16`        | 720×1280  | 1440×2560 | 2160×3840 |
| `21:9`        | 1456×624  | 3024×1296 | 3696×1584 |

> `2:1`, `1:2`, and `9:21` are not supported; passing them returns 400. Please use `size` for aspect ratios not listed in the table.

## Response

<ResponseField name="out_task_id" type="string">
  Caller task ID, used for querying results
</ResponseField>

<ResponseField name="status" type="string">
  Initial status, fixed as `"pending"`
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  Estimated credit cost
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time (ISO format)
</ResponseField>

To query the completion status, use `POST https://aireiter.com/api/openapi/query` with the same `out_task_id`. Failed tasks will not deduct credits.
