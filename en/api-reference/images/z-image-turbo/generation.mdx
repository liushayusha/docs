description: |
    - Asynchronous processing mode, returns a task ID for subsequent queries
    - Alibaba Tongyi high-speed text-to-image model, generates images in about 8 sampling steps, focused on realistic texture
    - Clear rendering of Chinese and English text, suitable for posters, banners, and social media assets with titles
    - Supports 9 image aspect ratios and returns 1 image per request
    - Only supports text-to-image generation; reference images, image editing, and custom pixel dimensions are not supported
    - Submitted prompts undergo platform sensitive-word / safety review, and violating content will be rejected outright

## Body

<ParamField body="model" type="string" required>
  Model name.

  Fixed value: `"z_image_turbo"`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Image generation prompt, up to 2000 characters.

      * Supports both Chinese and English. It is recommended to clearly describe the subject, scene, composition, lighting, and materials
      * The model leans toward a realistic style, so prompts that describe real lighting and materials work better
      * If text needs to appear in the image, wrap the text in quotation marks. Chinese and English are both supported
      * Before submission, it will go through the platform's sensitive-word / safety review. If prohibited content is detected, an error will be returned directly
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      Image aspect ratio.

      Supported values:

      * `1:1` - Square (default)
      * `16:9` / `9:16` - Widescreen landscape / portrait
      * `4:3` / `3:4` - Standard landscape / portrait
      * `3:2` / `2:3` - Classic landscape / portrait
      * `2:1` / `1:2` - Panoramic landscape / tall portrait

      <Warning>
        `aspect_ratio` indicates the model's target aspect-ratio bucket and does not guarantee a fixed pixel size. The returned image uses the model's native size closest to that ratio. For example, a measured 16:9 returns 1536×864.
      </Warning>
    </ParamField>

    <ParamField body="seed" type="integer">
      Random seed, used to reproduce results, range 1-2147483647.

      * The same `prompt` + `seed` combination will generate images with a similar composition
      * If not provided, each generation will be random
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Caller-defined task ID, used for idempotent submission and result queries.

  * Length: 1-64 characters
  * Only letters, numbers, underscores, and hyphens are allowed
  * Cannot be reused under the same API Key
</ParamField>

<Note>
  Z-Image Turbo only supports text-to-image. Reference images (`image_url`), image editing, resolution tiers (`resolution`), and batch image generation (`output_n`) are not supported; passing a custom pixel size `size` will directly return `Model "z_image_turbo" does not support size parameter`. Each request returns exactly 1 image. If you need multiple images, please submit multiple times with different `seed` values.

  If you need reference images, image-to-image, or a larger canvas, please use GPT-Image 2, Seedream 5.0 Pro, or Nano Banana Pro instead.
</Note>

## Query Results

After submission succeeds, call with the same `out_task_id`:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "z_image_turbo_task_001"
  }'
```

Task statuses include `pending`, `processing`, `completed`, and `failed`. After the task is completed, the output image is located in `data.output`, and the actual credits used are in `data.credits_used`. If task generation fails, the system will automatically refund the pre-deducted credits for this task.
