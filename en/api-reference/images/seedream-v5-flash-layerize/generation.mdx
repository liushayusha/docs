---
title: 'Seedream 5.0 Flash Layerize Layer Separation'
description: |
    - Asynchronous processing mode, returning a task ID for subsequent queries
    - Splits an image into a background layer + up to 16 independently editable transparent PNG layers
    - Each layer includes name, description, z_index, and bounding_box
    - Post-billing mode: Checks balance upon submission and settles based on the actual number of output images after task completion (the background layer and each layer count as 1 image each)
api: 'POST https://aireiter.com/api/openapi/submit'
---

## Body

<ParamField body="model" type="string" required>
  Model name

  Fixed value: `"seedream_v5_flash_layerize"`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object

  <Expandable title="params Object Properties">
    <ParamField body="image_url" type="string | string[]" required>
      Original image to separate

      * Required, and only **1 image** can be passed
      * Supported image formats: png, jpeg; maximum 30 MB per image
      * Total pixel range: 262,144 – 36,000,000, aspect ratio range: 1:16 – 16:1
      * Supports the following two formats:
        1. Publicly accessible URL
        2. Base64 encoded format
           * Must use the full Data URI format: `data:image/{format};base64,{base64_data}`
           * Example: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ Note: Must include the `data:image/jpeg;base64,` prefix; Base64 image size cannot exceed 10 MB
    </ParamField>

    <ParamField body="prompt" type="string">
      Layer separation prompt (Optional)

      * When provided, separates specified elements according to the prompt, for example `Separate the title text and the parrot into independent layers`
      * You can use `<bbox>x1 y1 x2 y2</bbox>` to specify precise element positions with normalized coordinates from 0–1000, for example `Separate the parrot <bbox>330 274 641 991</bbox> into a layer`
      * If omitted or fewer than 4 characters, the model automatically identifies key elements in the image
      * Maximum 5,000 characters
    </ParamField>

    <ParamField body="resolution" type="string" default="auto">
      Output resolution tier

      * `auto` - Automatically selected based on the original image dimensions (Default)
      * `1K` - 1K resolution
      * `1.5K` - 1.5K resolution
      * `2K` - 2K resolution

      The base image maintains the aspect ratio of the original image, and each layer maintains the aspect ratio of its corresponding element in the original image.
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      Output format of the base image

      * `png` - PNG (Default)
      * `jpeg` - JPEG

      Only controls the base image format; separated layers are fixed as transparent PNG.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  Callback URL after task completion
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata, returned as-is
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Caller task ID

  User-defined task identifier, required
</ParamField>

## 查询任务结果

After the task is submitted, use the `POST /api/openapi/query` endpoint to poll the task status until `status` is `completed` or `failed`. After the task is completed, the `output` field returns the list of layers.

      "out_task_id": "my_task_123456"

### Query Response - Layer Output Structure

After the task is completed, `output` is an array of layer objects, where each layer contains `url` and `metadata`:

<ResponseField name="output" type="array">
  List of layers, each element is a layer object, up to 17 in total (1 base image + 16 layers)

  <Expandable title="Layer Object Properties">
    <ResponseField name="url" type="string">
      The image URL of this layer. The base image format is determined by `output_format`, while the remaining layers are transparent PNGs
    </ResponseField>

    <ResponseField name="metadata" type="object">
      Layer metadata

      <Expandable title="metadata Properties">
        <ResponseField name="kind" type="string">
          Fixed value `"layer"`, indicating that this is a layer output
        </ResponseField>

        <ResponseField name="z_index" type="number">
          Layer hierarchy index

          * `z_index = 0`: Base image (full background), `bounding_box` is `null`
          * `z_index ≥ 1`: Foreground layers, arranged in back-to-front order
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          The position area of the layer in the original image

          `null` for the base image (z_index=0); for the remaining layers, a coordinate object is returned:

          <Expandable title="bounding_box Properties">
            <ResponseField name="absolute" type="array">
              Absolute pixel coordinates `[x1, y1, x2, y2]`, based on the output base image resolution
            </ResponseField>

            <ResponseField name="normalized" type="array">
              Normalized coordinates `[x1, y1, x2, y2]`, range 0–1000
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          Layer name, `null` for the base image
        </ResponseField>

        <ResponseField name="description" type="string | null">
          Layer description, `null` for the base image
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>
