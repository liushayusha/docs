---
title: 'Seedream 5.0 Pro Layerize Layer Decomposition'
description: |
    - Asynchronous processing mode, returning a task ID for subsequent queries
    - Decompose a single image into multiple independently editable transparent PNG layers
    - Each layer includes a name, description, z_index, and bounding_box
    - Post-payment billing mode: balance is checked on submission, and settlement is based on actual output after the task is completed
api: 'POST https://aireiter.com/api/openapi/submit'

## Body

<ParamField body="model" type="string" required>
  Model name

  Fixed value: `"seedream_v5_pro_layerize"`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object

  <Expandable title="Params Object Properties">
    <ParamField body="image_url" type="string" required>
      Original image URL to be decomposed

      * Required, and only **1 image** can be submitted
      * Supports the following two formats:
        1. Publicly accessible URL
        2. Base64-encoded format
           * Must use the complete Data URI format: `data:image/{format};base64,{base64data}`
           * Supported image formats: jpeg, png, webp
           * Example: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ Note: The `data:image/jpeg;base64,` prefix must be included, and the Base64 image size cannot exceed 10MB
      * The minimum image size must be ≥ 300px
    </ParamField>

    <ParamField body="prompt" type="string">
      Text prompt (optional)

      Can be used to guide the generation language for layer naming and descriptions. For example, passing `Return name and description in english.` can make the layer names and descriptions return in English.

      If not provided, the default language will be used.
    </ParamField>

    <ParamField body="image_size" type="string" default="auto">
      Output resolution tier

      * `auto` - Automatic selection (default)
      * `auto_1K` - 1K resolution
      * `auto_1.5K` - 1.5K resolution
      * `auto_2K` - 2K resolution
    </ParamField>

    <ParamField body="enhance_prompt_mode" type="string" default="standard">
      Prompt enhancement mode (API only)

      * `standard` - Standard mode (default)
      * `fast` - Fast mode
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  Callback URL after the task is completed
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata, returned as-is
</ParamField>

<ParamField body="out_task_id" type="string" required>

</ParamField>

## Query Task Results

After the task is submitted, use the `POST /api/openapi/query` endpoint to poll the task status. Once the task is completed, the `output` field returns a list of layers.

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "my_task_123456"
    }'
  ```
</RequestExample>

### Query Response - Layer Output Structure

After the task is completed, `output` is an array of layer objects, and each layer contains `url` and `metadata`:

<ResponseField name="output" type="array">
  Layer list, each element is a layer object

  <Expandable title="Layer Object Properties">
    <ResponseField name="url" type="string">
      The transparent PNG image URL for this layer
    </ResponseField>

    <ResponseField name="metadata" type="object">
      Layer metadata

      <Expandable title="Metadata Properties">
        <ResponseField name="kind" type="string">
          Fixed value `"layer"`, indicating that this is a layer output
        </ResponseField>

        <ResponseField name="z_index" type="number">
          Layer index

          * `z_index = 0`: bottom layer (the reconstructed full background image), `bounding_box` is `null`
          * `z_index ≥ 1`: foreground layers, ordered from back to front
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          The position area of the layer in the original image

          The bottom layer (`z_index=0`) is `null`, and the remaining layers return a coordinate object:

          <Expandable title="Bounding Box Properties">
            <ResponseField name="absolute" type="array">
              Absolute pixel coordinates `[x1, y1, x2, y2]`, based on the original image resolution
            </ResponseField>

            <ResponseField name="normalized" type="array">
              Normalized coordinates `[x1, y1, x2, y2]`, ranging from 0–1000
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          Layer name (for example, `"Sky background"`, `"Moss platform"`)
        </ResponseField>

        <ResponseField name="description" type="string | null">
          Layer description (for example, `"Soft light blue sky with scattered fluffy white clouds"`)
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="credits_used" type="number">
  Actual credits used
</ResponseField>
