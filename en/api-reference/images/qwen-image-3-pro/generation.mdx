## Body

<ParamField body="model" type="string" required>
  Model name, fixed value: `"qwen_image_3_pro"`.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Image generation or editing instructions. Supports both Chinese and English.

      The Pro model is suitable for tasks that require readable text, complex hierarchy, dense layouts, and high-detail rendering. It is recommended to clearly describe the text content, font style, hierarchy, position, whitespace, and reference image features that need to be preserved.
    </ParamField>

    <ParamField body="image_url" type="string[]">
      Array of reference images. When provided, image-to-image mode is used; when omitted, text-to-image mode is used.

      * Up to 3 reference images
      * Maximum 10MB per image
      * Supports jpeg, png, webp
      * Supports publicly accessible URLs or complete Base64 Data URIs

      <Warning>
        The image URL must be directly accessible from the public internet and cannot rely on login status, cookies, or temporary page authorization.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      Output resolution tier.

      * `1K` - Base resolution (default)
      * `2K` - High-definition resolution, suitable for text, posters, and dense layouts
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      Output image aspect ratio.

      Supports the following values:

      * `1:1` - Square (default)
      * `3:2` / `2:3` - Classic landscape / portrait
      * `4:3` / `3:4` - Standard landscape / portrait
      * `16:9` / `9:16` - Widescreen landscape / portrait

    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      Number of images generated for this task, ranging from `1` to `6`.
    </ParamField>

    <ParamField body="prompt_extend" type="boolean" default="false">
      Intelligent prompt rewriting. Disabled by default to ensure predictable results. Set to `true` when intelligent rewriting is needed.
    </ParamField>

    <ParamField body="prompt_extend_mode" type="string" default="direct">
      Prompt rewriting mode. Effective only when `prompt_extend` is `true`.

      * `direct` - Balanced rewriting, supports both text-to-image and image-to-image
      * `agent` - Aggressive rewriting, supports text-to-image only
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      Negative prompt, used to describe content that should not appear in the result, such as blur, garbled text, crowded layouts, or distorted structures.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Caller-defined task ID, used for idempotent submission and result querying.

  * Length of 1-64 characters
  * Recommended to use only letters, numbers, underscores, and hyphens
  * Do not reuse the same value under the same API Key
</ParamField>

## Query Results

After the submission succeeds, call the query endpoint using the same `out_task_id`:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "qwen_image_3_pro_task_001"
  }'
```

Task statuses include `pending`, `processing`, `completed`, and `failed`. After the task is completed, the image array is located in `data.output`.
