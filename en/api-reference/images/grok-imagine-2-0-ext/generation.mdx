---
title: 'Grok Imagine 2.0 Ext Image Generation'
description: |
    - Asynchronous text-to-image generation. After submission, get the result through the task query endpoint
    - Supports 7 common image aspect ratios
    - Supports generating 1-12 images per request, and the number can be any integer within the supported range
    - Text-to-image only; reference image input is not supported
    - Submitted prompts will go through the platform's sensitive word / safety review, and violating content will be rejected directly
api: 'POST https://aireiter.com/api/openapi/submit'

## Authorizations

<ParamField header="Authorization" type="string" required>
  All endpoints require Bearer Token authentication.

  Visit the <a href={apiKeyUrl} target="_blank">API Key management page</a> to get your API Key, and add the following to the request header:

  ```text
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  Model name, fixed value: `"grok_imagine_2_0_ext"`.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Image generation prompt. Supports Chinese and English, and cannot be empty after trimming leading and trailing spaces.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      Output image aspect ratio. Supported:

      * `1:1` (default)
      * `2:3` / `3:2`
      * `3:4` / `4:3`
      * `9:16` / `16:9`

      <Warning>
        `auto`, custom pixel dimensions, and other aspect ratios are not supported.
      </Warning>
    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      Number of output images, ranging from `1` to `12`.

      Any integer within the range can be used, such as `3`, `5`, or `7`, not limited to `1`, `4`, `8`, or `12`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Caller-defined task ID, used for idempotent submission and result retrieval.

  * Length is 1-64 characters
  * Only letters, numbers, underscores, and hyphens are supported
  * Cannot be reused under the same API Key
</ParamField>

<Warning>
  This model only supports text-to-image generation. Do not pass `image_url`, `resolution`, `quality`, `size`, or output format parameters.
</Warning>

## Response

<ResponseField name="out_task_id" type="string">
  Caller task ID, can be used to query the task status and result.
</ResponseField>

<ResponseField name="status" type="string">
  Initial status, usually `"pending"`.
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  Estimated credit consumption for this task.
</ResponseField>

<ResponseField name="created_at" type="string">
  Task creation time, in ISO 8601 format.
</ResponseField>

## Query Results

After the submission succeeds, call [Get Task Status](/en/api-reference/tasks/status) and query using the same `out_task_id`. After the task is completed, the image results are located in `data.output`.

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/submit \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "model": "grok_imagine_2_0_ext",
      "params": {
        "prompt": "Red apples on a white ceramic plate, clean studio product photography",
        "aspect_ratio": "1:1",
        "output_n": 3
      },
      "out_task_id": "grok_image_2_ext_001"
    }'
  ```

  ```python Python
  import requests

  response = requests.post(
      "https://aireiter.com/api/openapi/submit",
      headers={
          "Authorization": "Bearer <token>",
          "Content-Type": "application/json"
      },
      json={
          "model": "grok_imagine_2_0_ext",
          "params": {
              "prompt": "Glass greenhouse in a wildflower meadow at sunrise, editorial photography style",
              "aspect_ratio": "2:3",
              "output_n": 3
          },
          "out_task_id": "grok_image_2_ext_python_001"
      }
  )

  print(response.json())
  ```
