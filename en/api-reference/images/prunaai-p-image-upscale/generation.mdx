---
title: 'P-Image-Upscale Image Upscaling'
description: |
    - Asynchronous processing mode, returns a task ID for subsequent queries
    - PrunaAI super-resolution model, upscaling small or compressed images into clearer, large-scale images
    - Supports upscaling by target megapixels (MP) or by scale factor, outputting up to 128 MP
    - Optional detail enhancement and realism enhancement, supporting jpg / png / webp output
api: 'POST https://aireiter.com/api/openapi/submit'

## Body

<ParamField body="model" type="string" required>
  Model Name

  Fixed value: `"prunaai_p_image_upscale"`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object

  <Expandable title="params Object Properties">
    <ParamField body="image_url" type="string" required>
      Original image URL to be upscaled

      * Required, and only **1 image** can be passed
      * Supports the following two formats:
        1. Publicly accessible URL
        2. Base64 encoded format
           * Must use the full Data URI format: `data:image/{format};base64,{base64_data}`
           * Supported image formats: jpeg, png, webp
           * Example: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ Note: Must include the `data:image/jpeg;base64,` prefix part, Base64 image size cannot exceed 10 MB
    </ParamField>

    <ParamField body="upscale_mode" type="string" default="target">
      Upscale mode

      * `target` - Upscale to a fixed megapixel (MP) size based on target pixels (default), used with the `target` parameter
      * `factor` - Upscale by factor, each side multiplied by `factor`, used with the `factor` parameter
    </ParamField>

    <ParamField body="target" type="integer" default="4">
      Target resolution (unit: MP, megapixels)

      * Value range: `1` ~ `128`
      * Only takes effect when `upscale_mode` is `target`
    </ParamField>

    <ParamField body="factor" type="number" default="2">
      Upscale factor

      * Value range: `1` ~ `8`
      * Only takes effect when `upscale_mode` is `factor`
      * Output image cannot exceed 128 MP at maximum; capped automatically if exceeded
    </ParamField>

    <ParamField body="enhance_details" type="boolean" default="false">
      Detail enhancement

      Enhances subtle textures and fine details, which may increase contrast and cause slight deviations from the original image.
    </ParamField>

    <ParamField body="enhance_realism" type="boolean" default="false">
      Realism enhancement

      Enhances image realism, but may cause larger deviations from the original image. Recommended for AI-generated images.
    </ParamField>

    <ParamField body="output_format" type="string" default="jpg">
      Output image format

      * `jpg` - JPEG format (default)
      * `png` - PNG format
      * `webp` - WebP format
    </ParamField>

    <ParamField body="output_quality" type="integer" default="80">
      Output image quality

      * Value range: `0` ~ `100`, where 100 is best quality and 0 is lowest quality
      * This parameter is invalid when `output_format` is `png`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  Callback URL after task completion
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata, returned as is
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Originator task ID

  User-defined task identifier, required
</ParamField>

## 查询任务结果

After submitting the task, use the `POST /api/openapi/query` endpoint to poll the task status. After the task is completed, the `output` field returns the upscaled image.

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "my_task_123456"
    }'
  ```
</RequestExample>

<ResponseField name="output" type="array">
  List of output images, each element containing the `url` of the upscaled image
</ResponseField>
