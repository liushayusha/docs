    - Asynchronous processing mode, returns a task ID for subsequent queries
    - Supports text-to-image and image-to-image. If no reference image is provided, it uses text-to-image

## Body

<ParamField body="model" type="string" required>
  Model name, fixed value: `"qwen_image_3"`.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Image generation or editing instruction. Chinese and English are supported.

      It is recommended to clearly describe the subject, scene, composition, lighting, materials, text content, and the parts in the reference image that need to be preserved or modified.
    </ParamField>

    <ParamField body="image_url" type="string[]">
      Array of reference images. If provided, image-to-image mode is used; if omitted, text-to-image mode is used.

      * Up to 3 reference images
      * Maximum size per image: 10MB
      * Supports jpeg, png, and webp
      * Supports publicly accessible URLs or a complete Base64 Data URI

      <Warning>
        The image URL must be directly accessible from the public internet and cannot rely on login status, cookies, or temporary page authorization.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      Output resolution tier.

      * `1K` - Standard resolution (default)
      * `2K` - High-definition resolution
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      Output image aspect ratio.

      Supported values:

      * `1:1` - Square (default)
      * `3:2` / `2:3` - Classic landscape / portrait
      * `4:3` / `3:4` - Standard landscape / portrait
      * `16:9` / `9:16` - Widescreen landscape / portrait

    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      Number of images generated in this task, ranging from `1` to `6`.
    </ParamField>

    <ParamField body="prompt_extend" type="boolean" default="false">
      Intelligent prompt rewriting. Disabled by default to keep results predictable. Set to `true` when intelligent rewriting is needed.
    </ParamField>

    <ParamField body="prompt_extend_mode" type="string" default="direct">
      Prompt rewriting mode. Takes effect only when `prompt_extend` is `true`.

      * `direct` - Balanced rewriting, supports both text-to-image and image-to-image
      * `agent` - Aggressive rewriting, supports text-to-image only
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      Negative prompt, used to describe content that you do not want to appear in the result, such as blur, distortion, or incorrect text.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Client-defined task ID, used for idempotent submission and result queries.

  * Length: 1-64 characters
  * It is recommended to use only letters, numbers, underscores, and hyphens
  * Do not reuse it under the same API Key
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">

<ResponseField name="status" type="string">
  Initial status, usually `"pending"`.
</ResponseField>

<ResponseField name="created_at" type="string">

</ResponseField>

## Query Results

After submission succeeds, use the same `out_task_id` to call the query endpoint:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "qwen_image_3_task_001"
  }'
```

Task statuses include `pending`, `processing`, `completed`, and `failed`. After the task is completed, the image array is located in `data.output`.
