## Body

<ParamField body="model" type="string" required>
  Model name, fixed value: `"qwen_image_3"`.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Image generation or editing instructions. Supports Chinese and English.

      It is recommended to clearly describe the subject, scene, composition, lighting, materials, text content, and the parts in the reference image that need to be kept or modified.
    </ParamField>

    <ParamField body="image_url" type="string[]">
      Reference image array. When provided, image-to-image mode is used; when not provided, text-to-image mode is used.

      * Up to 3 reference images
      * Maximum size of a single image: 10MB
      * Supports jpeg, png, webp
      * Supports publicly accessible URLs or complete Base64 Data URIs

      <Warning>
        The image URL must be directly accessible from the public internet and cannot rely on login status, cookies, or temporary page authorization.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      Output resolution tier.

      * `1K` - Standard resolution (default)
      * `2K` - High definition resolution
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      Output image aspect ratio.

      Supported values:

      * `1:1` - Square (default)
      * `3:2` / `2:3` - Classic landscape / portrait
      * `4:3` / `3:4` - Standard landscape / portrait
      * `16:9` / `9:16` - Widescreen landscape / portrait

      <Warning>
        The current endpoint does not support `21:9`, nor does it support custom pixel dimensions such as `1024x1024`.
      </Warning>
    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      Number of images generated for this task, ranging from `1` to `6`.
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      Output format, currently fixed to `png`.

      <Warning>
        The current AIReiter integration channel does not provide a JPEG output option.
      </Warning>
    </ParamField>

    <ParamField body="prompt_extend" type="boolean" default="true">
      Whether to enable intelligent prompt expansion. Enabled by default, suitable for shorter prompts.
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      Negative prompt, used to describe content that should not appear in the result, such as blur, distortion, or incorrect text.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Caller-defined task ID, used for idempotent submission and result querying.

  * Length must be 1-64 characters
  * It is recommended to use only letters, numbers, underscores, and hyphens
  * Do not reuse the same value under the same API Key
</ParamField>

## Billing

| Billing Item | Price |
| --- | ---: |
| Per 1K output image | 2.40 credits ($0.024) |
| Per 2K output image | 2.40 credits ($0.024) |
| Per input reference image | 0.25 credits ($0.0025) |

Billing formula: `2.40 × output_n + 0.25 × number of reference images`.

For example, generating 1 image and passing in 1 reference image is expected to consume `2.65` credits. When the submission succeeds, `estimated_credits` in the Response is the estimated consumption; after the task is completed, `credits_used` in the query Response is the actual consumption. No final charge will be applied if the task fails.

## Query Results

After submission succeeds, call the query endpoint using the same `out_task_id`:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "qwen_image_3_task_001"
  }'
```

Task status includes `pending`, `processing`, `completed`, and `failed`. After the task is completed, the image array is located in `data.output`, and the actual credits used are located in `data.credits_used`.
