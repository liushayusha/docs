<Note>
The model name for Kling 4.0 in AIReiter is `kling_v4`. Use `type` to select the generation mode. Different modes accept different assets, see [Mode Parameter Comparison](#模式参数对照) below.

The generated video always includes a stereo audio track, which cannot be turned off. 4K, `negative_prompt`, and `seed` are not supported.
</Note>

## Body

<ParamField body="model" type="string" required>
  Model name, fixed to `kling_v4`.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Text description for video generation, supporting Chinese and English. Required.

      * `reference` - Can use `@Image1`, `@Video1`, and `@Audio1` to refer to assets, numbered starting from 1 in the order of the `image_url`, `video_url`, and `audio_url` arrays respectively
      * `edit` - The original video is `@Video1`, reference images are `@Image1`, `@Image2`, etc. Clearly state what to modify
      * `extend` - Describe what happens next
    </ParamField>

    <ParamField body="type" type="string" default="reference">
      Generation mode:

      * `reference` - Text-to-video / Reference, default value. Passing only a prompt generates text-to-video; reference images, reference videos, and reference audio can also be added
      * `frame` - First and last frames. The first frame is required, with optional intermediate frames and last frame
      * `edit` - Video editing. Modifies an original video based on the prompt
      * `extend` - Video extension. Continues generation from the end of the original video
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      Video duration, in seconds. Supports integers from `3` to `30`.

      * `edit` - Duration of the output video
      * `extend` - Duration of the added segment; the returned video will be the original video plus the added segment
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      Output resolution:

      * `720p` - Default value
      * `1080p`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      Video aspect ratio, only effective in `reference` mode:

      * `auto` - Default value. Follows the assets when reference assets are provided; 16:9 for pure text
      * `16:9` - Landscape
      * `9:16` - Portrait
      * `1:1` - Square
      * `21:9` - Ultrawide

      `frame` follows the aspect ratio of the first frame, while `edit` and `extend` inherit the aspect ratio of the original video. This field is ignored in these three modes.
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Image URL, must be directly accessible via the public network. Meaning varies by mode:

      * `reference` - Reference images, up to 10 images
      * `frame` - First frame, required. Only the first image is used; please use `end_image_url` for the last frame
      * `edit` - Reference images, up to 10 images, used to guide editing effects
      * `extend` - Not used

      Image requirements: Short edge no less than 300px, each image not exceeding 20 MB.
    </ParamField>

    <ParamField body="keyframe_url" type="string[]">
      Intermediate frame image URLs, only valid in `frame` mode. Up to 8 images, appearing between the first frame and last frame in array order.

      <Warning>
        The total number of first frames, intermediate frames, and last frames cannot exceed 10 images, and cannot exceed `video_length` + 1. For example, a 3-second video allows at most 4 images.
      </Warning>
    </ParamField>

    <ParamField body="end_image_url" type="string">
      Last frame image URL:

      * `frame` - Last frame, optional
      * `extend` - Target last frame, optional. The added segment will end with this image
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      Video URL, must be directly accessible via the public network. Formats: MP4, MOV, each not exceeding 200 MB.

      * `reference` - Reference videos, up to 5 segments, totaling no more than 30 seconds
      * `edit` - Original video, required, exactly 1 segment, duration 3-30 seconds
      * `extend` - Original video, required, exactly 1 segment, up to 30 seconds
      * `frame` - Not used
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      Reference audio URL, only valid in `reference` mode. Up to 3 segments, formats: MP3, WAV, 5-30 seconds each, each not exceeding 20 MB.

      <Warning>
        In `reference` mode, the total count of reference images, reference videos, and reference audio cannot exceed 15.
      </Warning>
    </ParamField>

    <ParamField body="audio_setting" type="string" default="origin">
      Audio processing method for the original video, only valid in `edit` mode:

      * `origin` - Retain original video audio, default value
      * `auto` - Regenerate audio
    </ParamField>
  </Expandable>
</ParamField>

  User-defined task identifier, required. Supports only letters, digits, underscores, and hyphens, with a length of 1-64 characters. This ID can be used later to query task status and results.
</ParamField>

## Query Task

Kling 4.0 is an asynchronous video generation model. After submitting a task, please use `out_task_id` to query the task status. You can also refer to [Get Task Status](/en/api-reference/tasks/status).

<ParamField body="out_task_id" type="string" required>
  The originator task ID passed when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "kling_v4_t2v_123456"
  }'
```

Once the query succeeds and is completed, the `output` array in the response will contain the generated video, with elements containing the `video` field.

Generation time varies depending on the mode and duration: a 1080p 5-second text-to-video task takes approximately 4.5 minutes in actual testing. The longer the duration and the more assets involved, the longer it will take. Please continue polling and do not resubmit.

## 模式参数对照

| `type` | Required | Optional | Duration |
|---|---|---|---|
| `reference` | `prompt` | `image_url` (≤10), `video_url` (≤5, total ≤30 seconds), `audio_url` (≤3), total ≤15; `aspect_ratio` | `video_length` 3-30 seconds |
| `frame` | `prompt`, first frame `image_url` | `keyframe_url` (≤8), `end_image_url` | `video_length` 3-30 seconds |
| `edit` | `prompt`, original video `video_url` (3-30 seconds) | `image_url` (≤10), `audio_setting` | Output duration is `video_length` |
| `extend` | `prompt`, original video `video_url` (≤30 seconds) | `end_image_url` | Adds `video_length` seconds, returns original video + new clip |

<Warning>
When `frame` mode is missing the first frame, or `edit` / `extend` mode is missing the original video, the task will end in failure. Please provide all required assets according to the table above.
</Warning>

## 使用说明

* When passing only prompts, it operates as text-to-video; when any reference material is provided, it is processed as reference-based generation. When `aspect_ratio` is set to `auto`, it follows the aspect ratio of the reference material.
* Video extension returns a single complete file: the original video comes first, followed by the newly added segment. In actual testing, extending a 5-second original video by 5 seconds returns a 10.0-second video with the same resolution as the original video and no noticeable seam at the transition.
* Video extension preserves the audio of the original video portion and automatically generates audio for the newly added segment; if the original video has no audio, that portion remains silent.
* Video editing preserves the original video audio by default; when new audio is required, pass `audio_setting: "auto"`.
