## Body

<ParamField body="model" type="string" required>
  Model name, fixed value:

  * `seedance2_5`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Text description for video generation.

      It is recommended to describe the subject, scene, action, camera movement, visual style, dialogue, and ambient sound.
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      Reference mode, which determines how reference materials are used:

      * `all_reference` - Full reference mode, which can use reference images, reference videos, and reference audio
      * `first_last_frame` - First and last frame mode, which uses the first frame and an optional last frame image
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Reference image URL.

      * `all_reference` mode: up to 30 images; maximum 50MB per image; minimum image side length 300px
      * `first_last_frame` mode: used as the first frame image; maximum 10MB; minimum image side length 300px

      The URL must be directly accessible from the public internet.
    </ParamField>

    <ParamField body="end_image_url" type="string">
      Last frame image URL, valid only in `first_last_frame` mode.

      Maximum image size is 10MB, minimum side length is 300px, and the URL must be directly accessible from the public internet.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      Reference video URL, valid only in `all_reference` mode, with support for up to 9 reference videos.

      Video requirements:

      * Single video duration: 2-30 seconds, total reference video duration must not exceed 30 seconds
      * Maximum size per video: 200MB
      * Frame rate: 24-60 FPS
      * Aspect ratio range: 0.4-2.5
      * Width and height range: 300-6000px
      * Total pixel count range: 409600-8295044

      <Warning>Do not pass this parameter in `first_last_frame` mode.</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      Reference audio URL, valid only in `all_reference` mode, with support for up to 10 audio files.

      Audio requirements:

      * Single audio duration: 2-30 seconds, total reference audio duration must not exceed 30 seconds
      * Supports WAV, MP3
      * Maximum size per audio file: 15MB

      <Warning>Do not pass this parameter in `first_last_frame` mode.</Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      Video resolution:

      * `480p`
      * `720p` - Default value
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      Output video duration, in seconds.

      Supports integers from `4` to `30`.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      Video aspect ratio:

      * `21:9` - Ultra-wide screen
      * `16:9` - Landscape, default value
      * `9:16` - Portrait
      * `4:3` - Standard landscape
      * `3:4` - Standard portrait
      * `1:1` - Square
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      Whether to generate AI audio synchronized with the video.

      * `true` - Generate audio, default value
      * `false` - Do not generate audio
    </ParamField>

    <ParamField body="output_format" type="string" default="mp4">
      Output video format:

      * `mp4` - General-purpose format with a smaller file size, default value
      * `mov` - High color precision format (yuv444p), suitable for post-production expansion and stitching
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Requesting party task ID.

  Generated by the caller and guaranteed to be unique. It supports letters, numbers, underscores, and hyphens, and must be 1-64 characters long. This ID is used later to query the task status and results.
</ParamField>

## Query Task

Seedance 2.5 uses asynchronous processing. After submission succeeds, use the same `out_task_id` to query the task:

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "seedance2_5_task_123456"
    }'
  ```
</RequestExample>

After the task is completed, the `output` array in the Response will contain the generated video URL. For the full field list, see [Get Task Status](/en/api-reference/tasks/status).

## Mode Rules

| type | Available Assets | Asset Limitations |
| --- | --- | --- |
| `all_reference` | `image_url`, `video_url`, `audio_url` | Up to 30 images, 9 videos, and 10 audio files |
| `first_last_frame` | `image_url`, `end_image_url` | Provide the first and last frame images as needed; please do not pass videos or audio |

<Warning>
Please ensure that all asset URLs are directly accessible from the public internet. The task is processed asynchronously, so do not use the HTTP connection from the submission request to wait for the final video.
</Warning>
