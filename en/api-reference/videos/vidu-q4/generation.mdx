  - Shengshu Technology Vidu Q4 video generation model
  - Asynchronous processing mode, returns a task ID for subsequent queries
  - Supports two modes: first-frame image-to-video and reference-image (with optional reference audio) to video
  - Supports 540p / 720p / 1080p / 2K / 4K output, video duration of 3-16 seconds, and generates synchronized dialogue and sound effects by default

<Note>
The model name for Vidu Q4 in AIReiter is `vidu_q4`. This model requires at least one image to be passed in, does not support pure text-to-video generation, and does not support start and end frames.
</Note>

## Body

<ParamField body="model" type="string" required>
  Model name, fixed value:

  * `vidu_q4`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string">
      Video content description, up to 20,000 characters.

      * Optional in `frame` mode, used to describe visual motion and camera movements
      * Required in `reference` mode

      In reference mode, assets can be referenced in order of upload, for example "the man in reference image 2" or "use the voice from reference audio 1".
    </ParamField>

    <ParamField body="type" type="string" default="frame">
      Generation mode:

      * `frame` - First frame, default value. Pass in 1 image as the first frame of the video; the video will retain the image's aspect ratio
      * `reference` - Reference, pass in 1-15 reference images, optionally with 0-3 reference audio clips

      <Warning>
        First frame mode allows only 1 image and does not accept `audio_url`.
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]" required>
      Image URL, must be directly accessible via the public network.

      * `frame` - Exactly 1 image required, used as the first frame
      * `reference` - 1-15 reference images

      Image requirements:

      * Formats: JPG, JPEG, PNG, WEBP
      * Up to 50 MB per image
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      Reference audio URL, used to guide the tone and inflection in the generated video.

      Valid only in `reference` mode, up to 3 clips.

      Audio requirements:

      * Format: MP3
      * 3-12 seconds per clip
      * Up to 50 MB per clip

      <Warning>Do not pass this parameter in `frame` mode.</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      Generated video duration, in seconds.

      Supports integers: `3` to `16`.
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      Output resolution:

      * `540p`
      * `720p` - Default value
      * `1080p`
      * `2K`
      * `4K`

      Resolution tiers are calculated based on total pixels. Non-16:9 aspect ratios (e.g., square, vertical) will differ in width and height from the tier name, such as 720×720 for a 1:1 video at 540p.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      Video aspect ratio, valid only in `reference` mode. In `frame` mode, it adopts the aspect ratio of the first frame image and will be ignored if passed.

      Supported aspect ratios:

      * `16:9` - Landscape, default value
      * `9:16` - Portrait
      * `1:1` - Square
      * `4:3` - Standard landscape
      * `3:4` - Standard portrait
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      Whether to generate synchronized audio (dialogue and sound effects).

      * `true` - Generate video with an audio track, default value
      * `false` - Output silent video
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Caller task ID.

  User-defined task identifier, required. Supports only letters, numbers, underscores, and hyphens, with a length of 1-64 characters. This ID can be used later to query task status and results.
</ParamField>

## Query Task

Vidu Q4 is an asynchronous video generation model. After submitting a task, please use `out_task_id` to query the task status; querying every 10-15 seconds is recommended.

<ParamField body="out_task_id" type="string" required>
  The initiator task ID passed when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "vidu_q4_frame_123456"
  }'
```

After the query succeeds and completes, the `output` array in the response will contain the generated video, with elements containing the `video` field.

## Mode Notes

<Note>
`frame` uses 1 image as the first frame to generate a video, the prompt is optional, and the aspect ratio follows the image; `reference` combines 1-15 reference images and up to 3 reference audio clips to generate new visuals, the prompt is required, and the aspect ratio can be specified.
</Note>

<Warning>
When `type` is `frame`, `image_url` must contain exactly 1 image, and do not pass `audio_url`. When `type` is `reference`, `prompt` cannot be empty, with a maximum of 15 reference images and up to 3 reference audio clips.
</Warning>
