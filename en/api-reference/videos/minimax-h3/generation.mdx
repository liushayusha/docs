## Body

<ParamField body="model" type="string" required>
  Model name, fixed value:

  * `minimax_h3`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="Properties of the params object">
    <ParamField body="prompt" type="string" required>
      Text description for video generation, up to 7000 characters.

      You can describe the subject, scene, camera movement, action, style, lighting, rhythm, and more.
    </ParamField>

    <ParamField body="type" type="string" default="text_to_video">
      Generation type, which determines which video generation mode to use.

      * `text_to_video` - Text-to-video, generates a video using only the prompt
      * `first_last_frame` - First-frame/last-frame image-to-video, generates a video using the first frame, last frame, or a transition between them
      * `all_reference` - Generate video from multiple reference materials, can use reference images, reference videos, and reference audio
    </ParamField>

    <ParamField body="video_length" type="number" default="4">
      Video duration, in seconds.

      Integer values supported: `4` to `15`.
    </ParamField>

    <ParamField body="quality" type="string" default="2k">
      Output quality:

      * `768p`
      * `2k`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      Video aspect ratio.

      Supported aspect ratios:

      * `21:9` - Ultra-wide
      * `16:9` - Landscape, default value
      * `4:3` - Standard landscape
      * `1:1` - Square
      * `3:4` - Standard portrait
      * `9:16` - Portrait

      <Warning>`first_last_frame` mode does not support selecting the aspect ratio separately; the output will follow the input image ratio.</Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Image URL.

      The meaning varies by `type`:

      * `text_to_video` - No image needs to be passed
      * `first_last_frame` - Used as the first-frame image; you can also pass an array, with the first image as the first frame and the second image as the last frame
      * `all_reference` - Used as reference images, up to 9 images

      Image requirements:

      * Supports JPG, JPEG, PNG, WEBP, HEIC, HEIF
      * Maximum size for a single image is 30MB
      * Width and height range: 256-5760px
      * Image aspect ratio range: 0.4-2.5
    </ParamField>

    <ParamField body="end_image_url" type="string">
      Last-frame image URL.

      Only valid in `first_last_frame` mode. You can also pass the last frame as the second image in the `image_url` array.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      Reference video URL.

      Only valid in `all_reference` mode.

      Currently, up to 1 reference video is supported.

      Video requirements:

      * Single video duration: 2-15 seconds
      * Supports MP4, MOV
      * Video encoding: H.264 or H.265
      * Audio encoding: AAC or MP3
      * Maximum size for a single video is 50MB
      * Width and height range: 256-5760px
      * Frame rate: 23.976-60 FPS

      <Warning>Please ensure the URL is publicly accessible and that the video duration metadata can be read.</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      Reference audio URL.

      Only valid in `all_reference` mode, with up to 3 audio files.

      Audio requirements:

      * Single audio duration: 2-15 seconds
      * Supports WAV, MP3
      * Maximum size for a single audio file is 15MB
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>

## Query Task

MiniMax H3 is an asynchronous video generation model. After submitting the task, use `out_task_id` to query the task status.

<ParamField body="out_task_id" type="string" required>
  The originating task ID passed in when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "minimax_h3_task_123456"
  }'
```

After the query succeeds and is completed, the `output` field in the Response will contain the generated video URL.

## Mode Notes

<Note>
The `text_to_video` mode invokes MiniMax H3 text-to-video capabilities; the `first_last_frame` mode invokes image-to-video capabilities; the `all_reference` mode invokes multi-reference asset generation capabilities.
</Note>

<Warning>
When `type` is `first_last_frame`, do not rely on the `aspect_ratio` parameter. The output aspect ratio in this mode is determined by the input image.
</Warning>
