  - MiniMax H3 Turbo, an accelerated version of MiniMax H3
  - Asynchronous processing mode, returns a task ID for subsequent queries
  - Supports text-to-video, up to 9 reference images, and 3 reference audio tracks
  - Supports 480P / 720P output, video duration of 5-15 seconds, with native audio track by default

<Note>
The model name for MiniMax H3 Turbo in AIReiter is `minimax_h3_turbo`. This model differs from `minimax_h3`: resolution is 480P / 720P, duration is 5-15 seconds, and it does not support reference videos or first/last frames.
</Note>

## Body

<ParamField body="model" type="string" required>
  Model name, fixed value:

  * `minimax_h3_turbo`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Text description for video generation.

      Can describe subjects, scenes, camera movements, actions, styles, lighting, pacing, etc.

      When using reference assets, you can use "Image 1 / Audio 1" in the prompt to refer to uploaded content in sequential order.
    </ParamField>

    <ParamField body="video_length" type="number" default="5">
      Generated video duration, in seconds.

      Supports integers: `5` to `15`.
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      Output resolution:

      * `480p`
      * `720p` - Default
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      Video aspect ratio.

      Supported aspect ratios:

      * `21:9` - Ultrawide
      * `16:9` - Landscape, Default
      * `4:3` - Standard landscape
      * `3:2` - Photo landscape
      * `1:1` - Square
      * `3:4` - Standard portrait
      * `2:3` - Photo portrait
      * `9:16` - Portrait
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Reference image URL, optional. Up to 9 images.

      When no images are provided, it performs text-to-video; when images are provided, they serve as reference images to guide the subject, style, or composition.

      Image requirements:

      * Supports JPEG, PNG, WEBP
      * Maximum 20 MB per image
      * URL must be publicly accessible
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      Reference audio URL, optional. Up to 3 clips.

      Audio requirements:

      * Supports MP3, WAV
      * Maximum 20 MB per audio file
      * Duration must not exceed 15 seconds per audio file
      * URL must be publicly accessible
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID.

  User-defined task identifier, required. Can be used later to query task status and results.
</ParamField>

## Query Task

MiniMax H3 Turbo is an asynchronous video generation model. After submitting a task, please use `out_task_id` to query the task status.

<ParamField body="out_task_id" type="string" required>
  The initiator task ID passed when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "minimax_h3_turbo_task_123456"
  }'
```

Once the query succeeds and the task is completed, the `output` field in the response will contain the generation results. The video URL is located in `output.list[].video`.

## Mode Notes

<Note>
When `image_url` is not provided, it defaults to text-to-video. When a reference image is provided, the image is used to guide the subject, style, or composition, rather than serving as the first or last frame.
</Note>

<Warning>
This model does not support reference videos or the `first_last_frame` mode. Please do not pass `video_url`, `end_image_url`, `type`, or `quality`.
</Warning>
