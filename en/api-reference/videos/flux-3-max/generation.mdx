## Body

<ParamField body="model" type="string" required>
  Model name, fixed value:

  * `flux_3_max`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Video content description, required for all modes.

      It is recommended to describe the visual scene, actions, camera movements, and audio simultaneously. The model will automatically understand and expand the prompt before generation (see `reasoning_level` for expansion intensity).
    </ParamField>

    <ParamField body="type" type="string" default="text">
      Generation mode:

      * `text` - Text-to-video, default value. Uses only the prompt; passed images will be ignored
      * `frame` - First and last frames. `image_url[0]` is used as the first frame (required), and `image_url[1]` as the last frame (optional)
      * `keyframes` - Keyframes. Pass up to 10 images in order, evenly distributed along the video timeline, with the video transitioning sequentially through each one

      <Warning>
        The `frame` and `keyframes` modes require at least 1 image; if no image is passed, it generates using `text` mode.
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Image URL, must be directly accessible via the public network. Not required for `text` mode.

      * `frame` - 1-2 images: The 1st image is the first frame, and the 2nd image (optional) is the last frame
      * `keyframes` - 1-10 images, evenly placed from the first frame to the last frame in the order of upload

      Image requirements:

      * Format: PNG, JPEG, WEBP
      * Maximum 20 MB per image
    </ParamField>

    <ParamField body="end_image_url" type="string">
      Last frame image URL, valid only for `frame` mode. Can also be passed directly as the 2nd image in `image_url`; if both are passed, `end_image_url` takes precedence.
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      Generated video duration, in seconds.

      Supports integers: `5` to `20`.
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      Output resolution (24 fps):

      * `720p` - Default value
      * `1080p`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      Video aspect ratio:

      * `auto` - Default value. 16:9 for `text` mode; follows the 1st image when images are provided
      * `16:9` - Landscape
      * `9:16` - Portrait
      * `1:1` - Square
      * `4:3` - Standard landscape
      * `3:4` - Standard portrait
      * `21:9` - Ultra-widescreen
    </ParamField>

    <ParamField body="reasoning_level" type="string" default="high">
      Prompt reasoning intensity, the degree to which the model understands and expands the prompt before generation:

      * `high` - Default value. More comprehensive expansion, better results, slower generation
      * `low` - Faster

      Both levels have the same price.
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      Whether to generate native audio with the video.

      * `true` - Generates video with an audio track, default value
      * `false` - Outputs silent video

      The price is the same whether audio is enabled or disabled.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Caller task ID.

  User-defined task identifier, required. Supports only letters, numbers, underscores, and hyphens, with a length of 1-64 characters. This ID can be used later to query the task status and results.
</ParamField>

## Query Task

FLUX 3 Max is an asynchronous video generation model. After submitting a task, please use `out_task_id` to query the task status; querying every 10-15 seconds is recommended.

<ParamField body="out_task_id" type="string" required>
  The initiator task ID passed when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flux_3_max_frame_123456"
  }'
```

After the query succeeds and completes, the `output` array in the response will contain the generated video, with elements containing the `video` field.

## Mode Notes

<Note>
`text` generates using only prompts; `frame` fixes the beginning of the video (and optionally the end); `keyframes` uses multiple images to constrain the flow of the entire video, with the images evenly distributed in sequence across the timeline (for example, providing 3 images for a 10-second video places them at seconds 0, 5, and 10). All three modes are priced the same, billed by output duration in seconds and resolution.
</Note>

<Warning>
`frame` mode uses up to 2 images (first frame + last frame), and any excess will be ignored; `keyframes` mode supports up to 10 images. `text` mode will ignore any provided images.
</Warning>
