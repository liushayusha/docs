## Body

<ParamField body="model" type="string" required>
  Model name, fixed to `happyhorse_1_0`.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="Properties of the params Object">
    <ParamField body="type" type="string" default="text_to_video" required>
      Video workflow:

      * `text_to_video` - Generate a video based on text
      * `image_to_video` - Generate a video using a first-frame image
      * `reference_to_video` - Generate a video using 1-9 reference images
      * `video_edit` - Edit a source video based on instructions
    </ParamField>

    <ParamField body="prompt" type="string">
      Video content description or editing instructions. Required for `text_to_video`, `reference_to_video`, and `video_edit`, optional for `image_to_video`.

      Supports up to 2500 Chinese characters or 5000 non-Chinese characters; any excess will be truncated.

      In `reference_to_video` mode, use the names `character1`, `character2`, and so on to refer to reference images in image order.
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Image URL, must be directly accessible from the public internet.

      * `image_to_video` - Required, use the first image as the first frame
      * `reference_to_video` - Required, supports 1-9 ordered reference images
      * `video_edit` - Optional, up to 5 style or subject reference images

      Supports JPEG, JPG, PNG, and WEBP. For image-to-video and video editing, images must have both width and height of at least 300px; for multi-reference image mode, the shorter side must be at least 400px. A single image must not exceed 10MB.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      Required for `video_edit` mode, only one source video is used.

      Supports MP4 and MOV, and H.264 encoding is recommended. Source video requirements:

      * Duration: 3-60 seconds; if it exceeds 15 seconds, only the first 15 seconds will be processed
      * File size must not exceed 100MB
      * The longer side must not exceed 2160px, and the shorter side must be at least 320px
      * Aspect ratio must be between 1:2.5 and 2.5:1
      * Frame rate must be greater than 8 FPS
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      Output resolution: `720p` or `1080p`.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      Output aspect ratio for `text_to_video` and `reference_to_video` modes.

      Supported: `16:9`, `9:16`, `1:1`, `4:3`, `3:4`, `4:5`, `5:4`, `9:21`, `21:9`.

      <Warning>`video_edit` does not support this parameter. Do not pass it. The output aspect ratio of `image_to_video` follows the input image.</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      Output video duration, in seconds. Supports integers between 3 and 15.

      <Warning>`video_edit` does not support this parameter. Do not pass it. The output duration is automatically determined by the source video, equal to `min(input video duration, 15 seconds)`.</Warning>
    </ParamField>

    <ParamField body="seed" type="integer" default="0">
      Random seed, in the range 0-2147483647. When `0` is passed or omitted, a random seed is used.
    </ParamField>

    <ParamField body="keep_original_sound" type="boolean" default="false">
      Valid only for `video_edit` mode. When set to `true`, the source video audio track is forcibly preserved; when set to `false` or omitted, the model decides automatically.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  A unique task ID generated by the caller, used later to query task status and results.

  Only letters, numbers, underscores, and hyphens are supported, with a length of 1-64 characters.
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  Caller task ID, can be used to query results.
</ResponseField>

<ResponseField name="status" type="string">
  Initial status, usually `pending`.
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation time, in ISO 8601 format.
</ResponseField>

## Query Task

After the task is submitted successfully, query its status using the same `out_task_id`. Task statuses include `pending`, `processing`, `completed`, and `failed`; after completion, the `output` array contains the video result.

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "happyhorse_1_0_task_123456"
  }'
```

## Workflow Parameter Comparison

| `type` | Required Assets | Duration and Aspect Ratio |
|---|---|---|
| `text_to_video` | `prompt` | `video_length` 3-15 seconds, optional `aspect_ratio` |
| `image_to_video` | `image_url` | `video_length` 3-15 seconds, aspect ratio follows the image |
| `reference_to_video` | `prompt`, `image_url` | `video_length` 3-15 seconds, optional `aspect_ratio` |
| `video_edit` | `prompt`, `video_url` | Duration and aspect ratio follow the source video, output up to 15 seconds |
