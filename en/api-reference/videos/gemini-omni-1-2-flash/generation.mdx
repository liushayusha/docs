<Note>
The final video is fixed at 720p H.264 MP4: landscape 1280×720, portrait 720×1280. 1080p / 4K, reference videos, and start/end frames are not supported.
</Note>

## Body

<ParamField body="model" type="string" required>
  Model name. Always pass `gemini_omni_1_2_flash`.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Text description for video generation. Required.
    </ParamField>

    <ParamField body="video_length" type="string" default="8">
      Duration of the generated video in seconds. Only accepts whole-second strings from `"3"` to `"15"`:

      * `"3"` / `"4"` / `"5"` / `"6"` / `"7"`
      * `"8"` - Default
      * `"9"` / `"10"` / `"11"` / `"12"` / `"13"` / `"14"` / `"15"`

      <Warning>
        Enum validation requires a string; please pass `"8"` instead of the number `8`. Values from `"11"` to `"15"` can only be paired with an `aspect_ratio` of `9:16`.
      </Warning>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      Video aspect ratio:

      * `16:9` - Landscape 1280×720, Default
      * `9:16` - Portrait 720×1280

      For durations of 11–15 seconds, only `9:16` is allowed; passing `16:9` will be rejected.
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Reference image URL(s), which must be directly accessible via the public internet. A single string can also be passed. If omitted, text-to-video generation is performed.

      * Up to 3 images; a 4th image will be rejected
      * Short edge must be at least 300px, and each image must not exceed 10MB

      Reference images are used to define the subject and style, not as the first or last frame; the final video will not be forced to start or end with any specific image.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID.

  User-defined task identifier, required. Only letters, numbers, underscores, and hyphens are supported, with a length of 1-64 characters. This ID can be used later to query the task status and results.
</ParamField>

## Query Task

This model generates videos asynchronously. After submitting a task, please use `out_task_id` to query the task status. You can also refer to [Get Task Status](/en/api-reference/tasks/status).

<ParamField body="out_task_id" type="string" required>
  The caller's task ID passed when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_12_t2v_123456"
  }'
```

Once the query succeeds and the task is completed, the `output` array in the response will contain the generated videos, with each element containing a `video` field.

## Parameter Comparison

| Input | `image_url` | `video_length` | `aspect_ratio` |
|---|---|---|---|
| Text-to-Video | Omit or empty array | `"3"`–`"10"` | `16:9` or `9:16` |
| Text-to-Video (Long) | Omit or empty array | `"11"`–`"15"` | `9:16` only |
| Reference Image | 1–3 images | `"3"`–`"10"` | `16:9` or `9:16` |
| Reference Image (Long) | 1–3 images | `"11"`–`"15"` | `9:16` only |

Unsupported fields: `resolution` (fixed at 720p), `video_url` (reference videos not supported).
