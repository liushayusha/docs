<Note>
Output is always 720p H.264 MP4: 1280×720 landscape or 720×1280 portrait. 1080p / 4K, reference video, and first/last frames are not supported.
</Note>

## Body

<ParamField body="model" type="string" required>
  Model name. Always send `gemini_omni_1_2_flash`.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Text description for video generation. Required.
    </ParamField>

    <ParamField body="video_length" type="string" default="8">
      Video length in seconds. Only whole-second strings from `"3"` to `"15"` are accepted:

      * `"3"` / `"4"` / `"5"` / `"6"` / `"7"`
      * `"8"` - Default
      * `"9"` / `"10"` / `"11"` / `"12"` / `"13"` / `"14"` / `"15"`

      <Warning>
        Enum validation requires a string: send `"8"`, not the number `8`. `"11"` to `"15"` only work with `aspect_ratio` set to `9:16`.
      </Warning>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      Video aspect ratio:

      * `16:9` - Landscape 1280×720, Default
      * `9:16` - Portrait 720×1280

      For 11–15 seconds, only `9:16` is allowed. `16:9` is rejected.
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Reference image URLs, which must be publicly accessible. A single string is also accepted. Omit it for text-to-video.

      * Up to 3 images; a 4th image is rejected
      * Shortest side at least 300px, each image up to 10MB

      Reference images guide the subject and style. They are not first/last frames, so the clip is not forced to start or end on any of them.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID.

  User-defined task identifier, required. Only letters, numbers, underscores, and hyphens are supported, with a length of 1-64 characters. You can use this ID later to query the task status and results.
</ParamField>

## Query Task

This model uses asynchronous video generation. After submitting a task, please use `out_task_id` to query the task status. You can also refer to [Get Task Status](/en/api-reference/tasks/status).

<ParamField body="out_task_id" type="string" required>
  The initiator task ID passed when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_12_t2v_123456"
  }'
```

Once the query succeeds and is completed, the `output` array in the response will contain the generated video, with each element containing a `video` field.

## Parameter Comparison

| Input | `image_url` | `video_length` | `aspect_ratio` |
|---|---|---|---|
| Text-to-video | Omit, or empty array | `"3"`–`"10"` | `16:9` or `9:16` |
| Text-to-video (long) | Omit, or empty array | `"11"`–`"15"` | `9:16` only |
| Reference images | 1–3 images | `"3"`–`"10"` | `16:9` or `9:16` |
| Reference images (long) | 1–3 images | `"11"`–`"15"` | `9:16` only |

Unsupported fields: `resolution` (fixed at 720p) and `video_url` (reference video is not supported).
