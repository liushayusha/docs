## Body

<ParamField body="model" type="string" required>
  Model name, fixed value:

  * `wan3_0`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string">
      Text description for video generation.

      For `all_reference`, it is recommended to provide a prompt, or at least one image, video, or audio reference. For `first_last_frame` and `file_web`, the prompt is optional, but providing it will make the control more precise.

      When using reference materials, you can refer to uploaded content in the prompt using "Image 1 / Video 1 / Audio 1" according to type and order.
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      Generation mode, which determines which video generation method to use. The same request cannot mix the three modes:

      * `all_reference` - Text/reference, can use only a prompt or also include images, videos, and audio
      * `first_last_frame` - First and last frames, uses a required first frame and an optional last frame
      * `file_web` - File/web, pass in a document URL or a public web page URL

      <Warning>
        First and last frames cannot appear in the same request as reference images, reference videos, reference audio, documents, or web pages. `file_url` and `link_url` cannot be passed at the same time either.
      </Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      Video duration to generate, in seconds.

      Integer values supported: `2` to `30`. When using reference video, the sum of input seconds and output seconds cannot exceed 30.
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      Output resolution:

      * `480p`
      * `720p` - Default value
      * `1080p`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      Video aspect ratio.

      Supported aspect ratios:

      * `auto` - Follows the reference material or prompt, default value
      * `16:9` - Landscape
      * `9:16` - Portrait
      * `4:3` - Standard landscape
      * `3:4` - Standard portrait
      * `1:1` - Square
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      Whether to generate a native audio track.

      * `true` - Generate audio track, default value
      * `false` - Output a video without audio track
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Image URL, must be directly accessible from the public internet.

      The meaning differs under different `type` values:

      * `all_reference` - Optional reference images, up to 10 images
      * `first_last_frame` - The first image is the first frame (required), the second image is the last frame (optional)
      * `file_web` - Do not pass this parameter

      Image requirements:

      * The short side must be at least 240px, and the long side must not exceed 8000px
      * Each image must not exceed 20MB
    </ParamField>

    <ParamField body="end_image_url" type="string">
      Last-frame image URL.

      Only valid in `first_last_frame` mode. You can also pass the last frame as the second image in the `image_url` array.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      Reference video URL.

      Only valid in `all_reference` mode, up to 5 clips.

      Video requirements:

      * Formats: MP4, MOV
      * Each clip 1-15 seconds, total not exceeding 15 seconds
      * Each clip must not exceed 100MB
      * The short side must be at least 240px, and the long side must not exceed 4096px

      Reference video duration will be counted toward billing duration: billed seconds = final video seconds + reference video seconds (rounded up).

      <Warning>Do not pass this parameter in `first_last_frame` or `file_web`. Make sure the URL is publicly accessible and that the video duration metadata can be read.</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      Reference audio URL.

      Only valid in `all_reference` mode, up to 5 clips.

      Audio requirements:

      * Formats: WAV, MP3
      * Each clip 1-15 seconds, total not exceeding 15 seconds
      * Each clip must not exceed 15MB

      Reference audio is not counted toward billing duration.

      <Warning>Do not pass this parameter in `first_last_frame` or `file_web`.</Warning>
    </ParamField>

    <ParamField body="file_url" type="string">
      Document URL.

      Only valid in `file_web` mode, and must be directly accessible from the public internet.

      Supports DOC(X), XLS(X), PPT(X), PDF, TXT, KEY, Pages, Numbers, MD; no more than 100MB and 50 pages. Documents are not counted toward billing duration.

      <Warning>Mutually exclusive with `link_url`; do not pass both.</Warning>
    </ParamField>

    <ParamField body="link_url" type="string">
      Public web page URL.

      Only valid in `file_web` mode. Web pages are not counted toward billing duration.

      <Warning>Mutually exclusive with `file_url`; do not pass both.</Warning>
    </ParamField>

    <ParamField body="watermark" type="boolean" default="false">
      Whether to add a watermark to the final video. Default `false`.
    </ParamField>

    <ParamField body="seed" type="integer">
      Random seed. Takes effect when an integer greater than or equal to `0` is passed; omitted values will be random.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID.

  A user-defined task identifier, required. Only letters, numbers, underscores, and hyphens are supported, with a length of 1-64 characters. You can use this ID later to query task status and results.
</ParamField>

## Query Task

Wan 3.0 is an asynchronous video generation model. After submitting the task, use `out_task_id` to query the task status.

<ParamField body="out_task_id" type="string" required>
  The originator task ID passed when the task was submitted.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "wan3_0_t2v_123456"
  }'
```

After the query succeeds and the task is completed, the `output` array in the Response will contain the generated video, and each element includes a `video` field.

## Mode Notes

<Note>
`all_reference` can be generated from prompt only, or with additional image, video, and audio references; `first_last_frame` uses a first frame and an optional last frame; `file_web` uses `file_url` or `link_url` to convert a document or web page into a video.
</Note>

<Warning>
When `type` is `first_last_frame`, do not pass `video_url`, `audio_url`, `file_url`, or `link_url` at the same time. When `type` is `file_web`, only one of `file_url` and `link_url` can be passed.
</Warning>
