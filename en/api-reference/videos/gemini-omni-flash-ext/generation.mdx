## Body

<ParamField body="model" type="string" required>
  Model name, choose one of two:

  * `gemini_omni_flash_ext`
  * `gemini_omni_1_1_flash_ext`

  Parameter fields are the same; do not pass `type`.
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Text description for video generation. Required.
    </ParamField>

    <ParamField body="video_length" type="string" default="6">
      Generated video duration in seconds. Accepts strings only:

      * `"4"`
      * `"6"` - Default
      * `"8"`
      * `"10"`

      Do not pass this field when a reference video is provided; the output duration follows the uploaded video.

      <Warning>
        Do not pass `3`, `5`, `7`, `9`, or other durations in seconds. Enum validation requires a string; please pass `"6"` instead of the number `6`.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      Output resolution:

      * `720p` - Default
      * `1080p`
      * `4K`

      720p and 1080p are the same price; 4K is more expensive.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      Video aspect ratio:

      * `16:9` - Landscape, Default
      * `9:16` - Portrait
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Reference image URL(s), must be directly accessible via the public network. Can also be passed as a single string. If omitted, text-to-video generation will be performed.

      * Up to 7 images, **2 images allowed**
      * Short edge no less than 300px, up to 10MB per image

      When passed together with a reference video, number of images + 2 must be ≤ 7.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      Reference video URL, optional, up to 1 video. Can also be passed as a single string. Can be passed together with reference images.

      Video requirements:

      * Formats: MP4, MOV
      * Duration not exceeding 10 seconds
      * Up to 100MB
      * Short edge no less than 300px

      Do not pass `video_length` when passing a reference video; output duration follows the uploaded video, up to 10 seconds. Reference video counts as 2 slots towards the 7-slot quota.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID.

  User-defined task identifier, required. Only letters, numbers, underscores, and hyphens are supported, with a length of 1-64 characters. You can use this ID later to query the task status and results.
</ParamField>

## Query Task

Both models use asynchronous video generation. After submitting a task, please use `out_task_id` to query the task status. You can also refer to [Get Task Status](/en/api-reference/tasks/status).

<ParamField body="out_task_id" type="string" required>
  The initiator task ID passed when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_ext_t2v_123456"
  }'
```

Once the query succeeds and is completed, the `output` array in the response will contain the generated video, with each element containing a `video` field.

## Parameter Comparison

| Input | `image_url` | `video_url` | Duration |
|---|---|---|---|
| Text-to-Video | Do not pass, or empty array | Do not pass | `video_length` `"4"` / `"6"` / `"8"` / `"10"` |
| Reference Image | 1–7 images (including 2 images) | Do not pass | Same as above |
| Reference Video | Do not pass, or empty array | 1 video, up to 10 seconds | Do not pass `video_length`, follows source video |
| Image + Video | Up to 5 images (number of images + 2 ≤ 7) | 1 video, up to 10 seconds | Do not pass `video_length`, follows source video |
