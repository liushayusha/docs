<Note>
The model name of Gemini Omni Flash Ext in AIReiter is `gemini_omni_flash_ext`.

It is not the site's official Omni Flash SKU (`gemini_omni_flash_preview`, output 720p). The SKU on this page outputs 720p / 1080p / 4K, and the duration is only 4, 6, 8, and 10 seconds.
</Note>

## Body

<ParamField body="model" type="string" required>
  Model name, fixed value:

  * `gemini_omni_flash_ext`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params object properties">
    <ParamField body="prompt" type="string" required>
      Text description for video generation. Required.
    </ParamField>

    <ParamField body="type" type="string" default="frame">
      Generation type. Only the following two values are accepted:

      * `frame` - First Frame. Prompt plus 0 or 1 image. Reference video cannot be passed.
      * `reference` - Reference. Prompt plus 0, 1, or 3 images, with 1 reference video optional.

      If no images are provided, it is text-to-video. Both types are supported.

      <Warning>
        Do not pass `type=text`. `frame` cannot be passed together with `video_url`.
      </Warning>
    </ParamField>

    <ParamField body="video_length" type="string" default="6">
      Generated video duration, in seconds. Only the following strings are accepted:

      * `"4"`
      * `"6"` - Default value
      * `"8"`
      * `"10"`

      When a reference video is provided, do not pass this field. The output duration follows the uploaded video.

      <Warning>
        Do not pass `3`, `5`, `7`, `9`, or any other number of seconds. Enum validation requires a string, so pass `"6"` instead of the number `6`.
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      Output resolution:

      * `720p` - Default value
      * `1080p`
      * `4K`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      Video aspect ratio:

      * `16:9` - Landscape, default value
      * `9:16` - Portrait
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Image URL, must be directly accessible from the public internet. A single string can also be passed.

      * `frame` - Optional 0 or 1 image, used as the first frame. If omitted, it becomes text-to-video.
      * `reference` - Optional 0, 1, or 3 images. If omitted, it becomes text-to-video.

      Image requirements: the shorter side must be at least 300px, and each image must be no larger than 10MB.

      <Warning>
        Two images are not supported. Passing 2 images for `reference` returns `Invalid image_url count. Allowed: [1, 3]`. Do not pass 4 or more images either.
      </Warning>
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      Reference video URL. Valid only when `type=reference`, up to 1 video. A single string can also be passed.

      Video requirements:

      * Format MP4, MOV
      * Duration no more than 10 seconds
      * Size no more than 100MB
      * Shorter side no less than 300px

      When a reference video is provided, do not pass `video_length`. The output duration follows the uploaded video, up to 10 seconds.

      <Warning>`type=frame` must not include this parameter; the API will reject it directly.</Warning>
    </ParamField>
  </Expandable>
</ParamField>

## Query Task

Gemini Omni Flash Ext is an asynchronous video generation model. After submitting the task, use `out_task_id` to query the task status. Also see [Get Task Status](/en/api-reference/tasks/status).

<ParamField body="out_task_id" type="string" required>
  The originating task ID passed when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_ext_t2v_123456"
  }'
```

After the query succeeds and completes, the `output` array in the response will contain the generated video, and each element includes a `video` field.

## 模式参数对照

| `type` | `image_url` | `video_url` | Duration |
|---|---|---|---|
| `frame`, no image | Do not send, or send an empty array | Do not send | `video_length` `"4"` / `"6"` / `"8"` / `"10"` |
| `frame` | 1 image | Do not send | Same as above |
| `reference`, no image | Do not send, or send an empty array | Do not send | Same as above |
| `reference` | 1 image or 3 images | Do not send | Same as above |
| `reference` | 0, 1, or 3 images | 1 clip, up to 10 seconds | Do not send `video_length`; follow the source video |
