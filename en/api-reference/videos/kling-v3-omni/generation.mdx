## Body

<ParamField body="model" type="string" required>
  Model name, fixed value:

  * `kling_v3_omni`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="params object properties">
    <ParamField body="prompt" type="string" required>
      Text description for video generation. Required.

      Reference images can be cited in the prompt as `<<<image_1>>>`, `<<<image_2>>>` in the same order as `image_url`. If images are sent without a citation, the system prepends `<<<image_1>>>`.
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      Negative prompt. Up to 2500 characters.
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      Generation mode. Do not mix modes in one request:

      * `all_reference` - Text/reference. Prompt required. Optional: up to 7 reference images and one reference video
      * `first_last_frame` - First/last frame. First frame required, last frame optional

      <Warning>
        First/last frames cannot appear in the same request as reference images or a reference video.
      </Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      Output duration in seconds. Integer from `3` to `15`.

      * `all_reference` with no reference video, or `refer_type=feature`: output follows this field
      * `refer_type=base`: output follows the uploaded clip; do not rely on this field
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      Output resolution:

      * `720p` - default
      * `1080p`
      * `4K`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      Aspect ratio. Ignored when a first frame or reference video is provided.

      * `16:9` - landscape, default
      * `9:16` - portrait
      * `1:1` - square
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="false">
      Whether to generate a native audio track.

      * `false` - no audio, default
      * `true` - generate audio

      <Warning>
        Ignored when `video_url` is set. Cannot be combined with a reference video.
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Image URL. Must be publicly reachable.

      * `all_reference` - optional, up to 7 images
      * `first_last_frame` - first item is the first frame (required), second item is the last frame (optional)

      Shortest side at least 300px. Max 20MB per image.
    </ParamField>

    <ParamField body="end_image_url" type="string">
      Last-frame image URL.

      Only valid for `first_last_frame`. You can also pass the last frame as the second item in `image_url`. Last frame without a first frame is rejected.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      Reference video URL. Only valid for `all_reference`. Max 1 clip.

      Requirements:

      * MP4 or MOV
      * 3-10 seconds
      * Max 200MB
      * Shortest side at least 720px

      <Warning>Do not send this field with `first_last_frame`. The URL must be public and the duration metadata must be readable.</Warning>
    </ParamField>

    <ParamField body="refer_type" type="string" default="feature">
      How the reference video is used. Only applies when `video_url` is set:

      * `feature` - style or motion reference; output duration follows `video_length`
      * `base` - edit the uploaded clip; output duration follows the source and ignores `video_length`
    </ParamField>

    <ParamField body="keep_original_sound" type="boolean" default="false">
      Keep the source audio track. Only applies when `video_url` is set.

      * `false` - do not keep, default
      * `true` - keep original sound
    </ParamField>

    <ParamField body="watermark" type="boolean" default="false">
      Add a watermark. Default `false`.
    </ParamField>

    <ParamField body="multi_shot" type="boolean" default="false">
      Enable multi-shot. When `true`, the model splits the prompt into shots automatically.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Caller task ID.

  Required. Letters, digits, underscore, and hyphen only, 1-64 characters. Use the same ID to query status and results.
</ParamField>

## Query Task

Kling v3 Omni is asynchronous. After submit, query status with `out_task_id`.

<ParamField body="out_task_id" type="string" required>
  The caller task ID sent at submit time.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "kling_v3_omni_t2v_123456"
  }'
```

When the task completes, `output` contains the generated video objects with a `video` field.

## Mode parameter map

| `type` / reference video | Required | Duration |
|---|---|---|
| `all_reference`, no `video_url` | `prompt` | `video_length` 3-15s |
| `all_reference`, `refer_type=feature` | `prompt`, `video_url` | output follows `video_length` |
| `all_reference`, `refer_type=base` | `prompt`, `video_url` | output follows the upload, 3-10s |
| `first_last_frame` | `prompt`, first-frame `image_url` | `video_length` 3-15s |
