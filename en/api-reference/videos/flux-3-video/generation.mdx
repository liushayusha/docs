<Note>
The model name for FLUX 3 Video in AIReiter is `flux_3_video`. It currently supports three modes: text-to-video, ordered keyframes, and video continuation.
</Note>

  Authorization: Bearer YOUR_API_KEY

## Body

<ParamField body="model" type="string" required>
  Model name, fixed value:

  * `flux_3_video`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="Properties of the params Object">
    <ParamField body="mode" type="string" default="t2v">
      Generation mode:

      * `t2v` - text-to-video, generate video using only a prompt
      * `i2v` - ordered keyframes, use 1-10 images to control video content and transitions
      * `v2v` - video continuation, continue generating dynamic content from a source video
    </ParamField>

    <ParamField body="prompt" type="string" required>
      Text description for video generation.

      It is recommended to describe the subject, scene, action, camera movement, visual style, dialogue, and ambient sound.
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Ordered keyframe image URLs, used only in `i2v` mode.

      * Supports 1-10 publicly accessible images
      * The image order is the playback order
      * The first and last images can be used to define the start and end frames of the video

      <Warning>`i2v` mode must provide at least one image; do not pass this parameter in other modes.</Warning>
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      Source video URL, used only in `v2v` mode.

      Currently, only one publicly accessible MP4 video is supported at most. When passed as an array, only the first URL is used.

      <Warning>`v2v` mode must provide a source video; do not pass this parameter in other modes.</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      Output video duration, in seconds.

      Supports integers from `5` to `20`.
    </ParamField>

    <ParamField body="resolution" type="string" default="hd">
      Output quality:

      * `hd` - HD
      * `fhd` - FHD

      <Note>FHD has more pixels than HD, and the exact output size varies by aspect ratio.</Note>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      Video aspect ratio:

      * `auto` - Automatic
      * `21:9` - Ultrawide
      * `2:1` - Wide screen
      * `16:9` - Landscape
      * `4:3` - Standard landscape
      * `1:1` - Square
      * `3:4` - Standard portrait
      * `9:16` - Portrait
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      Whether to generate native audio synchronized with the video.

      Can include dialogue, ambient sound, and sound effects.
    </ParamField>

    <ParamField body="safety_tolerance" type="integer" default="2">
      Content safety tolerance, supports integers from `0` to `4`.

      * `0` - Strictest filtering
      * `4` - Most permissive setting
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID.

  Generated by the caller and guaranteed to be unique. Use this ID later to query the task status and results.
</ParamField>

## Query Task

FLUX 3 Video uses asynchronous processing. After submission succeeds, use the same `out_task_id` to query the task:

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "flux_3_video_task_123456"
    }'
  ```
</RequestExample>

After the task is completed, the `output` array in the response will contain the generated video URL. For the full field list, see [Get Task Status](/en/api-reference/tasks/status).

## Mode Rules

| mode | Required Assets | Asset Limitations |
| --- | --- | --- |
| `t2v` | None | Do not pass `image_url` or `video_url` |
| `i2v` | `image_url` | 1-10 ordered images |
| `v2v` | `video_url` | At most one source video |

<Warning>
Please ensure that the image and video URLs are directly accessible from the public internet. Tasks are processed asynchronously, so do not keep the HTTP connection from the submission request open while waiting for the final video.
</Warning>
