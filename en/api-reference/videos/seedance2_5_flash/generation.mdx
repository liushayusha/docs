<Note>
The model name for Seedance 2.5 Flash in AIReiter is `seedance2_5_flash`. It is the fast version of Seedance 2.5: it generates faster, has a lower limit on reference materials, and shares the same parameter structure as `seedance2_5`.
</Note>

## Differences from Seedance 2.5

| Item | `seedance2_5` | `seedance2_5_flash` |
| --- | --- | --- |
| Reference Image Limit | 30 images | 10 images |
| Reference Video Limit | 9 clips | 5 clips |
| Reference Audio Limit | 10 clips | 5 clips |
| Generation Speed | Standard | Faster |

Aside from the table above, both models share the same parameters, value ranges, and asset specifications.

## Body

<ParamField body="model" type="string" required>
  Model name, fixed as:

  * `seedance2_5_flash`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Text description for video generation.

      It is recommended to describe the subject, scene, action, camera movement, visual style, dialogue, and ambient sound.
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      Reference mode, which determines how reference materials are used:

      * `all_reference` - Full reference mode, allows using reference images, reference videos, and reference audio
      * `first_last_frame` - First and last frame mode, uses a first frame image and an optional last frame image

      The two modes are mutually exclusive; only one can be used per request.
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Reference image URL.

      * `all_reference` mode: Up to 10 images; max 30MB per image; minimum side length of 300px
      * `first_last_frame` mode: 1-2 images, used sequentially as the first frame and last frame; max 10MB per image

      The URL must be directly accessible from the public internet.
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      Reference video URL, valid only in `all_reference` mode. Supports up to 5 reference videos.

      Video requirements:

      * Single video duration: 2-30 seconds; total duration of reference videos must not exceed 30 seconds
      * Max 200MB per video
      * Frame rate: 24-60 FPS
      * Aspect ratio range: 0.4-2.5
      * Width and height range: 300-6000px
      * Total pixel count range: 409600-927408

      <Warning>Do not pass this parameter in `first_last_frame` mode.</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      Reference audio URL, valid only in `all_reference` mode. Supports up to 5 audio files.

      Audio requirements:

      * Single audio duration: 2-30 seconds; total duration of reference audio must not exceed 30 seconds
      * Supports WAV, MP3
      * Max 15MB per audio file

      <Warning>Do not pass this parameter in `first_last_frame` mode.</Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      Video resolution:

      * `480p`
      * `720p` - Default

      1080p and 4K are not supported.
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      Output video duration in seconds.

      Supports integers between `4` and `30`, default is `5`.
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      Video aspect ratio:

      * `21:9` - Ultra-widescreen
      * `16:9` - Landscape, default
      * `9:16` - Portrait
      * `4:3` - Standard landscape
      * `3:4` - Standard portrait
      * `1:1` - Square

      In `first_last_frame` mode, the aspect ratio follows the first frame image, and this parameter does not take effect.
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      Whether to generate AI audio synchronized with the video.

      * `true` - Generate audio, default
      * `false` - Do not generate audio
    </ParamField>

    <ParamField body="output_format" type="string" default="mp4">
      Output video format:

      * `mp4` - Universal format with smaller file size, default
      * `mov` - High color precision format (yuv444p), suitable for post-processing extension and splicing
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID.

  Generated by the caller and guaranteed to be unique. Supports letters, numbers, underscores, and hyphens, with a length of 1-64 characters. This ID will be used subsequently to query the task status and results.
</ParamField>

## Query Task

Seedance 2.5 Flash uses asynchronous processing. After a successful submission, use the same `out_task_id` to query the task:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "seedance2_5_flash_task_123456"
  }'
```

Once the task is completed, the `output` array in the response will contain the generated video URLs. For the full list of fields, see [Get Task Status](/en/api-reference/tasks/status).

## Mode Rules

| type | Available Assets | Asset Limits |
| --- | --- | --- |
| `all_reference` | `image_url`, `video_url`, `audio_url` | Up to 10 images, 5 videos, 5 audio clips |
| `first_last_frame` | `image_url` | 1-2 images, serving as the first frame and last frame in order; do not pass `video_url` or `audio_url`; aspect ratio follows the first frame image |

<Warning>
