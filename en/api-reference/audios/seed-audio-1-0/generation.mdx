## Body

<ParamField body="model" type="string" required>
  Model name, fixed value:

  * `seed_audio_1_0`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      The text to synthesize, or a description of the audio scene, up to 1500 characters.

      When using reference audio, you can use `@audio1` / `@audio2` / `@audio3` in the prompt to point to the reference voice in order.
    </ParamField>

    <ParamField body="reference_mode" type="string" default="text">
      Reference mode, which determines what type of reference material this request uses:

      * `text` - Generate using the prompt only, without passing reference audio or reference images
      * `audio` - Clone the voice with reference audio
      * `image` - Use one reference image to guide mood and expression

      <Warning>Reference audio and reference images cannot be used at the same time. When using reference material, you must explicitly pass the corresponding `reference_mode`, otherwise the reference fields will be ignored.</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      Reference audio URL.

      Only valid when `reference_mode` is `audio`, up to 3 segments, in the order of `@audio1` / `@audio2` / `@audio3`.

      Reference audio requirements:

      * Formats: WAV, MP3, PCM, OGG Opus
      * Each segment must not exceed 30 seconds
      * Each segment must not exceed 10MB
      * The URL must be publicly accessible
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      Reference image URL.

      Only valid when `reference_mode` is `image`, up to 1 image.

      Image requirements:

      * Formats: JPEG, PNG, WEBP
      * Must not exceed 10MB
      * The URL must be publicly accessible
    </ParamField>

    <ParamField body="speech_rate" type="number" default="1">
      Speech rate multiplier, ranging from `0.5` to `2`, supports two decimal places. `1` is the normal speaking rate.
    </ParamField>

    <ParamField body="loudness_rate" type="number" default="1">
      Volume multiplier, ranging from `0.5` to `2`, supports two decimal places. `1` is the normal volume.
    </ParamField>

    <ParamField body="pitch_rate" type="integer" default="0">
      Pitch, measured in semitones. Range `-12` to `12`. `0` is the original key, `12` raises it by one octave, and `-12` lowers it by one octave.
    </ParamField>

    <ParamField body="sample_rate" type="string" default="24000">
      Output sample rate (Hz):

      * `8000`
      * `16000`
      * `24000` - Default Value
      * `32000`
      * `44100`
      * `48000`
    </ParamField>

    <ParamField body="format" type="string" default="wav">
      Output audio format:

      * `wav` - Default Value
      * `mp3`
      * `ogg_opus`
      * `pcm`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID.

  A user-defined task identifier, required. Only letters, numbers, underscores, and hyphens are supported, with a length of 1-64 characters. You can use this ID later to query the task status and results.
</ParamField>

<ResponseField name="out_task_id" type="string">

## Query Task

Seed Audio 1.0 is an asynchronous audio generation model. After submitting a task, use `out_task_id` to query the task status.

<ParamField body="out_task_id" type="string" required>
  The initiator's task ID passed when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "seed_audio_text_123456"
  }'
```

After the query succeeds and is completed, example `output`:

```json
{
  "statusCode": 200,

      {
        "audio": "https://s1.pxz.ai/upload/audio-generator/20260826/seed-audio-item-0.wav"
```

## Mode Notes

<Note>
The `text` mode only generates speech, dialogue, or sound effects based on the prompt; the `audio` mode clones the timbre using a reference audio; the `image` mode uses a reference image to guide the expression.
</Note>

<Warning>
When `reference_mode` is `audio`, do not pass `image_url`. When `reference_mode` is `image`, do not pass `audio_url`. Each request can be up to 120 seconds long.
</Warning>
