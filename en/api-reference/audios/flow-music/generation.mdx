title: 'Flow Music Music Generation'
description: |
  - Google Lyria text-to-music, generating one complete song each time
  - Asynchronous processing mode, returns a task ID for later queries
  - Can include vocals or be instrumental, supports Lyria 3 Pro / 3.5
  - The result includes clip_id, which can be used for continuation, cover version, replacement, stem separation, download, and MV generation
api: 'POST https://aireiter.com/api/openapi/submit'

<Note>
The model name of Flow Music in AIReiter is `flow_music`. For lyrics, continuation, replacement, cover, stem separation, upload, download, and MV generation, please use the corresponding model.
</Note>

## Body

<ParamField body="model" type="string" required>
  Model name, use the following fixed value:

  * `flow_music`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="params Object Properties">
    <ParamField body="prompt" type="string" required>
      Style prompt. Describe the genre, instruments, mood, and vocals. You can also set `lyrics` at the same time.
    </ParamField>

    <ParamField body="lyrics" type="string">
      Optional lyrics. If omitted, instrumental music will be generated or the model will handle vocals automatically.
    </ParamField>

    <ParamField body="title" type="string">
      Optional song title.
    </ParamField>

    <ParamField body="bpm" type="string">
      Optional BPM, greater than or equal to 1. Pass it as a string, for example `"120"`.
    </ParamField>

    <ParamField body="length" type="number" default="60">
      Expected duration, in seconds, range `1` to `240`. This is only a reference; the upstream service may not generate an output with exactly this duration. Billing is per request, not by duration.
    </ParamField>

    <ParamField body="version" type="string" default="lyria-3-pro">
      Lyria version, same price:

      * `lyria-3-pro` - Default value
      * `lyria-3.5` - Updated vocal model
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Client task ID.

  User-defined task identifier, required. Only letters, numbers, underscores, and hyphens are supported, length 1-64 characters. You can use this ID later to query task status and results.
</ParamField>

## Query Task

Flow Music is an asynchronous music generation model. After submitting the task, use `out_task_id` to query the task status. Once completed, `output` usually contains 1 item, with fields `audio` (audio URL), `url` (cover image), `title`, `text` (lyric excerpt), and `clip_id`.

<ParamField body="out_task_id" type="string" required>
  The initiator task ID passed when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flow_music_gen_123456"
  }'
```

After the query succeeds and the task is completed, `output` example:

```json
{
  "statusCode": 200,
  "message": "",
  "data": {
    "out_task_id": "flow_music_gen_123456",
    "status": "completed",
    "created_at": "2026-08-28T07:44:48.000Z",
    "completed_at": "2026-08-28T07:45:40.000Z",
      "output": [
      {
        "url": "https://static.aireiter.com/tmp/audio-generator/20260828/mmPiP-MSedubqGEZ2Y6Ih-item-0.jpg",
        "audio": "https://static.aireiter.com/tmp/audio-generator/20260828/mmPiP-MSedubqGEZ2Y6Ih-audio-0.m4a",
        "title": "Untitled",
        "text": "(end - 0:20)",
        "clip_id": "cd984d09-5a77-4a06-9553-e47a55f009b0"
      }
    ]
  }
}
```

## Mode Notes

<Note>
The `clip_id` from a successful result is used for `flow_music_extend` / `flow_music_replace` / `flow_music_cover` / `flow_music_stems` / `flow_music_download` / `flow_music_video`. `length` is not a hard limit.
</Note>
