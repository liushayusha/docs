---
title: 'Suno Cover'
description: |
  - Convert a public audio track into a new style cover while keeping the melody close to the original
  - Asynchronous processing mode returns a task ID for later querying
  - Uses a public audio URL and does not pass an upstream clip ID
  - Supports simple mode and custom mode
api: 'POST https://aireiter.com/api/openapi/submit'

<Note>
Suno Cover's model name in AIReiter is `suno_cover`. The melody stays close to the original song, and the prompt mainly changes the style, vocals, and production.
</Note>

## Body

<ParamField body="model" type="string" required>
  Model name, use the following fixed value:

  * `suno_cover`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameter object.

  <Expandable title="params object properties">
    <ParamField body="prompt" type="string" required>
      What the cover should sound like after conversion. The melody will stay close to the original song; this is where you change the style, vocals, and production.

      When custom mode is enabled and the track is not instrumental, the prompt is treated as lyrics. The V5 / V5.5 / V4.5 series supports up to 5000 characters.
    </ParamField>

    <ParamField body="audio_url" type="string | string[]" required>
      The audio URL to be covered. It must be publicly accessible. If an array is provided, the first item is used.

      Audio requirements:

      * Formats MP3, WAV
      * Duration must not exceed 8 minutes
      * No more than 20MB
    </ParamField>

    <ParamField body="suno_model" type="string" default="V5">
      Suno versions:

      * `V4`
      * `V4_5`
      * `V4_5PLUS`
      * `V4_5ALL`
      * `V5` - default value
      * `V5_5`
    </ParamField>

    <ParamField body="custom_mode" type="boolean" default="false">
      Whether to enable custom mode.

      * `false` - Simple mode, only `prompt` and `audio_url` are required
      * `true` - Custom mode, `title` and `style` must be specified
    </ParamField>

    <ParamField body="instrumental" type="boolean" default="false">
      Whether to convert it into instrumental only.

      * `false` - Keep vocals
      * `true` - Instrumental only
    </ParamField>

    <ParamField body="vocal_gender" type="string" default="m">
      Preferred vocal gender. Ignored for instrumental tracks.

      * `m` - Male vocals, default value
      * `f` - Female vocals
    </ParamField>

    <ParamField body="title" type="string">
      Song title. Only valid in custom mode, up to 100 characters. Required when `custom_mode` is enabled.
    </ParamField>

    <ParamField body="style" type="string">
      The new style and production direction. Only valid in custom mode, up to 1000 characters. Required when `custom_mode` is enabled.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID.

  A user-defined task identifier. Required. Only letters, numbers, underscores, and hyphens are supported, with a length of 1-64 characters. You can use this ID later to query the task status and results.
</ParamField>

## Query Task

Suno Cover is an asynchronous cover model. After submitting the task, use `out_task_id` to query the task status. Once completed, `output` usually contains 2 cover results, and each item includes `audio`, `url`, `title`, and `text`.

<ParamField body="out_task_id" type="string" required>
  The requester task ID passed when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "suno_cover_123456"
  }'
```

Example of a successful query after completion, `output`:


## Mode Notes

<Note>
Simple mode only requires `prompt` and `audio_url`. For custom mode, please pass both `title` and `style`.
</Note>

<Warning>
Please provide a publicly accessible audio URL. Local files must first be uploaded to an address that can be read publicly.
</Warning>
