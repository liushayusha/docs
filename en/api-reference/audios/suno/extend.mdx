---
title: 'Suno Continuation'
description: |
  - Extend a segment of public audio into a longer track
  - Asynchronous processing mode, returning a task ID for subsequent queries
  - Uses a public audio URL, no upstream task ID required
  - You can specify which second of the original track to continue from
api: 'POST https://aireiter.com/api/openapi/submit'
---

<Note>
The model name for Suno Extend in AIReiter is `suno_extend`. Upload an audio track or reuse the audio URL from the previous generation result to continue generating.
</Note>

## Body

<ParamField body="model" type="string" required>
  Model name, fixed as:

  * `suno_extend`
</ParamField>

<ParamField body="params" type="object" required>
  Model parameters object.

  <Expandable title="params Object Properties">
    <ParamField body="audio_url" type="string | string[]" required>
      The audio URL to continue, and it must be publicly accessible. If an array is passed, use the first item.

      Audio requirements:

      * Format: MP3, WAV
      * Duration: no more than 8 minutes
      * Size: no more than 20MB
    </ParamField>

    <ParamField body="prompt" type="string">
      Optional. Describe how you want the continuation to develop, for example, a louder chorus, a quieter outro, or the addition of a new instrument.
    </ParamField>

    <ParamField body="continue_at" type="number" default="60">
      The second in the original track from which to continue. Range `0` to `240`, and it must be shorter than the original audio duration. Default `60`, usually placed after the verse or chorus.
    </ParamField>

    <ParamField body="suno_model" type="string" default="V5">
      Suno version:

      * `V4`
      * `V4_5`
      * `V4_5PLUS`
      * `V4_5ALL`
      * `V5` - Default value
      * `V5_5`
    </ParamField>

    <ParamField body="instrumental" type="boolean" default="false">
      Whether the continuation is instrumental only.

      * `false` - Continue with vocals
      * `true` - Instrumental only
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  Initiator task ID.

  User-defined task identifier, required. Only letters, numbers, underscores, and hyphens are supported, with a length of 1-64 characters. You can later use this ID to query the task status and results.
</ParamField>

## Query Task

Suno Extend is an asynchronous music continuation model. After submitting the task, please use `out_task_id` to query the task status. Once completed, `output` usually contains 2 continuation results, and each item includes `audio`, `url`, `title`, and `text`.

<ParamField body="out_task_id" type="string" required>
  The initiator task ID passed in when submitting the task.
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "suno_extend_123456"
  }'
```

After a successful query and completion, the `output` example is:

```json
{
  "statusCode": 200,
  "message": "",
  "data": {
    "out_task_id": "suno_extend_123456",
    "status": "completed",
    "created_at": "2026-08-26T10:12:11.000Z",
    "completed_at": "2026-08-26T10:14:41.000Z",
    "output": [
      {
        "audio": "https://s1.pxz.ai/upload/audio-generator/20260826/suno-extend-0.mp3",
        "url": "https://s1.pxz.ai/upload/audio-generator/20260826/suno-extend-cover-0.jpeg",
        "title": "Morning Coffee (Extended)",
        "text": "[Chorus]\\nLet the guitar keep going..."
      }
    ]
  }
}
```

## Mode Notes

<Note>
`continue_at` is the timestamp in the original track, not the total duration after continuation. Please make sure that this number of seconds falls within the original audio duration.
</Note>

<Warning>
Please pass in a publicly accessible audio URL. Local files must first be uploaded to an address that can be accessed publicly.
</Warning>
