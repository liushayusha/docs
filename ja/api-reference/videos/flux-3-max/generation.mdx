<Note>
FLUX 3 Max の AIReiter におけるモデル名は `flux_3_max` です。`type` を使用してテキスト生成（`text`）、開始・終了フレーム（`frame`）、またはキーフレーム（`keyframes`）モードを選択します。
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべてのインターフェースで Bearer Token による認証が必要です。

  API Key の取得：

  <a href={apiKeyUrl} target="_blank">API Key 管理ページ</a>にアクセスして API Key を取得してください。

  使用時はリクエストヘッダーに以下を追加します：

</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名。以下を固定で使用：

  * `flux_3_max`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      動画コンテンツの説明。すべてのモードで必須。

      画面、アクション、カメラワーク、および音声を同時に描写することをお勧めします。モデルは生成前にプロンプトを自動的に理解し、拡張します（拡張強度は `reasoning_level` を参照）。
    </ParamField>

    <ParamField body="type" type="string" default="text">
      生成モード：

      * `text` - テキストから動画生成（デフォルト値）。プロンプトのみを使用し、渡された画像は無視されます
      * `frame` - 開始・終了フレーム。`image_url[0]` を開始フレームとして使用（必須）、`image_url[1]` を終了フレームとして使用（任意）
      * `keyframes` - キーフレーム。順序どおりに最大10枚の画像を渡し、動画のタイムライン上に均等に配置され、動画が各画像を順番に通過します

      <Warning>
        `frame` および `keyframes` モードでは少なくとも1枚の画像が必要です。画像が渡されない場合は `text` モードとして生成されます。
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      画像URL。パブリックインターネットから直接アクセス可能である必要があります。`text` モードでは渡す必要はありません。

      * `frame` - 1〜2枚：1枚目が開始フレーム、2枚目（任意）が終了フレーム
      * `keyframes` - 1〜10枚、アップロード順に最初から最後のフレームまで均等に配置

      画像の要件：

      * フォーマット：PNG、JPEG、WEBP
      * 1枚あたり20MB以下
    </ParamField>

    <ParamField body="end_image_url" type="string">
      終了フレーム画像のURL。`frame` モードでのみ有効です。`image_url` の2枚目として直接渡すことも可能ですが、両方を同時に渡した場合は `end_image_url` が優先されます。
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      生成する動画の長さ（秒単位）。

      サポートされる整数：`5` 〜 `20`。
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      出力解像度（24 fps）：

      * `720p` - デフォルト値
      * `1080p`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      動画のアスペクト比：

      * `auto` - デフォルト値。`text` モードでは 16:9、画像がある場合は1枚目の画像に従う
      * `16:9` - 横向き
      * `9:16` - 縦向き
      * `1:1` - 正方形
      * `4:3` - 標準横向き
      * `3:4` - 標準縦向き
      * `21:9` - ウルトラワイド
    </ParamField>

    <ParamField body="reasoning_level" type="string" default="high">
      プロンプト推論強度。生成前にモデルがプロンプトを理解し拡張する強度：

      * `high` - デフォルト値。より十分に拡張され、効果が高くなりますが、生成速度は遅くなります
      * `low` - より高速

      どちらの設定も料金は同じです。
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      動画とともにネイティブ音声を生成するかどうか。

      * `true` - 音声トラック付きの動画を生成（デフォルト値）
      * `false` - 音声なしの動画を出力

      音声の有無に関わらず料金は同じです。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元のタスクID。

  ユーザー定義のタスク識別子（必須）。英数字、アンダースコア、ハイフンのみ対応し、長さは1〜64文字です。後からこのIDを使用してタスクのステータスや結果を照会できます。
</ParamField>

## Response

## Query Task

FLUX 3 Max は非同期動画生成モデルです。タスク送信後、`out_task_id` を使用してタスクステータスをクエリしてください。10〜15秒ごとにクエリすることをお勧めします。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡されたリクエスト元のタスク ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flux_3_max_frame_123456"
  }'
```

クエリが成功して完了すると、レスポンス内の `output` 配列に生成された動画が含まれ、要素には `video` フィールドが含まれます。

## Mode Notes

<Note>
`text` はプロンプトのみを使用して生成します。`frame` は動画の開始フレームを固定します（終了フレームの固定も可能）。`keyframes` は複数の画像で動画全体の流れを制御し、画像は順番通りタイムライン上に均等に配置されます（例：10秒の動画に3枚指定した場合、それぞれ0秒、5秒、10秒の位置に配置）。3つのモードの料金は同一で、出力秒数と解像度に基づいて課金されます。
</Note>

<Warning>
`frame` モードで使用できる画像は最大2枚（最初のフレーム＋最後のフレーム）で、余分な画像は無視されます。`keyframes` モードは最大10枚です。`text` モードは渡された画像を無視します。
</Warning>
