---
title: 'HappyHorse 1.1 多参考图视频生成'
description: |
  - 1〜9枚の順序付き参照画像を使用して動画を生成
  - 720p / 1080p、9種類のアスペクト比、および3〜15秒の長さをサポート
  - プロンプト内で [Image 1]、[Image 2] を対応する参照画像として使用
  - 非同期処理モード。後続のクエリに使用するタスクIDを返します
api: 'POST https://aireiter.com/api/openapi/submit'

import { apiKeyUrl } from '/snippets/_variables.mdx';

<Note>
HappyHorse 1.1 の AIReiter におけるモデル名は `happyhorse_1_1` で、現在は複数参考画像の動画生成ワークフローを提供しています。
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべてのエンドポイントは Bearer Token による認証が必要です。

  <a href={apiKeyUrl} target="_blank">API Key 管理ページ</a> にアクセスして API Key を取得し、リクエストヘッダーに次を追加してください:

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名。固定で `happyhorse_1_1` を使用します。
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメーターオブジェクト。

  <Expandable title="params オブジェクトの Properties">
    <ParamField body="prompt" type="string" required>
      動画の内容、動作、視覚スタイルの説明。

      プロンプト内では `[Image 1]`、`[Image 2]` などのマークを使用して `image_url` 配列内の同じ位置の画像を指し、画像内の具体的な対象を説明してください。たとえば、`[Image 1] の赤いチャイナドレスを着た女性が [Image 2] の折りたたみ扇子を開く`。

      最大 2500 個の中国語文字、または 5000 個の非中国語文字までサポートします。超過分は切り捨てられます。
    </ParamField>

    <ParamField body="image_url" type="string | string[]" required>
      参照画像 URL。1〜9枚の画像をサポートし、画像の順序はプロンプト内の `[Image N]` マークと一致している必要があります。

      画像要件:

      * JPEG、JPG、PNG、WEBP をサポート
      * 短辺は 400px 以上であること。720p 以上の解像度を推奨します
      * 1枚あたり 10MB 以下
      * URL はパブリックネットワークから直接アクセスできる必要があります
    </ParamField>

    <ParamField body="resolution" type="string" default="1080p">
      出力解像度: `720p` または `1080p`。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      出力動画のアスペクト比。

      対応: `16:9`、`9:16`、`3:4`、`4:3`、`4:5`、`5:4`、`1:1`、`9:21`、`21:9`。
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      出力動画の長さ。単位は秒です。3〜15の整数に対応しています。
    </ParamField>

    <ParamField body="seed" type="integer" default="0">
      乱数シード。範囲は 0〜2147483647 です。`0` を渡すか省略した場合は、ランダムシードが使用されます。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し側が生成する一意のタスク ID。後続ではこの ID を使用してタスクの Status と結果を照会します。

  英字、数字、アンダースコア、ハイフンのみ対応し、長さは 1〜64 文字です。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元のタスク ID。結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。通常は `pending` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻。ISO 8601 形式。
</ResponseField>

## Query Task

タスクの送信が成功した後、同じ `out_task_id` を通じてステータスを照会します。タスクのステータスには `pending`、`processing`、`completed`、`failed` が含まれます。完了後、`output` 配列に動画結果が含まれます。

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "happyhorse_1_1_task_123456"
  }'
```
