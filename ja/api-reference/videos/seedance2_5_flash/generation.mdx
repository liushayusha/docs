<Note>
AIReiterにおけるSeedance 2.5 Flashのモデル名は `seedance2_5_flash` です。これはSeedance 2.5の高速版であり、生成がより速く、参照素材の上限が少なくなっており、パラメータ構造は `seedance2_5` と同じです。
</Note>

## Seedance 2.5 との違い

| 項目 | `seedance2_5` | `seedance2_5_flash` |
| --- | --- | --- |
| 参照画像の上限 | 30枚 | 10枚 |
| 参照動画の上限 | 9本 | 5本 |
| 参照音声の上限 | 10本 | 5本 |
| 生成速度 | 標準 | より高速 |

上記の表を除き、両モデルのパラメータ、値の範囲、および素材仕様は同じです。

## Body

<ParamField body="model" type="string" required>
  モデル名。以下の固定値を使用します：

  * `seedance2_5_flash`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      動画生成のためのテキスト説明。

      被写体、シーン、動作、カメラワーク、ビジュアルスタイル、セリフ、および環境音を記述することをお勧めします。
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      参照モード。参照素材の使用方法を決定します：

      * `all_reference` - 全参照モード。参照画像、参照動画、および参照音声を使用できます
      * `first_last_frame` - 開始・終了フレームモード。開始フレーム画像とオプションの終了フレーム画像を使用します

      2つのモードは排他的であり、1回のリクエストでいずれか一方のみを使用できます。
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参照画像の URL。

      * `all_reference` モード：最大 10 枚の画像、1 枚あたり最大 30MB、画像の最小辺 300px
      * `first_last_frame` モード：1〜2 枚の画像（順番に開始フレームと終了フレームとして使用）、1 枚あたり最大 10MB

      URL はパブリックネットワークから直接アクセス可能である必要があります。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参照動画の URL。`all_reference` モードでのみ有効で、最大 5 個の参照動画に対応しています。

      動画の要件：

      * 単一動画の長さは 2〜30 秒、参照動画の合計時間は 30 秒以内
      * 単一動画は最大 200MB
      * フレームレートは 24〜60 FPS
      * アスペクト比の範囲は 0.4〜2.5
      * 幅と高さの範囲は 300〜6000px
      * 総ピクセル数の範囲は 409600〜927408

      <Warning>`first_last_frame` モードではこのパラメータを渡さないでください。</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参照音声の URL。`all_reference` モードでのみ有効で、最大 5 個の音声に対応しています。

      音声の要件：

      * 単一音声の長さは 2〜30 秒、参照音声の合計時間は 30 秒以内
      * WAV、MP3 に対応
      * 単一音声は最大 15MB

      <Warning>`first_last_frame` モードではこのパラメータを渡さないでください。</Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      動画の解像度：

      * `480p`
      * `720p` - デフォルト値

      1080p、4K には対応していません。
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      出力動画の長さ（秒単位）。

      `4` から `30` までの整数に対応しており、デフォルトは `5` です。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      動画のアスペクト比：

      * `21:9` - ウルトラワイド
      * `16:9` - 横向き、デフォルト値
      * `9:16` - 縦向き
      * `4:3` - 標準横向き
      * `3:4` - 標準縦向き
      * `1:1` - 正方形

      `first_last_frame` モードではアスペクト比は開始フレーム画像に従うため、このパラメータは無効になります。
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      動画と同期した AI 音声を生成するかどうか。

      * `true` - 音声を生成する、デフォルト値
      * `false` - 音声を生成しない
    </ParamField>

    <ParamField body="output_format" type="string" default="mp4">
      出力動画のフォーマット：

      * `mp4` - 汎用フォーマット。ファイルサイズが比較的小さく、デフォルト値です
      * `mov` - 高色精度フォーマット（yuv444p）。編集での拡張や結合に適しています
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元のタスク ID。

  呼び出し元が生成し、一意性を保証する必要があります。英数字、アンダースコア（_）、ハイフン（-）に対応しており、長さは 1〜64 文字です。後続の処理でこの ID を使用してタスクのステータスと結果を照会します。
</ParamField>

## Query Task

Seedance 2.5 Flashは非同期処理を採用しています。送信が成功したら、同じ `out_task_id` を使用してタスクをクエリします：

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "seedance2_5_flash_task_123456"
  }'
```

タスクが完了すると、レスポンスの `output` 配列に生成された動画のURLが含まれます。完全なフィールドについては、[タスクステータスの取得](/ja/api-reference/tasks/status)を参照してください。

## Mode Rules

| type | 利用可能な素材 | 素材の制限 |
| --- | --- | --- |
| `all_reference` | `image_url`、`video_url`、`audio_url` | 最大10枚の画像、5本の動画、5本の音声 |
| `first_last_frame` | `image_url` | 1〜2枚の画像（順番に最初のフレーム、最後のフレーム）。`video_url`、`audio_url`は渡さないでください。アスペクト比は最初のフレームの画像に従います |

<Warning>
すべての素材のURLにパブリックネットワークから直接アクセスできることを確認してください。タスクは非同期で処理されるため、リクエストを送信したHTTP接続で最終的な動画の完了を待機しないでください。
</Warning>
