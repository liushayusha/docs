<Note>
AIReiter における FLUX 3 Video のモデル名は `flux_3_video` です。現在、テキストから動画生成、順序付きキーフレーム、動画の続きを生成する 3 つのモードが利用できます。
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべてのインターフェースは Bearer Token による認証が必要です。

  <a href={apiKeyUrl} target="_blank">API Key management page</a> にアクセスして API Key を取得し、リクエストヘッダーに次を追加してください:

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名、固定で使用：

  * `flux_3_video`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメーターオブジェクト。

  <Expandable title="params オブジェクトの Properties">
    <ParamField body="mode" type="string" default="t2v">
      生成モード：

      * `t2v` - テキストから動画へ。プロンプトのみを使用して動画を生成します
      * `i2v` - 順序付きキーフレーム。1〜10枚の画像で動画の内容と遷移を制御します
      * `v2v` - 動画の続き生成。1つのソース動画から動的コンテンツを続けて生成します
    </ParamField>

    <ParamField body="prompt" type="string" required>
      動画生成のテキスト説明。

      主体、シーン、動作、カメラの動き、視覚スタイル、対話、および環境音を記述することを推奨します。
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      順序付きキーフレーム画像 URL。`i2v` モードでのみ使用します。

      * 公開アクセス可能な画像を1〜10枚サポート
      * 画像の順序がそのまま再生順序になります
      * 1枚目と最後の1枚は、動画の開始フレームと終了フレームを定義するために使用できます

      <Warning>`i2v` モードでは少なくとも1枚の画像を指定する必要があります。他のモードではこのパラメーターを渡さないでください。</Warning>
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      ソース動画 URL。`v2v` モードでのみ使用します。

      現在は、公開アクセス可能な MP4 動画を1つまでサポートしています。配列形式で渡された場合は、最初の URL のみが使用されます。

      <Warning>`v2v` モードではソース動画を指定する必要があります。他のモードではこのパラメーターを渡さないでください。</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      出力動画の長さ。単位は秒です。

      5〜20 の整数をサポートします。
    </ParamField>

    <ParamField body="resolution" type="string" default="hd">
      出力品質：

      * `hd` - HD
      * `fhd` - FHD

      <Note>FHD のピクセル数は HD より多く、具体的な出力サイズはアスペクト比によって変わります。</Note>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      動画のアスペクト比：

      * `auto` - 自動
      * `21:9` - ウルトラワイド
      * `2:1` - ワイドスクリーン
      * `16:9` - 横長
      * `4:3` - 標準横長
      * `1:1` - 正方形
      * `3:4` - 縦版標準
      * `9:16` - 縦長
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      動画と同期したネイティブ音声を生成するかどうか。

      対話、環境音、効果音を含めることができます。
    </ParamField>

    <ParamField body="safety_tolerance" type="integer" default="2">
      コンテンツ安全性の許容度。整数 `0` から `4` をサポートします。

      * `0` - 最も厳格なフィルタリング
      * `4` - 最も緩い設定
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  発信側のタスク ID。

  呼び出し元が生成し、一意性を保証します。後続ではこの ID を使用してタスクの状態と結果を照会します。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  Initiator task ID, can be used to query the result.
</ResponseField>

<ResponseField name="status" type="string">
  Initial status, usually `"pending"`.
</ResponseField>

<ResponseField name="created_at" type="string">

## Query Task

FLUX 3 Videoは非同期処理を採用しています。送信に成功した後、同じ`out_task_id`を使用してタスクをクエリします:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flux_3_video_task_123456"
  }'
```

タスクが完了すると、レスポンス内の`output`配列に生成された動画のURLが含まれます。完全なフィールドは[Get Task Status](/en/api-reference/tasks/status)を参照してください。

  ```r R
      safety_tolerance = 2
    ),
    out_task_id = "flux_3_video_t2v_123456"
  )

  response <- POST(
    url,
    add_headers(
      Authorization = "Bearer <token>",
      `Content-Type` = "application/json"
    ),
    body = toJSON(payload, auto_unbox = TRUE),

  )

  cat(content(response, "text"))
  ```

## Mode Rules

| mode | 必須素材 | 素材制限 |
| --- | --- | --- |
| `t2v` | なし | `image_url` または `video_url` を送信しないでください |
| `i2v` | `image_url` | 順序付きの画像を1〜10枚 |
| `v2v` | `video_url` | ソース動画は最大1つ |

<Warning>
画像と動画のURLが公開ネットワークから直接アクセス可能であることを確認してください。タスクは非同期処理のため、最終動画を待機するために送信リクエストのHTTP接続を使用しないでください。
</Warning>
