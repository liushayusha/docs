<Note>
AIReiter における FLUX 3 Video のモデル名は `flux_3_video` です。現在、テキストから動画生成、順序付きキーフレーム、動画の続きを生成する 3 つのモードが利用できます。
</Note>

## 本文

<ParamField body="model" type="string" required>
  モデル名。固定値を使用:

  * `flux_3_video`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメーターのオブジェクト。

  <Expandable title="params オブジェクトの Properties">
    <ParamField body="mode" type="string" default="t2v">
      生成モード:

      * `t2v` - テキストから動画を生成。プロンプトのみを使用して動画を生成します
      * `i2v` - 順序付きキーフレーム。1〜10枚の画像を使用して動画の内容と遷移を制御します
      * `v2v` - 動画の続き生成。1つのソース動画から動的コンテンツの生成を続けます
    </ParamField>

    <ParamField body="prompt" type="string" required>
      動画生成のテキスト説明。

      主体、シーン、動作、カメラの動き、ビジュアルスタイル、セリフ、環境音を説明することを推奨します。
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      順序付きキーフレーム画像 URL。`i2v` モードでのみ使用します。

      * 公開アクセス可能な画像を1〜10枚サポート
      * 画像の順序が再生順序になります
      * 最初の画像と最後の画像は、動画の開始フレームと終了フレームの定義に使用できます

      <Warning>`i2v` モードでは少なくとも1枚の画像を指定する必要があります。その他のモードではこのパラメーターを渡さないでください。</Warning>
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      ソース動画 URL。`v2v` モードでのみ使用します。

      現在は公開アクセス可能な MP4 動画を1つまでサポートしています。配列形式で渡された場合は、最初の URL のみを使用します。

      <Warning>`v2v` モードではソース動画を指定する必要があります。その他のモードではこのパラメーターを渡さないでください。</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      出力動画の長さ。単位は秒です。

      5〜20 の整数に対応しています。動画の長さは課金に直接影響します。
    </ParamField>

    <ParamField body="resolution" type="string" default="hd">
      出力品質:

      * `hd` - HD
      * `fhd` - FHD

      <Note>FHD は HD より画素数と価格が高く、具体的な出力サイズはアスペクト比によって変化します。</Note>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      動画のアスペクト比:

      * `auto` - 自動
      * `21:9` - ウルトラワイド
      * `2:1` - ワイドスクリーン
      * `16:9` - 横長
      * `4:3` - 標準横長
      * `1:1` - 正方形
      * `3:4` - 縦版標準
      * `9:16` - 縦長
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      動画と同期したネイティブ音声を生成するかどうか。

      セリフ、環境音、効果音を含めることができます。音声をオフにしても価格は下がりません。
    </ParamField>

    <ParamField body="safety_tolerance" type="integer" default="2">
      コンテンツ安全性の許容度。整数 `0` から `4` をサポートします。

      * `0` - 最も厳しいフィルター
      * `4` - 最も緩やかな設定
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  発行元のタスク ID。

  呼び出し元が生成し、一意であることを保証します。後続ではこの ID を使用してタスクのステータスと結果を照会します。
</ParamField>

## Query Task

FLUX 3 Video は非同期処理を採用しています。送信が成功した後、同じ `out_task_id` を使用してタスクを問い合わせます:

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "flux_3_video_task_123456"
    }'
  ```
</RequestExample>

タスク完了後、レスポンスの `output` 配列には生成された動画 URL が含まれます。実際の消費クレジットは `credits_used` から取得できます。完全なフィールドについては[タスクのステータスを取得](/en/api-reference/tasks/status)を参照してください。

## Pricing

FLUX 3 Video は生成モード、出力品質、動画の秒数に応じて課金されます。音声の生成には追加料金はかかりません。

| モード | HD | FHD |
| --- | ---: | ---: |
| Text-to-Video / Ordered Keyframes | 17.68 credits / 秒 | 30.16 credits / 秒 |
| Video Continuation | 42.64 credits / 秒 | 55.12 credits / 秒 |

課金式：

```text
credits = corresponding mode and quality per-second price × video_length
```

例：

* 5秒 HD Text-to-Video: `17.68 × 5 = 88.4 credits`
* 5秒 FHD Ordered Keyframes: `30.16 × 5 = 150.8 credits`
* 5秒 HD Video Continuation: `42.64 × 5 = 213.2 credits`
* 5秒 FHD Video Continuation: `55.12 × 5 = 275.6 credits`

## Mode Rules

| mode | 必要素材 | 素材制限 |
| --- | --- | --- |
| `t2v` | なし | `image_url` または `video_url` を送信しないでください |
| `i2v` | `image_url` | 1～10枚の順序付き画像 |
| `v2v` | `video_url` | ソース動画は最大1つ |

<Warning>
画像と動画のURLがパブリックネットワークから直接アクセス可能であることを確認してください。タスクは非同期処理のため、最終動画を待つためにリクエスト送信時のHTTP接続を使用しないでください。
</Warning>
