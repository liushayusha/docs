title: 'Muse Video Ext 動画生成'
description: |
  - 非同期処理モード、タスクIDを返却し後続の照会に使用
  - テキストからの動画生成、または最大9枚の参照画像による動画生成に対応
  - 1回につき10秒、720p、音声トラック付きの動画を1本生成
  - プロンプトに時間を記述するだけでシーン間のカメラ切り替えが可能
api: 'POST https://aireiter.com/api/openapi/submit'

import { apiKeyUrl } from '/snippets/_variables.mdx';

<Note>
長さは10秒固定、解像度は720p固定で、完成した動画には生成されたオーディオトラックが付属します。`video_length` と `resolution` は省略可能です。

参照動画、参照音声、開始・終了フレーム、`seed`、`negative_prompt` には対応しておらず、オーディオトラックを無効にすることもできません。
</Note>

## Body

<ParamField body="model" type="string" required>
  モデル名。`muse_video_ext` に固定。
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      動画生成のテキスト説明。中国語と英語に対応。必須であり、先頭と末尾の空白文字を除去した後に空にすることはできません。

      参照画像がある場合、プロンプト内で `Picture 1`、`Picture 2` を使用して1枚目、2枚目の画像を指定できます。

      複数のカットがある場合、カットごとに段落を分け、タイムスタンプで切り替え位置を示します。例：

      ```
      [Shot 1] リビングの全景、女性がハンガーにかかったTシャツを掲げている……
      [Shot 2] At 00:04.000、カメラが白い壁の前に切り替わり、男性がこのTシャツを着る……
      ```

      <Warning>
        プロンプトに実在するブランド、スポーツチーム、またはロゴ名が含まれている場合、コンテンツ審査を通過できず、タスクが失敗で終了する可能性があります。名称を含まない説明に変更して再試行してください。
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参照画像の URL。パブリックネットワークから直接アクセスできる必要があります。単一の文字列として渡すことも可能です。指定しない場合はテキストからの動画生成になります。

      * 最大 9 枚
      * すべての画像の元のサイズの合計が 11 MiB を超えないこと
      * PNG、JPEG、WebP を推奨

      ローカルパスおよび `blob:` アドレスには対応していません。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      動画のアスペクト比：

      * `auto` - デフォルト値。参照画像がある場合は参照画像の構図に従い、テキストのみの場合は `16:9`
      * `1:1`
      * `16:9`
      * `9:16`
      * `4:3`
      * `3:4`
      * `3:2`
      * `2:3`
    </ParamField>

    <ParamField body="video_length" type="string" default="10">
      動画の長さ。`"10"` に固定。省略可能。
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      出力解像度。`720p` に固定。省略可能。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元のタスク ID。

  ユーザー定義のタスク識別子。必須。英数字、アンダースコア、ハイフンのみ対応し、長さは 1-64 文字です。後からこの ID を使用してタスクのステータスと結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  リクエスト元タスクID。結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期ステータス。通常は `"pending"` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成日時、ISO形式。
</ResponseField>

## Query Task

本モデルは非同期動画生成です。タスク送信後、`out_task_id` を使用してタスクステータスをクエリしてください。[タスクステータスの取得](/ja/api-reference/tasks/status)もご参照ください。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡されたリクエスト元のタスクID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "muse_ext_t2v_123456"
  }'
```

クエリが成功して完了すると、レスポンス内の `output` 配列に生成された動画が含まれ、要素には `video` フィールドが含まれます。

生成にかかる時間は入力によって異なります：テキストのみの場合は通常約1〜2分、参照画像が多い場合は数分かかることがあります。重複して送信せず、継続してポーリングを行ってください。

## 使用说明

| 入力 | `image_url` | `aspect_ratio` |
|---|---|---|
| テキストから動画生成 | 送信しない、または空配列 | 未指定の場合はデフォルトで `16:9`、指定も可能 |
| 参照画像から動画生成 | 1〜9枚、合計で11 MiB以下 | 参照画像に追従する `auto` を推奨、または指定も可能 |

マルチショットプロンプトの効果：

* カット切り替えタイミングが正確：プロンプトに記載した時間に対し、実際の切り替え誤差は1秒以内です。
* 商品上のテキスト、プリント、ロゴは各ショット間で一貫性を維持します。
* 人物はカット切り替え後に参照画像と差異が生じる場合があります。同一人物の識別性を維持する必要がある場合は、切り替えポイントを最大2箇所までに抑え、各ショットでその外見の描写を繰り返し記述することをお勧めします。
