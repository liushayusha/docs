  - 同一のパラメータセット、2つのモデルID：`gemini_omni_flash_ext`（1.0）および `gemini_omni_1_1_flash_ext`（1.1）
  - 非同期処理モード、後続のクエリ用タスクIDを返却

* `gemini_omni_flash_ext` — Gemini Omni Flash Ext（1.0）
* `gemini_omni_1_1_flash_ext` — Gemini Omni 1.1 Flash Ext
</Note>

## Body

<ParamField body="model" type="string" required>
  モデル名。以下のいずれかを選択：

  * `gemini_omni_flash_ext`
  * `gemini_omni_1_1_flash_ext`

  パラメータフィールドは共通です。`type` は渡さないでください。
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      動画生成のテキスト説明。必須。
    </ParamField>

    <ParamField body="video_length" type="string" default="6">
      生成する動画の長さ（秒単位）。文字列のみ受け付けます：

      * `"4"`
      * `"6"` - デフォルト値
      * `"8"`
      * `"10"`

      参照動画がある場合はこのフィールドを渡さないでください。出力動画の長さはアップロードされた動画に従います。

      <Warning>
        `3`、`5`、`7`、`9` やその他の秒数は渡さないでください。列挙型の検証により文字列が必要となるため、数値の `6` ではなく `"6"` を渡してください。
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      出力解像度：

      * `720p` - デフォルト値
      * `1080p`
      * `4K`

      720p と 1080p は同価格で、4K はより高額になります。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      動画のアスペクト比：

      * `16:9` - 横向き、デフォルト値
      * `9:16` - 縦向き
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参照画像の URL。パブリックネットワークから直接アクセスできる必要があります。単一の文字列として渡すことも可能です。渡さない場合はテキストからの動画生成になります。

      * 最大 7 枚、**2枚も指定可能**
      * 短辺 300px 以上、1枚あたり 10MB 以下

      参照動画と同時に渡す場合、画像数 + 2 は 7 以下（≤ 7）である必要があります。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参照動画の URL。オプション、最大 1 本。単一の文字列として渡すことも可能です。参照画像と一緒に渡すことができます。

      動画要件：

      * フォーマット：MP4、MOV
      * 長さは 10 秒以内
      * 100MB 以下
      * 短辺 300px 以上

      参照動画を渡す場合は `video_length` を渡さないでください。出力動画の長さはアップロードされた動画に従い、最長 10 秒となります。参照動画は 7 スロットのクォータのうち 2 枠としてカウントされます。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元のタスク ID。

  ユーザー定義のタスク識別子。必須。英数字、アンダースコア、ハイフンのみ対応し、長さは 1〜64 文字です。後からこの ID を使用してタスクのステータスと結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元タスク ID。結果照会に使えます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。通常は `"pending"`。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  このタスクの推定消費クレジット。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻。ISO 形式。
</ResponseField>

## Query Task

これら2つのモデルはいずれも非同期動画生成です。タスクを送信後、`out_task_id` を使用してタスクステータスを照会してください。[タスクステータスの取得](/ja/api-reference/tasks/status) も参照できます。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡されたリクエスト元のタスクID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_ext_t2v_123456"
  }'
```

照会が成功して完了すると、レスポンス内の `output` 配列に生成された動画が含まれ、各要素に `video` フィールドが含まれます。

## パラメータ対応表

| 入力 | `image_url` | `video_url` | 再生時間 |
|---|---|---|---|
| テキスト生成 | 送信しない、または空配列 | 送信しない | `video_length` `"4"` / `"6"` / `"8"` / `"10"` |
| 参照画像 | 1〜7枚（2枚含む） | 送信しない | 同上 |
| 参照動画 | 送信しない、または空配列 | 1本、最長10秒 | `video_length` は送信しない、元動画に準拠 |
| 画像 + 動画 | 最大5枚（画像数 + 2 ≤ 7） | 1本、最長10秒 | `video_length` は送信しない、元動画に準拠 |
