title: 'Gemini Omni Flash Ext 動画生成'
description: |
  - AIReiter 上の独立した Omni Flash 動画 SKU
  - 非同期処理モードで、後続の照会用にタスク ID を返します
  - 2つの生成タイプ: First Frame（`frame`）と Reference（`reference`）
  - 720p / 1080p / 4K をサポートし、長さは 4 / 6 / 8 / 10 秒のみ
api: 'POST https://aireiter.com/api/openapi/submit'

<Note>
Gemini Omni Flash Ext の AIReiter におけるモデル名は `gemini_omni_flash_ext` です。

これは当サイトの公式 Omni Flash SKU（`gemini_omni_flash_preview`、出力 720p）ではありません。このページの SKU は 720p / 1080p / 4K を出力でき、長さは 4、6、8、10 秒のみです。
</Note>

## Body

<ParamField body="model" type="string" required>
  モデル名。固定で次を使用します:

  * `gemini_omni_flash_ext`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトの属性">
    <ParamField body="prompt" type="string" required>
      動画生成のテキスト説明。必須。
    </ParamField>

    <ParamField body="type" type="string" default="frame">
      生成タイプ。以下の2つの値のみ受け付けます:

      * `frame` - First Frame。プロンプトに0枚または1枚の画像を追加します。参考動画は渡せません
      * `reference` - Reference。プロンプトに0枚、1枚、または3枚の画像を追加します。参考動画を1本任意で指定できます

      画像を指定しない場合はテキストからの動画生成になります。どちらのタイプでも使用できます。

      <Warning>
        `type=text` は指定しないでください。`frame` は `video_url` と同時に指定できません。
      </Warning>
    </ParamField>

    <ParamField body="video_length" type="string" default="6">
      動画の長さ。単位は秒です。受け付けるのは文字列のみです:

      * `"4"`
      * `"6"` - デフォルト値
      * `"8"`
      * `"10"`

      参考動画がある場合はこのフィールドを指定しないでください。出力の長さはアップロードした動画に従います。

      <Warning>
        `3`、`5`、`7`、`9`、またはその他の秒数は指定しないでください。列挙チェックでは文字列が必要です。数値の `6` ではなく `"6"` を指定してください。
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      出力解像度:

      * `720p` - デフォルト値
      * `1080p`
      * `4K`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      動画のアスペクト比:

      * `16:9` - 横向き、デフォルト値
      * `9:16` - 縦向き
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      画像 URL。公開インターネットから直接アクセスできる必要があります。単一の文字列でも指定できます。

      * `frame` - オプションで0枚または1枚、最初のフレームとして使用します。指定しなければテキストからの生成になります
      * `reference` - オプションで0枚、1枚、または3枚。指定しなければテキストからの生成になります

      画像要件: 短辺は300px以上、1枚あたり10MB以下。

      <Warning>
        2枚の画像はサポートされません。`reference` に2枚指定すると `Invalid image_url count. Allowed: [1, 3]` が返されます。4枚以上も指定しないでください。
      </Warning>
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参考動画 URL。`type=reference` の場合のみ有効で、最大1本です。単一の文字列でも指定できます。

      動画要件:

      * 形式 MP4、MOV
      * 長さは10秒以内
      * 100MB以下
      * 短辺は300px以上

      参考動画を指定する場合は `video_length` を指定しないでください。出力の長さはアップロードした動画に従い、最大10秒です。

      <Warning>`type=frame` ではこのパラメータを指定しないでください。API はそのまま拒否します。</Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  発行元のタスク ID。

  ユーザーが定義するタスク識別子で、必須です。英字、数字、アンダースコア、ハイフンのみ使用でき、長さは1-64文字です。後からこの ID でタスクの状態と結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  発行元のタスク ID。結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。通常は `"pending"` です。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  今回のタスクの推定消費クレジット。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻。ISO 形式です。
</ResponseField>

## Query Task

Gemini Omni Flash Ext は非同期動画生成モデルです。タスクを送信した後は、`out_task_id` を使用してタスクの状態を確認してください。[タスクの状態を取得する](/en/api-reference/tasks/status) も参照してください。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡す送信元タスク ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_ext_t2v_123456"
  }'
```

クエリが成功して完了すると、レスポンス内の `output` 配列には生成された動画が含まれ、各要素には `video` フィールドがあります。

## モードパラメータ対応表

| `type` | `image_url` | `video_url` | 再生時間 |
|---|---|---|---|
| `frame`、画像なし | 送信しない、または空配列 | 送信しない | `video_length` `"4"` / `"6"` / `"8"` / `"10"` |
| `frame` | 1枚 | 送信しない | 同上 |
| `reference`、画像なし | 送信しない、または空配列 | 送信しない | 同上 |
| `reference` | 1枚または3枚 | 送信しない | 同上 |
| `reference` | 0、1、または3枚 | 1本、最長10秒 | `video_length` を送信せず、元動画に従う |
