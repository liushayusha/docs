---
title: 'Gemini Omni Flash Ext 動画生成'
description: |
  - 同じパラメータ、2つのモデル ID：`gemini_omni_flash_ext`（1.0）と `gemini_omni_1_1_flash_ext`（1.1）
  - 非同期処理モードで、後続の照会用にタスク ID を返します
  - テキスト生成、最大 7 枚の参照画像、任意の参照動画 1 本。画像と動画は同時に送れます
  - 720p / 1080p / 4K をサポートし、長さは 4 / 6 / 8 / 10 秒のみ
api: 'POST https://aireiter.com/api/openapi/submit'

<Note>
1.0 と 1.1 は本ページのパラメータを共有します。SKU の切り替えは `model` だけ変えてください。

* `gemini_omni_flash_ext` — Gemini Omni Flash Ext（1.0）
* `gemini_omni_1_1_flash_ext` — Gemini Omni 1.1 Flash Ext
</Note>

## Body

<ParamField body="model" type="string" required>
  モデル名。次のいずれか：

  * `gemini_omni_flash_ext`
  * `gemini_omni_1_1_flash_ext`

  パラメータフィールドは同じです。`type` は送らないでください。
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      動画生成のテキスト説明。必須。
    </ParamField>

    <ParamField body="video_length" type="string" default="6">
      生成動画の長さ（秒）。次の文字列のみ受け付けます：

      * `"4"`
      * `"6"` - デフォルト
      * `"8"`
      * `"10"`

      参照動画がある場合はこのフィールドを送らないでください。出力長はアップロード動画に従います。

      <Warning>
        `3`、`5`、`7`、`9` など他の秒数は送らないでください。列挙検証は文字列を要求します。数字の `6` ではなく `"6"` を送ってください。
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      出力解像度：

      * `720p` - デフォルト
      * `1080p`
      * `4K`

      720p と 1080p は同価格、4K はより高価です。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      動画のアスペクト比：

      * `16:9` - 横向き、デフォルト
      * `9:16` - 縦向き
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参照画像 URL。公開インターネットから直接アクセスできる必要があります。単一文字列でも可。省略するとテキスト生成になります。

      * 最大 7 枚、**2 枚も可**
      * 短辺 300px 以上、1 枚あたり 10MB 以下

      参照動画と同時に送る場合、画像数 + 2 は ≤ 7 である必要があります。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参照動画 URL。任意、最大 1 本。単一文字列でも可。参照画像と同時に送れます。

      動画要件：

      * 形式 MP4、MOV
      * 長さ 10 秒以内
      * 100MB 以内
      * 短辺 300px 以上

      参照動画がある場合は `video_length` を送らないでください。出力長はアップロード動画に従い、最大 10 秒です。参照動画は 7 スロット枠のうち 2 を使います。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し元タスク ID。

  ユーザー定義のタスク識別子。必須。英数字、アンダースコア、ハイフンのみ、長さ 1-64 文字。後でこの ID でタスク状態と結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元タスク ID。結果照会に使えます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。通常は `"pending"`。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  このタスクの推定消費クレジット。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻。ISO 形式。
</ResponseField>

## Query Task

どちらのモデルも非同期動画生成です。送信後は `out_task_id` で状態を照会してください。[タスク状態の取得](/ja/api-reference/tasks/status) も参照してください。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡した呼び出し元タスク ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_ext_t2v_123456"
  }'
```

照会が成功して完了すると、レスポンスの `output` 配列に生成動画が含まれ、各要素に `video` フィールドがあります。

## パラメータ対照

| 入力 | `image_url` | `video_url` | 長さ |
|---|---|---|---|
| テキスト生成 | 送らない、または空配列 | 送らない | `video_length` `"4"` / `"6"` / `"8"` / `"10"` |
| 参照画像 | 1–7 枚（2 枚可） | 送らない | 同上 |
| 参照動画 | 送らない、または空配列 | 1 本、最大 10 秒 | `video_length` を送らず、ソース動画に従う |
| 画像 + 動画 | 最大 5 枚（画像数 + 2 ≤ 7） | 1 本、最大 10 秒 | `video_length` を送らず、ソース動画に従う |
