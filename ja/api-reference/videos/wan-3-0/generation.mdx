## Body

<ParamField body="model" type="string" required>
  モデル名。固定値を使用:

  * `wan3_0`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメーターオブジェクト。

  <Expandable title="params オブジェクトの Properties">
    <ParamField body="prompt" type="string">
      動画生成のテキスト説明。

      `all_reference` では、プロンプトを入力することを推奨します。少なくとも1つの画像、動画、または音声の参照を提供してください。`first_last_frame` と `file_web` ではプロンプトは Optional ですが、入力すると制御精度が向上します。

      参照素材を使用する場合、プロンプト内で「画像1 / 動画1 / 音声1」のように、種類と順序に応じてアップロード内容を指すことができます。
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      生成モード。どの動画生成方式を使用するかを決定します。同一 Request で3つのモードを混在させることはできません:

      * `all_reference` - テキスト/参照。プロンプトのみでも使用でき、画像、動画、音声を追加することもできます
      * `first_last_frame` - 先頭・末尾フレーム。必須の先頭フレームと Optional の末尾フレームを使用します
      * `file_web` - ファイル/ウェブ。ドキュメント URL または公開ウェブページ URL を渡します

      <Warning>
        先頭・末尾フレームは、参照画像、参照動画、参照音声、ドキュメント、またはウェブページと同じ Request に含めることはできません。`file_url` と `link_url` も同時に渡せません。
      </Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      生成する動画の長さ。単位は秒です。

      整数をサポート: `2` から `30`。参照動画がある場合、入力秒数と出力秒数の合計は 30 秒を超えられません。
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      出力解像度:

      * `480p`
      * `720p` - デフォルト値
      * `1080p`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      動画のアスペクト比。

      サポートされているアスペクト比:

      * `auto` - 参照素材またはプロンプトに従う、デフォルト値
      * `16:9` - 横向き
      * `9:16` - 縦向き
      * `4:3` - 標準横向き
      * `3:4` - 標準縦向き
      * `1:1` - 正方形
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      ネイティブ音声トラックを生成するかどうか。

      * `true` - 音声トラックを生成、デフォルト値
      * `false` - 音声トラックなしの動画を出力
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      画像 URL。パブリックネットワークから直接アクセスできる必要があります。

      `type` によって意味が異なります:

      * `all_reference` - Optional の参照画像、最大 10 枚
      * `first_last_frame` - 1 枚目が先頭フレーム（必須）、2 枚目が末尾フレーム（Optional）
      * `file_web` - 渡さないでください

      画像の要件:

      * 短辺は 240px 以上、長辺は 8000px 以下
      * 1 枚あたり 20MB 以下
    </ParamField>

    <ParamField body="end_image_url" type="string">
      末尾フレームの画像 URL。

      `first_last_frame` モードでのみ有効です。末尾フレームを `image_url` 配列の2枚目の画像として渡すこともできます。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参照動画 URL。

      `all_reference` モードでのみ有効、最大 5 本まで。

      動画の要件:

      * 形式は MP4、MOV
      * 1 本あたり 1-15 秒、合計は 15 秒以下
      * 1 本あたり 100MB 以下
      * 短辺は 240px 以上、長辺は 4096px 以下

      参照動画の長さは課金対象時間に含まれます: 課金秒数 = 生成物の秒数 + 参照動画の秒数（切り上げ）。

      <Warning>`first_last_frame` と `file_web` ではこのパラメーターを渡さないでください。URL が公開アクセス可能で、動画の長さメタデータを読み取れることを確認してください。</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参照音声 URL。

      `all_reference` モードでのみ有効、最大 5 本まで。

      音声の要件:

      * 形式は WAV、MP3
      * 1 本あたり 1-15 秒、合計は 15 秒以下
      * 1 本あたり 15MB 以下

      参照音声は課金対象時間に含まれません。

      <Warning>`first_last_frame` と `file_web` ではこのパラメーターを渡さないでください。</Warning>
    </ParamField>

    <ParamField body="file_url" type="string">
      ドキュメント URL。

      `file_web` モードでのみ有効、パブリックネットワークから直接アクセスできる必要があります。

      DOC(X)、XLS(X)、PPT(X)、PDF、TXT、KEY、Pages、Numbers、MD をサポート。100MB 以下、50ページ以下。ドキュメントは課金対象時間に含まれません。

      <Warning>`link_url` とは排他的です。同時に渡さないでください。</Warning>
    </ParamField>

    <ParamField body="link_url" type="string">
      公開ウェブページ URL。

      `file_web` モードでのみ有効です。ウェブページは課金対象時間に含まれません。

      <Warning>`file_url` とは排他的です。同時に渡さないでください。</Warning>
    </ParamField>

    <ParamField body="watermark" type="boolean" default="false">
      生成物にウォーターマークを追加するかどうか。デフォルトは `false` です。
    </ParamField>

    <ParamField body="seed" type="integer">
      乱数シード。`0` 以上の整数を渡した場合に有効。省略するとランダムになります。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  発行元の Task ID。

  ユーザー定義の Task 識別子で、Required です。英字、数字、アンダースコア、ハイフンのみ使用でき、長さは 1-64 文字です。後続でこの ID を使用して Task の Status と結果を Query できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  送信側タスク ID。結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期ステータス。通常は `"pending"` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成日時、ISO 形式。
</ResponseField>

## Query Task

Wan 3.0 は非同期動画生成モデルです。タスクを送信した後は、`out_task_id` を使用してタスクの状態を確認してください。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡される送信元タスク ID です。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "wan3_0_t2v_123456"
  }'
```

クエリが成功して完了すると、レスポンスの `output` 配列に生成された動画が含まれ、要素には `video` フィールドが含まれます。

          NSMutableURLRequest *request = [NSMutableURLRequest requestWithURL:url];
          [request setHTTPMethod:@"POST"];
          [request setValue:@"Bearer <token>" forHTTPHeaderField:@"Authorization"];
          [request setValue:@"application/json" forHTTPHeaderField:@"Content-Type"];
          [request setHTTPBody:jsonData];

          NSURLSessionDataTask *task = [[NSURLSession sharedSession]
              dataTaskWithRequest:request
              completionHandler:^(NSData *data, NSURLResponse *response, NSError *error) {
                  if (error) {
                      NSLog(@"Error: %@", error);
                      return;
                  }
                  NSString *result = [[NSString alloc] initWithData:data
                                                          encoding:NSUTF8StringEncoding];
                  NSLog(@"%@", result);
              }];

          [task resume];
          [[NSRunLoop mainRunLoop] run];
      }
      return 0;
  }

## Mode Notes

<Note>
`all_reference` can be generated purely from prompts, or with additional image, video, and audio references; `first_last_frame` uses the first frame and an optional last frame; `file_web` uses `file_url` or `link_url` to convert a document or web page into a video.
</Note>

<Warning>
When `type` is `first_last_frame`, do not pass `video_url`, `audio_url`, `file_url`, or `link_url` at the same time. When `type` is `file_web`, only one of `file_url` and `link_url` can be passed.
</Warning>
