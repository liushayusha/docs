## Body

<ParamField body="model" type="string" required>
  モデル名。固定で `happyhorse_1_0` を使用します。
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメーターオブジェクト。

  <Expandable title="params オブジェクトの属性">
    <ParamField body="type" type="string" default="text_to_video" required>
      ビデオワークフロー:

      * `text_to_video` - テキストに基づいてビデオを生成する
      * `image_to_video` - 1枚の先頭画像を使ってビデオを生成する
      * `reference_to_video` - 1〜9枚の参考画像を使ってビデオを生成する
      * `video_edit` - 指示に基づいて元のビデオを編集する
    </ParamField>

    <ParamField body="prompt" type="string">
      ビデオ内容の説明または編集指示。`text_to_video`、`reference_to_video`、`video_edit` では必須、`image_to_video` ではオプションです。

      最大で中国語は2500文字、非中国語は5000文字まで対応し、超過分は切り捨てられます。

      `reference_to_video` モードでは、画像の順序に従って `character1`、`character2` などの名前で参考画像を指します。
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      画像の URL。公開ネットワークから直接アクセスできる必要があります。

      * `image_to_video` - 必須、最初の画像を先頭フレームとして使用します
      * `reference_to_video` - 必須、1〜9枚の順序付き参考画像をサポートします
      * `video_edit` - オプション、最大5枚のスタイルまたは被写体の参考画像をサポートします

      JPEG、JPG、PNG、WEBP をサポートします。画像からの動画生成と動画編集用画像は、幅と高さがどちらも300px以上である必要があります。複数参考画像モードでは短辺が400px以上である必要があります。1枚あたりの画像サイズは10MBを超えないでください。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      `video_edit` モードでは必須で、1つの元動画のみを使用します。

      MP4、MOV をサポートし、H.264 エンコードの使用を推奨します。元動画の要件:

      * 長さは3〜60秒。15秒を超える場合は最初の15秒のみ処理します
      * ファイルサイズは100MB以下
      * 長辺は2160px以下、短辺は320px以上
      * アスペクト比は1:2.5から2.5:1の範囲
      * フレームレートは8 FPSより大きいこと
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      出力解像度: `720p` または `1080p`。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      `text_to_video` と `reference_to_video` モードの出力アスペクト比。

      対応: `16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`4:5`、`5:4`、`9:21`、`21:9`。

      <Warning>`video_edit` はこのパラメーターをサポートしていないため、渡さないでください。`image_to_video` の出力アスペクト比は入力画像に従います。</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      出力ビデオの長さ。単位は秒です。3〜15の整数に対応しています。

      <Warning>`video_edit` はこのパラメーターをサポートしていないため、渡さないでください。出力時間は元動画によって自動的に決定され、`min(入力動画の長さ, 15 秒)` に等しくなります。</Warning>
    </ParamField>

    <ParamField body="seed" type="integer" default="0">
      乱数シード。範囲は0〜2147483647です。`0` を渡すか省略すると、ランダムシードが使用されます。
    </ParamField>

    <ParamField body="keep_original_sound" type="boolean" default="false">
      `video_edit` モードでのみ有効です。`true` に設定すると元動画のオーディオトラックを強制的に保持します。`false` にするか省略した場合は、モデルが自動的に判断します。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し元が生成する一意のタスク ID。後続ではこの ID を使ってタスクの状態と結果を照会します。

  英字、数字、アンダースコア、ハイフンのみサポートし、長さは1〜64文字です。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元のタスク ID。結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。通常は `pending` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻。ISO 8601 形式です。
</ResponseField>

## Query Task

タスクの送信に成功した後、同じ `out_task_id` を使ってステータスを照会します。タスクのステータスには `pending`、`processing`、`completed`、`failed` が含まれます。完了後、`output` 配列には動画の結果が含まれます。

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "happyhorse_1_0_task_123456"
  }'
```

## ワークフローパラメータ対照表

| `type` | 必須素材 | 時長とアスペクト比 |
|---|---|---|
| `text_to_video` | `prompt` | `video_length` 3-15秒、オプションで `aspect_ratio` |
| `image_to_video` | `image_url` | `video_length` 3-15秒、アスペクト比は画像に従う |
| `reference_to_video` | `prompt`、`image_url` | `video_length` 3-15秒、オプションで `aspect_ratio` |
| `video_edit` | `prompt`、`video_url` | 時長とアスペクト比は元動画に従い、出力は最大15秒 |
