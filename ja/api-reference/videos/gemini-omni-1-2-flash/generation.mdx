<Note>
出力は常に 720p の H.264 MP4 です：横向き 1280×720、縦向き 720×1280。1080p / 4K、参照動画、先頭・末尾フレーム指定には対応していません。
</Note>

## Body

<ParamField body="model" type="string" required>
  モデル名。常に `gemini_omni_1_2_flash` を指定してください。
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      動画生成のテキスト説明。必須。
    </ParamField>

    <ParamField body="video_length" type="string" default="8">
      生成する動画の長さ（秒）。`"3"` から `"15"` までの整数秒の文字列のみ受け付けます：

      * `"3"` / `"4"` / `"5"` / `"6"` / `"7"`
      * `"8"` - デフォルト値
      * `"9"` / `"10"` / `"11"` / `"12"` / `"13"` / `"14"` / `"15"`

      <Warning>
        列挙値の検証は文字列を要求します。数値 `8` ではなく `"8"` を渡してください。`"11"` 〜 `"15"` は `aspect_ratio` が `9:16` の場合のみ使用できます。
      </Warning>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      動画のアスペクト比：

      * `16:9` - 横向き 1280×720、デフォルト値
      * `9:16` - 縦向き 720×1280

      長さが 11〜15 秒の場合は `9:16` のみ指定できます。`16:9` は拒否されます。
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参照画像の URL。インターネットから直接アクセスできる必要があります。単一の文字列でも指定できます。省略するとテキストからの動画生成になります。

      * 最大 3 枚。4 枚目は拒否されます
      * 短辺 300px 以上、1 枚あたり 10MB 以下

      参照画像は被写体とスタイルの指定に使われます。先頭・末尾フレームではないため、動画が特定の画像から始まったり終わったりすることは保証されません。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元のタスク ID。

  ユーザー定義のタスク識別子。必須。英数字、アンダースコア、ハイフンのみ対応し、長さは 1〜64 文字です。後からこの ID を使用してタスクのステータスと結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元タスク ID。結果照会に使えます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。通常は `"pending"`。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  このタスクの推定消費クレジット。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻。ISO 形式。
</ResponseField>

## Query Task

このモデルは非同期動画生成です。タスクを送信後、`out_task_id` を使用してタスクステータスを照会してください。[タスクステータスの取得](/ja/api-reference/tasks/status) も参照できます。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡されたリクエスト元のタスクID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_12_t2v_123456"
  }'
```

照会が成功して完了すると、レスポンス内の `output` 配列に生成された動画が含まれ、各要素に `video` フィールドが含まれます。

## パラメータ対応表

| 入力 | `image_url` | `video_length` | `aspect_ratio` |
|---|---|---|---|
| テキストから生成 | 渡さない、または空配列 | `"3"`–`"10"` | `16:9` または `9:16` |
| テキストから生成（長尺） | 渡さない、または空配列 | `"11"`–`"15"` | `9:16` のみ |
| 参照画像 | 1〜3 枚 | `"3"`–`"10"` | `16:9` または `9:16` |
| 参照画像（長尺） | 1〜3 枚 | `"11"`–`"15"` | `9:16` のみ |

非対応のフィールド：`resolution`（720p 固定）、`video_url`（参照動画は非対応）。
