<Note>
出力動画は 720p H.264 MP4 に固定されています（横向き 1280×720、縦向き 720×1280）。1080p / 4K、参照動画、および開始・終了フレームには対応していません。
</Note>

## Body

<ParamField body="model" type="string" required>
  モデル名。固定で `gemini_omni_1_2_flash` を指定します。
</ParamField>

<ParamField body="params" type="object" required>
  モデルのパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      動画生成用のテキスト説明。必須。
    </ParamField>

    <ParamField body="video_length" type="string" default="8">
      生成する動画の長さ（秒単位）。`"3"` から `"15"` までの整数秒の文字列のみ受け付けます：

      * `"3"` / `"4"` / `"5"` / `"6"` / `"7"`
      * `"8"` - デフォルト値
      * `"9"` / `"10"` / `"11"` / `"12"` / `"13"` / `"14"` / `"15"`

      <Warning>
        列挙型のバリデーションでは文字列が必要なため、数値の `8` ではなく `"8"` を指定してください。`"11"` から `"15"` までは、`aspect_ratio` を `9:16` に設定した場合のみ使用できます。
      </Warning>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      動画のアスペクト比：

      * `16:9` - 横向き 1280×720、デフォルト値
      * `9:16` - 縦向き 720×1280

      長さが11–15秒の場合は `9:16` のみ指定可能です。`16:9` を指定すると拒否されます。
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参照画像のURL。パブリックネットワークから直接アクセス可能である必要があります。単一の画像URLを文字列として指定することも可能です。指定しない場合はテキストからの動画生成（Text-to-Video）になります。

      * 最大3枚まで（4枚目は拒否されます）
      * 短辺が300px以上、1枚あたり10MB以下

      参照画像は被写体やスタイルを決定するために使用されるものであり、開始フレームや終了フレームではありません。生成される動画が特定の画像から開始または終了することは強制されません。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元のタスクID。

  ユーザー定義のタスク識別子（必須）。英数字、アンダースコア（_）、ハイフン（-）のみサポートされており、長さは1〜64文字です。後でこのIDを使用して、タスクのステータスや結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元タスク ID。結果照会に使えます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。通常は `"pending"`。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  このタスクの推定消費クレジット。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻。ISO 形式。
</ResponseField>

## Query Task

このモデルは非同期の動画生成を行います。タスクを送信した後、`out_task_id` を使用してタスクのステータスを照会してください。[タスクステータスの取得](/ja/api-reference/tasks/status)も参照してください。

<ParamField body="out_task_id" type="string" required>
  タスクの送信時に渡されたリクエスト元のタスク ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_12_t2v_123456"
  }'
```

照会が成功しタスクが完了すると、レスポンスの `output` 配列に生成された動画が含まれ、各要素には `video` フィールドが含まれます。

## パラメータ比較

| 入力 | `image_url` | `video_length` | `aspect_ratio` |
|---|---|---|---|
| テキストから生成 | 送信しない、または空の配列 | `"3"`–`"10"` | `16:9` または `9:16` |
| テキストから生成（長尺） | 送信しない、または空の配列 | `"11"`–`"15"` | `9:16` のみ |
| 参考画像 | 1–3枚 | `"3"`–`"10"` | `16:9` または `9:16` |
| 参考画像（長尺） | 1–3枚 | `"11"`–`"15"` | `9:16` のみ |

サポートされていないフィールド：`resolution`（720p固定）、`video_url`（参考動画は非対応）。
