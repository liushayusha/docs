<Note>
MiniMax H3 Turbo の AIReiter におけるモデル名は `minimax_h3_turbo` です。このモデルは `minimax_h3` と異なり、解像度は768P固定（2K非対応）、動画の長さは6-15秒で、先頭および末尾フレームには対応していません。
</Note>

## Body

<ParamField body="model" type="string" required>
  モデル名。固定値：

  * `minimax_h3_turbo`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      動画生成用のテキスト説明。

      被写体、シーン、カメラワーク、アクション、スタイル、ライティング、リズムなどの内容を記述できます。

      参考素材を使用する場合、プロンプト内で「画像1 / 動画1 / 音声1」のように順番に指定してアップロードした内容を参照できます。
    </ParamField>

    <ParamField body="video_length" type="number" default="6">
      生成する動画の長さ（秒単位）。

      整数の `6` から `15` に対応。
    </ParamField>

    <ParamField body="resolution" type="string" default="768p">
      出力解像度。`768p` に固定、省略可能。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      動画のアスペクト比。

      サポートされているアスペクト比：

      * `16:9` - 横向き、デフォルト値
      * `9:16` - 縦向き
      * `1:1` - 正方形
      * `4:3` - 標準横向き
      * `3:4` - 標準縦向き
      * `21:9` - ウルトラワイド
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参照画像の URL（任意）。最大8枚。

      画像を指定しない場合はテキストからの動画生成となり、画像を指定した場合は被写体、スタイル、構図を誘導する参照画像として機能します。

      画像の要件：

      * JPEG、PNG、WEBP に対応
      * 1枚あたり最大20MB
      * URL は一般公開アクセス可能である必要があります
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参照動画の URL（任意）。最大3本。

      アクション、カメラワーク、リズムの誘導に使用されます。

      動画の要件：

      * MP4、MOV に対応
      * 1本あたり最大100MB
      * 1本あたりの長さは15秒以内
      * URL は一般公開アクセス可能である必要があります
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参照音声の URL（任意）。最大3本。

      音声の要件：

      * MP3、WAV に対応
      * 1ファイルあたり最大20MB
      * 1ファイルあたりの長さは15秒以内
      * URL は一般公開アクセス可能である必要があります
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト側のタスク ID。

  ユーザー定義のタスク識別子（必須）。後からこの ID を使用してタスクのステータスや結果を照会できます。
</ParamField>

## Query Task

MiniMax H3 Turbo は非同期動画生成モデルです。タスクの送信後、`out_task_id` を使用してタスクのステータスを照会してください。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡された送信元のタスク ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "minimax_h3_turbo_task_123456"
  }'
```

照会が成功して完了すると、レスポンスの `output` フィールドに生成結果が含まれます。動画の URL は `output.list[].video` にあります。

## Mode Notes

<Note>
`image_url` を渡さない場合はテキストから動画を生成します。参考画像を渡した場合、画像は被写体、スタイル、構図をガイドするために使用され、最初や最後のフレームではありません。
</Note>

<Note>
`video_url` を渡す場合、参考動画はアクション、カメラワーク、リズムのガイドに使用されます。参考画像や参考音声と同時に使用できます。
</Note>

<Warning>
本モデルは `first_last_frame`（最初と最後のフレーム）モードに対応しておらず、解像度は768Pのみ（480Pおよび2Kには非対応）、アスペクト比は3:2 / 2:3に対応していません。`end_image_url`、`type`、または `quality` を渡さないでください。
</Warning>
