title: 'MiniMax H3 ビデオ生成'
description: |
  - MiniMax H3、Hailuo 03 / Hailuo 3 とも呼ばれます
  - 非同期処理モードで、後続のクエリ用にタスク ID を返します
  - テキストからビデオ生成、最初のフレーム/最後のフレーム画像からビデオ生成、複数の参考素材によるビデオ生成をサポートします
  - 768P / 2K 出力をサポートし、ビデオの長さは 4-15 秒です
api: 'POST https://aireiter.com/api/openapi/submit'

</Note>

## Body

<ParamField body="model" type="string" required>
  モデル名。固定で以下を使用します:

  * `minimax_h3`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメーターオブジェクト。

  <Expandable title="params オブジェクトの属性">
    <ParamField body="prompt" type="string" required>
      動画生成用のテキスト説明。最大 7000 文字。

      主体、シーン、カメラの動き、動作、スタイル、光、リズムなどを説明できます。
    </ParamField>

    <ParamField body="type" type="string" default="text_to_video">
      生成タイプ。どの動画生成モードを使用するかを決定します。

      * `text_to_video` - テキストから動画を生成。プロンプトのみを使用して動画を生成します
      * `first_last_frame` - 先頭フレーム/末尾フレーム画像から動画を生成。先頭フレーム、末尾フレーム、または先頭と末尾フレームの遷移を使って動画を生成します
      * `all_reference` - 複数参照素材から動画を生成。参照画像、参照動画、参照音声を使用できます
    </ParamField>

    <ParamField body="video_length" type="number" default="4">
      生成する動画の長さ。単位は秒です。

      整数 `4` から `15` まで対応しています。
    </ParamField>

    <ParamField body="quality" type="string" default="2k">
      出力品質:

      * `768p`
      * `2k`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      動画のアスペクト比。

      対応するアスペクト比:

      * `21:9` - 超ワイド
      * `16:9` - 横向き、デフォルト値
      * `4:3` - 標準横向き
      * `1:1` - 正方形
      * `3:4` - 縦向き標準
      * `9:16` - 縦向き

      <Warning>`first_last_frame` モードでは、アスペクト比を個別に選択することはできません。出力は入力画像の比率に従います。</Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      画像 URL。

      `type` によって意味が異なります:

      * `text_to_video` - 画像の送信は不要です
      * `first_last_frame` - 先頭フレーム画像として使用します。配列で送ることもでき、1枚目が先頭フレーム、2枚目が末尾フレームになります
      * `all_reference` - 参照画像として使用します。最大 9 枚まで

      画像要件:

      * JPG、JPEG、PNG、WEBP、HEIC、HEIF をサポート
      * 画像 1 枚あたりの最大サイズは 30MB
      * 幅と高さの範囲は 256-5760px
      * 画像のアスペクト比範囲は 0.4-2.5
    </ParamField>

    <ParamField body="end_image_url" type="string">
      末尾フレーム画像 URL。

      `first_last_frame` モードでのみ有効です。末尾フレームは `image_url` 配列の2枚目として送信することもできます。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参照動画 URL。

      `all_reference` モードでのみ有効です。

      現在、参照動画は最大 1 つまで対応しています。

      動画要件:

      * 動画1本の長さは 2-15 秒
      * MP4、MOV をサポート
      * 動画エンコードは H.264 または H.265
      * 音声エンコードは AAC または MP3
      * 動画 1 本あたりの最大サイズは 50MB
      * 幅と高さの範囲は 256-5760px
      * フレームレートは 23.976-60 FPS

      <Warning>URL が公開アクセス可能であり、動画の長さのメタデータを読み取れることを確認してください。</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参照音声 URL。

      `all_reference` モードでのみ有効で、最大 3 つの音声に対応しています。

      音声要件:

      * 音声1本の長さは 2-15 秒
      * WAV、MP3 をサポート
      * 音声 1 本あたりの最大サイズは 15MB
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  送信元タスク ID。

  ユーザーがカスタム定義したタスク識別子で、必須です。後続でこの ID を使用してタスクのステータスと結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">

</ResponseField>

<ResponseField name="status" type="string">
  初期状態。通常は `"pending"` です。
</ResponseField>

</ResponseField>

</ResponseField>

## Query Task

MiniMax H3 は非同期ビデオ生成モデルです。タスクを送信した後、`out_task_id` を使用してタスクのステータスをクエリしてください。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡す、送信元のタスクID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "minimax_h3_task_123456"
  }'
```

クエリが成功して完了すると、レスポンスの `output` フィールドに生成されたビデオURLが含まれます。

## Mode Notes

<Note>
`text_to_video` モードは MiniMax H3 のテキストから動画生成機能を呼び出します。`first_last_frame` モードは画像から動画生成機能を呼び出します。`all_reference` モードは複数の参照素材生成機能を呼び出します。
</Note>

<Warning>
`type` が `first_last_frame` の場合、`aspect_ratio` パラメータには依存しないでください。このモードの出力比率は入力画像によって決まります。
</Warning>
