## Body

<ParamField body="model" type="string" required>
  モデル名。固定値:

  * `minimax_h3`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメーターオブジェクト。

  <Expandable title="params オブジェクトの属性">
    <ParamField body="prompt" type="string" required>
      動画生成のテキスト説明。最大 7000 文字。

      主体、シーン、カメラの動き、アクション、スタイル、光、リズムなどを記述できます。
    </ParamField>

    <ParamField body="type" type="string" default="text_to_video">
      生成タイプ。MiniMax H3 がどの上流モードを使用するかを決定します。

      * `text_to_video` - テキストから動画生成。プロンプトのみを使用して動画を生成します
      * `first_last_frame` - 最初のフレーム/最後のフレーム画像から動画生成。最初のフレーム、最後のフレーム、または両端フレームの遷移を使って動画を生成します
      * `all_reference` - 複数の参考素材による動画生成。参考画像、参考動画、参考音声を使用できます
    </ParamField>

    <ParamField body="video_length" type="number" default="4">
      生成動画の長さ。単位は秒です。

      整数 `4` から `15` をサポートします。

      <Warning>動画の長さは料金に直接影響します。</Warning>
    </ParamField>

    <ParamField body="quality" type="string" default="2k">
      出力品質。現在は固定で:

      * `2k`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      動画のアスペクト比。

      対応するアスペクト比:

      * `21:9` - 超ワイドスクリーン
      * `16:9` - 横向き、デフォルト値
      * `4:3` - 標準横向き
      * `1:1` - 正方形
      * `3:4` - 縦版標準
      * `9:16` - 縦向き

      <Warning>`first_last_frame` モードではアスペクト比を個別に選択できません。出力は入力画像の比率に従います。</Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      画像 URL。

      `type` によって意味が異なります:

      * `text_to_video` - 画像の送信は不要です
      * `first_last_frame` - 最初のフレーム画像として使用します。配列を送信することもでき、1 枚目を最初のフレーム、2 枚目を最後のフレームとして使用します
      * `all_reference` - 参考画像として使用します。最大 9 枚

      画像要件:

      * JPG、JPEG、PNG、WEBP、HEIC、HEIF をサポート
      * 1 枚あたりの最大サイズは 30MB
      * 幅と高さの範囲は 256-5760px
      * 画像のアスペクト比の範囲は 0.4-2.5
    </ParamField>

    <ParamField body="end_image_url" type="string">
      最後のフレーム画像 URL。

      `first_last_frame` モードでのみ有効です。最後のフレームは `image_url` 配列の 2 枚目として渡すこともできます。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参考動画 URL。

      `all_reference` モードでのみ有効です。

      AIReiter は現在、参考動画の長さに基づく課金を正確にするため、1 つの参考動画のみを公開しています。EvoLink の上流では最大 3 つの参考動画をサポートし、合計長は 15 秒を超えません。

      動画要件:

      * 1 本あたりの長さは 2-15 秒
      * MP4、MOV をサポート
      * 動画コーデックは H.264 または H.265
      * 音声コーデックは AAC または MP3
      * 1 本あたりの最大サイズは 50MB
      * 幅と高さの範囲は 256-5760px
      * フレームレートは 23.976-60 FPS

      <Warning>参考動画の長さは課金秒数に加算されます。URL が公開アクセス可能であり、動画の長さメタデータを読み取れることを確認してください。</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参考音声 URL。

      `all_reference` モードでのみ有効で、最大 3 つの音声をサポートします。

      音声要件:

      * 1 つあたりの長さは 2-15 秒
      * WAV、MP3 をサポート
      * 1 つあたりの最大サイズは 15MB

      <Note>参考音声は個別課金されません。</Note>
    </ParamField>
  </Expandable>
</ParamField>

  ユーザー定義のタスク識別子で、必須です。後続でこの ID を使用してタスクの状態と結果を問い合わせることができます。

## Query Task

MiniMax H3 は非同期ビデオ生成モデルです。タスクを送信した後は、`out_task_id` を使用してタスクのステータスを確認してください。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡す発信側のタスクID。
</ParamField>

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "minimax_h3_task_123456"
    }'
  ```
</RequestExample>

クエリが成功して完了した後、レスポンスの `output` フィールドに生成された動画の URL が含まれます。

## Pricing

MiniMax H3 は、生成動画の秒数、参考動画の秒数、追加の参考画像に基づいて課金されます。

| 課金項目 | 価格 |
| --- | --- |
| 2K 生成動画 | 40.15 credits / 秒 |
| 参考動画入力 | 40.15 credits / 秒 |
| 参考画像 | 最初の5枚は無料、5枚を超えると 12.1 credits / 枚 |
| 参考音声 | 無料 |

課金式:

```
(生成動画秒数 + 参考動画秒数) × 40.15 + max(参考画像枚数 - 5, 0) × 12.1
```

例:

* 4秒のテキストから動画生成: `4 × 40.15 = 160.6 credits`
* 4秒の出力 + 9秒の参考動画: `(4 + 9) × 40.15 = 521.95 credits`
* 15秒の出力 + 15秒の参考動画 + 9枚の参考画像: `30 × 40.15 + 4 × 12.1 = 1252.9 credits`

## Mode Notes

<Note>
`text_to_video` モードは MiniMax H3 のテキストから動画生成機能を呼び出します。`first_last_frame` モードは画像から動画生成機能を呼び出します。`all_reference` モードは複数の参照素材生成機能を呼び出します。
</Note>

<Warning>
`type` が `first_last_frame` の場合、`aspect_ratio` パラメータには依存しないでください。このモードの出力比率は入力画像によって決まります。
</Warning>
