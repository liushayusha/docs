title: 'Vidu Q4 動画生成'
description: |
  - 生数科技 Vidu Q4 動画生成モデル
  - 非同期処理モード、後続のクエリに使用するタスク ID を返却
  - ファーストフレーム画像からの動画生成、参照画像（参照音声の追加可能）からの動画生成の2つのモードに対応
  - 540p / 720p / 1080p / 2K / 4K 出力に対応、動画の長さは3〜16秒、デフォルトで同期したセリフと効果音を生成
api: 'POST https://aireiter.com/api/openapi/submit'

<Note>
Vidu Q4 の AIReiter におけるモデル名は `vidu_q4` です。このモデルは少なくとも1枚の画像を入力する必要があり、テキストのみからの動画生成および先頭・末尾フレームには対応していません。
</Note>

## Body

<ParamField body="model" type="string" required>
  モデル名、固定値：

  * `vidu_q4`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string">
      動画内容の説明、最大20000文字。

      * `frame` モードでは任意、画面のアクションやカメラワークの記述に使用
      * `reference` モードでは必須

      参考モードではアップロード順に素材を指定可能。例：「参考画像2の男性」「参考音声1の声を使用」。
    </ParamField>

    <ParamField body="type" type="string" default="frame">
      生成モード：

      * `frame` - 最初のフレーム、デフォルト値。1枚の画像を動画の最初のフレームとして渡し、動画は画像のアスペクト比を継承
      * `reference` - 参照、1〜15枚の参考画像を渡し、0〜3本の参考音声を追加可能

      <Warning>
        最初のフレームモードでは1枚の画像のみ渡すことができ、`audio_url` は指定できません。
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]" required>
      画像URL。パブリックネットワークから直接アクセス可能である必要があります。

      * `frame` - 最初のフレームとして、必ず1枚のみ
      * `reference` - 1〜15枚の参考画像

      画像要件：

      * フォーマット：JPG、JPEG、PNG、WEBP
      * 1枚あたり50MB以下
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参考音声URL。生成動画内の音色やトーンの指定に使用。

      `reference` モードでのみ有効、最大3本。

      音声要件：

      * フォーマット：MP3
      * 1本あたり3〜12秒
      * 1本あたり50MB以下

      <Warning>`frame` モードではこのパラメータを指定しないでください。</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      生成する動画の長さ（秒単位）。

      対応する整数：`3` から `16`。
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      出力解像度：

      * `540p`
      * `720p` - デフォルト値
      * `1080p`
      * `2K`
      * `4K`

      解像度レベルは画面の総ピクセル数に基づいて計算されます。16:9以外の画面（正方形や縦画面など）では、幅と高さがレベル名と異なる場合があります（例：540pの1:1動画は720×720）。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      動画のアスペクト比。`reference` モードでのみ有効。`frame` モードでは最初のフレーム画像のアスペクト比が継承され、指定しても無視されます。

      対応するアスペクト比：

      * `16:9` - 横画面、デフォルト値
      * `9:16` - 縦画面
      * `1:1` - 正方形
      * `4:3` - 標準横画面
      * `3:4` - 標準縦画面
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      同期音声（対話や効果音）を生成するかどうか。

      * `true` - 音声トラック付き動画を生成、デフォルト値
      * `false` - 音声なし動画を出力
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト側のタスクID。

  ユーザー定義のタスク識別子、必須。英数字、アンダースコア、ハイフンのみ対応、長さは1〜64文字。後からこのIDを使用してタスクのステータスや結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  リクエスト元のタスクID。結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期ステータス。通常は `"pending"` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成日時、ISO形式。
</ResponseField>

## Query Task

Vidu Q4は非同期動画生成モデルです。タスクを送信後、`out_task_id`を使用してタスクステータスを照会してください。10〜15秒ごとに照会することをお勧めします。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡された送信元タスクID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "vidu_q4_frame_123456"
  }'
```

照会が成功して完了すると、レスポンス内の `output` 配列に生成された動画が含まれ、要素には `video` フィールドが含まれます。

## Mode Notes

<Note>
`frame` は1枚の画像を最初のフレームとして動画を生成します。プロンプトは任意で、アスペクト比は画像に従います。`reference` は1〜15枚の参照画像と最大3つの参照音声を組み合わせて新しい映像を生成します。プロンプトは必須で、アスペクト比を指定できます。
</Note>

<Warning>
`type` が `frame` の場合、`image_url` は必ず1枚である必要があり、`audio_url` は渡さないでください。`type` が `reference` の場合、`prompt` を空にすることはできず、参照画像は最大15枚、参照音声は最大3つまでとなります。
</Warning>
