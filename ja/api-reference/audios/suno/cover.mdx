title: 'Suno カバー'
description: |
  - 1つの公開音声を新しいスタイルでカバーし、メロディーは原曲に近いままです
  - 非同期処理モードで、後続の照会用にタスク ID を返します
  - 公開音声 URL を使用し、上流の clip ID は送信しません
  - シンプルモードとカスタムモードをサポートします
api: 'POST https://aireiter.com/api/openapi/submit'

<Note>
AIReiter における Suno Cover のモデル名は `suno_cover` です。メロディは原曲に近くなり、プロンプトでは主に曲調、ボーカル、制作面を調整します。
</Note>

<ParamField header="Authorization" type="string" required>

## Body

<ParamField body="model" type="string" required>
  モデル名。以下で固定：

  * `suno_cover`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      カバー後にどのような雰囲気にしたいかを指定します。メロディは原曲を踏襲し、ここではジャンル、ボーカル、プロダクションを変更します。

      カスタムモードが有効でインストゥルメンタルではない場合、プロンプトは歌詞として扱われます。V6シリーズでは最大5000文字です。
    </ParamField>

    <ParamField body="audio_url" type="string | string[]" required>
      カバー対象の音声URL。一般公開アクセス可能である必要があります。配列を渡す場合は最初の要素が使用されます。

      音声要件：

      * 形式：MP3、WAV
      * 長さ：8分以内
      * サイズ：20MB以下
    </ParamField>

    <ParamField body="suno_model" type="string" default="V6">
      Sunoのバージョン：

      * `V6` - デフォルト値。ボーカルがより自然で、ディテールがより豊か
      * `V6_MINI` - 軽量で高速、品質と速度を両立
      * `V6_WILD` - より大胆で特徴的なスタイル
    </ParamField>

    <ParamField body="custom_mode" type="boolean" default="false">
      カスタムモードを有効にするかどうか。

      * `false` - シンプルモード。`prompt` と `audio_url` のみ必要
      * `true` - カスタムモード。`title` と `style` の指定が必要
    </ParamField>

    <ParamField body="instrumental" type="boolean" default="false">
      インストゥルメンタルとしてカバーするかどうか。

      * `false` - ボーカルを保持
      * `true` - 伴奏のみ生成
    </ParamField>

    <ParamField body="vocal_gender" type="string" default="m">
      ボーカルの性別の好み。インストゥルメンタルの場合は無視されます。

      * `m` - 男性ボーカル（デフォルト値）
      * `f` - 女性ボーカル
    </ParamField>

    <ParamField body="title" type="string">
      曲のタイトル。カスタムモードでのみ有効で、最大80文字です。`custom_mode` を有効にした場合は必須です。
    </ParamField>

    <ParamField body="style" type="string">
      新しいジャンルやプロダクションの方向性。カスタムモードでのみ有効で、最大1000文字です。`custom_mode` を有効にした場合は必須です。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト側のタスクID。

  ユーザー定義のタスク識別子（必須）。英数字、アンダースコア、ハイフンのみ対応し、文字数は1〜64文字です。後からこのIDを使用してタスクのステータスや結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  発信側のタスク ID。結果の取得に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。通常は `"pending"` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成日時。ISO 形式。
</ResponseField>

## Query Task

Suno Cover は非同期のカバー歌唱モデルです。タスクを送信した後は、`out_task_id` を使用してタスクの状態を照会してください。完了すると、`output` には通常 2 件のカバー結果が含まれ、各項目には `audio`、`url`、`title`、`text` が含まれます。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡す発行元のタスク ID です。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "suno_cover_123456"
  }'
```

照会が成功して完了した後の `output` の例:


## Mode Notes

<Note>
シンプルモードでは `prompt` と `audio_url` だけが必要です。カスタムモードでは `title` と `style` も同時に送信してください。
</Note>

<Warning>
公開アクセス可能な音声URLを指定してください。ローカルファイルは、まず公開アクセス可能な読み取り用アドレスにアップロードする必要があります。
</Warning>
