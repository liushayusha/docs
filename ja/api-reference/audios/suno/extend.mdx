---
title: 'Suno 続き生成'
description: |
  - 1つの公開音声をより長い曲として続き生成します
  - 非同期処理モードで、後続のクエリに使用するタスク ID を返します
  - 公開音声 URL を使用するため、上流のタスク ID は不要です
  - 元の曲の何秒目から続けるかを指定できます
api: 'POST https://aireiter.com/api/openapi/submit'

import { apiKeyUrl } from '/snippets/_variables.mdx';

<Note>
Suno Extend の AIReiter におけるモデル名は `suno_extend` です。音声トラックをアップロードするか、前回生成結果の音声 URL を再利用すると、そのまま続きを作成できます。
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべての API エンドポイントは Bearer Token による認証が必要です。

  API Key の取得：

  <a href={apiKeyUrl} target="_blank">API Key 管理ページ</a> にアクセスして、API Key を取得してください。

  使用する際はリクエストヘッダーに以下を追加してください：

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名。固定で使用：

  * `suno_extend`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトの Properties">
    <ParamField body="audio_url" type="string | string[]" required>
      続き書きする音声URL。公開アクセス可能である必要があります。配列を渡す場合は先頭の項目を使用します。

      音声要件：

      * 形式 MP3、WAV
      * 長さは8分以内
      * 20MB以下
    </ParamField>

    <ParamField body="prompt" type="string">
      任意。続き部分をどのように展開したいかを説明します。たとえば、サビをより大きく、アウトロをより静かに、新しい楽器を追加するなどです。
    </ParamField>

    <ParamField body="continue_at" type="number" default="60">
      元の曲の何秒目から続けるか。範囲は `0` から `240` で、元の音声の長さより短くなければなりません。デフォルトは `60` で、通常はAメロまたはサビの後に接続します。
    </ParamField>

    <ParamField body="suno_model" type="string" default="V5">
      Suno バージョン：

      * `V4`
      * `V4_5`
      * `V4_5PLUS`
      * `V4_5ALL`
      * `V5` - デフォルト値
      * `V5_5`
    </ParamField>

    <ParamField body="instrumental" type="boolean" default="false">
      続き部分がインストゥルメンタルかどうか。

      * `false` - ボーカルありで継続
      * `true` - 伴奏のみ出力
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  発行元タスクID。

  ユーザー定義のタスク識別子。必須です。英字、数字、アンダースコア、ハイフンのみ使用でき、長さは1-64文字です。後続でこのIDを使用してタスクのステータスと結果を取得できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  発行元のタスク ID。結果の取得に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態で、通常は `"pending"` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻、ISO 形式。
</ResponseField>

## Query Task

Suno Extend は非同期の音楽継続生成モデルです。タスクを送信した後、`out_task_id` を使用してタスクのステータスを確認してください。完了後、`output` には通常 2 件の継続結果が含まれ、各項目には `audio`、`url`、`title`、`text` が含まれます。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡される送信元のタスク ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "suno_extend_123456"
  }'
```

検索が成功し、完了した後の `output` の例:


## Mode Notes

<Note>
`continue_at` は元の曲上の時点であり、継続後の合計長さではありません。その秒数が元の音声の長さ以内に収まるようにしてください。
</Note>

<Warning>
公開アクセス可能な音声 URL を指定してください。ローカルファイルは、まず公開ネットワークから読み取れるアドレスにアップロードする必要があります。
</Warning>
