  - 非同期処理モード、後続のクエリ用にタスクIDを返却

<Note>
AIReiter における Suno のモデル名は `suno` です。歌詞、継続作成、カバーにはそれぞれ `suno_lyrics`、`suno_extend`、`suno_cover` を使用してください。
</Note>

## Body

<ParamField body="model" type="string" required>
  モデル名。固定で使用：

  * `suno`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      楽曲の説明。テーマ、感情、楽器、リズムなどを記述できます。

      カスタムモードが無効の場合、モデルはこれに基づいてタイトル、スタイル、歌詞を自動生成します。カスタムモードが有効でインストゥルメンタルではない場合、プロンプトは歌詞として扱われます。

      V6シリーズは最大5000文字。
    </ParamField>

    <ParamField body="suno_model" type="string" default="V6">
      Sunoバージョン：

      * `V6` - デフォルト値。ボーカルがより自然で、ディテールがより豊か
      * `V6_MINI` - 軽量かつ高速。品質と速度を両立
      * `V6_WILD` - より大胆で特徴的なスタイル
    </ParamField>

    <ParamField body="custom_mode" type="boolean" default="false">
      カスタムモードを有効にするかどうか。

      * `false` - シンプルモード。プロンプトのみ入力し、タイトル、スタイル、歌詞はモデルによって生成
      * `true` - カスタムモード。`title` と `style` の指定が必要。ボーカルがある場合、`prompt` は歌詞として使用
    </ParamField>

    <ParamField body="instrumental" type="boolean" default="false">
      インストゥルメンタルを生成するかどうか。

      * `false` - ボーカル入りの楽曲を生成
      * `true` - 伴奏のみ生成（ボーカルおよび歌詞なし）
    </ParamField>

    <ParamField body="vocal_gender" type="string" default="m">
      ボーカルの性別の好み。カスタムモードでのみ有効で、インストゥルメンタルの場合は無視されます。

      * `m` - 男性ボーカル、デフォルト値
      * `f` - 女性ボーカル
    </ParamField>

    <ParamField body="title" type="string">
      楽曲のタイトル。カスタムモードでのみ有効で、最大80文字。`custom_mode` を有効にした場合は必須です。
    </ParamField>

    <ParamField body="style" type="string">
      音楽スタイルおよび制作の方向性（例：indie folk、lo-fi hip hop、80s synthwave）。カスタムモードでのみ有効で、最大1000文字。`custom_mode` を有効にした場合は必須です。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元のタスクID。

  ユーザー定義のタスク識別子（必須）。英数字、アンダースコア、ハイフンのみ対応し、長さは1〜64文字です。後からこのIDを使用してタスクのステータスや結果を取得できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  発行元のタスク ID。結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態で、通常は `"pending"` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻。ISO 形式。
</ResponseField>

## Query Task

Suno は非同期の音楽生成モデルです。タスクを送信した後は、`out_task_id` を使用してタスクの状態を確認してください。完了後、`output` には通常2曲が含まれ、各項目には `audio`（音声URL）、`url`（カバー画像）、`title`、`text`（歌詞）が含まれます。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡す発信側のタスクID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "suno_gen_123456"
  }'
```

## Mode Notes

<Note>
シンプルモードでは `prompt` だけが必要です。カスタムモードでは `title` と `style` を両方送信してください。ボーカルありの場合は、歌詞を `prompt` に記入してください。
</Note>

<Warning>
`vocal_gender` は `instrumental` が `false` の場合にのみ有効です。1回のリクエストでは通常2曲の候補が返されます。
</Warning>
