---
title: 'Suno 歌詞生成'
description: |
  - テーマに基づいて構造化された歌詞を生成し、音声は生成しません
  - 非同期処理モードで、後続の照会用にタスク ID を返します
  - 通常、タイトル付きの2〜3版の主歌 / 副歌を返します
  - 結果はカスタムモードの Suno 楽曲生成に使用できます
api: 'POST https://aireiter.com/api/openapi/submit'
---
import { apiKeyUrl } from '/snippets/_variables.mdx';

<Note>
Suno Lyrics の AIReiter におけるモデル名は `suno_lyrics` です。このエンドポイントは歌詞のみを生成し、音声は生成しません。
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべての API エンドポイントは Bearer Token を使用した認証が必要です。

  API Key の取得：

  <a href={apiKeyUrl} target="_blank">API Key 管理ページ</a> にアクセスして、API Key を取得してください。

  使用時はリクエストヘッダーに次を追加してください：

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名。固定で使用:

  * `suno_lyrics`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトの属性">
    <ParamField body="prompt" type="string" required>
      歌詞のテーマ、感情、またはストーリー。最大で約 200 語。

      具体的に書くほど、ヴァース / コーラス構成が安定します。返却結果には `[Verse]`、`[Chorus]` などのセクション区切りタグが含まれます。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  送信元タスク ID。

  ユーザー定義のタスク識別子です。必須。英字、数字、アンダースコア、ハイフンのみ使用でき、長さは 1-64 文字です。後続でこの ID を使用してタスクのステータスと結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元のタスクID。結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。通常は `"pending"` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時間。ISO形式。
</ResponseField>

## Query Task

Suno Lyrics は非同期の歌詞生成モデルです。タスクを送信した後は、`out_task_id` を使用してタスクの状態を確認してください。完了後、`output` には通常 2〜3 版の歌詞が含まれ、各項目には `title` と `text` が含まれます。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡す送信元タスク ID です。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "suno_lyrics_123456"
  }'
```

クエリが成功して完了した後の、`output` の例:

```json
{
  "statusCode": 200,
  "message": "",
  "data": {
    "out_task_id": "suno_lyrics_123456",
    "status": "completed",
    "created_at": "2026-08-26T10:12:11.000Z",
    "completed_at": "2026-08-26T10:12:28.000Z",
    "output": [
      {
        "title": "Last Train Home",
        "text": "[Verse]\\nRain on the window of the last train home\\n[Chorus]\\nI'm still on my way..."
      },
      {
        "title": "After the Rain",
        "text": "[Verse]\\nThe station lights blur into gold\\n[Chorus]\\nTake me home tonight..."
      }
    ]
  }
}
```

## Mode Notes

<Note>
このAPIは音声を返しません。`text` を `suno` のカスタムモードの `prompt` に入れれば、引き続き楽曲を生成できます。
</Note>
