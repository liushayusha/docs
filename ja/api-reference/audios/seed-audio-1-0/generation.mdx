<Note>
AIReiter での Seed Audio 1.0 のモデル名は `seed_audio_1_0` です。このモデルは Doubao Seed Audio または Seed Audio API として検索されることもあります。
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべての API は Bearer Token を使用して認証する必要があります。

  API Key の取得：

  <a href={apiKeyUrl} target="_blank">API Key 管理ページ</a> にアクセスして、API Key を取得してください。

  使用時はリクエストヘッダーに以下を追加します：

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名。固定値は次のとおりです：

  * `seed_audio_1_0`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータのオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      合成するテキスト、または音声シーンの説明。最大1500文字です。

      参考音声を使用する場合は、プロンプト内で `@audio1` / `@audio2` / `@audio3` を順番に使って参考音色を指定できます。
    </ParamField>

    <ParamField body="reference_mode" type="string" default="text">
      参考モード。今回のリクエストで使用する参考素材の種類を決定します：

      * `text` - プロンプトのみで生成し、参考音声や参考画像は送信しません
      * `audio` - 参考音声を使って音色をクローンします
      * `image` - 1枚の参考画像で雰囲気と表現をガイドします

      <Warning>参考音声と参考画像は同時に使用できません。参考素材を使う場合は、対応する `reference_mode` を明示的に送信する必要があります。そうしないと、参考フィールドは無視されます。</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参考音声 URL。

      `reference_mode` が `audio` の場合のみ有効で、最大3件まで指定できます。順序は `@audio1` / `@audio2` / `@audio3` に対応します。

      参考音声の要件：

      * 形式は WAV、MP3、PCM、OGG Opus
      * 1件あたり30秒以内
      * 1件あたり10MB以内
      * URL は公開アクセス可能であること
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参考画像 URL。

      `reference_mode` が `image` の場合のみ有効で、最大1枚です。

      画像の要件：

      * 形式は JPEG、PNG、WEBP
      * 10MB以下
      * URL は公開アクセス可能であること
    </ParamField>

    <ParamField body="speech_rate" type="number" default="1">
      話速倍率。範囲は `0.5` から `2` で、小数点以下2桁まで対応しています。`1` は通常の話速です。
    </ParamField>

    <ParamField body="loudness_rate" type="number" default="1">
      音量倍率。範囲は `0.5` から `2` で、小数点以下2桁まで対応しています。`1` は通常の音量です。
    </ParamField>

    <ParamField body="pitch_rate" type="integer" default="0">
      音程。単位は半音です。範囲は `-12` から `12` です。`0` は原調、`12` は1オクターブ上、`-12` は1オクターブ下を意味します。
    </ParamField>

    <ParamField body="sample_rate" type="string" default="24000">
      出力サンプルレート（Hz）：

      * `8000`
      * `16000`
      * `24000` - デフォルト値
      * `32000`
      * `44100`
      * `48000`
    </ParamField>

    <ParamField body="format" type="string" default="wav">
      出力音声フォーマット：

      * `wav` - デフォルト値
      * `mp3`
      * `ogg_opus`
      * `pcm`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  発行側のタスク ID。

  ユーザー定義のタスク識別子で、必須です。使用できるのは英字、数字、アンダースコア、ハイフンのみで、長さは1〜64文字です。後続でこの ID を使ってタスクの状態と結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  発行元のタスク ID。結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態で、通常は `"pending"` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻。ISO 形式です。
</ResponseField>

## Query Task

Seed Audio 1.0 は非同期音声生成モデルです。タスク送信後、`out_task_id` を使用してタスクの状態を照会してください。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡す送信元タスク ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "seed_audio_text_123456"
  }'
```

照会が成功し、完了した後の、`output` の例：

```json
{
  "statusCode": 200,
  "message": "",
  "data": {
    "out_task_id": "seed_audio_text_123456",
    "status": "completed",
    "created_at": "2026-08-26T10:12:11.000Z",
    "completed_at": "2026-08-26T10:12:48.000Z",
    "output": [
      {
        "audio": "https://s1.pxz.ai/upload/audio-generator/20260826/seed-audio-item-0.wav"
      }
    ]
  }
}
```

## Mode Notes

<Note>
`text` モードはプロンプトに基づいてのみ音声、セリフ、または効果音を生成します。`audio` モードは参照音声を使って音色をクローンします。`image` モードは1枚の参照画像で表現をガイドします。
</Note>

<Warning>
`reference_mode` が `audio` の場合は、`image_url` を送信しないでください。`reference_mode` が `image` の場合は、`audio_url` を送信しないでください。1回のリクエストの最大長は120秒です。
</Warning>
