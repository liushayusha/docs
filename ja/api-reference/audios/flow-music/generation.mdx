---
title: 'Flow Music 音楽生成'
description: |
  - Google Lyria のテキストから音楽を生成し、毎回1曲の完成した楽曲を生成します
  - 非同期処理モードで、後続の照会に使用するタスク ID を返します
  - ボーカル付きまたはインストゥルメンタルに対応し、Lyria 3 Pro / 3.5 をサポートします
  - 結果には clip_id が含まれ、続きの生成、カバー、差し替え、トラック分離、ダウンロード、MV 作成に使用できます
api: 'POST https://aireiter.com/api/openapi/submit'
---
import { apiKeyUrl } from '/snippets/_variables.mdx';

<Note>
Flow Music の AIReiter におけるモデル名は `flow_music` です。歌詞、続き生成、置換、カバー、トラック分離、アップロード、ダウンロード、MV 作成には、それぞれ対応するモデルをご使用ください。
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべてのエンドポイントは Bearer Token を使用して認証する必要があります。

  API Key の取得：

  <a href={apiKeyUrl} target="_blank">API Key 管理ページ</a> にアクセスして、API Key を取得してください。

  使用する際は、リクエストヘッダーに次を追加します：

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名。固定で使用：

  * `flow_music`
</ParamField>

<ParamField body="params" type="object" required>
  モデルのパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      スタイルのプロンプト。音楽ジャンル、楽器、感情、ボイスを説明します。`lyrics` を同時に指定できます。
    </ParamField>

    <ParamField body="lyrics" type="string">
      任意の歌詞。未入力の場合は、インストゥルメンタルを生成するか、モデルがボーカルを自動処理します。
    </ParamField>

    <ParamField body="title" type="string">
      任意の曲タイトル。
    </ParamField>

    <ParamField body="bpm" type="string">
      任意の BPM。1以上。文字列で指定します。たとえば `"120"`。
    </ParamField>

    <ParamField body="length" type="number" default="60">
      希望する長さ。単位は秒、範囲は `1` から `240`。あくまで参考値で、上流側がこの秒数どおりに出力するとは限りません。課金は回数単位で、長さではありません。
    </ParamField>

    <ParamField body="version" type="string" default="lyria-3-pro">
      Lyria のバージョン。料金は同じです：

      * `lyria-3-pro` - デフォルト値
      * `lyria-3.5` - 更新されたボイスモデル
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  送信側のタスク ID。

  ユーザー定義のタスク識別子で、必須です。使用できるのは英字、数字、アンダースコア、ハイフンのみで、長さは1〜64文字です。後続では、この ID を使ってタスクのステータスと結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  発起側のタスク ID。結果の検索に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態で、通常は `"pending"` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時間、ISO 形式。
</ResponseField>

## Query Task

Flow Music は非同期の音楽生成モデルです。タスクを送信した後は、`out_task_id` を使用してタスクの状態を確認してください。完了後、`output` には通常 1 件が含まれ、フィールドは `audio`（音声 URL）、`url`（カバー画像）、`title`、`text`（歌詞の一部）、`clip_id` です。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡される、送信元のタスク ID です。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flow_music_gen_123456"
  }'
```

クエリが成功して完了した後の、`output` の例：
