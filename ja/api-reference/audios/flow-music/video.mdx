---
title: 'Flow Music 動画'
description: |
  - 1つの Flow Music 曲を MV テンプレートとしてレンダリングする
  - 非同期処理モード。後続の問い合わせに使用するタスク ID を返します
  - clip_id の入力が必須で、結果は mp4 です
api: 'POST https://aireiter.com/api/openapi/submit'
---
import { apiKeyUrl } from '/snippets/_variables.mdx';

<Note>
Flow Music Video の AIReiter でのモデル名は `flow_music_video` です。結果は `video` フィールドに出力され、`audio` ではありません。
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべてのエンドポイントは Bearer Token による認証が必要です。

  API Key を取得：

  <a href={apiKeyUrl} target="_blank">API Key 管理ページ</a> にアクセスして、API Key を取得してください。

  使用時はリクエストヘッダーに次を追加してください：

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名、固定で使用:

  * `flow_music_video`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトの属性">
    <ParamField body="clip_id" type="string" required>
      成功したタスクの `clip_id`。`output[].clip_id` から取得します。

      generate / extend / replace / cover / upload の成功後に返されます。stems / download / video は同じ `clip_id` を再利用し、新しいものは生成しません。`clip_id` がなく、音声ファイルのみの場合は、先に `flow_music_upload` を呼び出してください。
    </ParamField>

    <ParamField body="preset" type="string" default="simple">
      MV テンプレート:

      * `simple` - デフォルト値
      * `modern`
      * `player`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し元タスク ID。

  ユーザー定義のタスク識別子。必須です。英字、数字、下線、ハイフンのみ対応し、長さは 1-64 文字です。後続でこの ID を使用してタスクの状態と結果を照会できます。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  発行元タスク ID。結果の取得に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態で、通常は `"pending"` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻、ISO 形式。
</ResponseField>

## Query Task

Flow Music Video は非同期の MV レンダリングモデルです。タスク送信後、`out_task_id` を使用してタスクの状態を確認してください。完了後、`output` には `video`（mp4 URL）と元の `clip_id` が含まれ、`audio` はありません。

<ParamField body="out_task_id" type="string" required>
  タスク送信時に渡す発行元タスク ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flow_music_video_123456"
  }'
```

クエリが成功し、完了した後の `output` の例：

```json
{
  "statusCode": 200,
  "message": "",
  "data": {
    "out_task_id": "flow_music_video_123456",
    "status": "completed",
    "created_at": "2026-08-28T07:44:48.000Z",
    "completed_at": "2026-08-28T07:45:40.000Z",
      "output": [
      {
        "video": "https://static.aireiter.com/tmp/audio-generator/20260828/VrYUtqRotQBpoLIbkFB6N-video-0.mp4",
        "clip_id": "cd984d09-5a77-4a06-9553-e47a55f009b0"
      }
    ]
  }
}
```

## Mode Notes

<Note>
MV の出力では新しい `clip_id` は生成されません。`<video>` を使って `video` フィールドを再生し、`audio` として扱わないでください。
</Note>
