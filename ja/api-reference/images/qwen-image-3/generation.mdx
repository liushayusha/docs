## Body

<ParamField body="model" type="string" required>
  モデル名。固定値: `"qwen_image_3"`。
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトの属性">
    <ParamField body="prompt" type="string" required>
      画像生成または編集の指示。中国語と英語に対応しています。

      主体、シーン、構図、光、素材、テキスト内容、そして参考画像で保持または変更する必要がある部分を明確に記述することをおすすめします。
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参考画像の配列です。指定すると画像から画像へのモードを使用し、指定しない場合はテキストから画像へのモードを使用します。

      * 最大 3枚の参考画像
      * 1枚あたりの最大サイズは 10MB
      * jpeg、png、webp をサポート
      * 公開アクセス可能な URL または完全な Base64 Data URI をサポート

      <Warning>
        画像 URL は、ログイン状態、Cookie、またはページの一時的な認可に依存せず、パブリックネットワークから直接アクセスできる必要があります。
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      出力解像度のグレードです。

      * `1K` - ベース解像度（デフォルト）
      * `2K` - 高解像度
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      出力画像のアスペクト比です。

      次の値をサポートしています:

      * `1:1` - 正方形（デフォルト）
      * `3:2` / `2:3` - 標準の横長 / 縦長
      * `4:3` / `3:4` - 標準の横長 / 縦長
      * `16:9` / `9:16` - ワイドスクリーンの横長 / 縦長

      <Warning>
        現在のインターフェースは `21:9` をサポートしておらず、`1024x1024` などのカスタムピクセルサイズもサポートしていません。
      </Warning>
    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      このタスクで生成される画像の数です。値の範囲は `1` から `6` です。
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      出力形式です。現在は `png` に固定されています。

      <Warning>
        現在の AIReiter 接続チャネルでは JPEG 出力オプションは提供されていません。
      </Warning>
    </ParamField>

    <ParamField body="prompt_extend" type="boolean" default="true">
      インテリジェントなプロンプト拡張を有効にするかどうかです。デフォルトでは有効で、短いプロンプトに適しています。
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      ネガティブプロンプトです。ぼやけ、変形、誤った文字など、結果に含めたくない内容を記述します。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し元がカスタマイズするタスク ID で、冪等な送信と結果の問い合わせに使用します。

  * 長さは 1〜64文字
  * 使用するのは英字、数字、アンダースコア、ハイフンのみにすることを推奨します
  * 同じ API Key では重複して使用しないでください
</ParamField>

## 計費

| 計費項目 | 価格 |
| --- | ---: |
| 1K出力ごとに1枚 | 2.40クレジット（$0.024） |
| 2K出力ごとに1枚 | 2.40クレジット（$0.024） |
| 入力参照画像ごとに1枚 | 0.25クレジット（$0.0025） |

計算式: `2.40 × output_n + 0.25 × 参照画像数`。

たとえば、1枚の画像を生成し、1枚の参照画像を渡すと、予想消費は `2.65` クレジットです。送信成功時、レスポンス内の `estimated_credits` は予想消費量です。タスク完了後、クエリレスポンス内の `credits_used` は実際の消費量です。タスクが失敗した場合、最終的な課金は発生しません。

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し側のタスク ID。タスクの状態と結果を照会するために使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態で、通常は `"pending"` です。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  今回のタスクの推定消費ポイント。
</ResponseField>

<ResponseField name="created_at" type="string">
  タスク作成時間、ISO 8601 形式。
</ResponseField>

## Query Results

After submission succeeds, call the query endpoint using the same `out_task_id`:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "qwen_image_3_task_001"
  }'
```

Task statuses include `pending`, `processing`, `completed`, and `failed`. After the task is completed, the image array is located in `data.output`, and the actual credits consumed are located in `data.credits_used`.
