description: |
    - 非同期処理モードで、後続のクエリ用にタスク ID を返します
    - テキストから画像生成と画像から画像生成をサポートし、参考画像を指定しない場合はテキストから画像生成になります
    - 最大 3 枚の参考画像と、1回の生成で 1-6 枚の画像をサポートします
    - 1K / 2K の解像度と 7 種類の一般的な画像比率をサポートします
    - 提出された prompt はプラットフォームの敏感語 / 安全審査を通過し、規約違反の内容は直接拒否されます

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべてのエンドポイントは Bearer Token を使用して認証する必要があります。

  <a href={apiKeyUrl} target="_blank">API Key 管理ページ</a> にアクセスして API Key を取得し、Request Headers に次を追加してください:

  ```text
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名、固定値: `"qwen_image_3"`。
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトの Properties">
    <ParamField body="prompt" type="string" required>
      画像生成または編集の指示。中国語と英語に対応しています。

      主体、シーン、構図、光、素材、テキスト内容、および参考画像で保持または変更が必要な部分を明確に記述することを推奨します。
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参考画像の配列。送信すると画像から画像へのモードを使用します。送信しない場合はテキストから画像へのモードを使用します。

      * 最大 3 枚の参考画像
      * 1 枚あたりの画像サイズは最大 10MB
      * jpeg、png、webp をサポート
      * 公開アクセス可能な URL または完全な Base64 Data URI をサポート

      <Warning>
        画像 URL はインターネットから直接アクセス可能である必要があり、ログイン状態、Cookie、またはページの一時的な認証に依存してはいけません。
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      出力解像度のレベル。

      * `1K` - 基本解像度（デフォルト）
      * `2K` - 高解像度
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      出力画像のアスペクト比。

      以下の値をサポートしています:

      * `1:1` - 正方形（デフォルト）
      * `3:2` / `2:3` - 代表的な横長 / 縦長
      * `4:3` / `3:4` - 標準的な横長 / 縦長
      * `16:9` / `9:16` - ワイドスクリーンの横長 / 縦長

    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      このタスクで生成される画像数。値の範囲は `1` から `6` です。
    </ParamField>

    <ParamField body="prompt_extend" type="boolean" default="false">
      プロンプトのインテリジェントな書き換え。結果の予測可能性を確保するため、デフォルトでは無効です。インテリジェントな書き換えが必要な場合は `true` に設定してください。
    </ParamField>

    <ParamField body="prompt_extend_mode" type="string" default="direct">
      プロンプトの書き換え方式。`prompt_extend` が `true` の場合にのみ有効です。

      * `direct` - バランスの取れた書き換え。テキストから画像への生成と画像から画像への生成の両方をサポート
      * `agent` - 積極的な書き換え。テキストから画像への生成のみサポート
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      ネガティブプロンプト。ぼかし、変形、誤った文字など、結果に含めたくない内容を記述するために使用します。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し元が指定するタスク ID。冪等な送信と結果の取得に使用します。

  * 長さは 1〜64 文字
  * 英字、数字、アンダースコア、ハイフンのみを使用することを推奨します
  * 同じ API Key では重複して使用しないでください
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し側のタスク ID で、タスクの状態と結果をクエリするために使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態で、通常は `"pending"` です。
</ResponseField>

<ResponseField name="created_at" type="string">
  タスク作成時刻、ISO 8601 形式。
</ResponseField>

## クエリ結果

送信成功後、同じ `out_task_id` を使用してクエリAPIを呼び出します:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "qwen_image_3_task_001"
  }'
```

タスクのステータスには `pending`、`processing`、`completed`、`failed` が含まれます。タスク完了後、画像配列は `data.output` にあります。
