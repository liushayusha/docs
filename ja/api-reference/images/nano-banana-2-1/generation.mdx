description: |
    - 非同期処理モード、後続の問い合わせ用にタスクIDを返却
    - テキストからの画像生成、画像からの画像生成、複数参照画像の融合編集に対応、最大10枚の参照画像
    - 画像内の文字レンダリングがより正確に、1K / 2K / 4K 出力に対応

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべてのインターフェースでBearer Tokenによる認証が必要です

  API Keyの取得：

  <a href={apiKeyUrl} target="_blank">API Key管理ページ</a>にアクセスしてAPI Keyを取得してください

  使用時はリクエストヘッダーに以下を追加します：

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名。`"nano_banana_v2_1"` に固定
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      画像生成用のテキスト説明

      * 画像内に表示させたい文字は、引用符で明記することを推奨します（例：看板に "FRESH BREAD" と記載）
      * 参照画像を渡す場合は、何を保持し、何を変更するかを明記してください
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参照画像のURLリスト。Image-to-Image / 複数画像のブレンド・編集用

      * 最大10枚。指定された順序で使用されます
      * 未指定の場合はText-to-Imageになります
      * マスク（mask）による部分再描画には非対応
      * 以下の2つの形式をサポートしています：
        1. 公開アクセス可能なURL
        2. Base64エンコード形式
           * 完全なData URI形式を使用する必要があります：`data:image/{形式};base64,{base64データ}`
           * サポートされている画像形式：jpeg、png、webp
           * 例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：必ず `data:image/jpeg;base64,` プレフィックス部分を含める必要があります。Base64画像のサイズは10MB以下にしてください
    </ParamField>

    <ParamField body="aspect_ratio" type="string">
      画像生成のアスペクト比

      サポートされているアスペクト比：

      * `auto` - 自動（プロンプトまたは参照画像に基づいて適切な比率を選択）
      * `1:1` - 正方形
      * `3:2` - 横長 3:2
      * `2:3` - 縦長 2:3
      * `4:3` - 横長 4:3
      * `3:4` - 縦長 3:4
      * `5:4` - 横長 5:4
      * `4:5` - 縦長 4:5
      * `16:9` - 横長ワイド画面
      * `9:16` - 縦長画面
      * `21:9` - ウルトラワイド
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      画像解像度

      サポートされている解像度：

      * `1K` - 基本解像度（デフォルト）
      * `2K` - 標準解像度
      * `4K` - 高解像度
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元のタスクID

  ユーザー定義のタスク識別子、必須。英数字、`_`、`-` のみサポート、長さ 1〜64 文字
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  リクエスト側のタスクID、結果の照会に使用可能
</ResponseField>

<ResponseField name="status" type="string">
  初期ステータス、固定で `"pending"`
</ResponseField>

<ResponseField name="created_at" type="string">
  作成日時（ISO形式）
</ResponseField>
