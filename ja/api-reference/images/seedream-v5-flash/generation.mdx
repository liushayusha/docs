title: 'Seedream 5.0 Flash 画像生成'
description: |
    - 非同期処理モード、後続の問い合わせに使用するタスクIDを返却
    - Seedream 5.0シリーズの中でより高速かつ低コストなバージョン、高頻度のバッチ画像生成に最適
    - 同一モデルでテキストから画像生成（Text-to-Image）と画像から画像生成（Image-to-Image）に対応：参照画像を渡さない場合はテキストから画像生成、1〜10枚の参照画像を渡す場合は画像から画像生成
    - 1K / 1.5K / 2Kの3段階の解像度、8種類のアスペクト比、JPEGまたはPNGを出力
api: 'POST https://aireiter.com/api/openapi/submit'

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべてのAPIでBearer Tokenによる認証が必要です

  API Keyの取得：

  <a href={apiKeyUrl} target="_blank">API Key管理ページ</a>にアクセスしてAPI Keyを取得します

</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名

  固定値：`"seedream_v5_flash"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      画像生成のテキスト説明。参照画像を指定する場合は、参照画像に対する変更や結合方法を記述します

      * 参照画像上に枠線、矢印、座標などのマークを付けて変更箇所を指定し、プロンプトで説明することができます
      * 多言語テキストレンダリングに対応
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参照画像。Image-to-Image（編集、結合、スタイル変換）に使用

      * 未指定：Text-to-Image
      * 1〜10枚指定：Image-to-Image、複数枚の場合は配列形式で指定
      * サポートされている画像形式：jpeg、png、webp、1枚あたり最大30MB
      * 以下の2つの形式をサポート：
        1. 公開アクセス可能なURL
        2. Base64エンコード形式
           * 完全なData URI形式を使用する必要があります：`data:image/{形式};base64,{base64データ}`
           * 例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：必ず `data:image/jpeg;base64,` プレフィックスを含める必要があります。Base64画像サイズは10MB以下である必要があります
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      出力画像のアスペクト比

      * `1:1` - 正方形（デフォルト）
      * `4:3` - 横向き 4:3
      * `3:4` - 縦向き 3:4
      * `16:9` - 横向きワイド
      * `9:16` - 縦向き
      * `3:2` - 横向き 3:2
      * `2:3` - 縦向き 2:3
      * `21:9` - ウルトラワイド
    </ParamField>

    <ParamField body="resolution" type="string" default="2K">
      出力解像度レベル

      * `1K` - 1K 解像度
      * `1.5K` - 1.5K 解像度
      * `2K` - 2K 解像度（デフォルト）
    </ParamField>

    <ParamField body="output_format" type="string" default="jpeg">
      出力画像形式

      * `jpeg` - JPEG（デフォルト）
      * `png` - PNG
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  タスク完了後のコールバックURL
</ParamField>

<ParamField body="metadata" type="object">
  カスタムメタデータ、そのまま返されます
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元のタスクID

  ユーザー定義のタスク識別子、必須
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  リクエスト元のタスクID、結果のクエリに使用可能
</ResponseField>

<ResponseField name="status" type="string">
  初期ステータス、固定値は `"pending"`
</ResponseField>

<ResponseField name="created_at" type="string">
  作成日時（ISO形式）
</ResponseField>

  ```bash cURL
  curl --request POST \

    --data '{
      "out_task_id": "my_task_123456"
  ```
