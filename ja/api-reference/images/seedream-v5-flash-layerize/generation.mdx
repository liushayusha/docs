---
title: 'Seedream 5.0 Flash Layerize レイヤー分割'
description: |
    - 非同期処理モード。後続の照会用タスクIDを返却
    - 1枚の画像をベース画像 + 最大16枚の個別に編集可能な透明PNGレイヤーに分割
    - 各レイヤーに名前、説明、z_index、bounding_boxを含む
    - 後払いモード：送信時に残高を検証し、タスク完了後に実際の出力枚数に応じて精算（ベース画像と各レイヤーをそれぞれ1枚としてカウント）
api: 'POST https://aireiter.com/api/openapi/submit'

## Body

<ParamField body="model" type="string" required>
  モデル名

  固定値：`"seedream_v5_flash_layerize"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="image_url" type="string | string[]" required>
      分割対象の元画像

      * 必須。送信できる画像は **1枚** のみです
      * サポートされている画像形式：png、jpeg、1枚あたり最大 30MB
      * 総ピクセル数範囲 262,144 – 36,000,000、アスペクト比範囲 1:16 – 16:1
      * 以下の2つの形式をサポート：
        1. 公開アクセス可能な URL
        2. Base64 エンコード形式
           * 完全な Data URI 形式を使用する必要があります：`data:image/{形式};base64,{base64データ}`
           * 例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：`data:image/jpeg;base64,` プレフィックスを必ず含める必要があります。Base64 画像サイズは 10MB を超えないようにしてください
    </ParamField>

    <ParamField body="prompt" type="string">
      分割プロンプト（オプション）

      * 指定した場合、プロンプトに従って指定された要素を分割します（例：`Separate the title text and the parrot into independent layers`）
      * `<bbox>x1 y1 x2 y2</bbox>` を使用して要素の位置を正確に指定できます。座標は 0–1000 の正規化値です（例：`Separate the parrot <bbox>330 274 641 991</bbox> into a layer`）
      * 指定しない場合や 4 文字未満の場合は、モデルが画像内の主要な要素を自動認識します
      * 最大 5000 文字
    </ParamField>

    <ParamField body="resolution" type="string" default="auto">
      出力解像度レベル

      * `auto` - 元画像のサイズに基づいて自動選択（デフォルト）
      * `1K` - 1K 解像度
      * `1.5K` - 1.5K 解像度
      * `2K` - 2K 解像度

      背景画像は元画像のアスペクト比を維持し、各レイヤーは元画像内の対応する要素のアスペクト比を維持します。
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      背景画像の出力形式

      * `png` - PNG（デフォルト）
      * `jpeg` - JPEG

      背景画像の形式のみを制御し、分割されたレイヤーは透過 PNG に固定されます。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">

</ParamField>

### クエリレスポンス - レイヤー出力構造

タスク完了後、`output` はレイヤーオブジェクトの配列となり、各レイヤーには `url` と `metadata` が含まれます：

<ResponseField name="output" type="array">
  レイヤーのリスト。各要素はレイヤーオブジェクトで、最大17個（ベース画像1枚 + レイヤー16個）

  <Expandable title="レイヤーオブジェクトのプロパティ">
    <ResponseField name="url" type="string">
      このレイヤーの画像URL。ベース画像の形式は `output_format` によって決定され、その他のレイヤーは透過PNGになります
    </ResponseField>

    <ResponseField name="metadata" type="object">
      レイヤーのメタデータ

      <Expandable title="metadata プロパティ">
        <ResponseField name="kind" type="string">
          固定値 `"layer"`。これがレイヤー出力であることを示します
        </ResponseField>

        <ResponseField name="z_index" type="number">
          レイヤーの階層インデックス

          * `z_index = 0`：ベース画像（完全な背景）、`bounding_box` は `null`
          * `z_index ≥ 1`：前景レイヤー、奥から手前への順序で配置
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          元の画像内におけるレイヤーの位置領域

          ベース画像（z_index=0）は `null` となり、その他のレイヤーは座標オブジェクトを返します：

          <Expandable title="bounding_box プロパティ">
            <ResponseField name="absolute" type="array">
              絶対ピクセル座標 `[x1, y1, x2, y2]`。出力ベース画像の解像度に基づきます
            </ResponseField>

            <ResponseField name="normalized" type="array">
              正規化座標 `[x1, y1, x2, y2]`、範囲は 0–1000
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          レイヤー名。ベース画像の場合は `null`
        </ResponseField>

        <ResponseField name="description" type="string | null">
          レイヤーの説明。ベース画像の場合は `null`
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>
