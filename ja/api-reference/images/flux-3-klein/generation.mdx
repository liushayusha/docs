## Body

<ParamField body="model" type="string" required>
  モデル名。

  固定値：`"flux_3_klein"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      画像生成または編集の指示。最大4000文字。

      * 中国語と英語に対応。被写体、シーン、構図、ライティング、質感、保持したい参照画像の特徴を明確に記述することを推奨します
      * 画像から画像を生成（Image-to-Image）する場合、プロンプト内で保持する内容と変更する内容を明確に記述してください
      * モデルは生成前にプロンプトを自動拡張するため、意図を明確に記述するだけでよく、修飾語を過剰に重ねる必要はありません
      * 送信前にプラットフォームの不適切ワード／セキュリティ審査が行われ、規約違反に該当する場合は直接エラーが返されます
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参照画像配列。渡された場合は自動的に Image-to-Image モードが使用され、指定しない場合は Text-to-Image モードが使用されます。

      * 最大3枚の参照画像。1枚目は編集対象の画像で、残りは被写体、商品、またはスタイルの参照を提供するために使用されます
      * 画像1枚あたり最大10MB
      * jpeg、png、webp に対応
      * 以下の2つの形式に対応：
        1. パブリックアクセス可能な URL
        2. 完全な Base64 Data URI（例：`data:image/jpeg;base64,/9j/4AAQ...`）

      <Warning>
        URL はインターネットから直接アクセス可能である必要があり、ログイン、Cookie、または一時的なページ認証を要求することはできません。
      </Warning>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      画像のアスペクト比。

      以下の値に対応しています：

      * `1:1` - 正方形（デフォルト）
      * `5:4` / `4:5` - 横長（小） / 縦長（小）
      * `4:3` / `3:4` - 標準横長 / 縦長
      * `16:9` / `9:16` - ワイド横長 / 縦長

      <Warning>
        `aspect_ratio` はモデルの目標アスペクト比の段階を示し、固定のピクセルサイズを保証するものではありません。その比率に近いモデルのネイティブ解像度が返されます。
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      画像の解像度グレード。

      * `1K` - 基本解像度（デフォルト）
      * `2K` - 高解像度
    </ParamField>

    <ParamField body="output_n" type="string" default="1">
      生成枚数。

      以下の値に対応しています：

      * `"1"` - 1枚生成（デフォルト）
      * `"2"` - 2枚生成
      * `"4"` - 4枚生成
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し元が定義するカスタムタスク ID。べき等な送信および結果の照会に使用されます。

  * 長さは1〜64文字
  * 半角英数字、アンダースコア、ハイフンのみ使用可能
  * 同じ API Key 内で重複して使用することはできません
</ParamField>
