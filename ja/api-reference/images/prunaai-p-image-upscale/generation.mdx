## Body

<ParamField body="model" type="string" required>
  モデル名

  固定値：`"prunaai_p_image_upscale"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="image_url" type="string" required>
      拡大する元画像の URL

      * 必須。渡せる画像は **1枚** のみです
      * 以下の2つの形式をサポートしています：
        1. パブリックアクセス可能な URL
        2. Base64 エンコード形式
           * 完全な Data URI 形式を使用する必要があります：`data:image/{フォーマット};base64,{base64データ}`
           * サポートされている画像形式：jpeg、png、webp
           * 例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：必ず `data:image/jpeg;base64,` プレフィックス部分を含める必要があります。Base64 画像のサイズは 10MB を超えないようにしてください
    </ParamField>

    <ParamField body="upscale_mode" type="string" default="target">
      拡大モード

      * `target` - 目標ピクセル数に応じて固定のメガピクセル（MP）サイズに拡大（デフォルト）、`target` パラメータと併用
      * `factor` - 倍率指定で拡大し、各辺に `factor` を乗算、`factor` パラメータと併用
    </ParamField>

    <ParamField body="target" type="integer" default="4">
      目標解像度（単位：MP、メガピクセル）

      * 設定範囲：`1` 〜 `128`
      * `upscale_mode` が `target` の場合のみ有効
    </ParamField>

    <ParamField body="factor" type="number" default="2">
      拡大倍率

      * 設定範囲：`1` 〜 `8`
      * `upscale_mode` が `factor` の場合のみ有効
      * 出力画像は最大 128 MP までで、超過した場合は自動的に上限値に切り詰められます
    </ParamField>

    <ParamField body="enhance_details" type="boolean" default="false">
      ディテール強調

      微細なテクスチャや細部を強調します。コントラストが高くなり、元画像とわずかに差異が生じる可能性があります。
    </ParamField>

    <ParamField body="enhance_realism" type="boolean" default="false">
      リアリズム強調

      画像のリアルさを向上させますが、元画像との差異が大きくなる可能性があります。AI 生成画像への使用を推奨します。
    </ParamField>

    <ParamField body="output_format" type="string" default="jpg">
      出力画像形式

      * `jpg` - JPEG 形式（デフォルト）
      * `png` - PNG 形式
      * `webp` - WebP 形式
    </ParamField>

    <ParamField body="output_quality" type="integer" default="80">
      出力画質

      * 設定範囲：`0` 〜 `100`、100 が最高画質、0 が最低画質
      * `output_format` が `png` の場合、このパラメータは無効です
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  タスク完了後のコールバック先 URL
</ParamField>

<ParamField body="metadata" type="object">

<ParamField body="out_task_id" type="string" required>
