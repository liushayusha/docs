title: 'Midjourney V8.1 背景削除'
description: |
    - 非同期処理モードで、後続の問い合わせ用にタスクIDを返します
    - ワンクリックで画像の背景を削除し、きれいな被写体切り抜きを生成します
    - プロンプトは不要で、画像を1枚アップロードするだけです
api: 'POST https://aireiter.com/api/openapi/submit'

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべてのエンドポイントは Bearer Token による認証が必要です。

  API Key の取得:

  <a href={apiKeyUrl} target="_blank">API Key 管理ページ</a> にアクセスして、API Key を取得してください。

  使用時はリクエストヘッダーに次を追加します:

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名。

  固定値: `"mj_v8_1_remove_bg"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルのパラメーターオブジェクト。

  <Expandable title="params オブジェクトのProperties">
    <ParamField body="image_url" type="string[]" required>
      処理対象の画像配列。1枚の画像を必ず指定してください。

      * 最大1枚の画像
      * 1枚あたり最大10MB
      * jpeg、png、webpをサポート
      * 以下の2つの形式をサポート:
        1. 公開アクセス可能なURL
        2. 完全なBase64 Data URI。例: `data:image/jpeg;base64,/9j/4AAQ...`

      <Warning>
        URL はインターネットから直接アクセス可能である必要があります。ログイン、Cookie、または一時的なページ権限は要求できません。
      </Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し元がカスタマイズするタスクID。冪等な送信と結果の取得に使用します。

  * 長さは1〜64文字
  * 英字、数字、アンダースコア、ハイフンのみ使用可能
  * 同一のAPI Key内で重複使用不可
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元のタスクID。結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。固定で `"pending"` です。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  推定消費ポイント。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻。ISO 8601 形式。
</ResponseField>

## クエリ結果

送信成功後、同じ `out_task_id` を使って呼び出します:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "mj_v8_1_removebg_task_001"
  }'
```

タスクの状態には `pending`、`processing`、`completed`、`failed` が含まれます。タスク完了後、結果画像は `data.output` にあり、実際の消費ポイントは `data.credits_used` にあります。
