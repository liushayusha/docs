---
title: 'Midjourney V8.1 画像生成'
description: |
    - 非同期処理モードで、後続の照会に使用するタスクIDを返します
    - ネイティブの Midjourney 構文（--ar、--s、--chaos、--seed、--sref など）に対応
    - Draft、Fast の2段階の速度と、Standard、HD の2段階の画質を提供します
    - テキストから画像生成と画像から画像生成に対応し、image_url を渡すと自動的に画像から画像生成に切り替わります
    - 1回のリクエストで4枚の画像を生成し、実際には1〜4枚返されます
api: 'POST https://aireiter.com/api/openapi/submit'
---

## Authorizations

## Body

<ParamField body="model" type="string" required>
  モデル名。

  固定値: `"mj_v8_1"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメーターオブジェクト。

  <Expandable title="params オブジェクトの Properties">
    <ParamField body="prompt" type="string" required>
      画像生成指示。ネイティブの Midjourney 構文をサポートしており、プロンプト内で以下のパラメーターを直接使用できます:

      * `--ar` - アスペクト比（例: `--ar 16:9`）
      * `--s` - スタイライズ度 0-1000
      * `--chaos` - 変化度 0-100
      * `--seed` - 再現用の乱数シード
      * `--sref` - スタイル参照画像 URL
      * `--oref` - 画像参照 URL
      * `--iw` - 画像の重み
      * `--no` - ネガティブプロンプト
    </ParamField>

    <ParamField body="speed" type="string" default="fast">
      スピードのレベル。

      次の値をサポートしています:

      * `draft` - 低コストで高速な反復
      * `fast` - 標準生成（デフォルト）

      <Warning>
        Draft スピードは Standard 画質のみをサポートし、HD 画質はサポートしません。
      </Warning>
    </ParamField>

    <ParamField body="quality" type="string" default="standard">
      画質レベル。

      次の値をサポートしています:

      * `standard` - 標準画質（デフォルト）
      * `hd` - 高画質、Fast スピードのみ対応

      <Warning>
        HD 画質は Fast スピードでのみ利用可能で、Draft スピードは HD をサポートしません。
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参照画像配列。指定すると自動的に画像生成モードが使用され、指定しない場合はテキストから画像生成モードが使用されます。

      * 参照画像は最大 1 枚まで
      * 1 枚あたりの画像サイズは最大 10MB
      * jpeg、png、webp をサポート
      * 次の 2 つの形式をサポート:
        1. 公開アクセス可能な URL
        2. 完全な Base64 Data URI。例: `data:image/jpeg;base64,/9j/4AAQ...`

      <Warning>
        URL はインターネットから直接アクセス可能である必要があり、ログイン、Cookie、または一時的なページ認証を必要としてはいけません。
      </Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し元がカスタマイズするタスク ID。冪等な送信と結果の取得に使用します。

  * 長さは 1-64 文字
  * 英字、数字、アンダースコア、ハイフンのみ使用可能
  * 同じ API Key では重複使用できません
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元のタスクID。結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。固定で `"pending"` です。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  推定消費クレジット。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻、ISO 8601形式。
</ResponseField>

## クエリ結果

送信が成功した後、同じ `out_task_id` を使って呼び出します:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "mj_v8_1_task_001"
  }'
```

タスクのステータスには `pending`、`processing`、`completed`、`failed` が含まれます。タスク完了後、結果画像は `data.output` に、実際の消費ポイントは `data.credits_used` にあります。
