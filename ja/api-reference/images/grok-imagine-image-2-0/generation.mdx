## Authorizations

<ParamField header="Authorization" type="string" required>
  すべてのエンドポイントでは Bearer Token 認証が必要です。

  <a href={apiKeyUrl} target="_blank">API Key 管理ページ</a> にアクセスして API Key を取得し、Request Header に追加してください:

  ```text
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  モデル名、固定値：`"grok_imagine_image_2_0"`。
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメーターオブジェクト。

  <Expandable title="params オブジェクトの Properties">
    <ParamField body="prompt" type="string" required>
      画像生成または編集の指示。中国語と英語をサポートしています。

      複数の参考画像を使用する場合は、プロンプト内で `<IMAGE_0>`、`<IMAGE_1>`、`<IMAGE_2>` を使って対応する画像を参照できます。
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参考画像の配列。省略した場合はテキストから画像を生成します。渡すと自動的に画像から画像への生成または画像編集モードが使用されます。

      * 最大 3枚
      * 1枚あたり最大 10MB
      * JPG、PNG、WebP をサポート
      * 公開 URL、完全な Base64 Data URI、または純粋な Base64 をサポート

      <Warning>
        URL を使用する場合、画像はインターネットから直接アクセスできる必要があり、ログイン状態、Cookie、または一時的なページ認可に依存できません。
      </Warning>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      出力画像のアスペクト比。サポート：

      * `auto`（デフォルト）
      * `1:1`
      * `4:3` / `3:4`
      * `3:2` / `2:3`
      * `16:9` / `9:16`
      * `2:1` / `1:2`
      * `19.5:9` / `9:19.5`
      * `20:9` / `9:20`

      カスタム `WIDTHxHEIGHT` ピクセルサイズはサポートされていません。
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      出力解像度のレベル：`1K`（デフォルト）または `2K`。`4K` はサポートされていません。
    </ParamField>

    <ParamField body="quality" type="string" default="medium">
      生成品質のレベル：

      * `low` - より高速で、費用が低い
      * `medium` - より高いディテール（デフォルト）
    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      出力画像の枚数。値の範囲は `1` から `10` です。各画像は個別に課金されます。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し元が指定するタスク ID。冪等な送信と結果の照会に使用します。

  * 長さは 1-64文字
  * 英字、数字、アンダースコア、ハイフンのみサポート
  * 同じ API Key では重複使用できません
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元のタスクID。タスクのステータスと結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期ステータス。通常は `"pending"` です。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  今回のタスクの推定消費ポイント。
</ResponseField>

<ResponseField name="created_at" type="string">
  タスク作成時刻、ISO 8601形式。
</ResponseField>

## 検索結果

送信成功後、[タスク状態の取得](/en/api-reference/tasks/status) を呼び出し、同じ `out_task_id` を使用して検索します。タスクが完了すると、画像結果は `data.output` にあります。

<RequestExample>
  ```bash cURL（画像生成）
  curl --request POST \
    --url https://aireiter.com/api/openapi/submit \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "model": "grok_imagine_image_2_0",
      "params": {
        "prompt": "雨の夜の東京の街角、ネオンが濡れた路面に映り込む、シネマティックな写真",
        "aspect_ratio": "16:9",
        "resolution": "2K",
        "quality": "medium",
        "output_n": 1
      },
      "out_task_id": "grok_image_2_text_001"
    }'
  ```

  ```bash cURL（画像編集）
  curl --request POST \
    --url https://aireiter.com/api/openapi/submit \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "model": "grok_imagine_image_2_0",
      "params": {
        "prompt": "<IMAGE_0> の人物を <IMAGE_1> のシーンに入れ、光を一致させる",
        "image_url": [
          "https://example.com/person.png",
          "https://example.com/scene.png"
        ],
        "aspect_ratio": "16:9",
        "resolution": "1K",
        "quality": "medium",
        "output_n": 1
      },
      "out_task_id": "grok_image_2_edit_001"
    }'
  ```

  ```javascript JavaScript
  const response = await fetch("https://aireiter.com/api/openapi/submit", {
    method: "POST",
    headers: {
      Authorization: "Bearer <token>",
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      model: "grok_imagine_image_2_0",
      params: {
        prompt: "ミニマルな白いフォトスタジオにある青い陶器のカップ、柔らかな商品用ライティング",
        aspect_ratio: "1:1",
        resolution: "1K",
        quality: "low",
        output_n: 1
      },
      out_task_id: "grok_image_2_js_001"
    })
  });

  console.log(await response.json());
  ```
</RequestExample>
