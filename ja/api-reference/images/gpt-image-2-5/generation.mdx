## Body

<ParamField body="model" type="string" required>
  モデル名（以下のいずれかを選択）：

  * `"gpt_image_2_5_flare"` — Flare、日常的なテキストからの画像生成（Text-to-Image）/ 画像編集をより高速に処理
  * `"gpt_image_2_5_sunburst"` — Sunburst、編集の忠実度（人物、レイアウト、製品の外観）をより重視

  単体の `gpt-image-2.5` ID は存在しません。2つのモデルを比較する際は、プロンプト、参照画像、アスペクト比、解像度を同一に保ってください。
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      画像生成のテキスト説明

      * 中国語および英語に対応。詳細な記述を推奨します
      * 画像編集時は、変更する部分と維持しなければならない部分を明確に記述してください
      * 送信前にプラットフォームのNGワード / 安全性審査が行われ、違反コンテンツに該当する場合は直接エラーが返されます
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参照画像の配列。指定すると画像からの画像生成（Image-to-Image）/ 編集モードになります

      * 最大10枚の参照画像
      * 指定しない場合はテキストからの画像生成（Text-to-Image）になります
      * 以下の2つの形式に対応しています：
        1. 公開アクセス可能な URL
        2. Base64 エンコード形式
           * 完全な Data URI 形式を使用する必要があります：`data:image/{格式};base64,{base64数据}`
           * 対応画像形式：jpeg、png、webp
           * 例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：プレフィックス部分 `data:image/jpeg;base64,` を必ず含める必要があります
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      画像生成のアスペクト比。デフォルトは `auto`

      以下の値に対応しています：

      * `auto` - 最適なアスペクト比を自動選択
      * `1:1` - 正方形
      * `16:9` / `9:16` - ワイドスクリーン横 / 縦
      * `4:3` / `3:4` - スタンダード横 / 縦
      * `3:2` / `2:3` - クラシック横 / 縦
      * `5:4` / `4:5` - セミスクエア横 / 縦
      * `21:9` - ウルトラワイド横

      <Warning>
        アスペクト比の文字列または `auto` のみに対応しています。ピクセルサイズ（`1024x1024` など）を指定すると直接エラーになります。正確なピクセル数が必要な場合は `size` を使用してください。
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      解像度レベル。デフォルトは `1K`

      * `1K` - 約 1024 基準
      * `2K` - 約 2048 基準
      * `4K` - 約 3840 基準

      <Warning>
        `size` を指定する場合は、`resolution` / `aspect_ratio` を同時に指定しないでください。同時に指定すると 400 が返されます。
      </Warning>
    </ParamField>

    <ParamField body="size" type="string">
      カスタムピクセルサイズ（API のみ、`aspect_ratio` / `resolution` とは**排他的**）

      形式は `幅x高さ` です（例：`2048x1536`、`3840x2160`）。

      **使用制限：**

      * 形式は `^\d+x\d+$` である必要があります
      * 幅・高さはともに 16 の倍数である必要があります
      * 各辺は最大 3840 まで
      * 長辺 / 短辺の比率は 3:1 以下
      * 総ピクセル数（幅 × 高さ）は **655,360 ~ 8,294,400** の範囲内
      * `aspect_ratio`、`resolution` とは排他的であり、同時に指定すると 400 が返されます
    </ParamField>

    <ParamField body="background" type="string" default="auto">
      出力画像の背景。デフォルトは `auto`

      * `auto` - 透過するかどうかをモデルが決定
      * `opaque` - 不透明な背景
      * `transparent` - 透明な背景（アルファチャンネル付きの PNG を返します）

      <Warning>
        `transparent` を選択すると、プラットフォームは自動的に PNG で出力するため、`output_format` を指定する必要はありません。本ページでは `output_format` は公開されていません。
      </Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元のタスク ID

  ユーザー定義のタスク識別子（必須）。結果を照会する際は、同じ値を使用して `POST /api/openapi/query` を呼び出してください。
</ParamField>

## サイズ × 解像度マッピング表

`aspect_ratio × resolution` → 実際のピクセル数（`auto` はモデルが自動選択するため、表には含まれません）：

| aspect\_ratio | `1K`      | `2K`      | `4K`      |
| ------------- | --------- | --------- | --------- |
| `1:1`         | 1024×1024 | 2048×2048 | 2880×2880 |
| `3:2`         | 1248×832  | 2496×1664 | 3504×2336 |
| `2:3`         | 832×1248  | 1664×2496 | 2336×3504 |
| `4:3`         | 1152×864  | 2304×1728 | 3264×2448 |
| `3:4`         | 864×1152  | 1728×2304 | 2448×3264 |
| `5:4`         | 1120×896  | 2240×1792 | 3200×2560 |
| `4:5`         | 896×1120  | 1792×2240 | 2560×3200 |
| `16:9`        | 1280×720  | 2560×1440 | 3840×2160 |
| `9:16`        | 720×1280  | 1440×2560 | 2160×3840 |
| `21:9`        | 1456×624  | 3024×1296 | 3696×1584 |

> `2:1`、`1:2`、`9:21` はサポートされておらず、指定すると 400 が返されます。表にない比率が必要な場合は `size` を使用してください。
