---
title: 'Seedream 5.0 Pro Layerize レイヤー分解'
description: |
    - 非同期処理モードで、後続の照会に使用するタスクIDを返します
    - 1枚の画像を、個別に編集可能な複数の透明PNGレイヤーに分解します
    - 各レイヤーには、名前、説明、z_index、bounding_boxが含まれます
    - 後払い課金モード: 提出時に残高を確認し、タスク完了後に実際の出力に基づいて精算します
api: 'POST https://aireiter.com/api/openapi/submit'

## Body

<ParamField body="model" type="string" required>
  モデル名

  固定値: `"seedream_v5_pro_layerize"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト

  <Expandable title="params オブジェクト属性">
    <ParamField body="image_url" type="string" required>
      分解対象の元画像 URL

      * 必須で、**1枚**のみ送信できます
      * 次の2つの形式をサポートします:
        1. 公開アクセス可能な URL
        2. Base64 エンコード形式
           * 完全な Data URI 形式を使用する必要があります: `data:image/{格式};base64,{base64数据}`
           * サポートされる画像形式: jpeg、png、webp
           * 例: `data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意: `data:image/jpeg;base64,` プレフィックス部分を含める必要があります。base64 画像サイズは 10MB を超えてはいけません
      * 画像の最小サイズは ≥ 300px である必要があります
    </ParamField>

    <ParamField body="prompt" type="string">
      テキストプロンプト（オプション）

      レイヤー名と説明の生成言語を指定するために使用できます。たとえば `Return name and description in english.` を入力すると、レイヤー名と説明が英語で返されます。

      指定しない場合はデフォルトの言語が使用されます。
    </ParamField>

    <ParamField body="image_size" type="string" default="auto">
      出力解像度の段階

      * `auto` - 自動選択（デフォルト）
      * `auto_1K` - 1K 解像度
      * `auto_1.5K` - 1.5K 解像度
      * `auto_2K` - 2K 解像度
    </ParamField>

    <ParamField body="enhance_prompt_mode" type="string" default="standard">
      プロンプト強化モード（API のみ利用可能）

      * `standard` - 標準モード（デフォルト）
      * `fast` - 高速モード
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  タスク完了後のコールバック URL

### クエリレスポンス - レイヤー出力構造

タスク完了後、`output` はレイヤーオブジェクトの配列で、各レイヤーには `url` と `metadata` が含まれます:

<ResponseField name="output" type="array">
  レイヤー一覧。各要素は1つのレイヤーオブジェクトです

  <Expandable title="レイヤーオブジェクトの属性">
    <ResponseField name="url" type="string">
      このレイヤーの透過 PNG 画像 URL
    </ResponseField>

    <ResponseField name="metadata" type="object">
      レイヤーメタデータ

      <Expandable title="metadata の属性">
        <ResponseField name="kind" type="string">
          固定値 `"layer"`。これはレイヤー出力であることを示します
        </ResponseField>

        <ResponseField name="z_index" type="number">
          レイヤーの階層インデックス

          * `z_index = 0`: 最下層（再構成された完全な背景画像）、`bounding_box` は `null`
          * `z_index ≥ 1`: 前景レイヤー。奥から手前の順に並びます
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          元画像内におけるレイヤーの位置領域

          最下層（z_index=0）は `null` で、それ以外のレイヤーは座標オブジェクトを返します:

          <Expandable title="bounding_box の属性">
            <ResponseField name="absolute" type="array">
              絶対ピクセル座標 `[x1, y1, x2, y2]`。元画像の解像度に基づきます
            </ResponseField>

            <ResponseField name="normalized" type="array">
              正規化座標 `[x1, y1, x2, y2]`。範囲は 0–1000 です
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          レイヤー名（例: `"Sky background"`、`"Moss platform"`）
        </ResponseField>

        <ResponseField name="description" type="string | null">
          レイヤーの説明（例: `"Soft light blue sky with scattered fluffy white clouds"`）
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="credits_used" type="number">
  実際に消費されたクレジット
</ResponseField>
