---
title: 'Z-Image Turbo 画像生成'
description: |
    - 非同期処理モードで、後続の検索に使用するタスクIDを返します
    - Alibaba Tongyi の高速 text-to-image モデルで、約8ステップのサンプリングで画像を生成し、写実的な質感を重視しています
    - 中国語と英語の文字レンダリングが鮮明で、タイトル付きのポスター、バナー、ソーシャルメディア素材に適しています
    - 9種類の画像比率に対応し、1回の実行で固定して1枚を返します
    - text-to-image のみ対応しており、参照画像、画像編集、カスタムピクセルサイズには対応していません
    - 提出された prompt はプラットフォームの機微な単語 / 安全審査を通過し、規約違反の内容は直接拒否されます
api: 'POST https://aireiter.com/api/openapi/submit'

## Body

<ParamField body="model" type="string" required>
  モデル名。

  固定値：`"z_image_turbo"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトの Properties">
    <ParamField body="prompt" type="string" required>
      画像生成プロンプト。最大 2000 文字。

      * 中国語と英語の両方をサポートします。主体、シーン、構図、光、素材を明確に記述することを推奨します
      * モデルはやや写実寄りのスタイルです。実際の光と影、素材を描写したプロンプトのほうがより良い結果になります
      * 画面内に文字を表示したい場合は、文字内容を引用符で囲んでください。中国語・英語のどちらでも構いません
      * 送信前にプラットフォームのセンシティブワード / 安全審査が行われ、違反コンテンツに該当した場合はそのままエラーが返されます
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      画像のアスペクト比。

      以下の値をサポートします：

      * `1:1` - 正方形（デフォルト）
      * `16:9` / `9:16` - ワイド横向き / 縦向き
      * `4:3` / `3:4` - 標準横向き / 縦向き
      * `3:2` / `2:3` - クラシック横向き / 縦向き
      * `2:1` / `1:2` - パノラマ横向き / ロング縦向き

      <Warning>
        `aspect_ratio` はモデルの目標アスペクト比の枠を表し、固定のピクセルサイズは保証されません。返されるのはその比率に近いモデルのネイティブサイズです。たとえば、実測では 16:9 の場合 1536×864 が返されます。
      </Warning>
    </ParamField>

    <ParamField body="seed" type="integer">
      ランダムシード。結果の再現に使用します。範囲は 1-2147483647 です。

      * 同じ `prompt` + `seed` の組み合わせでは、構図が近い画像が生成されます
      * 指定しない場合は毎回ランダムな結果が生成されます
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し側が指定するカスタムタスク ID で、冪等な送信と結果の取得に使用します。

  * 長さは 1-64 文字です
  * 英字、数字、アンダースコア、ハイフンのみ使用できます
  * 同じ API Key では重複して使用できません
</ParamField>

<Note>
  Z-Image Turbo はテキストから画像生成のみをサポートします。参照画像（`image_url`）、画像編集、解像度のプリセット（`resolution`）、一括画像生成（`output_n`）はいずれもサポートされません。カスタムピクセルサイズ `size` を渡すと、`Model "z_image_turbo" does not support size parameter` が直接返されます。各リクエストで返される画像は 1 枚に固定されています。複数枚必要な場合は、異なる `seed` で複数回送信してください。

  参照画像、画像から画像生成、またはより大きなキャンバスが必要な場合は、GPT-Image 2、Seedream 5.0 Pro、または Nano Banana Pro をご利用ください。
</Note>
