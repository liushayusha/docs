---
title: 'Midjourney V8.2 画像生成'
description: |
    - 非同期処理モード、後続の問い合わせ用タスクIDを返却
    - 1回のリクエストで4枚の独立した画像を生成、リクエスト単位で課金（枚数単位ではありません）
    - テキストからの画像生成、参照画像（最大4枚）、スタイル参照、画像編集に対応
    - アスペクト比、画質、速度はパラメータで選択可能、プロンプト内にMidjourneyパラメータを手動入力する必要はありません
api: 'POST https://aireiter.com/api/openapi/submit'
---

## Body

<ParamField body="model" type="string" required>
  モデル名。`"mj_v8_2"` に固定
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      画像のテキスト説明。希望する画面を自然言語で記述します

      * バージョン、アスペクト比、画質、生成速度などの Midjourney パラメータは下位フィールドによって自動的に追加されるため、手動で入力する必要はありません
      * プロンプト内に手動で入力された `--` パラメータ（`--ar`、`--v`、`--fast` など）は無視され、最初の `--` 以降の内容はすべて無効になります
      * 画像編集（`use_edit`）を使用する場合は、修正指示を直接記述できます。例："Render this logo as a hand drawn pencil sketch"
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参照画像（Image Prompt）の URL リスト。完成品の内容、構図、配色に影響します

      * 最大4枚。指定された順序で使用されます
      * 指定しない場合はテキストからの画像生成となります
      * 以下の2つの形式に対応しています：
        1. 一般公開されているアクセス可能な URL（ログイン、Cookie、一時的な認証を必要としないもの）
        2. Base64 エンコード形式
           * 完全な Data URI 形式を使用する必要があります：`data:image/{フォーマット};base64,{base64データ}`
           * サポートされている画像フォーマット：jpeg、png、webp
           * 例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：`data:image/jpeg;base64,` プレフィックス部分を含める必要があります。Base64 画像サイズは 10MB を超えないようにしてください
    </ParamField>

    <ParamField body="image_weight" type="number" default="1">
      参照画像のウェイト（`--iw` に対応）。完成品が参照画像にどの程度近づくかを指定します

      * 設定可能な範囲は 0-3、デフォルト値は 1。値が大きいほど参照画像に近くなります
      * `image_url` を渡した場合にのみ有効です
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      画像のアスペクト比（`--ar` に対応）

      サポートされているアスペクト比：

      * `1:1` - 正方形（デフォルト）
      * `16:9` - 横長ワイドスクリーン
      * `9:16` - 縦長画面
      * `4:3` - 横長 4:3
      * `3:4` - 縦長 3:4
      * `3:2` - 横長 3:2
      * `2:3` - 縦長 2:3
    </ParamField>

    <ParamField body="quality" type="string" default="sd">
      画質設定

      サポートされている値：

      * `sd` - 標準画質（デフォルト）、1:1 の場合は1枚あたり 1024×1024
      * `hd` - ネイティブ高解像度、1:1 の場合は1枚あたり 2048×2048

      その他のアスペクト比は比例換算され、実際のサイズは返却された画像に準じます。
    </ParamField>

    <ParamField body="speed" type="string" default="fast">
      生成速度（`--fast` / `--relax` に対応）

      サポートされている値：

      * `fast` - 高速モード（デフォルト）
      * `relax` - 低速モード（キューの待機時間が長くなります）

      低速モードは専用チャンネルで処理され、実測では高速モードより2倍以上遅くなります。
    </ParamField>

    <ParamField body="use_style_ref" type="boolean" default="false">
      スタイル参照（`--sref` に対応）を有効にするかどうか

      別の画像の画風、配色、質感を適用しますが、人物や物体をそのまま流用することはありません。`true` に設定する場合、`style_image_url` の指定が必須となります。
    </ParamField>

    <ParamField body="style_image_url" type="string">
      スタイル参照画像、1枚

      * `use_style_ref` が `true` の場合にのみ有効であり、その際は必須です
      * フォーマット要件は `image_url` と同様です
    </ParamField>

    <ParamField body="style_weight" type="number" default="100">
      スタイルの強度（`--sw` に対応）

      * 設定可能な範囲は 0-1000、デフォルト値は 100
      * `use_style_ref` が `true` の場合にのみ有効です
    </ParamField>

    <ParamField body="use_edit" type="boolean" default="false">
      画像編集（`--edit` に対応）を有効にするかどうか

      `prompt` を修正指示として既存の画像を編集します。`true` に設定する場合、`edit_image_url` の指定が必須となります。`image_url` やスタイル参照と併用可能です。
    </ParamField>

    <ParamField body="edit_image_url" type="string">
      編集対象の画像、1枚

      * `use_edit` が `true` の場合にのみ有効であり、その際は必須です
      * フォーマット要件は `image_url` と同様です
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元のタスクID

  ユーザー定義のタスク識別子、必須。英数字、`_`、`-` のみサポート、長さ 1-64
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  リクエスト元のタスクID。結果の照会に使用可能
</ResponseField>

<ResponseField name="status" type="string">
  初期ステータス、固定値は `"pending"`
</ResponseField>

<ResponseField name="created_at" type="string">
  作成日時（ISO形式）
</ResponseField>

タスク完了後、照会エンドポイント経由で結果を取得します。`data.output` には4枚の画像が含まれ、元の4分割グリッドの左上、右上、左下、右下の順に並んでいます。生成には通常数分かかりますので、待機中に重複して送信しないでください。
