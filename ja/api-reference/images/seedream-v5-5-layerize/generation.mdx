---
title: 'Seedream 5.5 Layerize レイヤー分割'
description: |
    - 非同期処理モード。後続のクエリに使用するタスクIDを返します
    - 1枚の画像をベース画像と個別に編集可能な複数の透過 PNG レイヤー（ベース画像を含めて最大 100 枚）に分割します
    - 各レイヤーには名前、説明、z_index、および bounding_box が含まれます
    - オプションのテキスト認識により、テキストレイヤーの内容とスタイルを返します
api: 'POST https://aireiter.com/api/openapi/submit'

## Body

<ParamField body="model" type="string" required>
  モデル名

  固定値：`"seedream_v5_5_layerize"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="image_url" type="string" required>
      分割する元画像のURL

      * 必須。指定できる画像は**1枚**のみです
      * サポートされている画像形式：jpeg、png
      * 以下の2つの形式をサポートしています：
        1. 公開アクセス可能なURL
        2. Base64エンコード形式
           * 完全なData URI形式を使用する必要があります：`data:image/{形式};base64,{base64データ}`
           * 例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：`data:image/jpeg;base64,` プレフィックス部分を含める必要があり、base64画像のサイズは10MB以下である必要があります
    </ParamField>

    <ParamField body="prompt" type="string">
      テキストプロンプト（任意）

      分割する要素を指定するために使用します（例：`把标题文字和鹦鹉拆成单独的图层`）。指定しない場合、画像内の要素を自動的に認識します。
    </ParamField>

    <ParamField body="resolution" type="string" default="auto">
      出力解像度レベル

      * `auto` - 元画像のサイズで出力（デフォルト）：1K未満の元画像は1Kに拡大され、2Kを超える元画像は2Kに縮小されます
      * `1K` - 1K解像度
      * `1.5K` - 1.5K解像度
      * `2K` - 2K解像度

      レベルを指定した場合、ベース画像と各レイヤーは選択したレベルで出力され、それぞれ元のアスペクト比を維持します。アスペクト比の指定やカスタムピクセルサイズには対応していません。
    </ParamField>

    <ParamField body="max_images" type="integer" default="30">
      返却される画像枚数の上限（ベース画像を含む）

      * 有効範囲：2–100
      * 実際に返却される枚数は画像の内容によって決まり、この値を超えることはありません
      * 30枚を超えると処理時間が長くなり、100枚の場合は約5分かかります
    </ParamField>

    <ParamField body="text_recognition" type="boolean" default="false">
      文字認識

      有効にすると、画像内の鮮明で判別可能なテキストレイヤーに対して、テキスト内容とスタイルを認識します
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      ベース画像の出力形式

      * `png` - PNG（デフォルト）
      * `jpeg` - JPEG

      ベース画像（z_index = 0）にのみ適用され、その他のレイヤーは透過背景のPNGに固定されます
    </ParamField>
  </Expandable>
</ParamField>

## タスク結果のクエリ

タスクの送信後、`POST /api/openapi/query` エンドポイントを使用してタスクのステータスをポーリングします。レイヤー分割には通常数十秒から数分かかります。`out_task_id` を保存して最終ステータスになるまで継続的にクエリを実行し、重複して送信しないでください。タスクが完了すると、`output` フィールドにベース画像とレイヤーのリストが返されます。

  curl --request POST \

    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "my_task_123456"

### クエリレスポンス - レイヤー出力構造

タスクが完了すると、`output` は画像オブジェクトの配列になります。最初の項目はベース画像で、残りはレイヤーです。各項目には `url` と `metadata` が含まれます：

<ResponseField name="output" type="array">
  ベース画像とレイヤーのリスト

  <Expandable title="画像オブジェクトのプロパティ">
    <ResponseField name="url" type="string">
      画像 URL（ベース画像は不透明な画像、レイヤーは透過 PNG）
    </ResponseField>

    <ResponseField name="metadata" type="object">
      レイヤーメタデータ

      <Expandable title="metadata プロパティ">
        <ResponseField name="kind" type="string">
          固定値 `"layer"`、これがレイヤー出力であることを識別します
        </ResponseField>

        <ResponseField name="z_index" type="number">
          レイヤー階層インデックス

          * `z_index = 0`：ベースレイヤー（再構築された完全な背景画像）、`bounding_box`、`name`、`description` は `null`
          * `z_index ≥ 1`：前景レイヤー、数値が大きいほど上に配置されます
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          元画像内でのレイヤーの位置領域

          ベースレイヤー（z_index=0）は `null`、その他のレイヤーは座標オブジェクトを返します：

          <Expandable title="bounding_box プロパティ">
            <ResponseField name="absolute" type="array">
              ベース画像の解像度に基づく絶対ピクセル座標 `[x1, y1, x2, y2]`
            </ResponseField>

            <ResponseField name="normalized" type="array">
              正規化座標 `[x1, y1, x2, y2]`、範囲は 0–1000
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          レイヤー名
        </ResponseField>

        <ResponseField name="description" type="string | null">
          レイヤーの説明
        </ResponseField>

        <ResponseField name="background" type="string">
          背景タイプ：ベース画像は `"opaque"`、レイヤーは `"transparent"`
        </ResponseField>

        <ResponseField name="output_format" type="string">
          画像フォーマット（例：`"png"`）
        </ResponseField>

        <ResponseField name="size" type="string">
          該当画像のピクセルサイズ、フォーマットは `幅x高さ`
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="credits_used" type="number">
  実際に消費されたクレジット
</ResponseField>
