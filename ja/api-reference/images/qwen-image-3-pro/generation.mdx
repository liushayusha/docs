## Body

<ParamField body="model" type="string" required>
  モデル名、固定値: `"qwen_image_3_pro"`。
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメーターオブジェクト。

  <Expandable title="params オブジェクトのProperties">
    <ParamField body="prompt" type="string" required>
      画像生成または編集の指示。中国語と英語をサポートします。

      Pro モデルは、読める文字、複雑な階層、密なレイアウト、高いディテール表現が必要なタスクに適しています。文字の内容、フォントスタイル、階層、位置、余白、保持したい参照画像の特徴を明確に記述することを推奨します。
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参照画像の配列。入力すると画像生成・編集モードを使用します。入力しない場合はテキストから画像生成モードを使用します。

      * 最大 3 枚の参照画像
      * 1 枚あたり最大 10MB
      * jpeg、png、webp をサポート
      * 公開アクセス可能な URL または完全な Base64 Data URI をサポート

      <Warning>
        画像 URL は公開ネットワークから直接アクセスできる必要があり、ログイン状態、Cookie、またはページの一時的な認可に依存してはいけません。
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      出力解像度のレベル。

      * `1K` - 基本解像度（デフォルト）
      * `2K` - 高解像度。文字、ポスター、密なレイアウトに適しています
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      出力画像のアスペクト比。

      次の値をサポートします:

      * `1:1` - 正方形（デフォルト）
      * `3:2` / `2:3` - 典型的な横長 / 縦長
      * `4:3` / `3:4` - 標準的な横長 / 縦長
      * `16:9` / `9:16` - ワイドスクリーンの横長 / 縦長

      <Warning>
        現在のインターフェースは `21:9` をサポートしておらず、`1024x1024` などのカスタムピクセルサイズもサポートしていません。
      </Warning>
    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      このタスクで生成する画像数。値の範囲は `1` から `6` です。
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      出力形式。現在は `png` に固定されています。

      <Warning>
        現在の AIReiter 接続チャネルでは JPEG 出力オプションは提供されていません。
      </Warning>
    </ParamField>

    <ParamField body="prompt_extend" type="boolean" default="true">
      インテリジェントなプロンプト拡張を有効にするかどうか。デフォルトで有効で、短いプロンプトに適しています。
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      ネガティブプロンプト。結果に表示してほしくない内容を記述するために使用します。たとえば、ぼやけ、文字化け、詰まったレイアウト、構造の変形などです。
    </ParamField>
  </Expandable>
</ParamField>

  * 長さは 1〜64 文字
  * 英字、数字、アンダースコア、ハイフンのみを使用することを推奨します
  * 同じ API Key では重複して使用しないでください

## 計費

| 計費項目 | 価格 |
| --- | ---: |
| 1K 出力ごと | 3.20 クレジット（$0.032） |
| 2K 出力ごと | 6.00 クレジット（$0.060） |
| 入力参考画像ごと | 0.25 クレジット（$0.0025） |

計費式：

* 1K：`3.20 × output_n + 0.25 × 参考画像数`
* 2K：`6.00 × output_n + 0.25 × 参考画像数`

たとえば、1枚の1K画像を生成し、1枚の参考画像を渡す場合、予想消費は `3.45` クレジットです。1枚の2K画像を生成し、1枚の参考画像を渡す場合、予想消費は `6.25` クレジットです。送信成功時、Response の `estimated_credits` は予想消費量です。タスク完了後、Query Response の `credits_used` は実際の消費量です。タスクが失敗した場合、最終的な課金は発生しません。

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元のタスクID。タスクのステータスと結果の照会に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期ステータス。通常は `"pending"` です。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  今回のタスクで予想される消費ポイント。
</ResponseField>

<ResponseField name="created_at" type="string">
  タスク作成時刻。ISO 8601 形式。
</ResponseField>

## クエリ結果

送信成功後、同じ `out_task_id` を使用してクエリインターフェースを呼び出します:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "qwen_image_3_pro_task_001"
  }'
```

タスクのステータスには `pending`、`processing`、`completed`、`failed` が含まれます。タスク完了後、画像配列は `data.output` にあり、実際の消費ポイントは `data.credits_used` にあります。
