    - 非同期処理モード。後続の照会用にタスクIDを返却
    - OpenAI GPT Image 1.5、テキストから画像生成 / 画像から画像生成（参照画像編集、複数画像合成）に対応
    - image_url を渡した場合は自動的に画像から画像生成を行い、渡さない場合はテキストから画像生成を行います

    - 送信された prompt はプラットフォームのセンシティブワード／セキュリティ審査を受け、規約違反コンテンツは直接拒否されます

## Body

<ParamField body="model" type="string" required>
  モデル名

  固定値：`"gpt_image_1_5"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト

  <Expandable title="params オブジェクトのプロパティ">
    <ParamField body="prompt" type="string" required>
      画像生成のテキスト説明

      * 中国語および英語に対応、詳細な説明を推奨
      * Image-to-Image（画像から画像）生成時は、「何を変更するか」と「何を維持するか」（人物の顔、ポーズ、背景など）を明確に記述してください
      * 画像内に表示させたい文字は引用符で囲んでください
      * 送信前にプラットフォームのセンシティブワード/セキュリティ審査が行われ、規約違反コンテンツが検出された場合は直接エラーが返されます
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参照画像の配列。指定した場合は Image-to-Image モードになり、指定しない場合は Text-to-Image モードになります

      * 最大 16 枚の参照画像
      * 1枚あたり 10MB 以下、jpeg、png、webp に対応
      * 以下の2つの形式に対応：
        1. 公開アクセス可能な URL
        2. Base64 エンコード形式
           * 完全な Data URI 形式を使用する必要があります：`data:image/{形式};base64,{base64データ}`
           * 例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：`data:image/jpeg;base64,` プレフィックス部分を含める必要があります
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      画像生成のアスペクト比

      以下の値に対応しています：

      * `1:1` - 正方形（デフォルト）
      * `3:2` - 横向き
      * `2:3` - 縦向き

      <Warning>
        上記 3 つの値のみ対応しています。その他の比率（`16:9`、`auto` など）やピクセル解像度（`1024x1024` など）を指定すると直接エラーになります
      </Warning>
    </ParamField>

    <ParamField body="quality" type="string" default="medium">
      画像品質レベル

      * `medium` - バランス型、生成がより高速（デフォルト）
      * `high` - より低速、ディテールがより豊かで、最終稿に最適

      まずは `medium` でプロンプトや構図を調整し、確定後に `high` で最終画像を生成することをお勧めします。レベルによって料金が異なり、送信レスポンス内の `estimated_credits` に準じます。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  リクエスト元タスクID

  ユーザー定義のタスク識別子、必須
</ParamField>

## 使用方法

* **Text-to-Image / Image-to-Imageの自動切り替え**：`image_url` を渡さない場合はText-to-Imageとなり、1〜16枚の参照画像を渡すとImage-to-Imageとなります。部分修正、着せ替え、背景変更、スタイル変換、複数画像の合成に利用できます。
* **両モード共通のパラメータ**：Text-to-ImageとImage-to-Imageは同じパラメータを使用し、`quality` のグレードに応じて課金されます。
* **出力サイズ**：`aspect_ratio` と `quality` によって決まり、実際のピクセル数は返却された画像に準じます。1K / 2K / 4K やその他の比率が必要な場合は、[GPT-Image-2](/ja/api-reference/images/gpt-image-2/generation) をご利用ください。
* **失敗時の課金なし**：タスクが失敗した場合、クレジットは消費されません。
