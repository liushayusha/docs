---
title: 'Midjourney V7 整图再描画'
description: |
    - 非同期処理モードで、後続の問い合わせに使用するタスクIDを返します
    - 元画像の構図を維持したまま、新しいテクスチャやスタイルで画像を再生成します
    - Fast と Turbo の2つの速度から選択できます
    - 1回のリクエストで4枚の画像を生成し、実際には1〜4枚が返されます
api: 'POST https://aireiter.com/api/openapi/submit'
---

## Authorizations

## Body

<ParamField body="model" type="string" required>
  モデル名。

  固定値: `"mj_v7_retexture"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメータオブジェクト。

  <Expandable title="params オブジェクトの属性">
    <ParamField body="image_url" type="string[]" required>
      元画像配列。再描画のベースとして1枚の画像を渡す必要があります。

      * 最大1枚の画像
      * 1枚あたり最大10MB
      * jpeg、png、webpをサポート
      * 次の2つの形式をサポート:
        1. 公開アクセス可能な URL
        2. 完全な Base64 Data URI, 例えば `data:image/jpeg;base64,/9j/4AAQ...`

      <Warning>
        URL はインターネットから直接アクセスできる必要があり、ログイン、Cookie、または一時的なページ認可を要求してはいけません。
      </Warning>
    </ParamField>

    <ParamField body="prompt" type="string" required>
      リテクスチャ指示。目標のスタイルまたはテクスチャ変換を説明します。ネイティブの Midjourney 構文（--ar、--s、--no など）をサポートします。
    </ParamField>

    <ParamField body="speed" type="string" default="fast">
      速度レベル。

      次の値をサポートします:

      * `fast` - 標準生成（デフォルト）
      * `turbo` - 最速速度

      速度レベルは生成時間に影響します。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し元がカスタマイズしたタスク ID。冪等な送信と結果の取得に使用します。

  * 長さは1〜64文字
  * 英字、数字、アンダースコア、ハイフンのみ許可
  * 同じ API Key では再利用できません
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元のタスクID。結果の検索に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。固定で `"pending"` です。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  予想消費クレジット。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時刻、ISO 8601形式。
</ResponseField>

## Query Results

After the submission succeeds, call the endpoint using the same `out_task_id`:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "mj_v7_retexture_task_001"
  }'
```

The task status includes `pending`, `processing`, `completed`, and `failed`. After the task is completed, the result image is located in `data.output`, and the actual credits used are located in `data.credits_used`.
