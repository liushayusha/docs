---
title: 'Midjourney V7 画像生成'
description: |
    - 非同期処理モードで、後続のクエリ用にタスクIDを返します
    - ネイティブな Midjourney 構文（--ar、--s、--chaos、--seed、--sref など）をサポートします
    - Draft、Fast、Turbo の3つの速度オプションを提供します
    - 画像生成と画像変換をサポートし、image_url を渡すと自動的に画像変換に切り替わります
    - 1回のリクエストで4枚の画像を生成し、実際には1〜4枚が返されます
api: 'POST https://aireiter.com/api/openapi/submit'
---

## Authorizations

<ParamField header="Authorization" type="string" required>
  すべてのAPIはBearer Tokenによる認証が必要です。

  API Keyを取得するには:

  <a href={apiKeyUrl} target="_blank">API Key管理ページ</a>にアクセスして、API Keyを取得してください。

  使用時はリクエストヘッダーに次を追加します:


## Body

<ParamField body="model" type="string" required>
  モデル名。

  固定値: `"mj_v7"`
</ParamField>

<ParamField body="params" type="object" required>
  モデルパラメーターオブジェクト。

  <Expandable title="params オブジェクトの Properties">
    <ParamField body="prompt" type="string" required>
      画像生成プロンプト。ネイティブの Midjourney 構文をサポートしており、プロンプト内で以下のパラメーターを直接使用できます:

      * `--ar` - アスペクト比 (例: `--ar 16:9`)
      * `--s` - スタイライズ度 0-1000
      * `--chaos` - 変化度 0-100
      * `--seed` - 再現用のランダムシード
      * `--sref` - スタイル参考画像 URL
      * `--oref` - 画像参考 URL
      * `--iw` - 画像の重み
      * `--no` - ネガティブプロンプト
    </ParamField>

    <ParamField body="speed" type="string" default="fast">
      速度のレベル。

      次の値をサポートしています:

      * `draft` - 低コストの高速反復
      * `fast` - 標準生成 (デフォルト)
      * `turbo` - 最速

      速度のレベルは生成時間に影響します。
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参照画像配列。渡すと自動的に画像から画像生成モードが使用されます。渡さない場合はテキストから画像生成モードが使用されます。

      * 参照画像は最大 1 枚まで
      * 画像 1 枚あたりの最大サイズは 10MB
      * jpeg、png、webp をサポート
      * 次の 2 つの形式をサポート:
        1. 公開アクセス可能な URL
        2. 完全な Base64 Data URI。例: `data:image/jpeg;base64,/9j/4AAQ...`

      <Warning>
        URL はパブリックネットワークから直接アクセスできる必要があり、ログイン、Cookie、または一時的なページ認証を要求してはいけません。
      </Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  呼び出し元がカスタマイズしたタスク ID。冪等な送信と結果の問い合わせに使用します。

  * 長さは 1-64 文字
  * 使用できるのは英字、数字、アンダースコア、ハイフンのみ
  * 同じ API Key では重複使用できません
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  呼び出し元のタスクID。結果の取得に使用できます。
</ResponseField>

<ResponseField name="status" type="string">
  初期状態。固定で `"pending"` です。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  予想消費クレジット。
</ResponseField>

<ResponseField name="created_at" type="string">
  作成時間、ISO 8601形式。
</ResponseField>

## クエリ結果

送信成功後、同じ `out_task_id` を使って以下を呼び出します:

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "mj_v7_task_001"
  }'
```

タスクのステータスには `pending`、`processing`、`completed`、`failed` が含まれます。タスク完了後、結果画像は `data.output` に、実際の消費クレジットは `data.credits_used` にあります。
