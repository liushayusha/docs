---
title: 'Seedream 5.0 Flash Layerize 图层拆分'
description: |
    - 异步处理模式，返回任务ID用于后续查询
    - 将一张图片拆分为底图 + 最多 16 个可独立编辑的透明 PNG 图层
    - 每个图层包含名称、描述、z_index 和 bounding_box
    - 后扣费模式：提交时校验余额，任务完成后按实际输出张数结算（底图和每个图层各计 1 张）
api: 'POST https://aireiter.com/api/openapi/submit'
---

## Body

<ParamField body="model" type="string" required>
  模型名称

  固定值：`"seedream_v5_flash_layerize"`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象

  <Expandable title="params 对象属性">
    <ParamField body="image_url" type="string | string[]" required>
      待拆分的原图

      * 必填，且只能传 **1 张** 图片
      * 支持的图片格式：png、jpeg，单张不超过 30MB
      * 总像素范围 262,144 – 36,000,000，宽高比范围 1:16 – 16:1
      * 支持以下两种格式：
        1. 公开可访问的 URL
        2. Base64 编码格式
           * 必须使用完整的 Data URI 格式：`data:image/{格式};base64,{base64数据}`
           * 示例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：必须包含 `data:image/jpeg;base64,` 前缀部分，base64 图片大小不超过 10MB
    </ParamField>

    <ParamField body="prompt" type="string">
      拆分提示词（可选）

      * 传入时，按提示词拆分指定元素，例如 `Separate the title text and the parrot into independent layers`
      * 可用 `<bbox>x1 y1 x2 y2</bbox>` 精确指定元素位置，坐标为 0–1000 归一化值，例如 `Separate the parrot <bbox>330 274 641 991</bbox> into a layer`
      * 不传或少于 4 个字符时，由模型自动识别图中主要元素
      * 最长 5000 个字符
    </ParamField>

    <ParamField body="resolution" type="string" default="auto">
      输出分辨率档位

      * `auto` - 根据原图尺寸自动选择（默认）
      * `1K` - 1K 分辨率
      * `1.5K` - 1.5K 分辨率
      * `2K` - 2K 分辨率

      底图保持原图的宽高比，各图层保持对应元素在原图中的宽高比。
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      底图的输出格式

      * `png` - PNG（默认）
      * `jpeg` - JPEG

      仅控制底图格式，拆分出的图层固定为透明 PNG。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  任务完成后的回调地址
</ParamField>

<ParamField body="metadata" type="object">
  自定义元数据，原样返回
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务ID

  用户自定义的任务标识，必填
</ParamField>

## 查询任务结果

任务提交后，使用 `POST /api/openapi/query` 接口轮询任务状态，直到 `status` 为 `completed` 或 `failed`。任务完成后，`output` 字段返回图层列表。

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "my_task_123456"
    }'
  ```
</RequestExample>

### 查询响应 - 图层输出结构

任务完成后，`output` 是一个图层对象数组，每个图层包含 `url` 和 `metadata`：

<ResponseField name="output" type="array">
  图层列表，每个元素是一个图层对象，最多 17 个（1 张底图 + 16 个图层）

  <Expandable title="图层对象属性">
    <ResponseField name="url" type="string">
      该图层的图片 URL。底图格式由 `output_format` 决定，其余图层为透明 PNG
    </ResponseField>

    <ResponseField name="metadata" type="object">
      图层元数据

      <Expandable title="metadata 属性">
        <ResponseField name="kind" type="string">
          固定值 `"layer"`，标识这是一个图层输出
        </ResponseField>

        <ResponseField name="z_index" type="number">
          图层层级索引

          * `z_index = 0`：底图（完整背景），`bounding_box` 为 `null`
          * `z_index ≥ 1`：前景图层，按从后到前的顺序排列
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          图层在原图中的位置区域

          底图（z_index=0）为 `null`，其余图层返回坐标对象：

          <Expandable title="bounding_box 属性">
            <ResponseField name="absolute" type="array">
              绝对像素坐标 `[x1, y1, x2, y2]`，基于输出底图分辨率
            </ResponseField>

            <ResponseField name="normalized" type="array">
              归一化坐标 `[x1, y1, x2, y2]`，范围 0–1000
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          图层名称，底图为 `null`
        </ResponseField>

        <ResponseField name="description" type="string | null">
          图层描述，底图为 `null`
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>
