## Authorizations

<ParamField header="Authorization" type="string" required>
  所有接口均需要使用 Bearer Token 进行认证。

  访问 <a href={apiKeyUrl} target="_blank">API Key 管理页面</a> 获取 API Key，并在请求头中添加：

  ```text
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定值：`"qwen_image_3_pro"`。
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      图片生成或编辑指令。支持中文和英文。

      Pro 模型适合需要可读文字、复杂层级、密集布局和高细节表现的任务。建议明确描述文字内容、字体风格、层级、位置、留白和需要保留的参考图特征。
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参考图数组。传入后使用图生图模式；不传时使用文生图模式。

      * 最多 3 张参考图
      * 单张图片最大 10MB
      * 支持 jpeg、png、webp
      * 支持公开可访问的 URL 或完整 Base64 Data URI

      <Warning>
        图片 URL 必须能被公网直接访问，不能依赖登录状态、Cookie 或页面临时授权。
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="1K">
      输出分辨率档位。

      * `1K` - 基础分辨率（默认）
      * `2K` - 高清分辨率，适合文字、海报和密集布局
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      输出图片宽高比。

      支持以下取值：

      * `1:1` - 正方形（默认）
      * `3:2` / `2:3` - 经典横版 / 竖版
      * `4:3` / `3:4` - 标准横版 / 竖版
      * `16:9` / `9:16` - 宽屏横版 / 竖版

    </ParamField>

    <ParamField body="output_n" type="integer" default="1">
      本次任务生成的图片数量，取值范围为 `1` 到 `6`。
    </ParamField>

    <ParamField body="prompt_extend" type="boolean" default="false">
      提示词智能改写。默认关闭，以保证结果可预测。需要智能改写时设为 `true`。
    </ParamField>

    <ParamField body="prompt_extend_mode" type="string" default="direct">
      提示词改写方式。仅当 `prompt_extend` 为 `true` 时生效。

      * `direct` - 均衡改写，支持文生图和图生图
      * `agent` - 激进改写，仅支持文生图
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      负向提示词，用于描述不希望出现在结果中的内容，例如模糊、文字乱码、布局拥挤或结构变形。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  调用方自定义任务 ID，用于幂等提交和查询结果。

  * 长度为 1-64 个字符
  * 建议仅使用字母、数字、下划线和连字符
  * 同一个 API Key 下不要重复使用
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  调用方任务 ID，可用于查询任务状态和结果。
</ResponseField>

<ResponseField name="status" type="string">
  初始状态，通常为 `"pending"`。
</ResponseField>

<ResponseField name="created_at" type="string">
  任务创建时间，ISO 8601 格式。
</ResponseField>

## 查询结果

提交成功后，使用相同的 `out_task_id` 调用查询接口：

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "qwen_image_3_pro_task_001"
  }'
```

任务状态包括 `pending`、`processing`、`completed` 和 `failed`。任务完成后，图片数组位于 `data.output`。
