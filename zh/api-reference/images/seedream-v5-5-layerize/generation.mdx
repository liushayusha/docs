---
title: 'Seedream 5.5 Layerize 图层拆分'
description: |
    - 异步处理模式，返回任务ID用于后续查询
    - 将一张图片拆分为底图和多个可独立编辑的透明 PNG 图层（含底图最多 100 张）
    - 每个图层包含名称、描述、z_index 和 bounding_box
    - 可选文字识别，返回文字图层的内容与样式
api: 'POST https://aireiter.com/api/openapi/submit'
---

## Body

<ParamField body="model" type="string" required>
  模型名称

  固定值：`"seedream_v5_5_layerize"`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象

  <Expandable title="params 对象属性">
    <ParamField body="image_url" type="string" required>
      待拆分的原图 URL

      * 必填，且只能传 **1 张** 图片
      * 支持的图片格式：jpeg、png
      * 支持以下两种格式：
        1. 公开可访问的 URL
        2. Base64 编码格式
           * 必须使用完整的 Data URI 格式：`data:image/{格式};base64,{base64数据}`
           * 示例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：必须包含 `data:image/jpeg;base64,` 前缀部分，base64 图片大小不超过 10MB
    </ParamField>

    <ParamField body="prompt" type="string">
      文本提示词（可选）

      用于指定要拆分的元素，例如 `把标题文字和鹦鹉拆成单独的图层`。不传则自动识别画面中的元素。
    </ParamField>

    <ParamField body="resolution" type="string" default="auto">
      输出分辨率档位

      * `auto` - 按原图尺寸输出（默认）：低于 1K 的原图提升到 1K，高于 2K 的原图缩小到 2K
      * `1K` - 1K 分辨率
      * `1.5K` - 1.5K 分辨率
      * `2K` - 2K 分辨率

      指定档位时，底图和每个图层都按所选档位输出，各自保持原比例。不支持宽高比或自定义像素尺寸。
    </ParamField>

    <ParamField body="max_images" type="integer" default="30">
      返回图片张数上限（含底图）

      * 取值范围：2–100
      * 实际返回张数由画面内容决定，不会超过该值
      * 超过 30 张耗时更长，100 张约需 5 分钟
    </ParamField>

    <ParamField body="text_recognition" type="boolean" default="false">
      文字识别

      开启后，对画面中清晰可辨的文字图层识别其文字内容与样式
    </ParamField>

    <ParamField body="output_format" type="string" default="png">
      底图输出格式

      * `png` - PNG（默认）
      * `jpeg` - JPEG

      仅作用于底图（z_index = 0），其余图层固定为透明背景 PNG
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  任务完成后的回调地址
</ParamField>

<ParamField body="metadata" type="object">
  自定义元数据，原样返回
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务ID

  用户自定义的任务标识，必填
</ParamField>

## 查询任务结果

任务提交后，使用 `POST /api/openapi/query` 接口轮询任务状态。图层拆分通常需要几十秒到数分钟，请保存 `out_task_id` 持续查询直到终态，不要重复提交。任务完成后，`output` 字段返回底图和图层列表。

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "my_task_123456"
    }'
  ```
</RequestExample>

### 查询响应 - 图层输出结构

任务完成后，`output` 是一个图片对象数组，第一项为底图，其余为图层，每项包含 `url` 和 `metadata`：

<ResponseField name="output" type="array">
  底图与图层列表

  <Expandable title="图片对象属性">
    <ResponseField name="url" type="string">
      图片 URL（底图为不透明图片，图层为透明 PNG）
    </ResponseField>

    <ResponseField name="metadata" type="object">
      图层元数据

      <Expandable title="metadata 属性">
        <ResponseField name="kind" type="string">
          固定值 `"layer"`，标识这是一个图层输出
        </ResponseField>

        <ResponseField name="z_index" type="number">
          图层层级索引

          * `z_index = 0`：底层（重建的完整背景图），`bounding_box`、`name`、`description` 为 `null`
          * `z_index ≥ 1`：前景图层，数值越大越靠上
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          图层在原图中的位置区域

          底层（z_index=0）为 `null`，其余图层返回坐标对象：

          <Expandable title="bounding_box 属性">
            <ResponseField name="absolute" type="array">
              绝对像素坐标 `[x1, y1, x2, y2]`，基于底图分辨率
            </ResponseField>

            <ResponseField name="normalized" type="array">
              归一化坐标 `[x1, y1, x2, y2]`，范围 0–1000
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          图层名称
        </ResponseField>

        <ResponseField name="description" type="string | null">
          图层描述
        </ResponseField>

        <ResponseField name="background" type="string">
          背景类型：底图为 `"opaque"`，图层为 `"transparent"`
        </ResponseField>

        <ResponseField name="output_format" type="string">
          图片格式，如 `"png"`
        </ResponseField>

        <ResponseField name="size" type="string">
          该图片的像素尺寸，格式 `宽x高`
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="credits_used" type="number">
  实际消耗积分
</ResponseField>
