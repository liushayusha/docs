---
title: 'Seedream 5.0 Pro Layerize 图层分解'
description: |
    - 异步处理模式，返回任务ID用于后续查询
    - 将一张图片分解为多个可独立编辑的透明 PNG 图层
    - 每个图层包含名称、描述、z_index 和 bounding_box
    - 后扣费模式：提交时校验余额，任务完成后按实际产出结算
api: 'POST https://aireiter.com/api/openapi/submit'
---

## Body

<ParamField body="model" type="string" required>
  模型名称

  固定值：`"seedream_v5_pro_layerize"`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象

  <Expandable title="params 对象属性">
    <ParamField body="image_url" type="string" required>
      待分解的原图 URL

      * 必填，且只能传 **1 张** 图片
      * 支持以下两种格式：
        1. 公开可访问的 URL
        2. Base64 编码格式
           * 必须使用完整的 Data URI 格式：`data:image/{格式};base64,{base64数据}`
           * 支持的图片格式：jpeg、png、webp
           * 示例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：必须包含 `data:image/jpeg;base64,` 前缀部分，base64 图片大小不超过 10MB
      * 图片最小尺寸需 ≥ 300px
    </ParamField>

    <ParamField body="prompt" type="string">
      文本提示词（可选）

      可用于指导图层命名与描述的生成语言。例如传入 `Return name and description in english.` 可使图层名称和描述以英文返回。

      不传则使用默认语言。
    </ParamField>

    <ParamField body="image_size" type="string" default="auto">
      输出分辨率档位

      * `auto` - 自动选择（默认）
      * `auto_1K` - 1K 分辨率
      * `auto_1.5K` - 1.5K 分辨率
      * `auto_2K` - 2K 分辨率
    </ParamField>

    <ParamField body="enhance_prompt_mode" type="string" default="standard">
      提示词增强模式（仅 API 可用）

      * `standard` - 标准模式（默认）
      * `fast` - 快速模式
    </ParamField>
  </Expandable>
</ParamField>

  任务完成后的回调地址

## 查询任务结果

任务提交后，使用 `POST /api/openapi/query` 接口轮询任务状态。任务完成后，`output` 字段返回图层列表。

<RequestExample>
  ```bash cURL
  curl --request POST \

    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "my_task_123456"
    }'
  ```
</RequestExample>

### 查询响应 - 图层输出结构

任务完成后，`output` 是一个图层对象数组，每个图层包含 `url` 和 `metadata`：

<ResponseField name="output" type="array">
  图层列表，每个元素是一个图层对象

  <Expandable title="图层对象属性">
    <ResponseField name="url" type="string">
      该图层的透明 PNG 图片 URL
    </ResponseField>

    <ResponseField name="metadata" type="object">
      图层元数据

      <Expandable title="metadata 属性">
        <ResponseField name="kind" type="string">
          固定值 `"layer"`，标识这是一个图层输出
        </ResponseField>

        <ResponseField name="z_index" type="number">
          图层层级索引

          * `z_index = 0`：底层（重建的完整背景图），`bounding_box` 为 `null`
          * `z_index ≥ 1`：前景图层，按从后到前的顺序排列
        </ResponseField>

        <ResponseField name="bounding_box" type="object | null">
          图层在原图中的位置区域

          底层（z_index=0）为 `null`，其余图层返回坐标对象：

          <Expandable title="bounding_box 属性">
            <ResponseField name="absolute" type="array">
              绝对像素坐标 `[x1, y1, x2, y2]`，基于原图分辨率
            </ResponseField>

            <ResponseField name="normalized" type="array">
              归一化坐标 `[x1, y1, x2, y2]`，范围 0–1000
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="name" type="string | null">
          图层名称（如 `"Sky background"`、`"Moss platform"`）
        </ResponseField>

        <ResponseField name="description" type="string | null">
          图层描述（如 `"Soft light blue sky with scattered fluffy white clouds"`）
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="credits_used" type="number">
  实际消耗积分
</ResponseField>
