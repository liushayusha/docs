---
title: 'Midjourney V8.2 图片生成'
description: |
    - 异步处理模式，返回任务ID用于后续查询
    - 每次请求生成 4 张独立图片，按次计费，不按张数
    - 支持文生图、参考图（最多 4 张）、风格参考、编辑图片
    - 画幅、画质、速度用参数选择，无需在提示词里手写 Midjourney 参数
api: 'POST https://aireiter.com/api/openapi/submit'
---

## Body

<ParamField body="model" type="string" required>
  模型名称，固定为 `"mj_v8_2"`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      图像的文本描述，用自然语言写想要的画面

      * 版本、画幅、画质、速度等 Midjourney 参数由下方字段自动添加，无需手写
      * 提示词里手写的 `--` 参数（如 `--ar`、`--v`、`--fast`）会被忽略，从第一个 `--` 起的内容都不会生效
      * 使用编辑图片（`use_edit`）时，可直接写修改指令，例如："Render this logo as a hand drawn pencil sketch"
    </ParamField>

    <ParamField body="image_url" type="string[]">
      参考图（Image Prompt）的 URL 列表，影响成品的内容、构图和配色

      * 最多 4 张图片，按传入顺序使用
      * 不传则为文生图
      * 支持以下两种格式：
        1. 公开可访问的 URL（不能要求登录、Cookie 或临时授权）
        2. Base64 编码格式
           * 必须使用完整的 Data URI 格式：`data:image/{格式};base64,{base64数据}`
           * 支持的图片格式：jpeg、png、webp
           * 示例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：必须包含 `data:image/jpeg;base64,` 前缀部分，base64 图片大小不超过 10MB
    </ParamField>

    <ParamField body="image_weight" type="number" default="1">
      参考图权重（对应 `--iw`），成品贴近参考图的程度

      * 取值范围 0-3，默认 1，越大越像参考图
      * 仅在传入 `image_url` 时生效
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="1:1">
      图像宽高比（对应 `--ar`）

      支持的宽高比：

      * `1:1` - 正方形（默认）
      * `16:9` - 横向宽屏
      * `9:16` - 纵向竖屏
      * `4:3` - 横向 4:3
      * `3:4` - 纵向 3:4
      * `3:2` - 横向 3:2
      * `2:3` - 纵向 2:3
    </ParamField>

    <ParamField body="quality" type="string" default="sd">
      画质档位

      支持的取值：

      * `sd` - 标准画质（默认），1:1 下每张为 1024×1024
      * `hd` - 原生高清，1:1 下每张为 2048×2048

      其他画幅按比例换算，实际尺寸以返回图片为准。
    </ParamField>

    <ParamField body="speed" type="string" default="fast">
      生成速度（对应 `--fast` / `--relax`）

      支持的取值：

      * `fast` - 快速档（默认）
      * `relax` - 慢速档，排队时间更长

      慢速档由单独的通道处理，实测比快速档慢一倍以上。
    </ParamField>

    <ParamField body="use_style_ref" type="boolean" default="false">
      是否开启风格参考（对应 `--sref`）

      借用另一张图的画风、配色和质感，不会照搬其中的人物或物体。设为 `true` 时必须传 `style_image_url`。
    </ParamField>

    <ParamField body="style_image_url" type="string">
      风格参考图，1 张

      * 仅在 `use_style_ref` 为 `true` 时生效，且此时必填
      * 格式要求同 `image_url`
    </ParamField>

    <ParamField body="style_weight" type="number" default="100">
      风格强度（对应 `--sw`）

      * 取值范围 0-1000，默认 100
      * 仅在 `use_style_ref` 为 `true` 时生效
    </ParamField>

    <ParamField body="use_edit" type="boolean" default="false">
      是否开启编辑图片（对应 `--edit`）

      以 `prompt` 作为修改指令编辑一张现有图片。设为 `true` 时必须传 `edit_image_url`。可与 `image_url`、风格参考同时使用。
    </ParamField>

    <ParamField body="edit_image_url" type="string">
      待编辑的图片，1 张

      * 仅在 `use_edit` 为 `true` 时生效，且此时必填
      * 格式要求同 `image_url`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务ID

  用户自定义的任务标识，必填。仅支持字母、数字、`_`、`-`，长度 1-64
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  发起方任务ID，可用于查询结果
</ResponseField>

<ResponseField name="status" type="string">
  初始状态，固定为 `"pending"`
</ResponseField>

<ResponseField name="created_at" type="string">
  创建时间（ISO 格式）
</ResponseField>

任务完成后，通过查询接口获取结果：`data.output` 中包含 4 张图片，按原四宫格左上、右上、左下、右下的顺序排列。生成通常需要几分钟，请勿因等待而重复提交。
