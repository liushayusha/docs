---
title: 'P-Image-Upscale 图片超分放大'
description: |
    - 异步处理模式，返回任务ID用于后续查询
    - PrunaAI 超分辨率模型，将小图或压缩图放大为更清晰的大尺寸图片
    - 支持按目标像素（MP）或按倍数放大，输出最高 128 MP
    - 可选细节增强、真实感增强，支持 jpg / png / webp 输出
api: 'POST https://aireiter.com/api/openapi/submit'

## Body

<ParamField body="model" type="string" required>
  模型名称

  固定值：`"prunaai_p_image_upscale"`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象

  <Expandable title="params 对象属性">
    <ParamField body="image_url" type="string" required>
      待放大的原图 URL

      * 必填，且只能传 **1 张** 图片
      * 支持以下两种格式：
        1. 公开可访问的 URL
        2. Base64 编码格式
           * 必须使用完整的 Data URI 格式：`data:image/{格式};base64,{base64数据}`
           * 支持的图片格式：jpeg、png、webp
           * 示例：`data:image/jpeg;base64,/9j/4AAQSkZJRgABAQEAYABg...`
           * ⚠️ 注意：必须包含 `data:image/jpeg;base64,` 前缀部分，base64 图片大小不超过 10MB
    </ParamField>

    <ParamField body="upscale_mode" type="string" default="target">
      放大模式

      * `target` - 按目标像素放大到固定的百万像素（MP）尺寸（默认），配合 `target` 参数使用
      * `factor` - 按倍数放大，每条边乘以 `factor`，配合 `factor` 参数使用
    </ParamField>

    <ParamField body="target" type="integer" default="4">
      目标分辨率（单位：MP，百万像素）

      * 取值范围：`1` ~ `128`
      * 仅在 `upscale_mode` 为 `target` 时生效
    </ParamField>

    <ParamField body="factor" type="number" default="2">
      放大倍数

      * 取值范围：`1` ~ `8`
      * 仅在 `upscale_mode` 为 `factor` 时生效
      * 输出图片最大不超过 128 MP，超出时自动封顶
    </ParamField>

    <ParamField body="enhance_details" type="boolean" default="false">
      细节增强

      增强细微纹理和小细节，可能会提高对比度并与原图产生轻微偏差。
    </ParamField>

    <ParamField body="enhance_realism" type="boolean" default="false">
      真实感增强

      提升画面真实感，但可能与原图偏差更大。推荐用于 AI 生成的图片。
    </ParamField>

    <ParamField body="output_format" type="string" default="jpg">
      输出图片格式

      * `jpg` - JPEG 格式（默认）
      * `png` - PNG 格式
      * `webp` - WebP 格式
    </ParamField>

    <ParamField body="output_quality" type="integer" default="80">
      输出图片质量

      * 取值范围：`0` ~ `100`，100 为最佳质量，0 为最低质量
      * 当 `output_format` 为 `png` 时该参数无效
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="callback_url" type="string">
  任务完成后的回调地址
</ParamField>

<ParamField body="metadata" type="object">
  自定义元数据，原样返回
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务ID

  用户自定义的任务标识，必填
</ParamField>

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "my_task_123456"
    }'
  ```
</RequestExample>

  输出图片列表，每个元素包含放大后图片的 `url`
