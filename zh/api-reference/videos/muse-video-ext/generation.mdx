---
title: 'Muse Video Ext 视频生成'
description: |
  - 异步处理模式，返回任务 ID 用于后续查询
  - 支持文生视频，或最多 9 张参考图生视频
  - 每次生成 1 段 10 秒、720p、自带音轨的视频
  - 提示词里写时间点即可在场景间切换镜头
api: 'POST https://aireiter.com/api/openapi/submit'
---

import { apiKeyUrl } from '/snippets/_variables.mdx';

<Note>
时长固定 10 秒，分辨率固定 720p，成片自带生成的音轨。`video_length` 和 `resolution` 可以不传。

不支持参考视频、参考音频、首尾帧、`seed`、`negative_prompt`，也不能关闭音轨。
</Note>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定为 `muse_video_ext`。
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      视频生成的文本描述，支持中文和英文。必填，且去掉首尾空白后不能为空。

      有参考图时，可以在提示词里用 `Picture 1`、`Picture 2` 指代第 1、第 2 张图。

      多个镜头时，每个镜头单独写一段，并用时间点标出切换位置，例如：

      ```
      [Shot 1] 客厅全景，女生举着挂在衣架上的 T 恤……
      [Shot 2] At 00:04.000，镜头切到白墙前，男生穿上这件 T 恤……
      ```

      <Warning>
        提示词里出现真实品牌、球队或 logo 名称，可能无法通过内容审核，任务会以失败结束。请改用不带名称的描述后重试。
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参考图 URL，必须可由公网直接访问。也可传单张字符串。不传就是文生视频。

      * 最多 9 张
      * 所有图片的原始大小合计不超过 11 MiB
      * 推荐 PNG、JPEG、WebP

      不支持本地路径和 `blob:` 地址。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      视频宽高比：

      * `auto` - 默认值。有参考图时跟随参考图的构图，纯文字时为 `16:9`
      * `1:1`
      * `16:9`
      * `9:16`
      * `4:3`
      * `3:4`
      * `3:2`
      * `2:3`
    </ParamField>

    <ParamField body="video_length" type="string" default="10">
      视频时长，固定为 `"10"`。可以不传。
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      输出分辨率，固定为 `720p`。可以不传。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。仅支持字母、数字、下划线和横线，长度为 1-64 个字符。后续可使用该 ID 查询任务状态和结果。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">

## Query Task

本模型是异步视频生成。提交任务后，请使用 `out_task_id` 查询任务状态。也可参见 [获取任务状态](/zh/api-reference/tasks/status)。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "muse_ext_t2v_123456"
  }'
```

查询成功并完成后，响应中的 `output` 数组会包含生成的视频，元素含 `video` 字段。

生成耗时因输入而异：纯文字通常约 1 到 2 分钟，参考图较多时可能需要几分钟，请持续轮询，不要重复提交。

## 使用说明

| 输入 | `image_url` | `aspect_ratio` |
|---|---|---|
| 文生视频 | 不要传，或空数组 | 不传默认 `16:9`；也可指定 |
| 参考图生视频 | 1–9 张，合计不超过 11 MiB | 建议用 `auto` 跟随参考图，或指定 |

多镜头提示词的效果：

* 切点时间可靠：提示词里写的时间点，实际切换误差在 1 秒以内。
* 商品上的文字、印花和 logo 在各镜头间保持一致。
* 人物在切镜后可能与参考图有差异。需要同一个人保持可辨认时，建议最多 2 个切点，并在每个镜头里重复写他的外貌描述。
