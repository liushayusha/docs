description: |
  - 快手 Kling v3 Omni，也常被称为 Kling O3
  - 异步处理模式，返回任务 ID 用于后续查询
  - 支持文本/参考、首尾帧两种生成模式
  - 支持 720p / 1080p / 4K，视频时长 3-15 秒，可选原生音轨和参考视频

## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `kling_v3_omni`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      视频生成的文本描述。必填。

      参考图可在提示词中用 `<<<image_1>>>`、`<<<image_2>>>` 按顺序指代 `image_url` 中的图片。已传图片但未写引用时，系统会自动在提示词前补上 `<<<image_1>>>`。
    </ParamField>

    <ParamField body="negative_prompt" type="string">
      负面提示词，用于排除不想出现的内容。最多 2500 个字符。
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      生成模式。同一请求不能混用：

      * `all_reference` - 文本/参考。可用提示词，可选最多 7 张参考图和 1 段参考视频
      * `first_last_frame` - 首尾帧。首帧必填，尾帧可选

      <Warning>
        首尾帧不能与参考图片或参考视频出现在同一次请求中。
      </Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      生成视频时长，单位为秒。支持整数 `3` 到 `15`。

      * `all_reference` 且未传参考视频、或 `refer_type=feature`：输出时长跟随该字段
      * `refer_type=base`：输出时长跟随上传视频，请勿依赖该字段
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      输出分辨率：

      * `720p` - 默认值
      * `1080p`
      * `4K`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      视频宽高比。有首帧或参考视频时由素材决定，该字段会被忽略。

      * `16:9` - 横屏，默认值
      * `9:16` - 竖屏
      * `1:1` - 方形
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="false">
      是否生成原生音轨。

      * `false` - 不生成，默认值
      * `true` - 生成音轨

      <Warning>
        传入 `video_url` 时该参数会被忽略，不能与参考视频同时使用。
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      图片 URL，必须可由公网直接访问。

      * `all_reference` - 可选参考图，最多 7 张
      * `first_last_frame` - 第一张为首帧（必填），第二张为尾帧（可选）

      图片要求：短边不小于 300px，单张不超过 20MB。
    </ParamField>

    <ParamField body="end_image_url" type="string">
      尾帧图片 URL。

      仅 `first_last_frame` 模式有效。也可以将尾帧作为 `image_url` 数组的第二张图片传入。仅有尾帧、没有首帧会报错。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参考视频 URL。仅 `all_reference` 模式有效，最多 1 段。

      视频要求：

      * 格式 MP4、MOV
      * 时长 3-10 秒
      * 不超过 200MB
      * 短边不小于 720px

      <Warning>`first_last_frame` 请勿传入此参数。请确保 URL 可公开访问，并且视频时长元数据可读取。</Warning>
    </ParamField>

    <ParamField body="refer_type" type="string" default="feature">
      参考视频用法，仅在传入 `video_url` 时生效：

      * `feature` - 把上传视频当作风格或动作参考，输出时长跟随 `video_length`
      * `base` - 按上传视频做编辑，输出时长跟随片源，忽略 `video_length`
    </ParamField>

    <ParamField body="keep_original_sound" type="boolean" default="false">
      是否保留参考视频原声。仅在传入 `video_url` 时生效。

      * `false` - 不保留，默认值
      * `true` - 保留原片音轨
    </ParamField>

    <ParamField body="watermark" type="boolean" default="false">
      是否在成片中添加水印。默认 `false`。
    </ParamField>

    <ParamField body="multi_shot" type="boolean" default="false">
      是否启用多镜头。为 `true` 时由模型按提示词自动分镜。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。仅支持字母、数字、下划线和横线，长度为 1-64 个字符。后续可使用该 ID 查询任务状态和结果。
</ParamField>

## Query Task

Kling v3 Omni 是异步视频生成模型。提交任务后，请使用 `out_task_id` 查询任务状态。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "kling_v3_omni_t2v_123456"
  }'
```

查询成功并完成后，响应中的 `output` 数组会包含生成的视频，元素含 `video` 字段。

## 模式参数对照

| `type` / 参考视频 | 必需素材 | 时长 |
|---|---|---|
| `all_reference`，无 `video_url` | `prompt` | `video_length` 3-15 秒 |
| `all_reference`，`refer_type=feature` | `prompt`、`video_url` | 输出跟随 `video_length` |
| `all_reference`，`refer_type=base` | `prompt`、`video_url` | 输出跟随上传视频 3-10 秒 |
| `first_last_frame` | `prompt`、首帧 `image_url` | `video_length` 3-15 秒 |
