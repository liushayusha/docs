<Note>
Vidu Q4 在 AIReiter 中的模型名称为 `vidu_q4`。该模型必须至少传入一张图片，不支持纯文生视频，也不支持首尾帧。
</Note>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `vidu_q4`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string">
      视频内容描述，最多 20000 个字符。

      * `frame` 模式下可选，用于描述画面动作和运镜
      * `reference` 模式下必填

      参考模式下可以按上传顺序指代素材，例如「参考图 2 里的男人」「使用参考音频 1 的声音」。
    </ParamField>

    <ParamField body="type" type="string" default="frame">
      生成模式：

      * `frame` - 首帧，默认值。传入 1 张图片作为视频第一帧，视频沿用图片的宽高比
      * `reference` - 参考，传入 1-15 张参考图，可附加 0-3 段参考音频

      <Warning>
        首帧模式只能传 1 张图片，且不能传 `audio_url`。
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]" required>
      图片 URL，必须可由公网直接访问。

      * `frame` - 必须正好 1 张，作为首帧
      * `reference` - 1-15 张参考图

      图片要求：

      * 格式 JPG、JPEG、PNG、WEBP
      * 单张不超过 50MB
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参考音频 URL，用于引导生成视频中的音色和语气。

      仅 `reference` 模式有效，最多 3 段。

      音频要求：

      * 格式 MP3
      * 单段 3-12 秒
      * 单段不超过 50MB

      <Warning>`frame` 模式请勿传入此参数。</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      生成视频时长，单位为秒。

      支持整数：`3` 到 `16`。
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      输出分辨率：

      * `540p`
      * `720p` - 默认值
      * `1080p`
      * `2K`
      * `4K`

      分辨率档位按画面总像素计算。非 16:9 的画面（如方形、竖屏）宽高会与档位名不同，例如 540p 的 1:1 视频为 720×720。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      视频宽高比，仅 `reference` 模式有效。`frame` 模式沿用首帧图片的比例，传入会被忽略。

      支持的宽高比：

      * `16:9` - 横屏，默认值
      * `9:16` - 竖屏
      * `1:1` - 方形
      * `4:3` - 标准横屏
      * `3:4` - 竖版标准
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      是否生成同步音频（对白和音效）。

      * `true` - 生成带音轨的视频，默认值
      * `false` - 输出无声视频
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。仅支持字母、数字、下划线和横线，长度为 1-64 个字符。后续可使用该 ID 查询任务状态和结果。
</ParamField>

## Query Task

Vidu Q4 是异步视频生成模型。提交任务后，请使用 `out_task_id` 查询任务状态，建议每 10-15 秒查询一次。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "vidu_q4_frame_123456"
  }'
```

查询成功并完成后，响应中的 `output` 数组会包含生成的视频，元素含 `video` 字段。

## Mode Notes

<Note>
`frame` 用 1 张图片作为第一帧生成视频，提示词可选，宽高比跟随图片；`reference` 用 1-15 张参考图和最多 3 段参考音频组合生成新画面，提示词必填，可指定宽高比。
</Note>

<Warning>
当 `type` 为 `frame` 时，`image_url` 必须正好 1 张，不要传入 `audio_url`。当 `type` 为 `reference` 时，`prompt` 不能为空，参考图最多 15 张，参考音频最多 3 段。
</Warning>
