## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `wan3_0`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string">
      视频生成的文本描述。

      `all_reference` 建议填写提示词，或至少提供一项图片、视频或音频参考。`first_last_frame` 和 `file_web` 下提示词可选，填写后控制更准。

      使用参考素材时，可在提示词中用「图1 / 视频1 / 音频1」按类型和顺序指代上传内容。
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      生成模式，决定使用哪一种视频生成方式。同一请求不能混用三种模式：

      * `all_reference` - 文本/参考，可仅用提示词，也可附加图片、视频和音频
      * `first_last_frame` - 首尾帧，使用必填首帧和可选尾帧
      * `file_web` - 文件/网页，传入文档 URL 或公开网页 URL

      <Warning>
        首尾帧不能与参考图片、参考视频、参考音频、文档或网页出现在同一次请求中。`file_url` 与 `link_url` 也不能同时传入。
      </Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      生成视频时长，单位为秒。

      支持整数：`2` 到 `30`。有参考视频时，输入秒数加输出秒数不能超过 30。
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      输出分辨率：

      * `480p`
      * `720p` - 默认值
      * `1080p`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      视频宽高比。

      支持的宽高比：

      * `auto` - 跟随参考素材或提示词，默认值
      * `16:9` - 横屏
      * `9:16` - 竖屏
      * `4:3` - 标准横屏
      * `3:4` - 竖版标准
      * `1:1` - 方形
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      是否生成原生音轨。

      * `true` - 生成音轨，默认值
      * `false` - 输出无音轨视频
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      图片 URL，必须可由公网直接访问。

      在不同 `type` 下含义不同：

      * `all_reference` - 可选参考图，最多 10 张
      * `first_last_frame` - 第一张为首帧（必填），第二张为尾帧（可选）
      * `file_web` - 请勿传入

      图片要求：

      * 短边不小于 240px，长边不超过 8000px
      * 单张不超过 20MB
    </ParamField>

    <ParamField body="end_image_url" type="string">
      尾帧图片 URL。

      仅 `first_last_frame` 模式有效。也可以将尾帧作为 `image_url` 数组的第二张图片传入。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参考视频 URL。

      仅 `all_reference` 模式有效，最多 5 段。

      视频要求：

      * 格式 MP4、MOV
      * 单段 1-15 秒，合计不超过 15 秒
      * 单段不超过 100MB
      * 短边不小于 240px，长边不超过 4096px

      参考视频时长会计入计费时长：计费秒数 = 成片秒数 + 参考视频秒数（向上取整）。

      <Warning>`first_last_frame` 和 `file_web` 请勿传入此参数。请确保 URL 可公开访问，并且视频时长元数据可读取。</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参考音频 URL。

      仅 `all_reference` 模式有效，最多 5 段。

      音频要求：

      * 格式 WAV、MP3
      * 单段 1-15 秒，合计不超过 15 秒
      * 单段不超过 15MB

      参考音频不计入计费时长。

      <Warning>`first_last_frame` 和 `file_web` 请勿传入此参数。</Warning>
    </ParamField>

    <ParamField body="file_url" type="string">
      文档 URL。

      仅 `file_web` 模式有效，必须可由公网直接访问。

      支持 DOC(X)、XLS(X)、PPT(X)、PDF、TXT、KEY、Pages、Numbers、MD；不超过 100MB、50 页。文档不计入计费时长。

      <Warning>与 `link_url` 互斥，不要同时传入。</Warning>
    </ParamField>

    <ParamField body="link_url" type="string">
      公开网页 URL。

      仅 `file_web` 模式有效。网页不计入计费时长。

      <Warning>与 `file_url` 互斥，不要同时传入。</Warning>
    </ParamField>

    <ParamField body="watermark" type="boolean" default="false">
      是否在成片中添加水印。默认 `false`。
    </ParamField>

    <ParamField body="seed" type="integer">
      随机种子。传入大于等于 `0` 的整数时生效；省略则随机。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。仅支持字母、数字、下划线和横线，长度为 1-64 个字符。后续可使用该 ID 查询任务状态和结果。
</ParamField>

## Query Task

Wan 3.0 是异步视频生成模型。提交任务后，请使用 `out_task_id` 查询任务状态。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "wan3_0_t2v_123456"
  }'
```

查询成功并完成后，响应中的 `output` 数组会包含生成的视频，元素含 `video` 字段。

## Mode Notes

<Note>
`all_reference` 可纯提示词生成，也可附加图片、视频和音频参考；`first_last_frame` 使用首帧和可选尾帧；`file_web` 使用 `file_url` 或 `link_url` 将文档或网页转为视频。
</Note>

<Warning>
当 `type` 为 `first_last_frame` 时，不要同时传入 `video_url`、`audio_url`、`file_url` 或 `link_url`。当 `type` 为 `file_web` 时，`file_url` 与 `link_url` 只能传其中一个。
</Warning>
