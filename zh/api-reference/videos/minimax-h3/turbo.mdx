description: |
  - MiniMax H3 Turbo，加速版 MiniMax H3
  - 异步处理模式，返回任务 ID 用于后续查询
  - 支持文生视频，以及最多 9 张参考图、3 段参考音频

<Note>
MiniMax H3 Turbo 在 AIReiter 中的模型名称为 `minimax_h3_turbo`。该模型与 `minimax_h3` 不同：分辨率为 480P / 720P，时长为 5-15 秒，不支持参考视频和首尾帧。
</Note>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `minimax_h3_turbo`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      视频生成的文本描述。

      可描述主体、场景、镜头运动、动作、风格、光线、节奏等内容。

      使用参考素材时，可在提示词中用「图1 / 音频1」按顺序指代上传内容。
    </ParamField>

    <ParamField body="video_length" type="number" default="5">
      生成视频时长，单位为秒。

      支持整数：`5` 到 `15`。
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      输出分辨率：

      * `480p`
      * `720p` - 默认值
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      视频宽高比。

      支持的宽高比：

      * `21:9` - 超宽屏
      * `16:9` - 横屏，默认值
      * `4:3` - 标准横屏
      * `3:2` - 照片横屏
      * `1:1` - 方形
      * `3:4` - 竖版标准
      * `2:3` - 照片竖屏
      * `9:16` - 竖屏
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参考图片 URL，可选。最多 9 张。

      不传图片时为文生视频；传入图片时作为参考图引导主体、风格或构图。

      图片要求：

      * 支持 JPEG、PNG、WEBP
      * 单张图片最大 20MB
      * URL 必须可公开访问
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参考音频 URL，可选。最多 3 段。

      音频要求：

      * 支持 MP3、WAV
      * 单个音频最大 20MB
      * 单个音频时长不超过 15 秒
      * URL 必须可公开访问
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。后续可使用该 ID 查询任务状态和结果。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  发起方任务 ID，可用于查询结果。
</ResponseField>

<ResponseField name="status" type="string">
  初始状态，通常为 `"pending"`。
</ResponseField>

<ResponseField name="created_at" type="string">
  创建时间，ISO 格式。
</ResponseField>

## Query Task

MiniMax H3 Turbo 是异步视频生成模型。提交任务后，请使用 `out_task_id` 查询任务状态。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "minimax_h3_turbo_task_123456"
  }'
```

查询成功并完成后，响应中的 `output` 字段会包含生成结果。视频地址在 `output.list[].video`。

## Mode Notes

<Note>
不传 `image_url` 时为文生视频。传入参考图后，图片用于引导主体、风格或构图，不是首尾帧。
</Note>

<Warning>
本模型不支持参考视频，也不支持 `first_last_frame` 首尾帧模式。请不要传入 `video_url`、`end_image_url`、`type` 或 `quality`。
</Warning>
