## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `minimax_h3`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      视频生成的文本描述，最多 7000 个字符。

      可描述主体、场景、镜头运动、动作、风格、光线、节奏等内容。
    </ParamField>

    <ParamField body="type" type="string" default="text_to_video">
      生成类型，决定 MiniMax H3 使用哪一种上游模式。

      * `text_to_video` - 文生视频，仅使用提示词生成视频
      * `first_last_frame` - 首帧/尾帧图生视频，使用首帧、尾帧或首尾帧过渡生成视频
      * `all_reference` - 多参考素材生成视频，可使用参考图片、参考视频和参考音频
    </ParamField>

    <ParamField body="video_length" type="number" default="4">
      生成视频时长，单位为秒。

      支持整数：`4` 到 `15`。

      <Warning>视频时长会直接影响计费。</Warning>
    </ParamField>

    <ParamField body="quality" type="string" default="2k">
      输出质量，当前固定为：

      * `2k`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      视频宽高比。

      支持的宽高比：

      * `21:9` - 超宽屏
      * `16:9` - 横屏，默认值
      * `4:3` - 标准横屏
      * `1:1` - 方形
      * `3:4` - 竖版标准
      * `9:16` - 竖屏

      <Warning>`first_last_frame` 模式不支持单独选择宽高比，输出会跟随输入图片比例。</Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      图片 URL。

      在不同 `type` 下含义不同：

      * `text_to_video` - 不需要传图片
      * `first_last_frame` - 作为首帧图片；也可以传数组，第一张作为首帧，第二张作为尾帧
      * `all_reference` - 作为参考图片，最多 9 张

      图片要求：

      * 支持 JPG、JPEG、PNG、WEBP、HEIC、HEIF
      * 单张图片最大 30MB
      * 宽高范围 256-5760px
      * 图片宽高比范围 0.4-2.5
    </ParamField>

    <ParamField body="end_image_url" type="string">
      尾帧图片 URL。

      仅 `first_last_frame` 模式有效。也可以将尾帧作为 `image_url` 数组的第二张图片传入。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参考视频 URL。

      仅 `all_reference` 模式有效。

      AIReiter 当前开放 1 个参考视频，以确保参考视频时长计费准确；EvoLink 上游支持最多 3 个参考视频，且总时长不超过 15 秒。

      视频要求：

      * 单个视频时长 2-15 秒
      * 支持 MP4、MOV
      * 视频编码 H.264 或 H.265
      * 音频编码 AAC 或 MP3
      * 单个视频最大 50MB
      * 宽高范围 256-5760px
      * 帧率 23.976-60 FPS

      <Warning>参考视频时长会加入计费秒数。请确保 URL 可公开访问，并且视频时长元数据可读取。</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参考音频 URL。

      仅 `all_reference` 模式有效，最多 3 个音频。

      音频要求：

      * 单个音频时长 2-15 秒
      * 支持 WAV、MP3
      * 单个音频最大 15MB

      <Note>参考音频不单独计费。</Note>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。后续可使用该 ID 查询任务状态和结果。
</ParamField>

## Query Task

MiniMax H3 是异步视频生成模型。提交任务后，请使用 `out_task_id` 查询任务状态。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "minimax_h3_task_123456"
    }'
  ```
</RequestExample>

查询成功并完成后，响应中的 `output` 字段会包含生成的视频 URL。

## Pricing

MiniMax H3 按生成视频秒数、参考视频秒数和额外参考图片计费。

| 计费项 | 价格 |
| --- | --- |
| 2K 生成视频 | 40.15 credits / 秒 |
| 参考视频输入 | 40.15 credits / 秒 |
| 参考图片 | 前 5 张免费，超出后 12.1 credits / 张 |
| 参考音频 | 免费 |

计费公式：

```
(生成视频秒数 + 参考视频秒数) × 40.15 + max(参考图片张数 - 5, 0) × 12.1
```

示例：

* 4 秒文生视频：`4 × 40.15 = 160.6 credits`
* 4 秒输出 + 9 秒参考视频：`(4 + 9) × 40.15 = 521.95 credits`
* 15 秒输出 + 15 秒参考视频 + 9 张参考图片：`30 × 40.15 + 4 × 12.1 = 1252.9 credits`

## Mode Notes

<Note>
`text_to_video` 模式会调用 MiniMax H3 文生视频能力；`first_last_frame` 模式会调用图生视频能力；`all_reference` 模式会调用多参考素材生成能力。
</Note>

<Warning>
当 `type` 为 `first_last_frame` 时，请不要依赖 `aspect_ratio` 参数。该模式输出比例由输入图片决定。
</Warning>
