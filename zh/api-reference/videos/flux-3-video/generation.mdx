<Note>
FLUX 3 Video 在 AIReiter 中的模型名称为 `flux_3_video`。当前开放文生视频、有序关键帧和视频续写三种模式。
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  所有接口均需要使用 Bearer Token 进行认证。

  访问 <a href={apiKeyUrl} target="_blank">API Key 管理页面</a> 获取 API Key，并在请求头中添加：

  ```

  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `flux_3_video`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="mode" type="string" default="t2v">
      生成模式：

      * `t2v` - 文生视频，仅使用提示词生成视频
      * `i2v` - 有序关键帧，使用 1-10 张图片控制视频内容和过渡
      * `v2v` - 视频续写，从一个源视频继续生成动态内容
    </ParamField>

    <ParamField body="prompt" type="string" required>
      视频生成的文本描述。

      建议描述主体、场景、动作、镜头运动、视觉风格、对白及环境声音。
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      有序关键帧图片 URL，仅 `i2v` 模式使用。

      * 支持 1-10 张公开可访问的图片
      * 图片顺序即播放顺序
      * 第一张和最后一张可用于定义视频的起止画面

      <Warning>`i2v` 模式必须提供至少一张图片；其他模式请勿传入此参数。</Warning>
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      源视频 URL，仅 `v2v` 模式使用。

      当前最多支持一个公开可访问的 MP4 视频。数组形式传入时仅使用第一个 URL。

      <Warning>`v2v` 模式必须提供源视频；其他模式请勿传入此参数。</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      输出视频时长，单位为秒。

      支持 `5` 到 `20` 之间的整数。
    </ParamField>

    <ParamField body="resolution" type="string" default="hd">
      输出质量：

      * `hd` - HD
      * `fhd` - FHD

      <Note>FHD 的像素数高于 HD，具体输出尺寸会随宽高比变化。</Note>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      视频宽高比：

      * `auto` - 自动
      * `21:9` - 超宽屏
      * `2:1` - 宽屏
      * `16:9` - 横屏
      * `4:3` - 标准横屏
      * `1:1` - 方形
      * `3:4` - 竖版标准
      * `9:16` - 竖屏
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      是否生成与视频同步的原生音频。

      可包含对白、环境声和音效。
    </ParamField>

    <ParamField body="safety_tolerance" type="integer" default="2">
      内容安全容忍度，支持整数 `0` 到 `4`。

      * `0` - 最严格过滤
      * `4` - 最宽松设置
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  由调用方生成并保证唯一，后续使用该 ID 查询任务状态和结果。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  发起方任务 ID，可用于查询结果。
</ResponseField>

<ResponseField name="status" type="string">
  初始状态，通常为 `"pending"`。
</ResponseField>

<ResponseField name="created_at" type="string">
  创建时间，ISO 8601 格式。
</ResponseField>

## Query Task

FLUX 3 Video 采用异步处理。提交成功后，使用同一个 `out_task_id` 查询任务：

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "flux_3_video_task_123456"
    }'
  ```
</RequestExample>

任务完成后，响应中的 `output` 数组会包含生成的视频 URL。完整字段参见[获取任务状态](/zh/api-reference/tasks/status)。

## Mode Rules

| mode | 必需素材 | 素材限制 |
| --- | --- | --- |
| `t2v` | 无 | 请勿传 `image_url` 或 `video_url` |
| `i2v` | `image_url` | 1-10 张有序图片 |
| `v2v` | `video_url` | 最多一个源视频 |

<Warning>
请确保图片和视频 URL 可由公网直接访问。任务为异步处理，请勿使用提交请求的 HTTP 连接等待最终视频。
</Warning>
