---
title: 'FLUX 3 Max 视频生成'
description: |
  - Black Forest Labs FLUX 3 Max 视频生成模型，基于 FLUX 3 Video 后训练，提示词遵循与画质更强、生成延迟更低
  - 异步处理模式，返回任务 ID 用于后续查询
  - 支持文生视频、首尾帧、关键帧（最多 10 张）三种模式
  - 支持 720p / 1080p 输出，视频时长 5-20 秒，默认生成原生音频
api: 'POST https://aireiter.com/api/openapi/submit'
---

<Note>
FLUX 3 Max 在 AIReiter 中的模型名称为 `flux_3_max`。通过 `type` 选择文生（`text`）、首尾帧（`frame`）或关键帧（`keyframes`）模式。
</Note>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `flux_3_max`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      视频内容描述，所有模式必填。

      建议同时描述画面、动作、运镜和声音。模型会在生成前自动理解并扩写提示词（扩写强度见 `reasoning_level`）。
    </ParamField>

    <ParamField body="type" type="string" default="text">
      生成模式：

      * `text` - 文生视频，默认值。只用提示词，传入的图片会被忽略
      * `frame` - 首尾帧。`image_url[0]` 作为首帧（必传），`image_url[1]` 作为尾帧（可选）
      * `keyframes` - 关键帧。按顺序传入最多 10 张图片，均匀分布在视频时间轴上，视频依次经过每一张

      <Warning>
        `frame` 和 `keyframes` 模式至少需要 1 张图片；不传图片时按 `text` 模式生成。
      </Warning>
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      图片 URL，必须可由公网直接访问。`text` 模式无需传入。

      * `frame` - 1-2 张：第 1 张为首帧，第 2 张（可选）为尾帧
      * `keyframes` - 1-10 张，按上传顺序从第一帧到最后一帧均匀放置

      图片要求：

      * 格式 PNG、JPEG、WEBP
      * 单张不超过 20MB
    </ParamField>

    <ParamField body="end_image_url" type="string">
      尾帧图片 URL，仅 `frame` 模式有效。也可以直接作为 `image_url` 的第 2 张传入，两者同时传时以 `end_image_url` 为准。
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      生成视频时长，单位为秒。

      支持整数：`5` 到 `20`。
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      输出分辨率（24 fps）：

      * `720p` - 默认值
      * `1080p`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="auto">
      视频宽高比：

      * `auto` - 默认值。`text` 模式为 16:9，有图片时跟随第 1 张图片
      * `16:9` - 横屏
      * `9:16` - 竖屏
      * `1:1` - 方形
      * `4:3` - 标准横屏
      * `3:4` - 竖版标准
      * `21:9` - 超宽屏
    </ParamField>

    <ParamField body="reasoning_level" type="string" default="high">
      提示词推理强度，模型在生成前理解和扩写提示词的力度：

      * `high` - 默认值。扩写更充分、效果更好，生成更慢
      * `low` - 更快

      两档价格相同。
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      是否随视频生成原生音频。

      * `true` - 生成带音轨的视频，默认值
      * `false` - 输出无声视频

      开关音频价格相同。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。仅支持字母、数字、下划线和横线，长度为 1-64 个字符。后续可使用该 ID 查询任务状态和结果。
</ParamField>

## Query Task

FLUX 3 Max 是异步视频生成模型。提交任务后，请使用 `out_task_id` 查询任务状态，建议每 10-15 秒查询一次。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flux_3_max_frame_123456"
  }'
```

查询成功并完成后，响应中的 `output` 数组会包含生成的视频，元素含 `video` 字段。

## Mode Notes

<Note>
`text` 只用提示词生成；`frame` 固定视频的开头（可再固定结尾）；`keyframes` 用多张图片约束整段视频的走向，图片按顺序均匀分布在时间轴上（例如 10 秒视频传 3 张，分别落在第 0、5、10 秒）。三种模式价格相同，按输出秒数和分辨率计费。
</Note>

<Warning>
`frame` 模式最多使用 2 张图片（首帧 + 尾帧），多余的会被忽略；`keyframes` 模式最多 10 张。`text` 模式会忽略传入的图片。
</Warning>
