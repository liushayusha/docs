## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `seedance2_5`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      视频生成的文本描述。

      建议描述主体、场景、动作、镜头运动、视觉风格、对白及环境声音。
    </ParamField>

    <ParamField body="type" type="string" default="all_reference">
      参考模式，决定参考素材的使用方式：

      * `all_reference` - 全参考模式，可使用参考图片、参考视频和参考音频
      * `first_last_frame` - 首尾帧模式，使用首帧和可选的尾帧图片
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参考图片 URL。

      * `all_reference` 模式：最多 30 张图片；单张最大 50MB；图片最小边长 300px
      * `first_last_frame` 模式：作为首帧图片；最大 10MB；图片最小边长 300px

      URL 必须可由公网直接访问。
    </ParamField>

    <ParamField body="end_image_url" type="string">
      尾帧图片 URL，仅 `first_last_frame` 模式有效。

      图片最大 10MB，最小边长 300px，URL 必须可由公网直接访问。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参考视频 URL，仅 `all_reference` 模式有效，最多支持 9 个参考视频。

      视频要求：

      * 单个视频时长 2-30 秒，参考视频总时长不超过 30 秒
      * 单个视频最大 200MB
      * 帧率 24-60 FPS
      * 宽高比范围 0.4-2.5
      * 宽高范围 300-6000px
      * 总像素数范围 409600-8295044

      <Warning>`first_last_frame` 模式请勿传入此参数。</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参考音频 URL，仅 `all_reference` 模式有效，最多支持 10 个音频。

      音频要求：

      * 单个音频时长 2-30 秒，参考音频总时长不超过 30 秒
      * 支持 WAV、MP3
      * 单个音频最大 15MB

      <Warning>`first_last_frame` 模式请勿传入此参数。</Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      视频分辨率：

      * `480p`
      * `720p` - 默认值
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      输出视频时长，单位为秒。

      支持 `4` 到 `30` 之间的整数。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      视频宽高比：

      * `21:9` - 超宽屏
      * `16:9` - 横屏，默认值
      * `9:16` - 竖屏
      * `4:3` - 标准横屏
      * `3:4` - 竖版标准
      * `1:1` - 方形
    </ParamField>

    <ParamField body="generate_audio" type="boolean" default="true">
      是否生成与视频同步的 AI 音频。

      * `true` - 生成音频，默认值
      * `false` - 不生成音频
    </ParamField>

    <ParamField body="output_format" type="string" default="mp4">
      输出视频格式：

      * `mp4` - 通用格式，文件体积较小，默认值
      * `mov` - 高色彩精度格式（yuv444p），适合后期扩展和拼接
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  由调用方生成并保证唯一，支持字母、数字、下划线和横线，长度为 1-64 个字符。后续使用该 ID 查询任务状态和结果。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  发起方任务 ID，可用于查询结果。
</ResponseField>

<ResponseField name="status" type="string">
  初始状态，通常为 `"pending"`。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  预估消耗积分。
</ResponseField>

<ResponseField name="created_at" type="string">
  创建时间，ISO 8601 格式。
</ResponseField>

## Query Task

Seedance 2.5 采用异步处理。提交成功后，使用同一个 `out_task_id` 查询任务：

<RequestExample>
  ```bash cURL
  curl --request POST \
    --url https://aireiter.com/api/openapi/query \
    --header 'Authorization: Bearer <token>' \
    --header 'Content-Type: application/json' \
    --data '{
      "out_task_id": "seedance2_5_task_123456"
    }'
  ```
</RequestExample>

任务完成后，响应中的 `output` 数组会包含生成的视频 URL。完整字段参见[获取任务状态](/zh/api-reference/tasks/status)。

## Mode Rules

| type | 可用素材 | 素材限制 |
| --- | --- | --- |
| `all_reference` | `image_url`、`video_url`、`audio_url` | 最多 30 张图片、9 个视频、10 个音频 |
| `first_last_frame` | `image_url`、`end_image_url` | 首帧和尾帧图片按需提供；请勿传视频或音频 |

<Warning>
请确保所有素材 URL 可由公网直接访问。任务为异步处理，请勿使用提交请求的 HTTP 连接等待最终视频。
</Warning>
