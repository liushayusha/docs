</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  所有接口均需要使用 Bearer Token 进行认证。

  访问 <a href={apiKeyUrl} target="_blank">API Key 管理页面</a> 获取 API Key，并在请求头中添加：

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用 `happyhorse_1_0`。
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="type" type="string" default="text_to_video" required>
      视频工作流：

      * `text_to_video` - 根据文本生成视频
      * `image_to_video` - 使用一张首帧图片生成视频
      * `reference_to_video` - 使用 1-9 张参考图片生成视频
      * `video_edit` - 根据指令编辑一个源视频
    </ParamField>

    <ParamField body="prompt" type="string">
      视频内容描述或编辑指令。`text_to_video`、`reference_to_video` 和 `video_edit` 必填，`image_to_video` 可选。

      最多支持 2500 个中文字符或 5000 个非中文字符，超出部分会被截断。

      `reference_to_video` 模式中，按图片顺序使用 `character1`、`character2` 等名称指代参考图片。
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      图片 URL，必须可由公网直接访问。

      * `image_to_video` - 必填，使用第一张图片作为首帧
      * `reference_to_video` - 必填，支持 1-9 张有序参考图片
      * `video_edit` - 可选，最多 5 张风格或主体参考图片

      支持 JPEG、JPG、PNG、WEBP。图生视频和视频编辑图片要求宽高均不小于 300px；多参考图模式要求短边不小于 400px。单张图片不超过 10MB。
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      `video_edit` 模式必填，仅使用一个源视频。

      支持 MP4、MOV，建议使用 H.264 编码。源视频要求：

      * 时长 3-60 秒，超过 15 秒时仅处理前 15 秒
      * 文件不超过 100MB
      * 长边不超过 2160px，短边不小于 320px
      * 宽高比范围为 1:2.5 到 2.5:1
      * 帧率大于 8 FPS
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      输出分辨率：`720p` 或 `1080p`。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      `text_to_video` 和 `reference_to_video` 模式的输出宽高比。

      支持：`16:9`、`9:16`、`1:1`、`4:3`、`3:4`、`4:5`、`5:4`、`9:21`、`21:9`。

      <Warning>`video_edit` 不支持此参数，请勿传入。`image_to_video` 的输出宽高比跟随输入图片。</Warning>
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      输出视频时长，单位为秒。支持 3-15 之间的整数。

      <Warning>`video_edit` 不支持此参数，请勿传入。输出时长由源视频自动决定，等于 `min(输入视频时长, 15 秒)`。</Warning>
    </ParamField>

    <ParamField body="seed" type="integer" default="0">
      随机种子，范围为 0-2147483647。传入 `0` 或省略时使用随机种子。
    </ParamField>

    <ParamField body="keep_original_sound" type="boolean" default="false">
      仅 `video_edit` 模式有效。设为 `true` 时强制保留源视频音轨；设为 `false` 或省略时由模型自动决定。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  调用方生成的唯一任务 ID，后续使用该 ID 查询任务状态和结果。

  仅支持字母、数字、下划线和横线，长度为 1-64 个字符。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  调用方任务 ID，可用于查询结果。
</ResponseField>

<ResponseField name="status" type="string">
  初始状态，通常为 `pending`。
</ResponseField>

<ResponseField name="created_at" type="string">
  创建时间，ISO 8601 格式。
</ResponseField>

## Query Task

任务提交成功后，通过同一个 `out_task_id` 查询状态。任务状态包括 `pending`、`processing`、`completed` 和 `failed`；完成后 `output` 数组包含视频结果。

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "happyhorse_1_0_task_123456"
  }'
```
