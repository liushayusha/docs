</Note>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定传 `gemini_omni_1_2_flash`。
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      视频生成的文本描述。必填。
    </ParamField>

    <ParamField body="video_length" type="string" default="8">
      生成视频时长，单位为秒。只接受字符串 `"3"` 到 `"15"` 的整秒：

      * `"3"` / `"4"` / `"5"` / `"6"` / `"7"`
      * `"8"` - 默认值
      * `"9"` / `"10"` / `"11"` / `"12"` / `"13"` / `"14"` / `"15"`

      <Warning>
        枚举校验要求字符串，请传 `"8"` 而不是数字 `8`。`"11"` 到 `"15"` 只能配 `aspect_ratio` 为 `9:16`。
      </Warning>
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      视频宽高比：

      * `16:9` - 横屏 1280×720，默认值
      * `9:16` - 竖屏 720×1280

      时长 11–15 秒只能传 `9:16`，传 `16:9` 会被拒绝。
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参考图 URL，必须可由公网直接访问。也可传单张字符串。不传就是文生视频。

      * 最多 3 张，第 4 张会被拒绝
      * 短边不小于 300px，单张不超过 10MB

      参考图用来定主体和风格，不是首帧 / 尾帧，成片不会强制从某张图开始或结束。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。仅支持字母、数字、下划线和横线，长度为 1-64 个字符。后续可使用该 ID 查询任务状态和结果。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  发起方任务 ID，可用于查询结果。
</ResponseField>

<ResponseField name="status" type="string">
  初始状态，通常为 `"pending"`。
</ResponseField>

<ResponseField name="estimated_credits" type="number">
  本次任务的预估消耗额度。
</ResponseField>

<ResponseField name="created_at" type="string">
  创建时间，ISO 格式。
</ResponseField>

## Query Task

本模型是异步视频生成。提交任务后，请使用 `out_task_id` 查询任务状态。也可参见 [获取任务状态](/zh/api-reference/tasks/status)。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_12_t2v_123456"
  }'
```

查询成功并完成后，响应中的 `output` 数组会包含生成的视频，元素含 `video` 字段。

## 参数对照

| 输入 | `image_url` | `video_length` | `aspect_ratio` |
|---|---|---|---|
| 文生 | 不要传，或空数组 | `"3"`–`"10"` | `16:9` 或 `9:16` |
| 文生（长） | 不要传，或空数组 | `"11"`–`"15"` | 只能 `9:16` |
| 参考图 | 1–3 张 | `"3"`–`"10"` | `16:9` 或 `9:16` |
| 参考图（长） | 1–3 张 | `"11"`–`"15"` | 只能 `9:16` |

不支持的字段：`resolution`（固定 720p）、`video_url`（不支持参考视频）。
