title: 'Gemini Omni Flash Ext 视频生成'
description: |
  - AIReiter 上独立的 Omni Flash 视频 SKU
  - 异步处理模式，返回任务 ID 用于后续查询
  - 两种生成类型：First Frame（`frame`）和 Reference（`reference`）
  - 支持 720p / 1080p / 4K，时长仅 4 / 6 / 8 / 10 秒
api: 'POST https://aireiter.com/api/openapi/submit'

import { apiKeyUrl } from '/snippets/_variables.mdx';

<Note>
Gemini Omni Flash Ext 在 AIReiter 中的模型名称为 `gemini_omni_flash_ext`。

它不是本站官方 Omni Flash SKU（`gemini_omni_flash_preview`，输出 720p）。本页 SKU 输出 720p / 1080p / 4K，时长只有 4、6、8、10 秒。
</Note>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `gemini_omni_flash_ext`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      视频生成的文本描述。必填。
    </ParamField>

    <ParamField body="type" type="string" default="frame">
      生成类型。只接受下面两个值：

      * `frame` - First Frame。提示词加 0 或 1 张图。不能传参考视频
      * `reference` - Reference。提示词加 0、1 或 3 张图，可选 1 段参考视频

      不传图就是文生视频，两种类型都可以。

      <Warning>
        不要传 `type=text`。`frame` 不能和 `video_url` 一起传。
      </Warning>
    </ParamField>

    <ParamField body="video_length" type="string" default="6">
      生成视频时长，单位为秒。只接受字符串：

      * `"4"`
      * `"6"` - 默认值
      * `"8"`
      * `"10"`

      有参考视频时不要传这个字段，输出时长跟随上传视频。

      <Warning>
        不要传 `3`、`5`、`7`、`9` 或其他秒数。枚举校验要求字符串，请传 `"6"` 而不是数字 `6`。
      </Warning>
    </ParamField>

    <ParamField body="resolution" type="string" default="720p">
      输出分辨率：

      * `720p` - 默认值
      * `1080p`
      * `4K`
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      视频宽高比：

      * `16:9` - 横屏，默认值
      * `9:16` - 竖屏
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      图片 URL，必须可由公网直接访问。也可传单张字符串。

      * `frame` - 可选 0 或 1 张，作为首帧。不传就是文生
      * `reference` - 可选 0、1 或 3 张。不传就是文生

      图片要求：短边不小于 300px，单张不超过 10MB。

      <Warning>
        不支持 2 张图。`reference` 传 2 张会返回 `Invalid image_url count. Allowed: [1, 3]`。也不要传 4 张及以上。
      </Warning>
    </ParamField>

    <ParamField body="video_url" type="string | string[]">
      参考视频 URL。仅 `type=reference` 有效，最多 1 段。也可传单段字符串。

      视频要求：

      * 格式 MP4、MOV
      * 时长不超过 10 秒
      * 不超过 100MB
      * 短边不小于 300px

      传入参考视频时不要传 `video_length`，输出时长跟随上传视频，最长 10 秒。

      <Warning>`type=frame` 请勿传入此参数，接口会直接拒绝。</Warning>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。仅支持字母、数字、下划线和横线，长度为 1-64 个字符。后续可使用该 ID 查询任务状态和结果。
</ParamField>

<ResponseField name="out_task_id" type="string">

## Query Task

Gemini Omni Flash Ext 是异步视频生成模型。提交任务后，请使用 `out_task_id` 查询任务状态。也可参见 [获取任务状态](/zh/api-reference/tasks/status)。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "omni_ext_t2v_123456"
  }'
```

查询成功并完成后，响应中的 `output` 数组会包含生成的视频，元素含 `video` 字段。

## 模式参数对照

| `type` | `image_url` | `video_url` | 时长 |
|---|---|---|---|
| `frame`，不传图 | 不要传，或空数组 | 不要传 | `video_length` `"4"` / `"6"` / `"8"` / `"10"` |
| `frame` | 1 张 | 不要传 | 同上 |
| `reference`，不传图 | 不要传，或空数组 | 不要传 | 同上 |
| `reference` | 1 张或 3 张 | 不要传 | 同上 |
| `reference` | 0、1 或 3 张 | 1 段，最长 10 秒 | 不要传 `video_length`，跟随片源 |
