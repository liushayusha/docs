<Note>
HappyHorse 1.1 在 AIReiter 中的模型名称为 `happyhorse_1_1`，当前提供多参考图视频生成工作流。
</Note>

## Authorizations

<ParamField header="Authorization" type="string" required>
  所有接口均需要使用 Bearer Token 进行认证。

  访问 <a href={apiKeyUrl} target="_blank">API Key 管理页面</a> 获取 API Key，并在请求头中添加：

  ```
  Authorization: Bearer YOUR_API_KEY
  ```
</ParamField>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用 `happyhorse_1_1`。
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      视频内容、动作和视觉风格描述。

      在提示词中使用 `[Image 1]`、`[Image 2]` 等标记指代 `image_url` 数组中相同位置的图片，并说明图片中的具体对象。例如：`[Image 1] 中穿红色旗袍的女人打开 [Image 2] 中的折扇`。

      最多支持 2500 个中文字符或 5000 个非中文字符，超出部分会被截断。
    </ParamField>

    <ParamField body="image_url" type="string | string[]" required>
      参考图片 URL，支持 1-9 张，图片顺序必须与提示词中的 `[Image N]` 标记一致。

      图片要求：

      * 支持 JPEG、JPG、PNG、WEBP
      * 短边不小于 400px，建议使用 720p 或更高分辨率
      * 单张图片不超过 10MB
      * URL 必须可由公网直接访问
    </ParamField>

    <ParamField body="resolution" type="string" default="1080p">
      输出分辨率：`720p` 或 `1080p`。
    </ParamField>

    <ParamField body="aspect_ratio" type="string" default="16:9">
      输出视频宽高比。

      支持：`16:9`、`9:16`、`3:4`、`4:3`、`4:5`、`5:4`、`1:1`、`9:21`、`21:9`。
    </ParamField>

    <ParamField body="video_length" type="integer" default="5">
      输出视频时长，单位为秒。支持 3-15 之间的整数。
    </ParamField>

    <ParamField body="seed" type="integer" default="0">
      随机种子，范围为 0-2147483647。传入 `0` 或省略时使用随机种子。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  调用方生成的唯一任务 ID，后续使用该 ID 查询任务状态和结果。

  仅支持字母、数字、下划线和横线，长度为 1-64 个字符。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  调用方任务 ID，可用于查询结果。
</ResponseField>

<ResponseField name="status" type="string">
  初始状态，通常为 `pending`。
</ResponseField>

<ResponseField name="created_at" type="string">
  创建时间，ISO 8601 格式。
</ResponseField>

## Query Task

任务提交成功后，通过同一个 `out_task_id` 查询状态。任务状态包括 `pending`、`processing`、`completed` 和 `failed`；完成后 `output` 数组包含视频结果。

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "happyhorse_1_1_task_123456"
  }'
```
