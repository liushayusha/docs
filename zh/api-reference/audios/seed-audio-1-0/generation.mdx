## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `seed_audio_1_0`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      要合成的文本，或对音频场景的描述，最多 1500 个字符。

      使用参考音频时，可在提示词中用 `@audio1` / `@audio2` / `@audio3` 按顺序指向参考音色。
    </ParamField>

    <ParamField body="reference_mode" type="string" default="text">
      参考模式，决定本次请求使用哪一类参考素材：

      * `text` - 仅用提示词生成，不传参考音频或参考图
      * `audio` - 用参考音频克隆音色
      * `image` - 用一张参考图引导情绪和表达

      <Warning>参考音频和参考图不能同时使用。要用参考素材时，必须显式传入对应的 `reference_mode`，否则参考字段会被忽略。</Warning>
    </ParamField>

    <ParamField body="audio_url" type="string | string[]">
      参考音频 URL。

      仅 `reference_mode` 为 `audio` 时有效，最多 3 段，顺序对应 `@audio1` / `@audio2` / `@audio3`。

      参考音频要求：

      * 格式 WAV、MP3、PCM、OGG Opus
      * 单段不超过 30 秒
      * 单段不超过 10MB
      * URL 必须可公开访问
    </ParamField>

    <ParamField body="image_url" type="string | string[]">
      参考图 URL。

      仅 `reference_mode` 为 `image` 时有效，最多 1 张。

      图片要求：

      * 格式 JPEG、PNG、WEBP
      * 不超过 10MB
      * URL 必须可公开访问
    </ParamField>

    <ParamField body="speech_rate" type="number" default="1">
      语速倍率，范围 `0.5` 到 `2`，支持两位小数。`1` 为正常语速。
    </ParamField>

    <ParamField body="loudness_rate" type="number" default="1">
      音量倍率，范围 `0.5` 到 `2`，支持两位小数。`1` 为正常音量。
    </ParamField>

    <ParamField body="pitch_rate" type="integer" default="0">
      音调，单位为半音。范围 `-12` 到 `12`。`0` 为原调，`12` 升高一个八度，`-12` 降低一个八度。
    </ParamField>

    <ParamField body="sample_rate" type="string" default="24000">
      输出采样率（Hz）：

      * `8000`
      * `16000`
      * `24000` - 默认值
      * `32000`
      * `44100`
      * `48000`
    </ParamField>

    <ParamField body="format" type="string" default="wav">
      输出音频格式：

      * `wav` - 默认值
      * `mp3`
      * `ogg_opus`
      * `pcm`
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。仅支持字母、数字、下划线和横线，长度为 1-64 个字符。后续可使用该 ID 查询任务状态和结果。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  发起方任务 ID，可用于查询结果。
</ResponseField>

<ResponseField name="status" type="string">
  初始状态，通常为 `"pending"`。
</ResponseField>

<ResponseField name="created_at" type="string">
  创建时间，ISO 格式。
</ResponseField>

## Query Task

Seed Audio 1.0 是异步音频生成模型。提交任务后，请使用 `out_task_id` 查询任务状态。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "seed_audio_text_123456"
  }'
```

查询成功并完成后，`output` 示例：

```json
{

      {
        "audio": "https://s1.pxz.ai/upload/audio-generator/20260826/seed-audio-item-0.wav"
```

## Mode Notes

<Note>
`text` 模式只根据提示词生成语音、对白或音效；`audio` 模式用参考音频克隆音色；`image` 模式用一张参考图引导表达。
</Note>

<Warning>
当 `reference_mode` 为 `audio` 时，请不要传 `image_url`。当 `reference_mode` 为 `image` 时，请不要传 `audio_url`。单次请求最长 120 秒。
</Warning>
