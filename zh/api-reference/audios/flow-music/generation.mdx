---
title: 'Flow Music 音乐生成'
description: |
  - Google Lyria 文生音乐，每次生成一首完整歌曲
  - 异步处理模式，返回任务 ID 用于后续查询
  - 可带人声或纯音乐，支持 Lyria 3 Pro / 3.5
  - 结果含 clip_id，可用于续写、翻唱、替换、分轨、下载和出 MV
api: 'POST https://aireiter.com/api/openapi/submit'
---

import { apiKeyUrl } from '/snippets/_variables.mdx';

<Note>
Flow Music 在 AIReiter 中的模型名称为 `flow_music`。歌词、续写、替换、翻唱、分轨、上传、下载、出 MV 请分别使用对应模型。
</Note>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `flow_music`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      风格提示词。描述曲风、乐器、情绪和声音。可同时填写 `lyrics`。
    </ParamField>

    <ParamField body="lyrics" type="string">
      可选歌词。不填则生成纯音乐或由模型自行处理人声。
    </ParamField>

    <ParamField body="title" type="string">
      可选歌曲标题。
    </ParamField>

    <ParamField body="bpm" type="string">
      可选 BPM，大于等于 1。传字符串，例如 `"120"`。
    </ParamField>

    <ParamField body="length" type="number" default="60">
      期望时长，单位秒，范围 `1` 到 `240`。只是参考，上游不一定按这个秒数出片，计费按次、不按时长。
    </ParamField>

    <ParamField body="version" type="string" default="lyria-3-pro">
      Lyria 版本，价格相同：

      * `lyria-3-pro` - 默认值
      * `lyria-3.5` - 更新的人声模型
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。仅支持字母、数字、下划线和横线，长度为 1-64 个字符。后续可使用该 ID 查询任务状态和结果。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  发起方任务 ID，可用于查询结果。
</ResponseField>

<ResponseField name="status" type="string">
  初始状态，通常为 `"pending"`。
</ResponseField>

<ResponseField name="created_at" type="string">
  创建时间，ISO 格式。
</ResponseField>

## Query Task

Flow Music 是异步音乐生成模型。提交任务后，请使用 `out_task_id` 查询任务状态。完成后 `output` 通常包含 1 项，字段为 `audio`（音频 URL）、`url`（封面图）、`title`、`text`（歌词片段）、`clip_id`。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "flow_music_gen_123456"
  }'
```

查询成功并完成后，`output` 示例：

