---
title: 'Suno 音乐生成'
description: |
  - Suno 文生音乐，一次返回两首原创歌曲
  - 异步处理模式，返回任务 ID 用于后续查询
  - 支持简单模式和自定义模式，可生成人声或纯音乐
  - 支持 V4 / V4.5 / V4.5+ / V4.5 All / V5 / V5.5
api: 'POST https://aireiter.com/api/openapi/submit'

<Note>
Suno 在 AIReiter 中的模型名称为 `suno`。歌词、续写、翻唱请分别使用 `suno_lyrics`、`suno_extend`、`suno_cover`。
</Note>

## Body

<ParamField body="model" type="string" required>
  模型名称，固定使用：

  * `suno`
</ParamField>

<ParamField body="params" type="object" required>
  模型参数对象。

  <Expandable title="params 对象属性">
    <ParamField body="prompt" type="string" required>
      歌曲描述。可写主题、情绪、乐器和节奏。

      关闭自定义模式时，模型会据此自动写标题、风格和歌词。打开自定义模式且不是纯音乐时，提示词会当作歌词。

      V5 / V5.5 / V4.5 系列最多 5000 个字符。
    </ParamField>

    <ParamField body="suno_model" type="string" default="V5">
      Suno 版本：

      * `V4`
      * `V4_5`
      * `V4_5PLUS`
      * `V4_5ALL`
      * `V5` - 默认值
      * `V5_5`
    </ParamField>

    <ParamField body="custom_mode" type="boolean" default="false">
      是否开启自定义模式。

      * `false` - 简单模式，只填提示词，标题、风格和歌词由模型生成
      * `true` - 自定义模式，需指定 `title` 和 `style`；有人声时 `prompt` 作为歌词
    </ParamField>

    <ParamField body="instrumental" type="boolean" default="false">
      是否生成纯音乐。

      * `false` - 生成带人声的歌曲
      * `true` - 只出伴奏，没有人声和歌词
    </ParamField>

    <ParamField body="vocal_gender" type="string" default="m">
      人声性别偏好。纯音乐时会被忽略。

      * `m` - 男声，默认值
      * `f` - 女声
    </ParamField>

    <ParamField body="title" type="string">
      歌曲标题。仅自定义模式有效，最多 100 个字符。打开 `custom_mode` 时必填。
    </ParamField>

    <ParamField body="style" type="string">
      曲风和制作方向，例如 indie folk、lo-fi hip hop、80s synthwave。仅自定义模式有效，最多 1000 个字符。打开 `custom_mode` 时必填。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="out_task_id" type="string" required>
  发起方任务 ID。

  用户自定义的任务标识，必填。仅支持字母、数字、下划线和横线，长度为 1-64 个字符。后续可使用该 ID 查询任务状态和结果。
</ParamField>

## Response

<ResponseField name="out_task_id" type="string">
  发起方任务 ID，可用于查询结果。
</ResponseField>

<ResponseField name="status" type="string">
  初始状态，通常为 `"pending"`。
</ResponseField>

<ResponseField name="created_at" type="string">
  创建时间，ISO 格式。
</ResponseField>

## Query Task

Suno 是异步音乐生成模型。提交任务后，请使用 `out_task_id` 查询任务状态。完成后 `output` 通常包含 2 首歌曲，每项含 `audio`（音频 URL）、`url`（封面图）、`title`、`text`（歌词）。

<ParamField body="out_task_id" type="string" required>
  提交任务时传入的发起方任务 ID。
</ParamField>

```bash
curl --request POST \
  --url https://aireiter.com/api/openapi/query \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "out_task_id": "suno_gen_123456"
  }'
```

## Mode Notes

<Note>
简单模式只需要 `prompt`。自定义模式请同时传 `title` 和 `style`；有人声时把歌词写在 `prompt` 中。
</Note>

<Warning>
`vocal_gender` 仅在 `instrumental` 为 `false` 时生效。一次请求通常返回两首候选歌曲。
</Warning>
